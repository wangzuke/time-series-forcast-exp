# MR-MSGF 实验计划

> 日期：2026-08-29  
> 目标：开始实现“缺失可靠多尺度图预测”idea，并形成可执行的代码搭建与实验推进计划。  
> 范围：本文档只规划实现与实验，不启动训练。正式训练前需要先完成 smoke 和配置核查。

## 1. 研究目标

我们要实现的核心模型暂定为：

```text
MR-MSGF: Missingness-Reliable Multi-Scale Graph Forecasting
```

中文表述：

```text
缺失可靠多尺度图预测模型
```

目标问题是：历史输入存在高缺失率时，多变量时间序列预测模型如何同时利用：

- 细粒度变量关系；
- 真实空间图关系；
- 基于观测值估计的变量时序关系；
- 变量聚类得到的区域级粗粒度关系；
- 当前缺失模式对不同关系尺度可靠性的影响。

第一版实现不追求一次性复现完整论文级系统，而是先做最小可验证模型：

```text
X_obs, mask
  -> mask-aware temporal encoder
  -> fine graph branch
  -> regional graph branch
  -> missingness/reliability residual gate
  -> forecasting head
```

## 3. 模型代码搭建计划

### 3.1 新增模型文件

新增：

```text
missing_ts_exp/src/models/mrmsgf.py
```

建议包含以下模块：

| 类/函数 | 作用 |
|---|---|
| `ObservedValueNorm` | 仅基于观测值计算均值/方差，避免缺失填充值污染统计量 |
| `MaskStatsEncoder` | 从 mask 中提取全局观测率、变量观测率、时间观测率、最长缺失段、区域覆盖率 |
| `TemporalGraphBuilder` | 基于 observed-only correlation 构造 `A_temp`，并用 overlap reliability 降低低重叠边权 |
| `RegionAssignment` | 根据 distance / temporal / hybrid / random 得到变量到区域的 `S` |
| `GraphPropagation` | 细粒度图传播，可先用轻量 GCN 或 mix-hop propagation |
| `RegionalGraphBranch` | `H_reg = S^T H`，区域图传播后 `S H_reg` 回到变量级 |
| `ReliabilityGate` | 根据 mask statistics 和 graph reliability 输出 residual gate `alpha` |
| `MRMSGFModel` | 组合 temporal encoder、fine branch、region branch、gate、forecast head |

第一版建议简化：

- temporal encoder 用 `nn.Linear + TCN/MLP` 或轻量 Transformer，先保证稳定。
- graph propagation 先做 1-2 层轻量 GCN，不引入 PyG 依赖。
- `A_temp` 和 `S` 优先离线缓存，训练时读取 buffer。
- `alpha` 先用 scalar 或 per-region gate，不直接做复杂 per-node/per-time gate。

### 3.2 扩展图与区域缓存

建议新增：

```text
missing_ts_exp/src/data/relations.py
```

负责统一生成和读取：

```text
missing_ts_exp/results_cache/relations/
  {dataset}__temp_top{k}.npz
  {dataset}__{missing_type}_{rate}__temp_top{k}.npz
  {dataset}__region_{method}_k{K}.npz
  {dataset}__region_{method}_ratio{ratio}.npz
```

需要支持：

| 资源 | 构造方式 |
|---|---|
| `A_temp` | 训练集 observed-only Pearson correlation + overlap reliability + top-k |
| `R_overlap` | 两变量共同观测比例，用于边可靠性 |
| `S_temporal` | 基于 `A_temp` 或相关距离做层次聚类 |
| `S_random` | 随机分组，作为负对照 |
| `S_hybrid` | 后续结合 `A_phy` 和 `A_temp` |
| `A_phy` | 初版可空；交通数据接入后读取道路距离图 |

可以复用 `src/data/grouping.py` 的相关性计算思路，但建议新建 `relations.py`，避免把旧 PMA 分组逻辑和 MR-MSGF 的图构造混在一起。

### Phase 4：消融与诊断

目标：证明论文里的每个机制都有必要。

图来源消融：

| 设置 | 目的 |
|---|---|
| `graph_source=none` | 判断纯时间编码能力 |
| `graph_source=temporal` | 验证 observed-only 时序图 |
| `graph_source=physical` | 验证真实空间图 |
| `graph_source=physical_temporal` | 验证双源图互补 |

区域分支消融：

| 设置 | 目的 |
|---|---|
| `region_method=none` | fine-only |
| `region_method=random` | 负对照 |
| `region_method=temporal` | 时序聚类 |
| `region_method=distance` | 空间聚类 |
| `region_method=hybrid` | 空间 + 时序 |

融合消融：

| 设置 | 目的 |
|---|---|
| `fusion=none` | 不用区域分支 |
| `fusion=fixed` | 直接固定融合 |
| `fusion=gate`, `gate_input=mask` | 只看缺失统计 |
| `fusion=gate`, `gate_input=mask_rel` | 缺失统计 + 边可靠性 |

诊断指标：

- `gate_mean`
- `gate_by_missing_type`
- `gate_by_rate`
- `region_internal_corr`
- `edge_overlap_mean`
- `fine_vs_region_feature_norm`
- `random_region_delta`

### Phase 5：最终主实验

只有 Phase 1-4 证明方向成立后再启动。

建议主实验：

```text
datasets = ETTh1, Weather, Electricity, METR-LA, PEMS-BAY
missing_types = random_point, continuous_segment, variable_channel, mixed / Block-ST
missing_rates = 0.3, 0.5, 0.7
pred_lens = 96, 336
seeds = 2024, 2025, 2026
```

主表方法：

```text
Linear + iTransformer
SAITS + iTransformer
MissTSM
PMA
CoIFNet
CRIB
BiTGraph / HD-TTS for traffic
MR-MSGF
```

主结论成立标准：

1. MR-MSGF 在高缺失率 `0.5/0.7` 下稳定优于 `fine-only` 和 `MissTSM/PMA`。
2. `temporal region` 或 `hybrid region` 明显优于 `random region`。
3. `gate` 在 PEMS-BAY 类可能错误粗化场景中不造成系统性大退化。
4. 图来源消融能支持 `A_phy` 和 `A_temp` 至少在部分数据集互补。

## 7. 风险与处理

| 风险 | 表现 | 处理 |
|---|---|---|
| `A_temp` 在高缺失下噪声大 | temporal graph 不如 no graph | 加强 overlap reliability；用训练集完整序列构造静态图作为对照 |
| 区域图无收益 | region 与 fine-only 接近 | 检查 random region；若 random 也有效，说明是参数量或平滑效应 |
| 区域图伤害 PEMS-BAY | fixed fusion 退化 | gate 初始化接近 0；报告 region quality 与退化关系 |
| 训练过慢 | Electricity/Traffic 卡住 | 先保留 ETTh1/Weather；降低 top-k、d_model、region ratio |
| 物理图接入成本高 | METR-LA/PEMS-BAY loader 拖慢进度 | 第一阶段先用现有 CSV 数据验证 `A_temp + region`，第二阶段再接交通数据 |
| 论文贡献变弱 | MR-MSGF 只在部分缺失类型有效 | 将贡献收缩为“识别并控制区域关系何时有益”，而不是宣称全面 SOTA |

## 9. 第一版不做的事

为了避免实现过大，第一版暂不做：

- 动态逐 batch 重算完整图；
- 复杂 hypergraph；
- diffusion model 或 heavy imputation objective；
- per-time/per-node 大型 gate；
- 直接追求 Traffic 862 通道全矩阵；
- 直接把 HD-TTS/P-GUTS 官方代码并入主工程。

第一版的目标是回答一个最小但关键的问题：

> 在当前统一缺失预测工程中，observed-only 时序图和区域图分支是否能在高缺失率下提供稳定预测收益，并且该收益是否不能由随机分组解释？
