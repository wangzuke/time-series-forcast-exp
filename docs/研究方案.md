# 观测缺失条件下多变量时间序列预测的多尺度图关系建模研究方案

> 版本：2026-08-23  
> 任务：围绕“高缺失率、中低变量维度、多变量时间序列预测”场景，调研相关文献，完善“真实空间信息 + 变量时序信息 + 区域化聚类关系”的研究 idea，并形成论文大纲与研究计划。  
> 口径：本文区分“文献证据”“本地已有实验观察”“本文推断/方案”。凡属于本文方案的内容，都应在后续实验中验证，不能直接当作已证明结论。

## 1. 问题定义

给定历史多变量时间序列：

```text
X in R^{T x N x C},  M in {0,1}^{T x N x C}
```

其中 `M=1` 表示观测值存在，`M=0` 表示观测缺失。目标是在历史窗口存在较高缺失率的条件下预测未来：

```text
Y_hat = f(X_obs, M, A_phy, optional metadata)
```

本文关注的设置是：

- 缺失率较高，重点包括 50% / 70% / 90% 压力测试。
- 变量维度为中低维或中等规模，典型如 METR-LA、PEMS-BAY、Weather、ETT 等。
- 部分数据集存在真实空间信息，例如交通传感器道路距离图；部分数据集只有变量时序信息。
- 研究目标是 forecasting，不是以恢复历史缺失值为最终目标。

核心问题可以表述为：

> 在观测缺失严重破坏变量间细粒度相关性的情况下，如何同时利用真实空间图、观测鲁棒的变量时序图，以及区域化/聚类后的粗粒度变量关系，从而提高多变量时间序列预测性能？

## 2. 文献脉络

### 2.1 缺失预测范式：从先插补再预测到预测导向表征

| 工作 | 任务与机制 | 对本课题的启发 | 局限或空白 |
|---|---|---|---|
| CRIB: Revisiting MTS Forecasting with Missing Values | 直接从 partially observed input 预测；用 unified-variate attention、information bottleneck、consistency regularization 过滤缺失噪声。来源：https://arxiv.org/abs/2509.23494 | 强支撑“不要盲目先插补再预测”；强调缺失会破坏变量相关性，预测表征应保留 task-relevant variate correlation。 | 未显式结合真实空间图或区域化变量图。 |
| CoIFNet | 统一插补和预测；输入 observed values、mask、timestamp embeddings；用 Cross-Timestep Fusion 和 Cross-Variate Fusion。来源：https://arxiv.org/abs/2506.13064 | 支持 mask 作为输入信号参与预测；支持时间维和变量维融合应在一个预测导向框架中联合优化。 | CVF 是轻量变量融合，不显式建图，也没有区域尺度关系。 |
| MissTSM | model-agnostic、imputation-free；时间-变量独立 token，Missing Feature-Aware Attention 聚合同一时间步观测变量。来源：https://arxiv.org/abs/2502.15785 | 支持可插拔、免插补 adapter 路线；高缺失率下先解决 token 可用性。 | 单时间步变量聚合偏压缩，不显式建模变量对、空间图或区域图。 |
| Merlin / robust missing-rate learning | 多视图/蒸馏增强缺失率变化下的鲁棒性。 | 支持“缺失模式泛化”应成为实验目标，而非只在固定缺失率测试。 | 不是专门的多尺度图关系方法。 |

结论：这些工作共同说明，缺失场景下的预测模型不能只把 mask 当作 loss 过滤器，也不能默认插补值可靠。我们的模型应以 forecasting loss 为主，辅助使用 consistency 或 observed reconstruction，但不能让插补目标主导。

### 2.2 图关系建模：变量依赖是 MTSF 的核心，但缺失条件下图可靠性下降

| 工作 | 任务与机制 | 对本课题的启发 | 局限或空白 |
|---|---|---|---|
| MTGNN / Connecting the Dots | 自动学习变量间单向关系，结合 mix-hop propagation 与 temporal convolution。来源：https://arxiv.org/abs/2005.11650 | 变量可作为图节点；外部知识和数据驱动图可结合。 | 默认输入相对完整；缺少高缺失率下的边可靠性控制。 |
| BiTGraph | ICLR 2024，面向 missing-value forecasting；用 mask-biased temporal convolution graph network 捕获时间依赖和空间结构。代码来源：https://github.com/chenxiaodanhit/BiTGraph | 证明缺失预测场景中图传播和 mask bias 是合理方向；可作为强基线。 | 对连续块缺失可能受限，因为同一时刻全缺时瞬时图传播缺少信息。 |
| GraFITi | 将 irregularly sampled time series 转为 sparsity structure graph，把 forecasting 转成 edge weight prediction。来源：https://arxiv.org/abs/2305.12932 | 支持用图结构保留原始观测依赖，而不是强行补成完整矩阵。 | 图是观测事件图，不是物理空间图或区域化变量图。 |
| T-PatchGNN | ICML 2024，transformable patching + GNN，用于 irregular MTS forecasting。代码来源：https://github.com/usail-hkust/t-PatchGNN | 支持 patch 化与图建模结合处理不规则/缺失数据。 | 主要是专用 IMTS 架构，不强调真实空间图与区域图协同。 |
| HyperIMTS | 用超图统一表示观测点，通过 temporal/variable hyperedges 进行 irregularity-aware message passing。来源：https://arxiv.org/abs/2505.17431 | 支持“变量依赖 + 时间依赖”可以通过高阶图结构统一建模。 | 没有把物理图和聚类区域图作为显式多尺度先验。 |
| ChannelTokenFormer | 面向 dependency、asynchrony、missingness 的真实 MTSF；用 channel token 显式捕获跨通道交互。来源：https://arxiv.org/abs/2506.08660 | 支持真实场景中通道依赖、异步采样和缺失需要统一处理；通道级表示有价值。 | 高维时需要稀疏化或分组机制，正好给区域化关系留下空间。 |

结论：图/超图/token 结构是处理缺失多变量关系的主流路径。但现有方法要么偏事件图，要么偏完整变量图，要么偏专用架构，尚未充分回答“真实空间图 + 时序相关图 + 区域粗图如何在预测任务中协同”。

### 2.3 多尺度与区域化关系：直接支撑本文 idea

| 工作 | 任务与机制 | 对本课题的启发 | 局限或空白 |
|---|---|---|---|
| HD-TTS / Graph-based Forecasting with Missing Data through Spatiotemporal Downsampling | ICML 2024；输入在时间和空间上逐步粗化，得到多尺度表征；根据观测和缺失模式用注意力组合；对 contiguous blocks 表现突出。来源：https://proceedings.mlr.press/v235/marisca24a.html | 直接支撑“高缺失率下需要粗时间/粗空间尺度”；支持缺失模式应影响多尺度选择。 | 聚焦传感器空间时空预测；没有系统讨论变量时序聚类与真实空间图双源关系。 |
| Learning Evolutionary and Multi-scale Graph Structure | 认为变量交互会动态变化，且不同时间尺度下相关性不同；用 hierarchical graph + dilated convolution 捕获 scale-specific correlations。来源：https://arxiv.org/abs/2206.13816 | 支撑“不能只用单一细粒度图”；变量关系要考虑尺度。 | 没有针对观测缺失做适配。 |
| Hierarchical Joint Graph Learning | 用图神经网络和 attention 学习变量关系，并在图上做 hierarchical signal decomposition 捕获多重空间依赖。来源：https://arxiv.org/abs/2311.12630 | 支撑层级图/区域图对多变量预测有价值。 | 不是缺失预测场景。 |
| P-GUTS | Product Graph U-networks with Temporal pooling，用多个 pooling factors 聚合表示；主要任务是时空插补，也有 forecasting 辅助结果。来源：https://kdd.org/kdd2025/wp-content/uploads/2025/07/CameraReady-18.pdf | 支持 pooled/coarse representations 可以改善缺失时空建模，且多视图比单视图更稳。 | 主任务是 imputation；区域图构造与预测目标之间的关系仍需验证。 |
| ImputeFormer | 低秩先验 + Transformer 做 generalizable spatiotemporal imputation。来源：https://arxiv.org/abs/2312.01728 | 支持结构先验能在缺失场景降低噪声、提升泛化。 | 低秩/插补方向，不直接解决 forecasting 中的区域化图关系。 |

结论：多尺度图关系有充分文献基础，但真正缺口在于：已有多尺度方法没有把“真实空间关系”和“变量时序关系”作为两个可互补的信息源，也没有把区域化聚类关系设计成 forecasting-oriented、missing-aware 的可控分支。

## 3. 本地已有实验观察

本仓库已有实验报告提供了重要边界条件：

1. `missing_ts_exp/docs/0721_PGUTS_HDPGUTS实验报告.md` 显示，在 forecasting 改造实验中：
   - `coarse graph + fixed fusion` 在 8/8 个关键块缺失条件下优于 P-GUTS `[3,6]`。
   - adaptive fusion full 版本反而不稳定，coarse graph 权重常被压低。
   - 结论应是“空间粗化有潜力，但当前 adaptive gate 没有释放收益”，而不是“完整 HD-PGUTS 已成功”。

2. `missing_ts_exp/docs/0723_PGUTS_CoarseGraph插补实验报告.md` 显示，在官方 P-GUTS 插补协议中：
   - CG-P-GUTS 在 METR-LA 上明显改善。
   - 在 PEMS-BAY 上退化，说明 coarse assignment 质量会影响结果。
   - 因此，区域化关系不是无条件有效模块，需要可靠性控制、负对照和分组质量分析。

这些观察对本文非常关键：论文不能把“区域化聚类”写成天然正确，应写成“缺失条件下可提供低频稳定补充，但需要缺失可靠性和可抑制融合”。

## 4. 研究空白

综合文献和本地实验，本文可定位在如下空白：

1. **缺失条件下变量图边不可靠**  
   大量图预测方法依赖完整或近完整序列估计变量关系；高缺失率下，细粒度边可能由少量观测决定，容易噪声化。

2. **真实空间图与时序相关图尚未统一**  
   交通等场景有物理空间图，但物理近邻不总等于动态相关；非交通数据又没有真实空间图。需要一个能同时利用 `A_phy` 和 `A_temp` 的框架。

3. **区域化变量关系缺少预测导向设计**  
   聚类通常用于解释或降维，但本课题要把聚类后的区域作为预测服务的关系尺度。其贡献应通过 forecasting loss、消融和 gate 解释验证。

4. **多尺度分支缺少缺失模式可靠性控制**  
   HD-TTS 证明多尺度选择有效，但本地实验也显示复杂 gate 可能学不到 coarse graph。需要更稳的 residual/gate 设计，允许模型在粗图错误时少用它。

5. **实验协议需要区分缺失类型**  
   random point、continuous segment、variable channel、Block-ST 对图关系的破坏方式不同。若只测一种缺失类型，无法证明方法对高缺失率真实场景有效。

## 5. 拟提出方法：MR-MSGF

暂定名称：

```text
MR-MSGF: Missingness-Reliable Multi-Scale Graph Forecasting
```

中文名称：

```text
缺失可靠性约束的多尺度图关系多变量时间序列预测方法
```

### 5.1 总体思路

```text
Partially observed X, mask M
        ↓
Observed-value normalization + mask/time encoding
        ↓
Node-level temporal encoder
        ↓
Three relational views:
  1. physical graph A_phy
  2. temporal dependency graph A_temp
  3. regional/coarse graph A_region = S^T A S
        ↓
Fine-scale graph propagation + regional graph propagation
        ↓
Missingness-reliable residual fusion
        ↓
Direct forecasting loss + consistency regularization
```

### 5.2 输入编码

借鉴 CoIFNet 和 MissTSM：

- 使用 observed values，不对缺失值做强插补。
- mask 作为输入特征，而不只是 loss 过滤器。
- 归一化统计量只基于观测值，避免缺失填充值污染均值/方差。
- 可选 patch/token 表示，兼顾缺失鲁棒性和局部时间语义。

### 5.3 双源细粒度图

构造两个细粒度变量图：

1. `A_phy`：真实空间图  
   - 用道路距离、传感器邻接、地理坐标等构造。
   - 没有真实空间图的数据集可置为 identity 或不启用。

2. `A_temp`：变量时序图  
   - 从训练集观测值估计变量相关性，例如 Pearson/Spearman、lag correlation、DTW similarity。
   - 必须引入 mask overlap reliability：

```text
r_ij = observed_overlap(i,j) / T
A_temp_ij = similarity(i,j) * g(r_ij)
```

其中 `g(r_ij)` 可以是阈值、sigmoid 或可学习函数，避免用观测重叠很少的变量对建立强边。

### 5.4 区域化变量关系

构造变量到区域的 assignment：

```text
S in R^{N x K}, K < N
```

候选方案：

- physical clustering：基于道路距离/地理邻近。
- temporal clustering：基于 observed-only 变量动态相关。
- hybrid clustering：融合空间距离和时序相似。
- soft assignment：允许变量属于多个区域。

区域图：

```text
A_region = normalize(S^T A_fine S)
H_region = S^T H_node
H_region' = GNN_region(H_region, A_region)
H_node_from_region = S H_region'
```

关键点：区域图不是为了替代细图，而是作为高缺失率下更稳定的低频补充分支。

### 5.5 缺失可靠性 residual fusion

不建议第一版使用过复杂 adaptive fusion。本地实验显示，复杂 gate 可能忽略 coarse graph。建议用更可控的 residual 形式：

```text
H_out = H_fine + alpha(M, S, A) * Project(H_region_to_node)
```

其中 `alpha` 初始接近 0，并依赖缺失模式统计：

- global observed ratio
- per-node observed ratio
- per-time observed ratio
- group-level observed ratio
- longest missing run
- spatial coverage ratio
- edge reliability summary

预期机制：

- point missing：细粒度图仍可用，`alpha` 不一定高。
- continuous segment / Block-ST：区域尺度更稳定，`alpha` 应上升。
- variable channel missing：若某变量整段缺失，区域/相似变量关系应更重要。
- 若区域分组质量差，`alpha` 应保持低，避免 PEMS-BAY 式错误平滑。

### 5.6 训练目标

主目标：

```text
L_forecast = MAE(Y_hat, Y)
```

辅助目标：

1. Consistency regularization  
   对观测输入额外 mask 一部分点，要求预测或隐表示稳定。支撑来自 CRIB。

2. Optional observed reconstruction  
   只作为轻量辅助，不作为主目标，避免模型过度优化历史插补。

3. Graph reliability regularization  
   对低 overlap 边进行惩罚，或限制其权重上限。

## 6. 可检验研究问题

RQ1：在高缺失率下，细粒度图 + 区域图是否优于仅细粒度图？

- H1：在 Block-T、Block-ST、variable-channel missing 下，`fine + region` 的 MAE/MSE 低于 `fine-only`。
- 反证：若 random group 与真实/时序聚类效果相同，则区域收益可能来自参数量而不是结构。

RQ2：真实空间图和变量时序图是否互补？

- H2：`A_phy + A_temp` 优于任一单图，尤其在物理近邻与动态相关不一致的数据集上。
- 反证：若 `A_temp` 单独最强，说明真实空间图不是必要先验；论文需弱化“真实空间信息”贡献。

RQ3：缺失可靠性 gate 是否必要？

- H3：mask-aware residual gate 优于 fixed fusion 和 branch-only gate，且在粗图质量差时能降低区域分支权重。
- 反证：若 fixed fusion 更好，则 gate 设计不足或样本量不够。

RQ4：聚类方式如何影响预测？

- H4：hybrid/temporal clustering 优于 random clustering；不同数据集存在最优 coarse ratio。
- 反证：若 random clustering 相近，区域解释不成立。

RQ5：该方法是否能泛化到未见缺失率？

- H5：多缺失率训练或 consistency 训练后，测试更高缺失率时退化更小。

## 7. 实验计划

### 7.1 阶段一：统一协议和基线

目标：把比较基础打牢。

数据集：

- 交通/有空间图：METR-LA、PEMS-BAY。
- 中低维/无真实空间图：Weather、ETTh1、ExchangeRate。
- 可选中高维：Electricity、Traffic。

缺失类型：

- random_point
- continuous_segment / Block-T
- Block-ST
- variable_channel
- mixed

缺失率：

- 主实验：30%、50%、70%
- 压力测试：90% 或 70% 以上

基线：

- Linear interpolation + DLinear/PatchTST/iTransformer
- SAITS + backbone
- MissTSM
- CoIFNet
- CRIB
- BiTGraph
- HD-TTS 或 P-GUTS-style forecasting

指标：

- MAE、MSE/RMSE
- 参数量、显存、训练时间
- 高缺失率退化曲线
- 跨 seed 标准差

### 7.2 阶段二：最小模型验证

只实现必要模块：

```text
fine graph branch
region graph branch
mask-aware residual alpha
```

首轮矩阵：

```text
datasets = METR-LA, PEMS-BAY
missing = Block-T, Block-ST
rates = 70%, 90%
seeds = 3
models = fine-only, region-only, fine+region-fixed, fine+region-mask-gate
```

成功标准：

- `fine+region-mask-gate` 在多数条件下优于 `fine-only`。
- 不出现单数据集系统性大幅退化。
- gate 权重在 Block-ST / 高缺失率下有合理变化。

### 7.3 阶段三：图和聚类消融

图消融：

| 设置 | 目的 |
|---|---|
| no graph | 判断预测主要来自时间编码还是图关系 |
| physical-only | 验证真实空间图贡献 |
| temporal-only | 验证时序相关图贡献 |
| physical + temporal | 验证双源互补 |

聚类消融：

| 设置 | 目的 |
|---|---|
| random clustering | 负对照 |
| distance clustering | 验证真实空间区域 |
| temporal clustering | 验证变量动态区域 |
| hybrid clustering | 验证空间 + 时序互补 |
| soft assignment | 判断硬聚类是否过刚性 |

coarse ratio：

```text
K/N in {1/2, 1/4, 1/8}
```

### 7.4 阶段四：缺失模式泛化

训练设置：

- 单一缺失率训练：30%、50%
- 多缺失率训练：30% + 50% + 70%

测试：

- seen rate：训练中出现过的缺失率
- unseen rate：90%
- seen type：训练中出现过的缺失类型
- unseen type：mixed 或 variable_channel

观察：

- 高缺失率退化是否更慢。
- gate 是否选择更粗区域尺度。
- 区域分支是否在未见缺失类型下稳定。

### 7.5 阶段五：解释性和失败案例分析

必要分析：

1. gate 权重与缺失率/缺失类型的关系。
2. group 内动态一致性与预测收益的关系。
3. PEMS-BAY 式退化原因：组内相关低、空间分组错误、coarse ratio 过大、gate 未抑制。
4. 边可靠性分布：低 overlap 边是否被压低。
5. 对比 CRIB 相关性破坏分析：本文方法是否更好保留变量相关结构。

## 8. 论文大纲

### Abstract

一句话问题：高缺失率下，多变量时间序列预测不仅缺少观测值，也会破坏变量间关系。  
一句话方法：提出 missingness-reliable multi-scale graph forecasting，同时利用真实空间图、观测鲁棒时序图和区域粗图。  
一句话结果：在多种缺失模式和高缺失率下提升预测，并通过消融证明区域图和缺失可靠性融合的作用。

### 1. Introduction

- 缺失值在交通、气象、工业传感器中常见。
- impute-then-forecast 存在目标错位和误差传播。
- 多变量预测依赖变量关系，但缺失会破坏细粒度关系估计。
- 真实空间图有用但不等同于动态相关；时序图有用但高缺失下不可靠。
- 区域化关系可提供低频稳定补充，但必须可控。
- 贡献：
  1. 提出缺失可靠的双源细粒度图构造。
  2. 提出预测导向的区域图分支。
  3. 提出缺失模式感知 residual 融合。
  4. 在多缺失模式、高缺失率下系统验证。

## 10. 风险与备选方案

| 风险 | 表现 | 处理 |
|---|---|---|
| 区域图收益不稳定 | METR-LA 提升，PEMS-BAY 退化 | 强化 gate；加入 random/quality analysis；将贡献写为可靠性控制而非区域图必然提升。 |
| 时序图高缺失下噪声大 | `A_temp` 退化 | 加 overlap reliability；只用训练集完整/低缺失段估计；限制低可靠边。 |
| 模型过复杂 | 显存或训练时间过高 | 保留中低维定位；用 sparse top-k graph；减少 region branch 层数。 |
| baseline 太强 | 改进幅度小 | 强调高缺失率、Block-ST、variable-channel、泛化场景；补解释性分析。 |
| gate 学不到合理权重 | 权重与缺失模式无关 | 从 branch-only gate 改为显式 mask statistics；或退回 fixed residual + learnable scalar。 |

## 11. 当前最稳妥的论文表述

推荐避免：

> 区域化聚类关系一定能提升缺失时间序列预测。

推荐使用：

> 高缺失率会使细粒度变量关系变得不稳定。区域化变量关系可以作为更稳的低频补充，但其有效性依赖区域划分质量和当前缺失模式。因此，本文将区域图设计为预测导向、缺失可靠、可抑制的多尺度关系分支，并通过消融验证它何时有效、为何有效、何时可能失效。

这个表述与 CRIB 对变量相关性破坏的分析、HD-TTS 的多尺度缺失预测结果、P-GUTS 的 pooled representation 机制，以及本仓库已有 coarse graph 正反实验都一致。
