# 相关工作网络调研：缺失观测、多变量建模、图建模与多尺度方法

> 日期：2026-09-02  
> 范围：时间序列预测、插补/插值、不规则采样建模、分类、聚类、图建模、多尺度/层级建模。  
> 说明：本笔记基于网络检索与本地论文集交叉整理，目的是为后续撰写 `Related Work` 提供素材；不是最终论文正文。

## 1. 总体判断

相关工作已经比较丰富，不能简单写成“缺失时间序列预测中没有图方法”或“没有多尺度方法”。更稳妥的定位是：

```text
已有工作分别研究了：
1. 缺失条件下的端到端预测或免插补预测；
2. 时空/图神经网络用于缺失值插补或预测；
3. 不规则采样时间序列的插值、分类与预测；
4. 多尺度、层级、粗化图结构建模；
5. 缺失模式、掩码结构和关系可靠性的利用。

但仍缺少一个面向预测任务的统一框架：
在带空间信息的多变量时间序列中，同时利用真实空间图、观测鲁棒的自适应/时序关系图、
区域级 coarse graph，并显式用缺失可靠性控制 fine-to-coarse 融合。
```

因此，本文 Related Work 不应只写“预测”，而应围绕四条主线组织：

1. Forecasting with missing multivariate time series
2. Graph-based modeling for incomplete / irregular time series
3. Adaptive and predefined relations under missingness
4. Multi-scale, hierarchical, and coarse graph representations

分类、聚类、插值文献可以作为补充证据，说明“缺失模式具有任务信息”“不规则观测可以直接建模”“多尺度/层级表示不只服务于预测”，但不要喧宾夺主。

## 2. 含缺失观测的多变量时间序列预测

| 工作 | 任务 | 核心思想 | 与本文关系 |
|---|---|---|---|
| CRIB: Revisiting Multivariate Time Series Forecasting with Missing Values | 预测 | 反思 imputation-then-prediction，指出无真实缺失值监督的插补会破坏分布和预测；用信息瓶颈和一致性正则直接从部分观测预测 | 强支撑 forecasting-oriented / imputation-free 立场；但不显式建图和粗图 |
| CoIFNet | 预测 | 将观测值、mask、timestamp embeddings 作为输入，统一插补与预测，使用跨时间步和跨变量融合 | 支撑 mask-aware / one-stage 建模；但不是图结构路线 |
| S4M | 预测 | 针对 block missing，将缺失模式融入 S4 状态空间模型；包含 temporal prototype 和 dual-stream S4 | 支撑 block missing 下需要专门建模；但图关系较弱 |
| MissTSM | 预测/分类 | 模型无关、免插补；以 individual observed value 为 token，并用 missing feature-aware attention 聚合 | 支撑不必先补齐完整矩阵；但没有真实空间图/区域图 |
| BiTGraph | 预测 | Multi-Scale Instance PartialTCN + Biased GCN，将 missing pattern 作为偏置注入时间和图传播 | 与本文任务很接近，是重要 baseline；但主要是细粒度图，无 explicit regional/coarse graph |
| GinAR | 预测 | 面向 variable missing；用 interpolation attention 恢复缺失变量表示，用 predefined graph + adaptive graph convolution 重建关系 | 最强支撑“缺失破坏时空关系”和“固定图/自适应图互补”；但没有粗图层级 |
| HD-TTS | 时空预测 | 对输入在时间和空间上逐步 coarsen，得到多尺度表示，再根据观测和缺失模式做 attention readout | 最强支撑“缺失场景下时空粗化有价值”；但没有 observed-overlap reliability 和 physical/adaptive graph 统一 |
| DGSPFN / Dynamic Attention Graph Network | 预测 | 直接建模 incomplete time series；动态图同时考虑长期关联、短期关联和缺失模式相似性 | 新近相邻工作，需要全文确认；看起来接近 dynamic graph + missingness，但未显示区域 coarse graph |
| Enter | 预测 | 端到端 incomplete MTS forecasting；missing-aware Transformer 预训练，再用 cross-attention 预测 | 说明端到端缺失预测方向仍在快速发展；但不是空间图/粗图主线 |
| ChannelTokenFormer | 预测 | 统一处理 channel dependency、asynchrony、missingness；用 channel token 建模跨通道关系 | 支撑现实 MTS 需要同时处理依赖、异步和缺失；但不是图粗化路线 |

## 3. 图神经网络用于缺失时间序列插补/插值

这类工作虽然主任务多为 imputation，而非 forecasting，但它们对本文非常重要，因为它们证明了三件事：

1. 变量/传感器间关系对缺失恢复有帮助；
2. 固定图、隐式图和自适应图各有偏差；
3. 多尺度时空结构能缓解单一尺度建模不足。

| 工作 | 任务 | 核心思想 | 对本文的启发 |
|---|---|---|---|
| GRIN | 时空插补 | 双向 recurrent GNN，通过 message passing 恢复传感器网络缺失值 | 经典图插补 baseline；支撑 relational inductive bias |
| SPIN | 时空插补 | 在图时空插补中引入 sparse attention，缓解自回归误差传播 | 支撑 sparse observations 下需要更谨慎传播 |
| ImputeFormer | 时空插补 | 低秩先验 + Transformer，强调时空结构先验和泛化能力 | 支撑结构先验可稳定缺失数据建模 |
| P-GUTS | 时空插补/预测评估 | product graph U-networks + temporal pooling，多分支 pooled representation | 支撑 coarse / pooled representation 在缺失时空数据中有价值 |
| CGCNImp | 插补 | 用 causal graph convolution 进行 MTS imputation | 支撑依赖关系不应只看相关性，也可考虑因果图 |
| EIGRN | 插补 | 结合 explicit graph 和 implicit graph 的 GCN/RNN | 直接支撑 fixed graph + learned graph 的互补思路 |
| DGBRIN | 插补 | 对滑动窗口构造 segment-specific dynamic graph，捕获局部动态相关 | 支撑关系应随时间/片段变化 |
| BMSTN | 插补 | bias-corrected predefined graph + multi-scale temporal convolution | 很贴近本文：固定图有价值但边权有偏，需要修正；多尺度也重要 |
| MSAGNN / MSFHGNN | 插补 | 多尺度特征提取 + 每个尺度自适应图学习 + attention fusion | 支撑不同尺度下变量关系不同，融合应自适应 |

## 4. 不规则采样、插值、连续时间建模与图结构

这条线与本文不完全重合，但可作为 Related Work 的边界说明：它们通常关注不规则采样、异步观测、连续时间插值/分类/预测，而本文关注规则时空网格中的缺失观测和空间图/粗图关系可靠性。

| 工作 | 任务 | 核心思想 | 与本文关系 |
|---|---|---|---|
| GRU-D | 分类/预测 | 早期显式利用 mask 和 time interval；提出 informative missingness | 支撑 mask 不是噪声，而是有任务信息 |
| Neural CDE | 分类/预测 | 直接处理 irregularly-sampled partially-observed MTS，连续时间建模 | 支撑不必强制补齐规则网格；但不强调空间图/区域图 |
| GP-VAE | 插补/降维 | latent GP prior + VAE，用平滑低维潜变量进行 probabilistic imputation | 支撑低维结构先验和不确定性，但不是图关系 |
| HeTVAE | 概率插值 | sparsity-aware encoder + heteroscedastic output，表达稀疏输入导致的不确定性 | 支撑输入观测稀疏度应影响输出置信度 |
| Raindrop | 分类 | 将每个样本表示成 sensor graph，结合 message passing 和 temporal self-attention | 支撑不规则 MTS 可通过 sensor-level graph 建模 |
| t-PatchGNN | 预测 | transformable patching 对齐不规则序列，再用 time-adaptive GNN 学习动态 inter-series correlation | 支撑异步/不规则场景下 dynamic graph 很重要 |
| HyperIMTS | 预测 | 将 observed values 作为超图节点，用 temporal/variable hyperedges 连接观测 | 支撑缺失观测可保留原始稀疏结构，而非补齐 |
| FgDGL | 分类 | multi-lag partial correlation 初始化 + fine-grained dynamic graph update | 支撑缺失/不规则下要减少 spurious correlation |
| Embracing Data Irregularities | 预测 | time-informed RNN + GNN，处理不同采样率、缺失和错位 | 支撑图结构也可用于更一般的不规则 MTS |

## 7. 与本文最相关的工作排序

### 7.1 第一梯队：必须重点写

1. **HD-TTS**：最直接支撑时空 downsampling、空间 coarse hierarchy、missing-pattern-conditioned scale fusion。
2. **GinAR**：最直接支撑 variable missing 下的 predefined graph + adaptive graph 互补，以及缺失导致错误 temporal/spatial dependency。
3. **BiTGraph**：缺失预测中显式 graph propagation + mask bias，是强相邻 baseline。
4. **CRIB / CoIFNet**：支撑 direct / one-stage / forecasting-oriented 缺失预测范式。

### 7.2 第二梯队：用于补充论证

1. **GRIN / SPIN / ImputeFormer / P-GUTS**：证明时空插补中 graph、attention、structure prior、pooling/coarse representation 的价值。
2. **t-PatchGNN / HyperIMTS / Raindrop**：证明不规则/异步观测可以直接以图或超图建模。
3. **S4M / MissTSM / ChannelTokenFormer**：支撑 mask-aware、imputation-free、channel dependency 与 missingness 的统一建模。

### 7.3 第三梯队：作为边界和扩展引用

1. 分类：GRU-D、ABTGNN、CATodyNet、FgDGL。
2. 聚类/表示学习：TKAE、contrastive incomplete MTS clustering、EMTC。
3. 异常检测：GST-Pro、HEIGHTS。

## 8. 建议的 Related Work 写法

建议最终 Related Work 写成四小节：

```text
2.1 Forecasting with Missing Multivariate Time Series
2.2 Graph-based Modeling for Incomplete and Irregular Time Series
2.3 Adaptive Relations and Missingness-aware Graph Learning
2.4 Multi-scale and Hierarchical Spatiotemporal Representations
```

每小节的写法：

- 先概括该方向解决什么问题；
- 再列举 3-5 个代表性工作；
- 最后用 1-2 句收束到本文差异。

本文最关键的差异句可以写成：

```text
Unlike prior works that focus on either missing-aware temporal modeling,
adaptive graph learning, or hierarchical spatiotemporal downsampling in isolation,
we explicitly couple physical relations, observed-data-driven temporal relations,
and regional coarse relations under a missingness reliability mechanism for
forecasting incomplete spatiotemporal multivariate time series.
```

## 9. 对论文定位的影响

调研后，本文不应把 novelty 写成“首个缺失时间序列图预测方法”。这个说法会被 BiTGraph、GinAR、HD-TTS、DGSPFN 直接反驳。

更稳妥的创新点是：

1. **关系可靠性视角**：缺失不仅影响数值，也影响边估计和消息传播可靠性。
2. **双源细粒度图**：真实空间图提供先验，observed-only temporal/adaptive graph 补足动态关系。
3. **区域 coarse graph**：高缺失下用区域级关系稳定传播，但不无条件使用。
4. **missingness-aware fine-to-coarse fusion**：用节点、边、区域层面的观测可靠性控制粗图贡献。

这条定位与 HD-TTS 和 GinAR 最兼容：HD-TTS 给出多尺度/粗化证据，GinAR 给出缺失下图关系重建证据，而本文在二者之间建立可靠性控制的统一预测框架。

### 10.4 对本文 Related Work 的影响

本轮新增文献没有改变当前第一梯队判断：本文最直接的理论和方法支撑仍然是 HD-TTS、GinAR、BiTGraph，以及 CRIB / CoIFNet 这一类 forecasting-oriented incomplete MTS 工作。

它们主要增强三类论据：

1. 真实传感器系统中的缺失经常来自设备故障、通信中断、电源问题和维护问题，因此缺失预测不是单纯的随机 mask benchmark，而是有实际空间结构和系统结构背景的问题。
2. 预定义物理图、数据相关图、自适应图、动态图和物理约束经常需要互补，而不是互相替代；这支持本文把空间先验、观测驱动关系和区域粗图放到统一框架中。
3. 简单融合时空特征、空间图特征或粗粒度特征可能引入过平滑、噪声传播或场景不匹配，因此本文强调 missingness-aware reliability gate 是合理的。

建议正文中轻量引用 4-6 篇外扩文献即可：MTPF、STFF、PT-GNODE、MGUAD、Graph Deep Learning for Time Series Forecasting，以及可选的 Water Distribution GCN-LSTM 或 GF-GGAT。其余文献更适合放在调研记录或附录中，不必挤占主线叙述。
