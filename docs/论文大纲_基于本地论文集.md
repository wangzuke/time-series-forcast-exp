## 1. 本地论文结构参考

| 论文 | 章节组织 | 对本文大纲的启发 |
|---|---|---|
| HD-TTS | Introduction -> Preliminaries and Problem Formulation -> Proposed Architecture -> Related Work -> Experiments -> Appendix | 先把 spatiotemporal forecasting with missing data 形式化，再讲 temporal hierarchy、spatial hierarchy、missing-pattern-conditioned readout；非常适合本文的方法章节组织 |
| GinAR | Introduction -> Related Works -> Preliminaries / Overall Framework -> Interpolation Attention -> Adaptive Graph Convolution -> GinAR -> Experimental Study -> Conclusion | Introduction 中先指出 variable missing 会导致 STGNN 捕获错误 temporal dependency 和 spatial correlation；方法中把 IA 和 AGCN 作为两个核心模块逐节展开 |
| BiTGraph | Introduction -> Related Work -> Preliminaries -> Methodology -> Experiments -> Conclusions | 标准缺失预测论文结构；Methodology 中按 temporal module、graph module、hierarchical architecture 分块，适合我们拆分 graph construction / hierarchy / fusion |
| CRIB | Introduction -> Preliminaries -> Methodology -> Experiment -> Related Work -> Appendix | 强调 missing-value MTSF 的问题重定义；实验部分主结果、消融和附录补充都比较完整 |
| CoIFNet | Introduction -> Related Work -> Methodology -> Theoretical Analysis -> Experiments -> Conclusion -> Appendix | 先提出 open question，再用 Overview、Normalization、Fusion、Objective 组织方法；实验中包含 main comparison、ablation、efficiency、case study |
| P-GUTS | Introduction -> Related Work -> Problem Setup -> Method -> Experiments -> Reproducibility | 对 pool / coarse / U-network 类方法，单独写 Problem Setup 和 reproducibility 很自然；实验中区分 imputation、robustness、forecasting、ablation |
| HyperIMTS | Introduction -> Related Work -> Problem Definition -> Methodology -> Experiments -> Appendix | 不规则/缺失观测论文常先定义输入、mask、观测事件和预测目标，再进入结构设计 |

结论：本地相近论文大多采用如下基本骨架：

```text
Introduction
Related Work 或 Problem Formulation
Problem Formulation / Preliminaries
Method / Proposed Architecture
Experiments
Conclusion
Appendix
```

其中，HD-TTS 和 CRIB 将 Related Work 放在 Method / Experiment 附近，GinAR、BiTGraph、CoIFNet 则采用更常规的 Introduction -> Related Work -> Method 顺序。本文如果面向常规时序/数据挖掘会议，建议采用 GinAR、BiTGraph、CoIFNet 式顺序；如果面向 ICML 风格，也可以把 Related Work 放到 Method 后。

## 2. 推荐论文主结构

### Title

工作标题建议暂定为：

```text
Missingness-Reliable Spatiotemporal Graph Forecasting with Adaptive Fine-to-Coarse Relations
```

中文含义：

```text
面向缺失观测多变量时间序列预测的缺失可靠时空图预测方法
```

标题中建议保留三个关键词：

- `Missingness-Reliable`：突出不是普通图预测，而是显式处理缺失可靠性。
- `Spatiotemporal Graph Forecasting`：突出空间信息和预测任务。
- `Fine-to-Coarse Relations`：突出 HD-TTS / coarse graph 支撑下的核心改造。

### Abstract

摘要应按四句话组织：

1. 背景：现实传感器多变量时间序列常存在缺失，且预测模型通常依赖时间动态和变量/空间关系。
2. 问题：缺失不仅移除数值，还会破坏 fine-grained temporal/spatial relation estimation；固定空间图和纯自适应图各有不足。
3. 方法：提出一个 missingness-reliable spatiotemporal graph forecasting framework，联合 predefined physical graph、observed-only/adaptive temporal graph、regional coarse graph，并用 reliability 控制 fine/coarse fusion。
4. 实验：在带空间信息的数据集和多种缺失模式下，与 HD-TTS、GinAR、BiTGraph 等方法对比，并通过消融验证 graph source、coarse relation 和 reliability gate 的作用。

### 1. Introduction

建议写成 5 个自然段：

1. **任务背景**  
   从 traffic / air quality / sensor network 这类空间多变量时间序列预测切入，说明准确预测依赖 temporal dynamics 和 spatial / inter-variate relations。

2. **缺失带来的核心问题**  
   借鉴 GinAR 的叙事：当变量或局部时空块缺失时，模型不仅缺少数值，还会学习到错误的 temporal dependency 和 spatial correlation；高缺失率下这个问题更严重。

3. **现有方法的不足**  
   分三类概括：impute-then-forecast / direct missing forecasting、graph-based forecasting、HD-TTS 式 hierarchical spatiotemporal downsampling。指出它们分别解决了部分问题，但还没有把 physical graph、observed/adaptive relation、regional coarse relation 和 reliability fusion 放到同一个预测框架里。

4. **本文思路**  
   说明本文继承 HD-TTS 的时空层级/粗化思想，并吸收 GinAR 的 predefined graph + adaptive graph 互补思想；进一步构造 observed-only temporal relation 和 missingness reliability，用于控制 fine/coarse information fusion。

5. **贡献总结**  
   建议控制在 4 条，不要写太散：
   - 提出 missingness-reliable fine-to-coarse spatiotemporal graph forecasting 问题视角。
   - 构造 predefined physical graph 与 observed-only/adaptive temporal graph 的可靠融合机制。
   - 引入 regional / coarse graph branch，并用 missingness reliability 控制 fine-to-coarse residual fusion。
   - 在带空间信息的数据集和多种缺失模式下验证，并给出图来源、粗化、可靠性门控等消融分析。

### 2. Related Work

建议分 4 小节：

#### 2.1 Multivariate Time Series Forecasting with Missing Values

覆盖 CRIB、CoIFNet、MissTSM、S4M 等。重点不是逐篇罗列，而是引出：

```text
direct / one-stage forecasting is preferable to naive impute-then-forecast,
but many methods do not explicitly model spatial graph and coarse graph relations.
```

#### 2.2 Graph-based and Spatiotemporal Forecasting

覆盖 MTGNN、STFGNN、DCRNN/AGCRN、ForecastGrapher、BiTGraph。重点引出：

```text
graph relations are important for MTSF,
but missingness makes learned or propagated fine-grained relations unreliable.
```

#### 2.3 Forecasting under Variable Missing and Adaptive Relations

重点写 GinAR。这里可以把 GinAR 放成最接近工作之一：

```text
GinAR shows that variable missing can corrupt temporal and spatial dependencies,
and predefined graph plus adaptive graph are complementary.
```

随后指出差异：

```text
GinAR does not build hierarchical / regional coarse representations
and mainly focuses on whole-variable missing.
```

#### 2.4 Multi-scale and Hierarchical Graph Modeling

重点写 HD-TTS，再补 P-GUTS、ESG、Graph U-Nets / graph coarsening。核心落点：

```text
HD-TTS directly supports spatiotemporal downsampling for missing-data forecasting,
but its hierarchy mainly follows the given graph topology and does not explicitly
model observed-overlap reliability or adaptive physical-temporal graph fusion.
```

### 3. Problem Formulation

这一节要像 HD-TTS、GinAR、BiTGraph 一样尽早固定符号，避免 Method 里边讲边定义。

建议包含：

#### 3.1 Incomplete Spatiotemporal MTS Forecasting

定义：

```text
X in R^{T x N x C}
M in {0,1}^{T x N x C}
A_phy in R^{N x N}
Y in R^{H x N x C}
Y_hat = f_theta(X_obs, M, A_phy)
```

强调训练和评价以 forecasting loss 为主，历史缺失值不作为主要监督目标。

#### 3.2 Missing Patterns

定义本文实验覆盖的缺失模式：

- point missing
- temporal block missing
- spatiotemporal block missing
- variable missing / channel missing
- mixed missing

这一小节要和实验协议一一对应。

#### 3.3 Graph Views and Reliability

定义三个图视角：

```text
A_phy: predefined physical / spatial graph
A_temp: observed-only temporal dependency graph
A_reg: regional / coarse graph
```

定义可靠性统计：

```text
edge observed overlap
node observation ratio
region coverage
missing block length
```

#### 3.4 Learning Objective

主损失：

```text
L = L_forecast
```

可选辅助项：

```text
L = L_forecast + lambda * L_aux
```

但论文主线应强调 forecasting-oriented，而不是把工作写成插补论文。

### 4. Method

这一节建议命名为：

```text
Missingness-Reliable Fine-to-Coarse Spatiotemporal Graph Forecasting
```

小节建议如下。

#### 4.1 Overview

给一张总框架图，对应管线：

```text
X_obs, M, A_phy
  -> mask-aware input encoding
  -> reliable fine graph construction
  -> temporal hierarchy
  -> spatial / regional hierarchy
  -> missingness-aware fine-to-coarse fusion
  -> forecasting decoder
```

这里要明确：HD-TTS 是主干支撑，GinAR 是图关系重建思想支撑。

#### 4.2 Missing-aware Input Encoding

借鉴 HD-TTS / CoIFNet 的写法：

- observed values
- mask
- time features / exogenous features
- node embeddings
- observed-value normalization

重点写清楚：填充值只是占位，mask 必须进入模型。

#### 4.3 Reliable Fine Graph Construction

这是本文区别于 HD-TTS 的关键小节。

建议拆成三段：

1. `A_phy`：物理/空间图，来自传感器距离或空间邻接。
2. `A_temp`：基于观测重叠片段估计的 temporal / adaptive relation。
3. reliability：低 observed overlap 的边需要降权或不参与关系估计。

这一节可以自然承接 GinAR：predefined graph 与 adaptive graph 互补，但我们的 adaptive relation 是 missingness-reliable 的。

#### 4.4 Temporal Hierarchy

借鉴 HD-TTS：

- temporal processing module
- temporal downsampling
- multi-scale temporal states

这一节不需要过度创新，重点说明它扩大 temporal receptive field，帮助处理 long block missing。

#### 4.5 Spatial / Regional Hierarchy

这一节对应 coarse graph。

建议写：

- fine graph message passing on fused reliable graph
- variable-to-region assignment / graph pooling
- regional graph construction
- lift / project regional representation back to nodes

如果最终实现基于 HD-TTS，则要说明哪些继承 HD-TTS spatial hierarchy，哪些是我们新增的 reliability / observed graph 改造。

#### 4.6 Missingness-aware Fine-to-Coarse Fusion

这是本文第二个关键小节。

写清楚：

```text
Z = Z_fine + alpha(M, reliability, region coverage) * Project(Z_coarse)
```

并解释：

- 高缺失、低 fine-edge reliability 时更依赖 coarse branch。
- 区域覆盖差或区域内动态不一致时降低 coarse branch。
- 这是为了避免粗图无条件融合导致过平滑。

#### 4.7 Forecasting Decoder and Training

借鉴 HD-TTS / GinAR 的 direct multi-step forecasting：

- MLP decoder
- horizon-wise output
- masked forecasting loss if target contains missing values
- optional auxiliary consistency / reconstruction loss

#### 4.8 Complexity and Implementation Details

如果篇幅允许，加入这一节。HD-TTS、CoIFNet、BiTGraph 都会关注效率或复杂度；我们的方法涉及多图和粗图，最好主动说明额外开销来自哪里，以及 coarse hierarchy 如何控制成本。

### 5. Experiments

实验结构建议参考 CoIFNet / BiTGraph / HD-TTS：

#### 5.1 Datasets

优先使用带空间信息的数据集：

- METR-LA
- AQI / AQI36
- 可选：PEMS-BAY / PEMS04 / PEMS08，取决于本地数据和图信息是否完整

每个数据集要说明：

```text
number of nodes
sampling interval
input length
forecast horizon
physical graph source
```

#### 5.2 Missing Scenarios

建议主实验不要太散，先固定 2-3 类：

- variable missing：对应 GinAR 强支撑
- temporal / spatiotemporal block missing：对应 HD-TTS 强支撑
- point missing：作为常规补充

缺失率可参考 GinAR：

```text
25%, 50%, 75%, 90%
```

如果实验量要压缩，主表可以先做：

```text
50%, 75%, 90%
```

#### 5.3 Baselines

核心 baseline 不宜太多，建议分组：

- strong missing spatiotemporal baseline：HD-TTS official
- variable missing graph baseline：GinAR official
- missing graph forecasting baseline：BiTGraph official / reproduced official
- strong non-graph forecasting backbone with mask handling：iTransformer / PatchTST variant，作为必要参照即可

这里要特别注意：HD-TTS 和 GinAR 如果作为 baseline，应尽量调用官方开源代码或官方结构，不要写成简化版 baseline。

#### 5.4 Implementation Details

写：

- input length / horizon
- optimizer / learning rate / batch size
- graph construction details
- number of regions / pooling layers
- random seeds
- metrics: MAE, RMSE, MAPE 或 MSE，按数据集习惯确定

#### 5.5 Main Results

主表建议按数据集和缺失模式组织：

```text
Dataset x Missing Scenario x Missing Rate
```

不要一开始铺太多表。主论文正文优先放最能支撑 claim 的结果，其余放 appendix。

#### 5.6 Ablation Studies

必须服务于贡献，建议包含：

- w/o `A_phy`
- w/o `A_temp`
- w/o reliability weighting
- w/o regional / coarse graph
- fixed fusion instead of missingness-aware fusion
- random region assignment negative control

#### 5.7 Robustness and Sensitivity

可选但很有价值：

- missing rate sensitivity
- number of regions / pooling layers
- edge overlap threshold
- gate weight visualization

#### 5.8 Case Study and Interpretability

借鉴 HD-TTS 的 scale attention 分析和 CoIFNet 的 case study：

- 不同缺失模式下 fine/coarse 权重如何变化
- 高缺失区域中 coarse branch 是否被更高权重使用
- 失败案例：粗图分组差、物理图和动态关系不一致时的退化

### 6. Discussion

建议保留短讨论节，尤其因为我们的 idea 有明确边界。

可讨论：

- 为什么 HD-TTS 和 GinAR 是本文最强支撑，但本文不是二者简单拼接。
- 方法适合哪些数据：有空间图、变量数量中等、缺失率较高、存在区域冗余。
- 方法可能失败的条件：空间图不可靠、区域划分过粗、变量间动态高度异质、缺失不是结构化而只是低比例随机点缺失。

如果目标会议篇幅紧张，这一节可以并入 Experiments 的 Analysis。

### 7. Conclusion

结论建议很短：

1. 重申缺失会破坏 relation reliability。
2. 总结 physical + observed/adaptive + coarse + reliability fusion 的方法。
3. 总结主要实验发现。
4. 给出未来工作：更好的 learnable region assignment、跨数据集缺失模式泛化、非传感器 MTS 扩展。

## 3. 推荐正文顺序

综合本地论文风格，我建议本文采用如下最终顺序：

```text
Abstract
1. Introduction
2. Related Work
3. Problem Formulation
4. Method
5. Experiments
6. Discussion
7. Conclusion
Appendix
```

原因：

- GinAR、BiTGraph、CoIFNet 都使用或接近这一主顺序，读者熟悉。
- 我们的方法牵涉 HD-TTS 和 GinAR 两条强支撑线，先 Related Work 可以提前框定“不是凭空提出”。
- Problem Formulation 放在 Method 前，可以把 missing pattern、graph view、reliability 等符号一次性定义清楚。
- Discussion 单独保留，便于诚实处理 coarse graph 何时有效、何时失败的问题。

如果目标会议更偏 ICML，也可以改成：

```text
Abstract
1. Introduction
2. Problem Formulation
3. Method
4. Related Work
5. Experiments
6. Conclusion
```

这个顺序更接近 HD-TTS / CRIB，但本文当前还处在定位需要讲清楚的阶段，暂时建议采用第一种。

## 4. 当前最应该先写的部分

建议撰写顺序不是从 Abstract 开始，而是：

1. Introduction 的 5 段逻辑链。
2. Problem Formulation 的符号定义。
3. Method Overview 和总框架图说明。

这样能先固定论文骨架，避免摘要和标题写得太早导致后面反复推翻。
