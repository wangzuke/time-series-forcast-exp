# 面向缺失观测多变量时间序列的缺失可靠多尺度图预测方法

> 草稿日期：2026-08-23  
> 工作标题：Missingness-Reliable Multi-Scale Graph Forecasting，MR-MSGF  
> 目标场景：高缺失率、中低变量维度条件下的多变量时间序列预测。  
> 说明：本文档为论文式 Markdown 中文草稿，可作为后续撰写会议论文的基础。

检索结果没有发现与下列组合完全一致的工作：

```text
面向预测的不完整多变量时间序列建模

+ 基于观测值的时序依赖图

+ 面向高缺失率的缺失可靠融合机制
```

最接近的已有工作覆盖了其中若干重要子问题：

- CRIB 研究含缺失值的多变量时间序列直接预测，并指出简单的“先插补后预测”可能存在问题，但未整合物理图或区域级粗粒度图。
- CoIFNet 联合建模插补与预测，并采用缺失掩码感知的时间/变量融合机制，但未构造物理-时序多视图图关系或聚类区域图。
- MissTSM 提供了一种免插补、模型无关的不完整时间序列适配方法，但其跨变量交互较为压缩，并非面向图结构或区域结构建模。
- BiTGraph 面向缺失值预测引入图卷积与掩码偏置传播，但未显式结合物理图、学习得到的时序图和聚类层面的图结构。
- HD-TTS 利用分层时空下采样进行含缺失数据的图预测，但其重点是传感器点级时空系统，而非统一的物理-时序-区域变量关系框架。
- GraFITi、T-PatchGNN、HyperIMTS 和 ChannelTokenFormer 分别从图、超图、patch 或通道 token 角度处理不规则或缺失多变量序列，但并未直接采用本文设想的物理-时序-区域多尺度图建模形式。

因此，较为稳妥的新颖性表述不是“已有工作没有研究缺失多变量时间序列预测中的图方法”，这一说法并不成立。更可支撑的表述是：

> 已有工作分别研究了缺失值预测、基于图的多变量时间序列预测、不规则时间序列图建模以及分层时空下采样。然而，在面向预测的不完整多变量时间序列建模中，仍缺少一种在显式缺失可靠性机制下同时利用物理空间关系、基于观测值的时序依赖关系与聚类区域关系的统一框架。

## 摘要

观测值缺失条件下的多变量时间序列预测具有较高难度，因为缺失不仅会移除历史数值信息，还会破坏许多预测模型所依赖的细粒度变量间关系。已有方法通常采用先插补后预测的流程，或直接从部分观测输入中学习全局变量交互，或在存在物理传感器拓扑时利用空间图结构。然而，在高缺失率场景下，学习得到的时序相关性和细粒度图消息传递都可能变得不可靠，而仅依赖物理邻近关系又难以刻画动态相似性。本文提出 **MR-MSGF**，即面向不完整多变量时间序列的缺失可靠多尺度图预测框架。该方法联合建模三类关系视图：可用空间信息对应的物理图、基于观测值并结合缺失可靠性估计的时序依赖图，以及通过变量聚类得到的区域级粗粒度图。进一步地，本文设计了一个由缺失状态条件控制的残差融合模块，以自适应调节区域信息的贡献，从而在粗粒度分配不可靠时避免有害的过平滑。模型直接以未来预测为训练目标，并可选择性加入额外观测掩蔽下的一致性正则化。实验设计覆盖随机点缺失、连续片段缺失、时空块缺失、变量通道缺失和混合缺失模式，用于验证区域图关系是否能够提升高缺失率预测性能，以及在何种条件下可能失效。

## 1. 引言

多变量时间序列预测是交通、气象、能源、工业监测、医疗健康与环境传感等领域中的核心问题。现代多变量时间序列预测模型通常同时依赖单个变量内部的时间模式以及变量之间的依赖关系。然而，在真实系统中，观测序列经常由于传感器故障、数据包丢失、异步采样、设备维护、天气干扰或变量级停机而出现不完整。在这种条件下，预测模型必须从部分观测的历史窗口中推断未来值，而不是假设输入序列完整可用。

缺失观测会从两个相互耦合的方面增加预测难度。第一，缺失会直接移除推断未来动态所需的时间证据。第二，更隐蔽但同样重要的是，缺失会扭曲多变量模型用于信息共享的变量间关系。在高缺失条件下，两个变量看似相关性较弱，可能只是由于二者共同被观测到的时间点不足。同样地，如果一条图边只由少量共同观测点估计得到，其边权可能非常噪声化；在这样的边上进行图消息传递，可能会传播不可靠信号。

一种常见解决方案是先插补历史缺失值，再将补全后的序列输入预测模型。近期研究已经对这一流程提出质疑。CRIB 指出，在真实缺失值不可观测的情况下，插补可能改变数据分布并破坏变量相关性，因此提出从部分观测输入中直接预测，并结合信息瓶颈与一致性正则化。CoIFNet 进一步说明，缺失掩码模式与时间戳本身应当参与预测表征，而不应在插补完成后被丢弃。MissTSM 则表明，免插补、模型无关的适配器可以使不完整时间序列被下游模型有效利用。

另一类工作将变量视为图节点。MTGNN 等图预测方法自适应学习跨变量依赖，并将图传播与时间卷积结合。BiTGraph 等缺失值图预测方法通过掩码偏置传播处理不完整数值。HD-TTS 等时空方法表明，在存在缺失数据时，时间和空间上的分层下采样可能有效，尤其适用于连续观测块缺失的场景。这些研究说明图关系与多尺度表征具有价值，但仍留下一个关键问题：

> 当高缺失率使细粒度变量关系变得不可靠时，预测模型能否以缺失感知的方式同时利用物理空间关系、基于观测值的时序关系和区域级粗粒度关系？

这一问题构成了本文工作的动机。物理图编码真实的空间或结构邻近性，例如交通传感器之间的道路网络距离。时序依赖图编码数据驱动的动态相似性，而这种相似性可能不同于物理邻近关系。区域级粗粒度图将变量划分为若干簇，并提供更低频的关系视角；在高缺失率条件下，这种关系视角可能更加稳定。然而，粗粒度区域信息并不总是有益。如果聚类分配将动态模式差异较大的变量混合在一起，区域分支可能造成过平滑并降低预测性能。因此，区域图建模需要受到缺失可靠性的控制，而不是被无条件融合。

本文提出 **MR-MSGF**，即缺失可靠多尺度图预测框架。该框架构造物理图、基于观测值的时序图和聚类区域图，并在细粒度与区域级图上分别进行传播，随后利用由缺失统计量控制的残差门控机制进行表征融合。这些缺失统计量包括观测比例、区域级覆盖率、最长连续缺失长度和边可靠性等。模型直接面向未来预测训练，而不是将历史插补作为主要目标。

本文预期贡献如下：

1. 将不完整多变量时间序列预测形式化为缺失可靠的多尺度关系建模问题，强调缺失不仅破坏数值，也会破坏变量依赖估计。
2. 提出一种双来源细粒度图构造方法，在考虑掩码重叠可靠性的条件下结合物理空间关系与基于观测值的时序依赖关系。
3. 引入面向预测的区域图分支，通过变量聚类在高缺失率下提供更稳定的粗粒度关系信息。
4. 设计由缺失状态条件控制的残差融合机制，用于调节区域信息，并在粗粒度分配不可靠时减弱有害过平滑。
5. 给出覆盖多种缺失机制的实验协议，并通过图来源、聚类策略、粗粒度比例和融合设计等消融实验验证方法有效性。

## 2. 相关工作

### 2.1 含缺失值的多变量时间序列预测

早期实用流程通常将插补方法与标准预测骨干结合。这一策略实现简单，但会造成插补目标与预测目标之间的不一致。对历史缺失值的最佳重构并不必然对应最有利于未来预测的表征。

CRIB 明确重新审视了含缺失值的多变量时间序列预测问题，并指出插补可能扭曲变量相关性。该方法通过统一变量注意力、信息瓶颈引导和一致性正则化，从部分观测输入中学习紧凑且包含预测信息的表征。这一工作支持本文的核心立场：模型应当保留与预测相关的变量关系，而不仅是重构缺失数值。

CoIFNet 提出协同插补-预测框架。该方法将观测值、掩码矩阵与时间戳同时作为输入，并进行跨时间步与跨变量融合。CoIFNet 支持了一个重要观点：缺失掩码本身携带有用信息，应参与表征学习。

MissTSM 研究了模型无关、免插补的不完整时间序列建模。其时间-特征独立嵌入和缺失特征感知注意力使模型能够在不显式插补的情况下处理不完整输入。该方向与本文互补：MissTSM 主要解决鲁棒 token 构造问题，而 MR-MSGF 关注缺失可靠的图关系与区域变量结构。

Merlin 及相关鲁棒缺失率学习方法进一步表明，缺失模式在训练和部署阶段可能发生变化。这提示实验评价不应只覆盖单一固定缺失率。

### 2.2 基于图的多变量时间序列预测

图神经网络被广泛用于多变量时间序列预测，因为变量通常通过显式或潜在依赖发生交互。MTGNN 自适应学习图结构，并将图传播与时间卷积结合。ForecastGrapher 从图神经网络角度重新定义多变量预测问题，并强调显式建模序列间关系的重要性。

在缺失值场景中，BiTGraph 提出带偏置的时间卷积图网络。该方法利用掩码相关信息修改图传播过程，使观测变量能够更好地补偿缺失变量。这与本文场景高度相关，但它主要仍属于细粒度图传播方法，并未引入区域级粗粒度图关系，也未形成物理-时序双图视角。

GraFITi、T-PatchGNN、HyperIMTS 和 ChannelTokenFormer 进一步说明，不完整或不规则多变量时间序列并不总是应被强行转换为稠密规则矩阵。GraFITi 通过图表示不规则观测；T-PatchGNN 将可变形 patch 与图神经网络结合；HyperIMTS 使用超图通过时间和变量超边连接观测点；ChannelTokenFormer 通过通道 token 与掩码引导注意力处理真实世界中的依赖、异步性和缺失。这些方法支持图结构或 token 结构的不完整多变量时间序列建模，但未直接研究本文提出的物理-时序-区域图组合。

### 2.3 多尺度与层次化关系

多尺度建模具有重要意义，因为时间序列依赖可能在不同时间尺度或结构尺度上呈现差异。HD-TTS 与本文尤其相关：它通过时空下采样进行含缺失数据的图预测，并表明在连续缺失块条件下，较粗的时间/空间尺度能够提供帮助。这为高缺失率预测受益于粗粒度关系视角提供了直接证据。

P-GUTS 使用带时间池化的 product graph U-network 进行时空插补。虽然其主要任务是插补，但其池化式多尺度设计支持了一个假设：粗粒度表征可以稳定缺失数据建模。

演化多尺度图结构学习和层次联合图学习等工作也表明，变量间依赖可能具有尺度特异性，层次图分解有助于预测。然而，这些工作通常假设观测完整或相对可靠，并未显式建模缺失可靠性。

本文的区别在于：将区域关系视为一种面向预测的缺失条件补充。区域图信息并非简单叠加，而是由观测覆盖率和可靠性统计量进行门控，以避免注入误导性的低频信号。

## 3. 问题定义

设：

```text
X = {x_1, ..., x_T} in R^{T x N x C}
M = {m_1, ..., m_T} in {0,1}^{T x N x C}
Y = {x_{T+1}, ..., x_{T+H}} in R^{H x N x C}
```

其中，`T` 表示输入长度，`H` 表示预测步长，`N` 表示变量数量，`C` 表示特征维度。`M_{t,n,c}=1` 表示 `X_{t,n,c}` 被观测到，`M_{t,n,c}=0` 表示该位置缺失。

模型接收：

```text
X_obs = M ⊙ X
M
A_phy optional
```

并预测：

```text
Y_hat = f_theta(X_obs, M, A_phy)
```

训练目标为预测目标：

```text
min_theta L_forecast(Y_hat, Y)
```

其中，`Y` 被假设可用于监督预测评估。历史缺失值不作为主要优化目标。

### 3.1 缺失模式

本文考虑多种缺失机制：

- 随机点缺失：单个条目被随机掩蔽。
- 连续片段缺失：部分变量在连续时间片段上缺失。
- 变量通道缺失：选定变量的完整历史窗口不可用。
- 时空块缺失：缺失在时间和变量或空间区域上同时呈现结构化模式。
- 混合缺失：点缺失、片段缺失和通道缺失的混合。

这些模式对图可靠性的影响不同。随机点缺失可能仍保留足够的成对重叠观测，而变量通道缺失和时空块缺失可能破坏整片区域的证据。

### 3.2 图视图

本文使用三类图视图：

1. 物理图：

```text
A_phy in R^{N x N}
```

该图编码真实空间或结构关系，例如道路网络距离。对于通用多变量时间序列数据集，该图可能不可用。

2. 时序依赖图：

```text
A_temp in R^{N x N}
```

该图由观测值估计，并根据缺失可靠性进行调整。

3. 区域图：

```text
S in R^{N x K},  K < N
A_reg in R^{K x K}
```

`S` 将变量映射到区域组。`A_reg` 建模这些区域组之间的关系。

## 4. 方法

### 4.1 总体框架

MR-MSGF 由五个模块组成：

```text
1. 缺失感知输入编码
2. 可靠物理-时序细粒度图构造
3. 基于变量聚类的区域图构造
4. 细粒度与区域级图传播
5. 缺失条件残差融合与预测
```

该方法遵循一个保守原则：

> 将区域信息作为可靠补充，而不是无条件替代细粒度变量关系。

### 4.2 缺失感知输入编码

首先编码观测值与缺失掩码：

```text
H_0 = Enc([X_obs, M, E_time])
```

其中，`E_time` 表示可选的时间戳或位置嵌入。

归一化仅基于观测值计算：

```text
mu_n = sum_t M_{t,n} X_{t,n} / (sum_t M_{t,n} + epsilon)
sigma_n = observed_std(X_{:,n}, M_{:,n})
```

这样可以避免由人工零填充或均值填充污染归一化统计量。

编码器可由时间卷积、patch 编码器、Transformer 模块或 MissTSM 风格的不完整 token 适配器实现。本文提出的图模块在概念上不依赖特定预测骨干。

### 4.3 可靠时序依赖图

当两个变量共同被观测到的时间点很少时，朴素的时序相关图可能并不可靠。本文计算观测重叠可靠性：

```text
rho_ij = sum_t 1[M_{t,i}=1 and M_{t,j}=1] / T
```

然后仅在重叠观测位置上估计相似性得分：

```text
s_ij = corr(X_i, X_j | M_i=1, M_j=1)
```

时序图定义为：

```text
A_temp_ij = TopK( ReLU(s_ij) * g(rho_ij) )
```

其中，`g` 可以为：

```text
g(rho) = sigmoid(a * (rho - tau))
```

或阈值函数。该设计防止低重叠变量对由于偶然相关而形成强图边。

### 4.4 物理-时序细粒度图融合

当物理图可用时，将其与时序图结合：

```text
A_fine = lambda A_phy + (1 - lambda) A_temp
```

`lambda` 可以固定、全局可学习，或根据图可靠性进行条件化。当 `A_phy` 不可用时：

```text
A_fine = A_temp
```

该设计同时覆盖传感器网络数据集和通用多变量时间序列数据集。

### 4.5 区域变量图构造

构造变量到区域的分配矩阵：

```text
S in R^{N x K}
```

可选分配策略包括：

- 距离聚类：基于物理距离对变量聚类。
- 时序聚类：基于观测值动态相似性对变量聚类。
- 混合聚类：结合物理距离与时序相似性。
- 软聚类：允许一个变量属于多个区域。
- 随机聚类：作为负对照，不作为真实模型选择。

区域表征与区域邻接矩阵为：

```text
H_reg = S^T H_node
A_reg = Normalize(S^T A_fine S)
```

区域图传播后得到：

```text
Z_reg = GNN_reg(H_reg, A_reg)
Z_reg_to_node = S Z_reg
```

该分支捕获低频的组级依赖关系。在细粒度节点观测稀疏时，这类关系可能更加稳定。

### 4.6 细粒度图传播

细粒度分支在变量图上进行信息传播：

```text
Z_fine = GNN_fine(H_node, A_fine)
```

`GNN_fine` 可根据具体骨干选择扩散卷积、图注意力、mix-hop 传播或轻量图卷积。

### 4.7 缺失条件残差融合

一个关键设计是避免无条件融合区域特征。本文采用残差门控：

```text
Z = Z_fine + alpha * Project(Z_reg_to_node)
```

其中：

```text
alpha = Gate(phi(M, S, A_fine))
```

`phi` 包含缺失与可靠性统计量：

- 全局观测比例
- 节点级观测比例
- 时间级观测比例
- 区域级观测比例
- 最长连续缺失长度
- 空间覆盖比例
- 平均边重叠可靠性
- 区域内部一致性

门控可以是标量级、变量级、区域级或通道级。初始实现中，标量门控或区域级门控更利于稳定训练。

残差门控应初始化为接近零：

```text
alpha ≈ 0 at initialization
```

这使模型从细粒度图基线出发，仅在有益时学习使用区域分支。

### 4.8 预测头与目标函数

最终表征被解码为未来预测：

```text
Y_hat = Dec(Z)
```

主要损失为：

```text
L = MAE(Y_hat, Y)
```

可选一致性正则化为：

```text
X_aug, M_aug = additional_mask(X_obs, M)
Y_hat_aug = f_theta(X_aug, M_aug, A_phy)
L_cons = || Y_hat - Y_hat_aug ||
```

总损失为：

```text
L_total = L_forecast + beta L_cons + gamma L_graph
```

`L_graph` 可用于惩罚不可靠边，或在区域内部一致性较低时限制模型过度依赖区域分支。第一版实现可暂时省略 `L_graph`，主要依赖显式可靠性加权与消融实验。

## 5. 实验设计

### 5.5 预期证据

论文只有在实验支持时才应声称以下结论：

1. MR-MSGF 在高缺失率下优于仅使用细粒度图的基线。
2. 在连续片段缺失、时空块缺失或变量通道缺失下，改进应强于较简单的随机点缺失。
3. 物理图和时序图具有互补性；若某一图来源占主导，也应如实报告。
4. 区域图收益不能被随机聚类复现。
5. 在粗粒度分组质量较差的数据集上，残差门控能够避免严重性能退化。
6. 对于中低维数据集，该方法在运行时间和显存开销上保持竞争力。

## 6. 讨论与风险控制

最重要的风险是过度声称区域聚类的价值。已有证据和本地实验均表明，粗粒度图分支可能有帮助，但较差的分配也可能损害性能。因此，论文不应将区域聚类表述为普遍有效。

较为稳妥的表述是：

> 区域关系在高缺失条件下提供了一种相对稳定的低频关系视角，但其有效性取决于区域质量和缺失模式。MR-MSGF 将区域信息视为由可靠性条件控制的残差信号，而不是对细粒度依赖的无条件替代。

如果实验结果显示收益并不稳定，只要论文能够清晰识别区域关系何时有效、何时失效，以及缺失可靠性如何预测这种行为，仍然可以形成有价值的研究贡献。
