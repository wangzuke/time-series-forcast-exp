# 实验实现对齐审计（2026-09-06）

## 结论

本轮开始前的 `official_reliable` 不是论文草稿中定义的完整 MR-MSGF，不能作为 M5 或主结果使用。它只把物理图、观测相关图和一个探索性的 adaptive graph 固定加权后送入 HD-TTS 的空间卷积；缺少边级可靠性门控、显式区域粗图、细到粗可靠性门控和缺失感知尺度读出。同时，旧 runner 默认 `propconv` 和 MSE 训练，也不对应实验计划中的 HD-TTS-AMP 与 MAE。

旧结果保留在 `missing_ts_exp/results/r0905_blockt/` 以便追溯，但不纳入本轮论文结果或方法结论。

## 修正后的实验边界

- 官方基线：`HDTTSModel` 直接从 `external_repro/official/hdtts` 导入，官方仓库不做修改。
- 本地适配配置：`hidden_size=64`、`dilation=4`、`rnn_layers=3`、`pooling_layers=3`、`mp_method=[anisoconv, anisoconv]`、直接多步读出。这与官方 `hd_tts_amp_mso_block_t.yaml` 的 AMP 配置一致；METR-LA 是本地空间数据适配，并非声称为 HD-TTS 原文主数据集复现。
- 训练：只在训练集可观测值上估计归一化统计量；输入缺失位置使用归一化零占位并把 mask 输入模型；优化目标为 masked MAE。
- 评估：所有模型读取同一份 HD-TTS-style Point/Block-T 固定 mask；测试 MAE、RMSE、MAPE 在反归一化后的原始量纲上计算，目标自然缺失位置不计入指标。

## MR-MSGF 与论文方法的实现映射

| 论文组件 | 实现位置 | 当前实现 |
|---|---|---|
| 缺失感知编码和时间层级 | 官方 HD-TTS `encoder_time`、`drnn` | 保留 |
| $A^{obs}$ 与 $q_{ij}$ | `OfficialMRMSGFHDTTSModel._observed_graph` | masked temporal pooling、query/key 相似度、$\log(q_{ij})$ 可靠性项、top-k |
| $A^{fine}$ | `_fine_graph` | $g_{ij}=\sigma(\psi_g[r_i,r_j,q_{ij},A^{phy}_{ij},A^{obs}_{ij}])$ |
| HD-TTS 空间层级 | 官方 `spatial_conv` | 保留，始终使用固定物理图 $A^{phy}$，避免 batch composition 改变预测 |
| 区域分配 $S$ | `graph_region_assignment` | 仅由物理图形成的固定空间连通分组，不使用节点编号分组 |
| $A^{coarse}=S^T A^{fine}S$ | `_coarse_propagate` | 对每个样本显式构造并传播 |
| 细到粗门控 $\alpha_i$ | `_coarse_propagate` | 输入节点观测率、邻边共同观测率、区域覆盖率、最长缺失比例和区域动态离散度 |
| 缺失感知尺度读出 | `_readout_with_reliability` | 在官方 HD-TTS 读出打分与直接多步 decoder 上加入可靠性偏置 |

`adaptive graph` 已从当前 MR-MSGF 和命令文件中移除。它不属于论文草稿的既定方法；若后续研究其作用，应单独作为扩展消融，而不能混入主模型。区域分配使用由物理图连通扩张得到的固定资源；每个区域都通过连通性和最大尺寸校验，运行时读取同一份 `S.npy` 并记录 hash。

## 可运行模型和消融

- `official_base`：未修改的官方 `HDTTSModel`。
- `mrmsgf --mrmsgf_variant phy_only`：M1，物理细图。
- `mrmsgf --mrmsgf_variant obs_only`：M2，观测驱动细图。
- `mrmsgf --mrmsgf_variant fine`：M3，可靠 $A^{fine}$。
- `mrmsgf --mrmsgf_variant coarse_no_gate`：M4，粗图但无可靠性门控。
- `mrmsgf --mrmsgf_variant full`：M5，完整 MR-MSGF。

实验命令由 `missing_ts_exp/scripts/r0905_build_blockt_cmds.py` 生成，主协议只包含 Point 和 Block-T；不包含 Block-ST。
