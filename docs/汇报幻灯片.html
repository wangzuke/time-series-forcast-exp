1. 背景

研究背景

观测缺失同时影响时间动态、变量关系估计和图传播可靠性。

建模背景

  • 历史观测值与缺失掩码共同决定模型可利用的信息。
  • 缺失不仅影响数值层面，也会破坏变量关系层面的信息。
  • 高缺失率下，细粒度变量关系估计更容易不稳定。
  • 预测模型需要学习与未来预测相关且缺失可靠的变量关系。
预测结果 = 预测模型(历史观测值, 缺失掩码, 变量关系结构)

2. 相关工作

文献基础

文献支撑链可归纳为四类：缺失预测、图关系建模、不规则观测建模、多尺度时空建模。

代表工作

  • CRIB / CoIFNet / MissTSM：支持预测导向的缺失感知表征。
  • MTGNN / BiTGraph：支持变量图建模和缺失下图传播。
  • GraFITi / T-PatchGNN / HyperIMTS：支持不完整观测结构化建模。
  • HD-TTS / P-GUTS：支持粗尺度关系在缺失场景中的价值。

3. 研究缺口

问题凝练

研究缺口集中在缺失条件下的关系可靠性与多尺度关系融合。

关键问题

  • 时序相关图依赖共同观测，缺失会削弱边权可靠性。
  • 真实空间邻近与动态相似并不等价。
  • 变量聚类关系需要面向预测目标设计。
  • 区域粗粒度信息应受到缺失可靠性控制。
物理关系 + 时序关系 + 区域关系 + 缺失可靠性

4. 问题定义

形式化问题

输入为部分观测历史窗口和缺失掩码，目标是直接预测未来序列。

形式化定义

  • 观测序列由完整历史序列与缺失掩码逐元素相乘得到。
  • 模型联合利用观测序列、缺失掩码和多类图关系预测未来。
  • 训练目标以未来预测误差为主，而不是历史缺失值重构。
  • 三类图视角：真实空间图、时序依赖图、区域图。

5. 缺失可靠的多尺度图关系预测方法

方法框架

该方法以缺失可靠的多尺度图关系作为预测表示的核心。

框架组成

  • 输入编码：联合编码观测值、缺失掩码和时间信息。
  • 细粒度图：融合真实空间关系与观测时序关系。
  • 区域图：通过变量聚类构造粗粒度关系结构。
  • 双路径传播：同时建模变量级关系与区域级关系。
  • 残差融合：由缺失统计控制区域分支贡献。

7. 总结

总结

背景

观测缺失同时破坏时间动态、变量关系估计和图传播可靠性。

相关工作

已有工作分别支持缺失预测、图关系建模、不规则观测建模和多尺度时空建模。

研究缺口

缺失条件下仍缺少统一建模物理关系、时序关系与区域关系的预测框架。

问题定义

从部分观测历史、缺失掩码与多类图关系中直接预测未来，不以历史插补作为主目标。

拟提方法

提出缺失可靠的多尺度图关系预测方法，通过可靠时序图、区域图分支和残差融合建模多尺度变量关系。

核心观点：区域关系可作为缺失条件下的低频补充，但其引入强度应受到可靠性约束。
