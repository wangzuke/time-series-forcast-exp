# MR-MSGF 方法定稿方案

本说明将论文的概念性设计固定为一套与当前 official HD-TTS overlay 一一对应的模型。它是论文写作、后续实验和消融的共同规格；不采用早期 PyTorch-only prototype 中的额外 adaptive graph。

## 1. 研究边界

本文处理带物理空间信息的缺失时空多变量预测。主任务是 forecasting，不将历史插补作为监督目标。模型输入为带缺失的历史观测、观测 mask、物理图；输出为未来多步预测。

Idea 的五项主张与最终模型的对应关系如下。

| Idea 模块 | 定稿实现 | 代码依据 |
|---|---|---|
| M1 预测导向 | 只优化 masked future MAE | `run_official_hdtts_local.py:56-61,151-152` |
| M2 物理图 | 行归一化道路/地理邻接 `A_phy` | `hdtts_official_reliable.py:120-124` |
| M3 观测关系 | masked pooling + query/key + co-observation penalty 的批内 `A_obs` | `hdtts_official_reliable.py:159-176` |
| M4 区域图 | 先融合为 `A_fine`，再以固定物理连通区域得到 `A_coarse=S^T A_fine S` | `hdtts_official_reliable.py:36-79,195-209` |
| M5 缺失适配 | edge gate、coarse residual gate、readout reliability bias | `hdtts_official_reliable.py:178-189,211-242` |

## 2. 唯一模型定义

1. 以官方 HD-TTS 作为 backbone，保留其 mask-aware encoder、dilated recurrent temporal hierarchy、静态物理空间 pooling/lifting hierarchy 和 attention readout。
2. 对每个输入窗口只构造一张 batch-wise `A_obs`。它是由可观测历史支持的节点间关系图，而不是额外的 GinAR-style node-embedding adaptive graph。
3. 以边级门控融合 `A_phy` 与 `A_obs`，并对结果行归一化，得到 `A_fine`。
4. 区域分配 `S` 是固定硬分配，仅由 `A_phy` 构造的连通、大小受限区域。它不是可学习聚类，也不依赖当前样本，避免将区域划分本身变成缺失驱动的随机变量。
5. `A_coarse` 是每个样本由 `S^T A_fine S` 得到的动态粗图。区域化发生在双源图融合之后，这是本文明确选择的设计。
6. 新增分支只替换 HD-TTS 的最细空间状态；HD-TTS 原有较粗空间状态完全保留。因此，本文不是重新实现 HD-TTS 的层级，而是在其多尺度状态池中增加一个可靠细到粗分支。
7. coarse gate 和 readout attention 均使用明确的可靠性统计。当前实现不使用任何 graph sparsity、assignment entropy、一致性或插补辅助损失。

## 3. GinAR 与 HD-TTS 的准确角色

- HD-TTS 是代码主干和主要 baseline。本文继承其时间层级、静态空间层级和多尺度 readout。
- GinAR 是关系建模动机：缺失会破坏依赖估计，先验图与数据驱动图应当互补。
- 本文不复用 GinAR 的 interpolation attention 或独立 adaptive adjacency。因此论文不得写成“integrates GinAR”或“uses GinAR adaptive graph”。

## 4. 必须保持的论文表述

- 使用 `observation-driven relation graph` 或 `observed-history graph` 描述 `A_obs`，不要将其写成逐未来时刻预测的动态图。
- 使用 `regional coarsening after fine-graph fusion` 描述空间层级，避免写成两张源图分别区域化。
- 将区域定义为 `physically connected, size-bounded regions`，不要暗示行政区域或无约束数据聚类。
- 将 reliability 描述为控制信息使用强度的证据变量，不声称它本身是经过校准的概率不确定性。

## 5. 需要由后续实验验证的假设

1. 低 co-observation 的细边更不可靠，`q_ij` 惩罚可以抑制它们。
2. `A_phy` 和 `A_obs` 在 Point/Block-T 下互补。
3. 融合后区域化能够在细粒度证据不足时提供补充。
4. 区域分支需要 gate；无条件注入会在低覆盖或高离散区域产生过平滑。

这些是假设而非既成事实；最终摘要、引言和结论只能在实验完成后陈述相应结果。
