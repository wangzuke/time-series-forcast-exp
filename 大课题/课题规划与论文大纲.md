# 基于深度学习的缺失数据条件下时空序列预测方法研究

## 硕士学位课题规划与论文大纲

**拟定题目：** 基于深度学习的缺失数据条件下时空序列预测方法研究  
**英文题目：** *Deep Learning Methods for Spatiotemporal Time Series Forecasting under Missing Data*

> 本文档用于确定毕业论文的研究边界、章节关系、可验证的创新点和实验路线。它不是开题报告的替代文本；开题报告中的格式、篇幅和成果要求，仍须以所在学院的最新规定为准。

---

## 1. 选题定位与核心问题

交通流、空气质量、气象观测、能耗等时空序列常同时具有时间相关性、空间关联性和观测缺失。实际系统中，缺失不是单一的随机空值：传感器偶发失效形成散点缺失，通信或维护形成连续时间块缺失，设备离线或区域故障形成整变量（整节点）缺失；缺失的位置、持续时间和空间分布会改变模型可用的信息。

本课题研究的**目标任务**是：在历史观测不完整的条件下，直接预测未来完整或指定目标节点的时空序列，并系统考察不同缺失模式、数据维度和应用场景下的方法有效性。核心不是追求一个对所有缺失条件都最优的模型，而是回答以下问题：

1. 不同缺失模式下，哪些时间信息和空间关系仍然可靠，如何让深度模型有效利用它们？
2. 多尺度空间关系能否在散点、时间块和整节点缺失下提高预测稳定性？
3. 当缺失模式或缺失率发生变化时，模型如何保持可迁移的预测能力？
4. 在整节点或区域连续不可观测时，如何给出可信的预测及其不确定性，而非仅在随机掩码下取得较小误差？

### 1.1 研究范围

| 内容 | 本课题的取舍 |
|---|---|
| 预测对象 | 连续值多变量时空序列，主要验证交通流与空气质量/环境监测数据 |
| 缺失位置 | **历史输入缺失**为主；未来预测标签在训练与评价时保持可得 |
| 缺失模式 | 散点缺失、连续时间块缺失、整变量/整节点缺失，并扩展到空间相邻区域缺失 |
| 建模范式 | 端到端缺失感知预测为主；“插补后预测”作为必要对照而非主贡献 |
| 空间结构 | 已知物理图、数据驱动关系图及区域/层次关系；不假设三者在所有数据集上都同时可得 |
| 不在主线内的问题 | 纯插补精度竞赛、非规则采样临床序列、因果缺失机制识别、异常检测；这些可作为相关工作或后续延伸 |

这里的“缺失数据条件”强调输入历史不完整，并不等同于一般的“插补问题”。插补的重构误差与下游预测误差并不必然一致，因此论文的主指标应以未来预测性能和稳定性为准，同时报告插补式流程的对照结果。

### 1.2 与已有小论文的关系

现有小论文“面向缺失时空序列的双关系区域多尺度图预测”可纳入本论文的第四章，作为“**缺失条件下多尺度空间关系建模**”的初步工作。该工作在 METR-LA 的部分散点/时间块缺失设置中有稳定增益，但在 AQI36 的自然缺失设置中尚未显示普适优势；消融也尚未证明共观测统计量本身的独立语义作用。因此，毕业论文应：

- 保留其“物理关系与数据关系结合、区域多尺度图”的合理思路；
- 扩展数据集、缺失率、缺失模式、预测步长和随机种子；
- 不把当前小增益表述为普适结论；
- 以新的缺失模式感知表示学习和整节点/区域缺失研究，构成更完整的学位论文主线。

## 2. 硕士学位论文的通用构成与本课题对应方式

公开高校规范通常将论文组织为前置部分、引言、若干相互衔接的研究章节、结论与展望、参考文献和附录。引言应交代研究意义、研究现状、问题、方法与论文结构；结论应概括研究发现、创新、局限和后续工作。[南开大学研究生学位论文写作规范](https://sfs.nankai.edu.cn/2025/0402/c7262a566018/pagem.htm) 与 [兰州大学学位论文写作规范](https://ge.lzu.edu.cn/xueweishouyu/guizhangzhidu/lunwenguanli/2020/1223/158947.html) 对这一逻辑有一致要求。最终封面、摘要、字数、成果认定和附录格式须服从本校、本学院规定。

本课题建议采用“**问题与证据基础 → 三个递进的方法研究章节 → 综合结论**”的结构，而不是将几篇相互独立的小论文顺序拼接。

```mermaid
flowchart LR
  A[缺失模式与数据条件分析] --> B[可靠空间关系建模]
  B --> C[缺失模式感知的多尺度预测]
  C --> D[整节点/区域缺失下的预测与可信度评估]
  A --> C
  A --> D
  B --> D
  D --> E[统一评价、边界与结论]
```

这条主线中，研究对象的难度逐步增加：局部值缺失下学习可靠关系，缺失模式变化下学习时空表征，再到节点或区域整体不可观测时的跨尺度信息补偿和预测。三个章节共享同一任务定义和评测协议，因而能够共同回答同一个毕业课题。

## 3. 文献调研形成的研究判断

### 3.1 近年方法脉络

| 方法类别 | 代表工作（近年） | 对本课题的启示 |
|---|---|---|
| 插补后预测 | GRIN、SAITS、CSDI、PriSTI、ImputeFormer 等 | 必须作为强对照；重构最优不代表预测最优，不能以插补 MAE 代替预测评价 |
| 直接缺失感知时空预测 | BiTGraph（ICLR 2024）、HD-TTS（ICML 2024）、GinAR（KDD 2024）、S4M（ICLR 2025）、Merlin（KDD 2025）、MissTSM（TMLR 2026）等 | 掩码、时间间隔、图关系和跨变量信息均可直接进入预测模型；不同工作对不同缺失形态有效 |
| 整变量/未见节点研究 | FDW（KDD 2022）、TRF（IJCAI 2024）、GinAR、IBN、UIGNN（ICDM 2023）等 | 整节点缺失不应被散点掩码替代；需要验证空间位置、静态属性和邻域结构能否支持预测 |
| 不规则采样与连续时间建模 | CRU、GraFITi（AAAI 2024）、t-PatchGNN（ICML 2024）、HyperIMTS 等 | 时间间隔和观测时间本身具有信息，应在连续时间块缺失中显式建模 |
| 任务导向评价和基准 | Task-oriented imputation evaluation（NeurIPS 2024）、AirQualityBench（2026）等 | 应分开报告缺失重构、未来预测、缺失模式迁移和计算代价，避免只在单一随机掩码上比较 |

完整的逐篇分类、证据等级和链接见 [文献调研综述](文献调研_20260926/综述正文.md)。上述年份、会议与结论应在正式写作前按最终引用版本再次核验。

### 3.2 现有证据不能支持的结论

现有实验与文献没有支持“某一模型对所有数据维度、缺失率和几何形态都最好”的说法。已有内部初步实验显示：低至中等缺失率时，“合理插补 + 强预测器”常有竞争力；高缺失率、高维或结构化缺失时，直接缺失感知方法可能更有优势；散点、连续时间块和整节点缺失的排名也会变化。

因此，论文的科学假设应是**条件性的**：当可用信息的空间尺度、时间连续性和缺失模式发生变化时，采用相应的可靠关系与表征选择，可以提升预测精度、稳定性或缺失模式迁移能力。所有结论均须注明数据集、缺失机制、缺失率和预测步长。

## 4. 总体技术路线与研究内容

### 4.1 统一问题定义

给定 (N) 个空间位置、(F) 个变量、长度为 (T) 的历史窗口，记原始观测为 (X\in\mathbb{R}^{T\times N\times F})，可观测掩码为 (M\in\{0,1\}^{T\times N\times F})。输入为已掩码序列、掩码、时间位置/时间间隔以及可用的图或静态属性，目标是在预测窗口 (H) 内估计未来值 (Y\in\mathbb{R}^{H\times N\times F})。

评价时需要区分：

- **历史输入缺失率**：被人为遮蔽或自然缺失的输入比例；
- **缺失几何形态**：散点、连续时间块、整变量/整节点、相邻区域块；
- **目标范围**：全节点预测，或对历史不可观测节点的未来预测；
- **训练—测试缺失分布关系**：同分布、缺失率变化、散点到块缺失、随机到空间相关缺失。

### 4.2 三个方法研究子方向

| 子方向 | 要解决的关键问题 | 拟开展的工作 | 对应论文位置 |
|---|---|---|---|
| A. 缺失条件下的多尺度空间关系建模 | 局部缺失使数据驱动关系不稳定，物理图又不足以表示功能相似性 | 将物理邻接、数据驱动关系和区域层次关系结合；使用可用观测信息估计关系可靠性；比较固定图、动态图和多尺度图 | 第四章；扩展已有小论文 |
| B. 缺失模式感知的时空预测 | 同一观测率下，散点与连续时间块提供的信息不同；固定时间尺度和固定融合方式不适配 | 显式输入掩码、距上次观测时间、连续缺失长度等标准信息；在短期/周期/长程时间表征和不同空间尺度间进行条件选择；考察缺失模式迁移 | 第五章；主创新章节 |
| C. 整节点和区域缺失下的预测与可信度评估 | 一个节点长期无历史观测时，局部时间插补失效；区域同时故障会降低邻域可用性 | 以静态位置、物理图、区域层次和其他节点历史为条件进行预测；研究节点级与区域级遮蔽；输出预测区间或分位数，评估覆盖率和校准性 | 第六章；难缺失条件的扩展章节 |

三个方向不是三个彼此孤立的模型：A 提供空间关系基础；B 决定不同缺失条件下如何使用时间与空间信息；C 在最少直接观测信息的情形检验 A、B 是否仍然成立。

### 4.3 方法研究的可检验假设

| 编号 | 假设 | 应有的证据 |
|---|---|---|
| H1 | 对散点和时间块缺失，可靠的多尺度空间关系比单一固定关系更稳健 | 在至少两个交通数据集和一个环境数据集上，固定物理图、单尺度数据图、已有小论文模型和改进模型的配对多随机种子比较 |
| H2 | 将缺失模式的时间信息纳入时空表征，并按条件选择不同时间/空间尺度，可改善缺失模式变化下的预测 | 同分布与迁移两类测试；去除掩码特征、去除时间间隔、固定尺度、固定融合的消融；报告均值、标准差和配对显著性检验 |
| H3 | 静态结构和区域层次可帮助整节点缺失下的未来预测，但增益随缺失节点比例、空间聚集程度和属性可用性变化 | 随机节点、空间相邻节点和区域块三类遮蔽；全节点与缺失节点子集分别报告；比较零填充、插补流程、直接模型与图/层次消融 |
| H4 | 在强缺失条件下，预测不确定性能够反映误差风险 | 分位数损失或概率损失、PICP/PINAW 或 CRPS、可靠性图；按缺失率与缺失模式分组检验校准性 |

H4 只有在模型确实输出预测分布或区间时才作为正式贡献；若时间不足，可作为第六章的扩展实验，不能仅凭误差条替代不确定性评估。

## 5. 拟定论文章节与各章工作

### 前置与后置部分

- 中文摘要、英文摘要、目录、符号说明和缩略语表；
- 参考文献、附录、攻读学位期间成果、致谢等按本校模板安排；
- 附录建议保存掩码生成算法、全部超参数、更多数据集结果、统计检验结果和复现实验说明，而不是将关键论证移出正文。

### 第一章 绪论

**目的：** 说明为什么“缺失数据条件下的时空预测”是独立且有实际价值的问题，并提出论文的研究问题。

1. 交通、环境监测等场景中的缺失来源与风险；
2. 时空预测、时间序列插补和缺失感知预测的区别；
3. 国内外研究现状的概览与不足；
4. 本文研究内容、技术路线和章节安排；
5. 可验证的贡献概述，避免使用“首次”“全面领先”等未证明表述。

### 第二章 相关理论、研究现状与问题定义

**目的：** 为后续三章建立统一术语、任务和评价边界，避免每章重新定义问题。

1. 时空图神经网络、注意力/Transformer、掩码建模、概率预测的基础；
2. 按“缺失模式—应用场景—数据维度—方法类型”系统整理文献；
3. 散点、时间块、整变量/节点、区域块缺失的形式化定义；
4. MCAR/MAR/MNAR 作为缺失机制讨论，说明合成掩码并不能自动代表真实机制；
5. 统一评价指标、数据划分、统计检验、泄漏防护和计算代价指标；
6. 从文献和预实验归纳出 H1–H4。

**应形成的成果：** 一张文献分类表、一套任务记号、一张“缺失模式—信息可用性—模型设计”对应表。现有文献调研可作为本章初稿的基础，但正式答辩前须补充最新工作。

### 第三章 缺失条件下时空预测的统一实验协议与基准分析

**目的：** 把实验设计本身做成可复核的证据基础，防止后续方法只在有利设置下比较。

1. 数据集选择与数据卡：
   - **交通（中维）**：METR-LA、PEMS-BAY；可加入 PEMS04/PEMS08 检验规模变化；
   - **空气质量/环境（中高维或自然缺失）**：AQI36，以及数据许可与清洗规则明确的公开空气质量数据；
   - 若资源有限，至少保证两个交通数据集加一个环境数据集，且不以同一数据集的不同切分代替跨场景验证。
2. 严格按时间划分训练、验证和测试；标准化统计量仅由训练集计算；掩码生成不接触未来标签；
3. 统一缺失协议：散点缺失（如 10%、30%、50%）、不同长度的连续时间块、随机节点缺失、空间相邻节点/区域缺失；实际缺失率和块长必须记录；
4. 基线分组：传统插补 + 同一预测器、深度插补 + 同一预测器、直接缺失感知预测器、与本任务匹配的整节点方法；
5. 指标：MAE、RMSE、MAPE/sMAPE（仅在适用时），不同预测步长结果，训练/推理时间、参数量；至少 5 个配对随机种子，报告均值和标准差，并对主比较做配对检验及多重比较校正；
6. 形成“何种条件下何类方法有效”的基准结论，为第四至六章选择具有代表性的困难条件。

**章节性质：** 这是研究设计和实证基线章节，不应作为唯一算法创新。其价值在于使后续结论可比较、可复现，并避免把单一随机掩码结果泛化为真实系统结论。

### 第四章 缺失条件下的多尺度空间关系建模

**目的：** 扩展现有小论文，研究在局部历史缺失时如何构建与使用较可靠的空间关系。

1. 分析物理邻接、相关/学习关系及区域层次关系在不同缺失率下的稳定性；
2. 构建由可用观测、物理结构和区域聚合共同支持的多尺度关系表示；
3. 设计与预测器结合的图信息传播/融合机制，确保仅使用历史窗口可得信息；
4. 在散点缺失与连续时间块缺失下，比较单尺度、仅物理图、仅数据图、固定融合、多尺度关系模型；
5. 做关系图消融，包括随机或置换关系、去除物理先验、去除区域层次、去除可靠性约束；
6. 在更多数据集和随机种子上复现并修正已有小论文结论。

**本章可成立的贡献表述：** 提出或完善一种面向不完整历史观测的多尺度空间关系建模方法，并在明确的局部缺失条件下验证其效果与边界。若置换关系等严格消融无法显示共观测统计量的独立作用，应把它降为实现细节或删除，不能作为核心创新。

### 第五章 缺失模式感知的多尺度时空预测方法

**目的：** 解决本课题最关键的科学问题：为什么同样缺失率、不同几何形态需要不同的信息利用方式。

1. 从输入掩码中提取标准且可解释的条件信息：当前观测状态、距上次观测的时间、连续缺失长度、节点/区域缺失比例、时间位置；
2. 以短期局部、周期性和长程依赖为候选时间表征，以局部邻域和区域尺度为候选空间表征；
3. 依据上述缺失条件学习不同表征的组合权重，使模型在散点、时间块及不同缺失率下选择合适的信息来源；
4. 与第四章的多尺度关系模块衔接，但在实验上清楚拆分“关系构建的作用”和“缺失条件选择的作用”；
5. 评价同分布性能、缺失率外推、散点到时间块/时间块到散点的迁移，以及不同预测步长下的稳定性；
6. 做完整消融：无掩码条件、无时间间隔、固定时间尺度、固定空间尺度、固定融合、只保留第四章模块等。

**本章是整篇论文的主创新。** 其创新不在于给已有模块取新名称，而在于提出可复核的机制和证据：模型明确利用哪些缺失条件，在何种缺失模式变化下改善了什么指标，以及这种改善是否来自预期模块。

### 第六章 整节点与区域缺失下的时空预测及可信度评估

**目的：** 将研究从局部输入缺失推进到更接近传感器离线和区域故障的强缺失条件。

1. 定义三类场景：随机整节点缺失、空间相邻整节点缺失、区域连续时间块缺失；
2. 在节点无历史观测或历史极少时，利用节点静态属性、物理位置、区域层次与其他节点历史进行预测；
3. 研究节点缺失比例、空间聚集度、区域大小和持续时间对方法的影响；
4. 采用分位数预测、异方差回归或其他已有概率预测方法输出区间；
5. 同时报点预测误差、区间覆盖率、区间宽度和校准性，识别“平均误差相近但风险不同”的条件；
6. 与适配的节点缺失方法、插补后预测流程、第五章模型的直接迁移版本比较。

**本章的边界：** 不需要宣称解决完全无任何外部属性的新节点冷启动。若没有节点属性或可靠空间关系，应如实报告方法局限；研究重点是已知传感器网络中历史观测整体缺失时的预测。

### 第七章 结论与展望

1. 逐项回答 H1–H4，并用“条件—方法—证据—结论”的形式总结；
2. 总结三个方法章节各自的贡献和统一贡献；
3. 讨论数据场景、缺失机制、计算资源和真实缺失可得性带来的局限；
4. 展望真实在线缺失机制、跨城市/跨网络迁移、主动采样、极端事件和更严格的不确定性建模。

## 6. 预期创新点及其证据要求

创新点应是问题、方法和证据的组合，不能只列出模型部件。建议在开题和最终论文中采用以下强度适中的表述。

| 预期创新点 | 方法层面的具体内容 | 最低证据要求 | 不宜作出的表述 |
|---|---|---|---|
| 1. 不完整历史观测下的多尺度空间关系建模 | 综合可用观测、物理邻接和区域层次构建关系，并分析其在不同缺失模式下的作用 | ≥3 个场景/数据集组合；充分图关系消融；配对多种子结果 | “共观测量必然揭示真实因果关系” |
| 2. 缺失模式感知的多尺度时空预测 | 使用掩码、时间间隔和连续缺失长度等条件，选择不同时间与空间表征 | 与固定融合、无条件信息、仅图模块等逐一对照；同分布和模式迁移测试 | “一个模型适用于所有缺失模式且始终最优” |
| 3. 整节点/区域缺失下的跨尺度预测与可信度评估 | 面向节点离线、区域故障进行预测，并给出经校准的预测区间 | 随机/聚集节点与区域块三类测试；误差与校准指标共同报告 | “完全解决无观测新节点问题” |
| 4. 可复现的缺失条件实验协议与实证结论 | 统一数据划分、掩码、基线、统计检验和报告模板 | 公开配置、掩码种子/代码、完整结果表 | 将单一数据集的经验结论写成普适规律 |

其中第 2 点应承担毕业论文最主要的方法创新，第 1 点承接已有论文并扩展，第 3 点体现课题深度，第 4 点使实证结论可信。若第六章的不确定性部分进度不足，可将“可信度评估”保留为实验分析而不单列为创新点，避免空泛承诺。

## 7. 实验设计与复现要求

### 7.1 数据与维度覆盖

| 场景 | 建议数据 | 维度定位 | 作用 |
|---|---|---|---|
| 城市交通 | METR-LA、PEMS-BAY | 中维节点网络 | 与主流时空预测工作可比，适合物理图与时间块缺失 |
| 更大规模交通 | PEMS04、PEMS08（视预处理兼容性选择） | 中高维 | 检验节点规模变化、关系学习成本和方法稳定性 |
| 环境监测 | AQI36 及一个规则、公开、许可清晰的空气质量数据 | 中维至高维，含自然缺失可能性 | 检验交通之外的空间关系及自然缺失场景 |

“低维/中维/高维”应在论文中以节点数、变量数和总输入维度明确报告，而不是只用主观标签。若实际可用数据不足，应诚实将论文定位为中维传感器网络研究，不用未经验证的“高维”描述扩大范围。

### 7.2 缺失协议

1. **散点缺失**：独立随机遮蔽，并报告 10%、30%、50% 等实际缺失率；
2. **连续时间块缺失**：固定与随机块长、不同起点，报告每个节点的连续缺失长度分布；
3. **整节点缺失**：随机抽取节点在历史窗口内全部遮蔽；
4. **空间相邻节点/区域块缺失**：按图邻近或行政/聚类区域选择连续节点，模拟通信区域或局部故障；
5. **自然缺失**：如果数据本身含缺失，单独报告，并将合成遮蔽叠加与否讲清楚；
6. **训练/测试失配**：至少设置缺失率变化、散点→时间块、随机节点→空间聚集节点三种测试。

必须区分“掩码生成机制”和严格统计学意义的 MCAR/MAR/MNAR。若没有真实缺失原因数据，只能称为“模拟的随机/结构化掩码”，不能声称复现了真实 MNAR。

### 7.3 对照与统计

- 对相同任务使用相同的数据切分、输入窗口、预测步长、掩码实例和训练预算；
- 对“插补后预测”流程，固定预测器后分别比较不同插补器，避免把预测器差异归因给插补器；
- 对直接预测模型，与 HD-TTS、BiTGraph、S4M、GinAR 等中能复现且任务匹配的模型比较；整节点任务只与适配节点缺失设定的方法比较；
- 主实验至少 5 个配对随机种子；报告均值、标准差、相对提升、配对显著性检验及多重比较处理；
- 按预测步长、缺失模式、缺失率、节点类别和自然/合成缺失分层报告，不只给总体平均数；
- 保存代码版本、数据下载和处理说明、掩码种子、超参数、硬件和运行时间；任何使用未来真值生成历史输入特征的操作都应禁止。

## 8. 论文贡献的组织方式

建议将最终摘要和答辩中的贡献组织为以下逻辑，而不是列出零散模块：

1. **问题层面：** 明确区分散点、连续时间块、整节点和区域缺失，并建立统一预测任务与评价协议；
2. **方法层面：** 针对局部缺失，研究多尺度空间关系；针对模式变化，研究缺失条件下的多尺度时空表征；针对强缺失，研究节点/区域预测与可信度；
3. **证据层面：** 在交通和环境两个场景、不同规模和缺失模式上做统一实验、严格消融和统计比较；
4. **结论层面：** 给出方法的有效条件与失效边界，而非将局部结果推广为所有缺失时空序列的定律。

这样可使小论文自然成为其中一个章节，也使大论文拥有比单个网络结构更完整的问题深度和实验广度。

## 10. 开题时需要先确认的事项

1. 本校对硕士论文的章节、字数、成果和查重要求；
2. 环境数据的公开许可、站点坐标/图结构可用性以及自然缺失的记录质量；
3. 交通与环境数据能否形成至少三个彼此独立的“场景—数据集”验证组合；
4. HD-TTS、BiTGraph、S4M、GinAR 等基线的代码可得性和任务接口；无法复现的工作可在综述中讨论，但不能作为不公平的实验对照；
5. GPU 预算与五随机种子实验的排期；
6. 是否将预测区间作为第六章正式目标。该决定应以可用计算资源和实现成熟度为依据。
