# 状态空间模型 / Mamba 在缺失数据时空序列预测中的应用与问题

> 文档性质：专题分享稿。
> 内容范围：方法机制、时间序列研究进展、S4M 案例与可验证研究路径。

---

## 1. 研究问题与任务界定

本文讨论**缺失历史条件下的时空序列未来预测**。模型输入为存在缺失的历史窗口，输出为预测起点之后的未来序列。交通、气象和多传感器系统均可能出现随机空缺、连续时间块缺失或部分节点掉线；模型需要联合表征数值内容、观测状态与可利用的关联信息。

| 任务           | 输出目标               | 可使用的信息                   | 与本文的关系                     |
| -------------- | ---------------------- | ------------------------------ | -------------------------------- |
| 历史插补       | 恢复历史片段中的缺失值 | 通常可使用缺失点前后两侧上下文 | 提供缺失表示和不确定性建模方法。 |
| 未来预测       | 预测未来时间段         | 仅可使用预测起点前的信息       | 本文的核心任务。                 |
| 不规则序列建模 | 预测、分类或状态估计   | 观测时间不等间隔               | 为时间间隔条件化提供方法基础。   |

插补与未来预测的关键区别在于可见信息范围。两类任务可以共享方法组件，但其误差不能直接横向比较。

## 2. SSM、S4 与 Mamba 的相关机制

离散状态空间模型以内部状态压缩历史信息：

$$
h_t = \bar{A}h_{t-1}+\bar{B}x_t, \qquad y_t=Ch_t+Dx_t.
$$

其中，$x_t$ 为输入，$h_t$ 为历史状态，$y_t$ 为输出。S4 通过结构化状态矩阵和高效核计算扩展了长序列状态建模能力；S5 将状态空间层推广至多输入多输出场景。[S4, ICLR 2022](https://arxiv.org/abs/2111.00396) [S5, ICLR 2023](https://mlanthology.org/iclr/2023/smith2023iclr-simplified/)

Mamba 在选择性状态空间模型中引入输入相关的参数，使模型能依据当前输入调节历史状态的信息保留与更新，并以硬件感知扫描保持线性序列复杂度。[Mamba, COLM 2024](https://arxiv.org/abs/2312.00752)

对于缺失时空预测，状态空间类模型的应用与设计主要在于三点：

- **缺失期间的历史状态如何变化**：模型已从过去学习到趋势、周期和突变信息；连续缺失后，需要结合缺失时长判断这些记忆应保持、逐渐减弱，还是由其他可靠信息修正。
- **模型如何识别缺失而非真实数值**：除数值外，还应输入 mask、距上次真实观测的时间和观测可靠性，使模型能够区分真实观测、缺失位置及不同长度的缺失。
- **如何利用其他可靠信息**：目标变量或节点缺失时，可利用仍有观测的关联变量、邻近节点或相似历史模式辅助预测；辅助信息不可靠时，应避免其传播误差。

SSM/Mamba 提供状态更新与高效序列计算机制；缺失信息仍需要通过显式条件输入表示。S4M 使用的是 S4 结构，而非 Mamba。[S4M, ICLR 2025](https://arxiv.org/abs/2503.00900)

## 3. 时间序列研究中的 SSM / Mamba 应用进展

现有研究可按任务目标、建模对象与历史观测条件划分为五类。该图谱用于明确不同论文能够支撑的结论，以及其与缺失历史预测的距离。

| 应用类型         | 主要建模对象             | SSM / Mamba 的作用                       | 代表工作                 | 对缺失时空预测的价值                     |

| 时间维长序列预测 | 历史时间步及长程依赖     | 长历史压缩、多步递推、局部—全局时间融合 | SpaceTime、TimeMachine   | 提供预测时间主干；通常以完整历史为输入。 |

**小结。** SSM/Mamba 已覆盖长期预测、变量关系、图时空依赖、缺失预测和插补。直接以“缺失历史 → 未来预测”为主任务的工作相对较少，S4M 是最具代表性的正式发表案例。

## 4. S4M 的方法机制与研究边界

S4M 的目标是：给定一段带缺失的多变量历史序列，直接预测之后的未来窗口。作者认为，先插补、再预测的两阶段流程可能将插补误差传递给预测器；因此，S4M 将缺失处理与未来预测整合在同一个端到端模型中。[S4M, ICLR 2025](https://arxiv.org/abs/2503.00900)

模型由两部分构成：**ATPM 负责从历史中寻找相似模式，MDS-S4 负责同时利用数值和缺失状态递推历史记忆。**

### 4.1 ATPM：从历史中检索相似时间模式

ATPM 可以理解为一个持续更新的“历史模式库”。当某个时刻的信息不完整时，模型先提取其局部统计特征，例如最近一次有效观测值、距离最近一次有效观测的时间，以及附近短窗口的变化情况。单个时间点的信息不足以判断模式时，模型会使用一小段局部统计序列形成查询。

该查询会在原型库中检索最相似的若干历史模式，并按相似度加权得到一个辅助表征。原型库中的内容不是原始观测值，而是编码后的模式表征；训练过程中，相似的新模式进入已有队列，明显不同的模式形成新类别，过时模式通过先进先出队列逐渐淘汰。

ATPM 的作用是回答：**当前这段不完整历史更接近过去出现过的哪一类变化模式。** 它提供模式级上下文，不是逐点恢复真实缺失值的插补器。

### 4.2 MDS-S4：观测值与 mask 的双信息流

ATPM 输出数值与模式融合后的表征 $o_t$。MDS-S4 在普通 S4 的状态更新中增加 mask 信息流：

$$
h_t=\bar{A}h_{t-1}+\bar{B}o_t+\bar{E}E_m(m_t),
$$

$$
y_t=Ch_t+Do_t+F E_m(m_t).
$$

其中，$h_t$ 是历史状态，$o_t$ 是数值与模式形成的表征，$m_t$ 是当前位置的观测 mask，$E_m(m_t)$ 是 mask 的嵌入表示。

普通 S4 主要依据数值更新状态；MDS-S4 还会读取当前位置是否真实观测到数据。因此，模型能够区分真实数值、缺失位置的占位信息和不同持续时间的缺失。论文仍保留 S4 的卷积计算方式，因此双信息流不会放弃其长序列计算优势。

### 4.3 从输入到预测的完整流程

| 步骤 | 处理内容                                                  | 作用                                       |
| ---- | --------------------------------------------------------- | ------------------------------------------ |
| 1    | 输入带缺失的历史值及其 mask。                             | 区分数值内容与观测状态。                   |
| 2    | ATPM 从局部统计特征构造查询，并在原型库检索相似时间模式。 | 为局部信息不足的缺失片段提供历史模式参考。 |
| 3    | 将局部统计、查询表征和检索原型融合为 $o_t$。            | 得到更稳健的数值表征。                     |
| 4    | MDS-S4 同时读取 $o_t$ 和 mask，递推状态并输出未来预测。 | 将数值变化与缺失状态共同纳入预测过程。     |

其核心流程可概括为：**不完整历史 → 相似模式辅助 → 数值流与 mask 流共同更新状态 → 未来预测。**

### 4.4 实验设计

该论文在 Electricity、ETTh1、Weather、Traffic 四个公开多变量数据集上实验。由于这些基准原始数据通常完整，作者在训练和测试数据上人为构造连续块缺失。

| 缺失协议   | 构造方式                                                        | 对应的现实含义                                     |
| ---------- | --------------------------------------------------------------- | -------------------------------------------------- |
| 时间点缺失 | 随机选择时间点，并将其后连续 5 个时间点的所有变量同时置为缺失。 | 一个系统在某段时间内整体无法记录数据。             |
| 变量缺失   | 对每个变量独立执行同样的连续块缺失过程。                        | 部分变量或传感器离线，其他变量在同一时刻仍可观测。 |

论文设置的缺失率参数为 0.03、0.06、0.12、0.24；预测长度固定为 96，历史窗口长度取 96、192、384、768。实验同时考察缺失比例增加和历史窗口变长时的预测表现。

消融实验的结论是：移除 mask 输入后，多数设置中的 MAE 与 MSE 上升；移除 ATPM 后，性能同样下降，在 Traffic 和 ETTh1 等设置中更为明显。该结果支持 mask 信息流和模式检索模块具有互补作用。

### 4.5 S4M 的贡献与研究边界

| S4M 已完成的工作                     | 尚未充分覆盖的设定                         | 对后续工作的含义                            |
| ------------------------------------ | ------------------------------------------ | ------------------------------------------- |
| 让 mask 直接进入状态更新与预测读出。 | 节点掉线、时空连片故障及空间邻居同步失效。 | 需要进一步评估空间支持的可靠性。            |
| 从历史原型库中检索相似模式辅助预测。 | 训练与测试缺失机制变化。                   | 需要比较已见与未见缺失模式下的预测稳定性。  |
| 在连续时间块缺失下端到端预测未来。   | 长缺口下状态衰减、间隔编码与预测可信度。   | 可在同一骨干下比较 mask、间隔和可靠性条件。 |

S4M 是多变量缺失时间序列预测模型，并非时空图预测模型。它没有显式使用道路拓扑、区域邻接关系或传感器图，因此没有研究空间邻居可靠性、节点掉线和时空连片故障。论文的主要缺失模式也是人工构造的连续时间块，尚未系统评价复杂真实故障机制或训练—测试缺失模式转移。

MAS-Mamba 已将 mask 与时间间隔用于缺失交通预测，因而“仅增加 mask／间隔条件”不宜作为独立贡献；更有价值的方向是严格验证其在未见结构化缺失下的泛化。[MAS-Mamba, IET ITS 2026](https://doi.org/10.1049/itr2.70304)

## 5. 研究问题与实验路径

### 5.1 核心问题：未见结构化缺失模式下的预测稳定性

S4M、HD-TTS 和 BiTGraph 均在预先定义的缺失协议下评价模型。[S4M, ICLR 2025](https://arxiv.org/abs/2503.00900) [HD-TTS, ICML 2024](https://arxiv.org/abs/2402.10634) [BiTGraph, ICLR 2024](https://openreview.net/pdf?id=O9nZCwdGcG) 一般缺失机制转移研究指出，源缺失机制下的模型排序可能无法迁移至目标缺失机制。[Robust Prediction under Missingness Shifts, 2024](https://arxiv.org/abs/2406.16484)

| 环节         | 设计                                                          |
| ------------ | ------------------------------------------------------------- |
| 数据         | 公开时空数据集，如 METR-LA、PEMS-BAY；可补充 PEMS04、PEMS08。 |
| 训练缺失机制 | 随机点缺失或固定长度时间块缺失。                              |
| 测试缺失机制 | 更长时间块、节点掉线、时空连片缺失及其组合。                  |
| 同骨干对照   | 零／前向填充、mask 嵌入、时间间隔编码、可靠性衰减。           |
| 报告方式     | 分别报告已见模式和未见模式，并按缺口长度与预测步长分层。      |

该协议检验状态条件编码是否仅适用于训练分布内的 mask，或能够提升面对未见结构化缺失时的预测稳定性。

### 5.2 方法切入：长缺口条件下的状态更新

在统一预测骨干中，仅替换状态条件方式：mask 嵌入、距上次观测的间隔编码和可靠性衰减。此消融用于识别不同条件信息在长缺口、不同预测步长和不同空间支持比例下的实际作用。

节点序列化顺序、复杂多图补偿和概率生成作为后续扩展问题，不纳入当前工作的主线。

---

## 6. 结论

1. SSM、S4 与 Mamba 为长历史压缩和输入条件状态更新提供了高效机制，但缺失信息需要显式建模，这是重点。
2. 时间序列中的 SSM/Mamba 研究已覆盖长期预测、变量关系、图时空依赖、缺失预测与插补；其中 S4M 是最直接的缺失历史未来预测案例。
3. 当前最有价值的研究问题是：1.在S4M的研究路径上加入空间信息从而改为时空预测，2.训练测试数据上的缺失不一致问题：在训练与测试缺失机制不一致时，状态条件编码能否稳定提升时空未来预测性能。
