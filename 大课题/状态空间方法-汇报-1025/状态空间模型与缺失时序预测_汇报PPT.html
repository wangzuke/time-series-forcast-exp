文献调研汇报｜缺失数据条件时空序列预测

状态空间模型 / Mamba
在缺失数据时空序列预测中的应用与问题

从跨领域机制、时序应用与 S4M 案例，到可验证研究问题

问题

历史窗口不完整，但任务仍是预测未来；数值、观测状态与空间支持需共同建模。

重点

状态空间 / Mamba 在时间序列中已经怎样使用？哪些证据可迁移到缺失时空预测？

边界

区分未来预测、历史插补与不规则采样；不将跨领域结果直接外推为交通预测性能。

直接问题证据：[R13] S4M, ICLR 2025；[R17] HD-TTS, ICML 2024；[R18] BiTGraph, ICLR 2024

02 / 09
基础机制

状态更新提供长历史压缩；选择性提供输入条件的信息流

hₜ = Āhₜ₋₁ + B̄xₜ
yₜ = Chₜ + Dxₜ

三层演进

普通 SSM：固定状态更新规则。

S4：结构化状态矩阵与高效核计算，支持长序列建模。

S5：多输入多输出状态空间层与并行扫描。

Mamba：步长、输入/输出投影随当前输入变化，并以硬件感知 scan 执行。

长状态

用状态承接长历史。

缺失长区间内：状态应保持、衰减，还是由可靠邻居校正？

选择性

当前输入影响信息流。

mask、距上次观测间隔是否应成为状态条件？

扫描

token 按一条路径进入递推。

时间天然有序；变量/节点为何按某一顺序扫描？

选择性 ≠ 自动感知缺失。没有显式 mask 或时间间隔，模型并不能保证把零填充值识别为不可观测值。S4M 使用 S4，而不是 Mamba。
[R1] S4, ICLR 2022；[R2] S5, ICLR 2023；[R3] Mamba, COLM 2024；[R13] S4M, ICLR 2025
03 / 09
跨领域证据 → 时空迁移

跨领域工作提供四类设计约束，而不是可直接照搬的网络

领域与原始论文状态空间方法怎样发挥作用到缺失时空预测的对应迁移不能直接外推的部分
长 token 序列
S4 [R1]		结构化状态矩阵与高效卷积核，在长依赖任务上验证长序列能力。沿时间维承担长历史窗口与长预测步的记忆主干。长程基准结果不等于在交通或缺失历史下自动更准。
语言 / DNA
Mamba [R3]		selective SSM 使部分参数依输入变化；硬件感知 scan 维持线性序列处理。突发变化、观测状态、时间间隔可成为影响状态更新的条件。输入选择性不等于已解决传感器缺失。
二维视觉
Vision Mamba / VMamba [R4][R5]		双向 SSM 编码视觉 token；四向二维 scan 减少二维网格串行化的方向偏置。比较拓扑遍历、社区排序、随机排序和双向节点路径。图像网格、非因果双向扫描不能照搬到未来预测。
图学习
Graph Mamba [R7]		邻域 token 化 → token 排序 → 双向 SSM 编码 → 局部编码。“节点如何成为序列”与“局部图信息如何保留”是两个独立设计问题。不是缺失交通预测；目标数据上必须重验。
医学影像 / 音频
U-Mamba / SaShiMi [R6][R8]		局部卷积或多尺度结构保留局部细节；SSM 汇聚长程依赖。短时突变与长期周期可由局部模块和状态模块分工。仅支撑结构假设，不支撑时空预测性能。
不规则医疗序列
CRU [R15]		连续时间状态与卡尔曼式更新处理不规则观测及不确定性。距上次有效观测的时间可作为状态更新条件。主任务并非缺失历史下多步交通预测。
四个可检验原则：时间维可使用长状态；空间维必须说明扫描路径；局部变化与长程传播可分工；缺失/不规则观测要进入状态更新条件。
[R1][R3] 基础机制；[R4][R5][R7] 路径与结构证据；[R6][R8][R15] 局部—全局与不规则更新启发。迁移的是机制约束，性能需由时空预测实验验证。

时间序列研究图谱

状态空间 / Mamba 在时序领域的已有应用：按任务与扫描轴分类

正式发表、直接相关插补或预印本，保留任务边界摘要级证据

① 时间维长预测

时间扫描完整历史为主

SpaceTime｜ICLR 2023 [R9]

向量状态空间闭环演化，面向多步预测。

TimeMachine｜ECAI 2024 [R10]

多组 Mamba 分别处理局部、全局、通道独立与通道混合。

② 变量 / 通道关系

变量扫描多变量预测

S-Mamba｜Neurocomputing 2025 [R11]

沿变量维而非时间维执行 Mamba 扫描。

CMamba / MambaTS｜2024 / 2026 [R12]

增强通道相关性或采用变量感知扫描。

③ 图时空预测

节点与时间预印本

STG-Mamba｜2024 [R23]

将 selective SSM 用于时空图依赖建模。

说明 Mamba 已进入图预测；其设定并非缺失历史主任务。

④ 缺失 / 不规则观测

直接预测插补

S4M｜ICLR 2025 [R13]

mask 进入 S4 状态层，时间模式原型辅助预测。

MAS-Mamba｜IET ITS 2026 [R19]

mask 与间隔条件化交通预测；摘要级证据。

SSSD / TIMBA / CRU [R14][R16][R15]

插补或不规则更新：可借鉴，不能替代因果预测结果。

结论：时序 SSM/Mamba 已从时间维长预测扩展到变量关系、图时空依赖、缺失历史与不规则观测；直接将“历史缺失 → 未来预测”作为主设定的工作仍较少。
SSSD、TIMBA 以插补为主，常可利用未来上下文；不能与因果预测误差直接比较。[R14][R16]　HD-TTS、BiTGraph 非 SSM/Mamba，不在本页展示。

直接案例｜S4M

S4M：把“是否观测到”送入状态空间层，而不是先补全再预测

不完整历史值 oₜ
→
局部统计查询
→
ATPM 原型检索
观测 mask mₜ
→
mask 嵌入 Eₘ(mₜ)
→
MDS-S4 状态更新
→
未来预测
hₜ = Āhₜ₋₁ + B̄oₜ + ĒEₘ(mₜ)
yₜ = Chₜ + Doₜ + F Eₘ(mₜ)

mask 以独立输入/输出通道进入状态更新与读出：区分“数值内容”和“是否可观测”。这不是声称 Ā 本身随 mask 任意变化。

ATPM 做什么？

局部统计生成查询 → 原型库检索相似时间模式 → 形成辅助表征 → 与 MDS-S4 融合。它提供模式级上下文，不是逐点恢复真实缺失值。

论文的直接设定

多变量未来预测；历史窗口已缺失。核心协议：所有变量同步的时间块缺失，以及各变量独立的时间块缺失。

数据：Electricity、ETTh1、Weather、Traffic，附录含 USHCN。

从范围出发的可改良设定

  • 节点掉线、时空连片故障、训练—测试缺失机制变化。[R17][R18][R20]
  • 道路拓扑、可观测邻居可靠性与节点扫描顺序。[R7]
  • 同骨干下比较 mask 嵌入、间隔编码与可靠性衰减。
  • 长缺口下置信度是否随信息减少而合理变化。[R15][R19]
避免将“缺失门控离散化 + 原型记忆”包装成新点；MAP-SSM 已与此组合近似。[R21]
核心来源：[R13] Peng et al., S4M, ICLR 2025。第 6 页先说明其方法与已验证范围，再从覆盖范围导出可检验的扩展设定。
06 / 09
可验证研究问题

先验证机制外泛化与顺序敏感性，再决定是否增加复杂模块

问题 1｜未见结构化缺失

文献事实：S4M、HD-TTS、BiTGraph 都在预设缺失协议内评价；缺失机制转移可能改变模型排序。[R13][R17][R18][R20]

实验：训练仅见一种或两种机制；测试改变块长度、节点掉线、时空连片缺失及其组合。

成功标准：同时报告已见与未见模式；只在随机 mask 提升不能称为机制外鲁棒。

问题 2｜节点扫描顺序

文献事实：VMamba、Graph Mamba 显式设计路径/排序；S-Mamba 表明扫描轴会改变建模对象。[R5][R7][R11]

实验：固定时间模块与参数量，仅换节点 ID、随机、拓扑遍历、谱/社区、双向顺序。

衡量：误差、置换方差、节点置换后输出变化、训练/推理延迟。

问题 3｜长缺口状态条件

文献事实：S4M 用 mask；MAS-Mamba 提及 mask/间隔；CRU 建模连续时间间隔。[R13][R15][R19]

实验：在同一骨干只替换 mask 嵌入、间隔编码、可靠性衰减；按缺口长度、预测步和邻居可见率分层。

边界：避免与 MAP-SSM 的门控离散化 + 原型组合重复。[R21]

① 统一缺失协议与基线
→
② 节点顺序低成本诊断
→
③ 再决定是否修改状态条件
一周内优先完成问题 1，再完成问题 2 的诊断。端到端插补—预测、复杂多图补偿、完整概率生成的实现成本高且与 TIMBA、ACSC-GCRN、MAP-SSM 存在近邻重叠风险。[R16][R21][R22]

总结与下一步

状态空间模型是工具；论文价值取决于是否验证了具体问题

01｜机制

S4、S5、Mamba 分别提供长状态、高效多变量状态层和输入条件选择；它们不自动解决缺失。

[R1][R2][R3]

02｜迁移

路径、局部—全局分工和观测间隔是迁移到时空预测时必须明确的设计约束。

[R4]–[R8][R15]

03｜案例

S4M 直接证明：mask 条件状态层与模式辅助信息可用于缺失历史下的未来预测。

[R13]

04｜小工作

先建立公开、可复现的跨模式缺失协议，再以同骨干消融验证一个状态条件设计。

[R17][R18][R20]

下一步不是直接提出复杂网络：先完成统一协议、基线和两个诊断实验；只有稳定问题被观察到，方法改动才有明确的问题支撑。
