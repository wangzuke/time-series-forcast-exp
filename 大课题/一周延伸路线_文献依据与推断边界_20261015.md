# 一周延伸路线的文献依据与推断边界

核查日期：2026-10-15。对应[一周方案](一周延伸研究方案_20261015.md)。

## 1. 修正结论

此前提案的直接起点是已有消融和代码行为，尚未给出充分的“文献—问题—具体方法”依据。现在可以确认：

- 研究缺失条件下的图关系建模具有直接文献支撑。
- 关注观测数量与关系估计质量具有统计研究依据，但经典假设与本任务不一致。
- “共同观测对数项过度影响 top-k，进而损害预测”仍是针对当前模型的待验证机制。
- “对共同观测次数加一就能改善预测”没有已核实的直接文献证据；不能据此称为可靠的独立论文方案。

因此，保留问题方向，把加性平滑降为诊断对照。若只得到数值稳定性修正，应合入原论文；只有新机制和跨条件证据成立，才进一步判断独立论文价值。

## 2. 直接相关的近年文献

### R1. GCN-M：缺失条件下的动态图关系学习

Jingwei Zuo, Karine Zeitouni, Yehia Taher, Sandra Garcia-Rodriguez. **Graph convolutional networks for traffic forecasting with missing values.** *Data Mining and Knowledge Discovery*, 37, 913–947, 2023（2022-12在线发表）。[出版方全文](https://link.springer.com/article/10.1007/s10618-022-00903-7)。

- 原文内容：联合考虑复杂缺失与预测，结合局部时空特征、全局历史记忆，并由这些特征构建动态图。
- 支撑：缺失处理与关系学习应共同考察；值得检查原模型如何使用不完整历史建立关系。
- 不支撑：共同观测惩罚一定有害、必须做计数平滑、该方案尚无人研究。
- 阅读证据：本地原文摘要、引言及贡献；出版方全文与正式书目。

### R2. GinAR：变量缺失引起时空依赖建模问题

Chengqing Yu et al. **GinAR: An End-To-End Multivariate Time Series Forecasting Model Suitable for Variable Missing.** *KDD 2024*, 3989–4000. DOI: 10.1145/3637528.3672055。[作者论文](https://arxiv.org/abs/2405.11333)，[作者正式稿](https://finleywang.github.io/files/2024_KDD_GinAR.pdf)。

- 原文内容：针对变量缺失，使用插值注意力与自适应图卷积恢复/建模时空依赖。
- 支撑：输入缺失导致的依赖建模问题是已有明确研究问题；图关系利用是合理研究入口。
- 不支撑：变量缺失实验与本项目时间块缺失完全等价；其结果证明 q 的函数应当如何设计。
- 阅读证据：本轮作者摘要、正式稿题名/会议信息与作者仓库；此前逐篇调研记录。

### R3. HD-TTS：缺失模式参与时空信息使用

Ivan Marisca, Cesare Alippi, Filippo Maria Bianchi. **Graph-based Forecasting with Missing Data through Spatiotemporal Downsampling.** *ICML 2024*, PMLR 235, 34846–34865。[官方论文页](https://proceedings.mlr.press/v235/marisca24a.html)。

- 原文内容：时间和空间逐级下采样，依据观测和缺失模式融合多尺度表示，在多种缺失分布中评测。
- 支撑：复用原多尺度骨干、固定其他模块，研究关系约束的作用，具有可比性和实现基础。
- 不支撑：缺失感知门控、多尺度融合本身是本次新贡献；该文支持我们的具体平滑公式。
- 阅读证据：本轮官方摘要，沿用此前全文与现有代码核查。

## 3. 统计与方法论支撑：明确属于间接依据

### R4. Lounici：缺失观测下的协方差估计

Karim Lounici. **High-dimensional covariance matrix estimation with missing observations.** *Bernoulli*, 20(3), 1029–1058, 2014. DOI: 10.3150/12-BEJ487。[作者原文](https://arxiv.org/pdf/1201.2577)。

- 研究高维协方差估计，给出缺失情况下的估计误差界及下界。原文的独立观测、独立Bernoulli缺失模型下，缺失会增加达到同等估计精度所需的样本量。
- 支撑：在使用关系估计时，需要考虑观测证据规模；不能默认极少共同样本形成的关系同样可靠。
- 严格边界：本文处理协方差，当前模型处理学习到的 query/key 相似度；本文使用独立样本与独立缺失，本任务有时间相关和连续缺失。不能把该文定理直接写成我们模型的理论保证。
- 更需区分：窗口 q 本身是由 mask 精确计算的统计量，并不是“算错的共同观测率”。真正待研究的是将 q 映射为关系置信/边惩罚的合理性。
- 原文定位：Sec.1 的式(1.1)及独立性条件；Sec.3 的 Remark 3 对缺失概率与样本量的讨论。

### R5. Ledoit–Wolf：有限样本关系估计的收缩

Olivier Ledoit, Michael Wolf. **A well-conditioned estimator for large-dimensional covariance matrices.** *Journal of Multivariate Analysis*, 88(2), 365–411, 2004. DOI: 10.1016/S0047-259X(03)00096-4。[出版记录与摘要](https://doi.org/10.1016/S0047-259X(03)00096-4)。

- 原文提出样本协方差与单位阵的收缩组合，在其设定与二次损失下研究估计精度和条件性。
- 只能启发“证据有限时，用先验/正则约束关系估计”的一般思路；不证明本项目加性平滑最优，也不证明向物理图收缩必然改善预测。
- 当前旧模型已有物理图与观测图门控融合，简单增加收缩融合也可能与原方法重复。
- 阅读证据：本轮出版摘要与作者论文搜索摘录；未完整复核证明，不援引具体定理。

### R6. Chen–Goodman：平滑是已有技术，但并不天然有效

Stanley F. Chen, Joshua Goodman. **An Empirical Study of Smoothing Techniques for Language Modeling.** *ACL 1996*, 310–318. DOI: 10.3115/981863.981904。[官方原文](https://aclanthology.org/P96-1041.pdf)。

- 原文Sec.2介绍加性平滑，Sec.4.2.2比较plus-one/plus-delta；Sec.5报告加性平滑在其比较中表现较差。
- 支撑：稀疏计数和零计数有成熟的处理方法，平滑不是我们发明的概念。
- 不支撑：语言模型平滑结果可直接迁移到时空图预测；加一法值得作为核心创新或性能有保证。
- 原方案的 (n+a)/(T+a) 也不是该文的语言模型类别概率公式，更不能直接称为标准对称Beta先验的后验均值。
- 此文作为方法出处和反向约束，不作为本研究领域的直接效果证据。它的负面结果也不意味着平滑在我们任务中必然失败。

R4—R6是基础方法参考，不计入近五年任务相关论文的主要覆盖，更不能替代R1—R3这类直接文献。

## 4. 本地证据在整个依据链中的位置

[0910消融](../missing_ts_exp/docs/0910实验报告_METRLA_BlockT机制消融.md)显示70%块缺失下去掉共同观测打分惩罚的MAE更低，但50%条件下完整模型均值略优。它支持复核适用条件，不能单独证明对数形式是原因。

[0917同版控制](../missing_ts_exp/docs/0917实验报告_METRLA_BlockT50协议闭环.md)没有显示Full相对Permuted-Q的显著MAE优势。这要求我们保留“q并非主要收益来源”“其他模块补偿”等竞争解释。

当前代码中从q=0到q=1/24的对数偏置差约10.64，是数值事实；是否压过学习分数、改变了哪些边以及是否损害预测，都尚待诊断。若一行q完全相同，其偏置不会改变top-k/softmax，不能用全局q较小来证明机制。

完整依据链应为：

**直接文献提出缺失影响依赖建模的问题 → 统计文献提示有限观测的关系估计需谨慎 → 本地实验发现约束收益随条件变化 → 诊断区分数值形式、正则强度与q语义的作用 → 才选择并验证方法。**

## 5. 对一周方案的实际修改

1. 前两天只做机制诊断与同版小规模复核；加性平滑、删除惩罚、减弱惩罚为并列候选。
2. 若收益可由调整epsilon或减弱正则完全解释，优先修正原论文，不将其改名为新工作。
3. 若关系证据不足问题稳定存在，且某项设计超出简单替代，需要再依据精确机制核查最近邻文献，然后判断是否值得投入完整主实验。
4. 每个后续idea都记录四栏：具体主张、原始文献及段落、适用假设、需要我们验证的新增部分。不用论文数量代替论证强度。

本轮没有启动训练，也没有证明新方法有效。当前最准确定位是：**文献支持的问题方向，加上待验证的局部方法假设。**
