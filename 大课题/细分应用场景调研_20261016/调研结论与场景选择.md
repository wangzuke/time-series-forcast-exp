# 细分应用场景调研与小课题选择

> **当前选题已修订：** 用户要求以现有公开数据集为边界，避免将主任务限定到过细业务现象。请优先阅读[基于公开数据集的场景修订](/media/data1/wangzk/time-series-forcast-exp/大课题/细分应用场景调研_20261016/基于公开数据集的场景修订.md)。本文的文献和数据审计继续有效；下文“高浓度低估、3—6小时重点、趋势辅助分支”等保留为上一版候选思路，尚未选定为主任务。

调研日期：2026-10-16。用途：在已有 DRR-MSGF 工作基础上，为约一周的延伸研究选择具体应用问题。本文件更新此前“仅收缩缺失形式”的选题建议，保留旧文档作为讨论记录。

## 1. 选择建议

**优先开展：城市中小规模空气质量监测网中，历史观测不完整条件下的站点级短期 PM2.5 浓度预测；重点检查未来 3—6 小时高浓度时段的预测低估。**

这里先确定应用问题，不预定论文名称，也不预设某个新模型一定有效。完整任务可以用一句话表达：

> 同一城市的十几个至几十个固定监测站，每小时更新一次 PM2.5；当部分站点近期记录不足时，利用本地历史和其他站点已到达的观测，预测各站未来六小时浓度，并检验高浓度过程是否被过度低估。

推荐顺序是：**上述空气质量场景 → 城市停车场营业时段占用率预测 → 小型多站光伏超短期预测**。这是一周约束、既有代码、可取得数据与应用区分度共同决定的排序，不是各领域学术价值排名。空气质量已有直接相关研究，不能宣称它是研究空白。真正待验证的是上述细分问题及一个有针对性的改进能否成立。

## 2. 本轮怎样调研

以 2021—2026-10-16 的应用研究为范围，近五年为主，同时复核此前调研中的风电、空气质量论文。通过网络检索进入出版社、期刊官网、arXiv 和官方数据仓库，使用英文与中文检索词，覆盖停车、空气质量、光伏/风电、负荷、水质、金融六类领域。

检索组合包括：应用词（parking occupancy / PM2.5 / photovoltaic / building load / salinity / wastewater / financial returns）与 missing data、forecasting、hour-ahead、imputation；再按具体题名回查方法、数据和预测跨度。补充检索“缺失数据 空气质量 短期 预测”“数据缺失 停车 预测”“缺失数据 水质 预测”等中文组合。

共整理 **24 个场景比较条目和 3 个边界条目**。24 个条目包含直接缺失预测研究、应用背景和相近任务，并不意味着全部是严格的缺失条件未来预测。未能获取全文的条目明确标 B，不补猜站点数、跨度或数据开放情况。检索返回记录只保存了部分调用，因此不虚构检索命中总数或 PRISMA 筛选数字。

这是一轮服务选题的定向范围调研，不是穷尽全部数据库的系统综述。依据 literature-review skill 的检索、提取和证据分级流程执行；本轮使用内置网络搜索。图表来自原始数据审计，未使用无法核验数据的示意性效果图。

完整逐篇分类见：[论文场景证据表](/media/data1/wangzk/time-series-forcast-exp/大课题/细分应用场景调研_20261016/论文场景证据表.md)，另有同名 CSV/JSON，可继续补充。

## 4. 横向比较：为什么这样排序

| 候选场景 | 可做的具体任务 | 数据及维度 | 与旧模型衔接 | 当前主要阻力 | 本轮判断 |
|---|---|---|---|---|---|
| 空气质量 | 既有站点未来 1—6h PM2.5；关注缺观测时的高浓度低估 | 12/36 站；每站 1 目标；小时 | 高：已有 AQI36 适配和坐标 | 场景本身已有研究；旧模型在自然缺失下未显出优势 | **主推；先诊断再开发** |
| 城市停车 | 营业时段未来 30/60min 占用率；传感记录不足时接近满位的误差 | 小规模停车场群；占用率单通道 | 中：可复用时序模块；空间关系要核实 | 公开样本短、ID需清理、缺坐标、夜间无记录 | **备选一；资料补齐后再推进** |
| 分布式光伏 | 白天未来 15/30/60min 功率；少量电站观测缺失 | 小型站群、功率与天气 | 中：图方法可用，数据接口重做 | 站点位置、容量和天气预报要匹配；真实零功率不能当缺失 | **备选二；已有可用数据时可升优先级** |
| 建筑/区域负荷 | 1h 负荷、天气传感器缺失或未见建筑 | 每建筑少量变量；建筑数不等于联合维度 | 中低：跨建筑问题需要改协议 | 邻接意义与原模型不同；时间/实体双重切分 | 有应用价值，一周内迁移不优先 |
| 河流/湖泊水质 | 24/48h 盐度或下一采样期透明度 | 少量站点/变量，或不规则观测 | 中低 | 原始水文数据、潮汐/流向知识、目标跨度要统一 | 问题最具体之一，但当前准备不足 |
| 金融 | 月度收益与缺失公司特征 | 159 特征可为高维；非地理站点 | 低 | 因子可用日期、授权、时间泄漏及市场评价 | 与现有时空监测主线衔接弱，暂不选 |

金融研究还提供一个有用反例：复杂插补并不必然带来更好的下游预测，因此不能以“加入更高级插补器”为默认贡献。[Chen 与 McCoy，2024](https://doi.org/10.1016/j.jfineco.2024.103815)

维度口径：同时记录节点数 N、每节点动态物理变量数 C、联合原始维度 N×C；时间窗口长度、衍生特征数另列。本文描述性地把 D≤10、11≤D≤100、D>100 称为低/中/高维，这只是整理约定，不是通行学术标准。推荐任务的每站 C=1，联合 D=12 或 36，属于中维；不能因每站只有一种污染物便称整个任务单变量。

## 5. 数据可行性已做什么核查

本轮除核对官方说明，还下载了 UCI 北京多站空气质量与 Birmingham 停车数据用于原始数据审计。审计只读取、统计和画图，没有插补或训练模型。可复现脚本为 [audit_public_data.py](/media/data1/wangzk/time-series-forcast-exp/大课题/细分应用场景调研_20261016/audit_public_data.py)，完整统计和 SHA256 见 [数据可用性审计.json](/media/data1/wangzk/time-series-forcast-exp/大课题/细分应用场景调研_20261016/数据可用性审计.json)。

### AQI36：可立即做诊断，不能再当全新独立验证集

本地 `pm25_ground.txt` 为 8759×36，时间从 2014-05-01 01:00 到 2015-04-30 23:00，小时索引连续。原始空值约 **13.247%**，不同站点约 **6.268%—21.247%**。这说明站点观测可用性确实不同，但原始文件不能确定每处缺失究竟来自设备故障、维护还是其他原因。

仅在前 70% 时间段做描述统计：以历史 24 小时有效观测不超过一半为“观测不足”，以该站训练段浓度 90% 分位数为“高浓度”，在 t+6h 有真实标签的位置，两者交集有 **1905 个站点—预测起点样本**。它们包含重叠窗口，不是 1905 个独立污染事件。这个结果只说明值得继续诊断，不说明模型存在系统低估或改进一定有效。

原有 AQI36 报告采用 24→12 设置，自然缺失下 DRR-MSGF/MR-MSGF 的 MAE 为 30.7269，HD-TTS-AMP 为 30.4839；其差异不能直接推断本次 3/6h 子任务效果。已有空气质量结果并非全面占优，这是需要保留的负面证据。[旧实验报告](/media/data1/wangzk/time-series-forcast-exp/missing_ts_exp/docs/0910实验报告_AQI36自然缺失与Point验证.md)

### UCI Beijing Multi-Site：建议作为新的主要时间外验证来源

官方数据为 12 个固定监测站、2013-03 至 2017-02 的逐小时记录，包含六项污染物和六项气象变量，并保留 NA。第一阶段只选择 PM2.5 通道，保持现有模型输入改动较小。[UCI 官方说明](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data)

下载后实际核验得到 **35064×12** 的 PM2.5 矩阵，小时索引连续，原始缺失 **2.077%**，站点间约 **1.089%—2.718%**。最长单站连续缺口为343小时。整体缺失率低和个别连续缺口长可以同时出现；额外高缺失率实验只能称压力测试，不能写成这份数据普遍存在的真实情况。

建议切分为：2013-03—2015-12 训练，2016-01—06 验证，2016-07—2017-02 测试；最终以数据审计与方案冻结记录为准。AQI36 与它同属北京且历史时段有重叠，不能称为两个独立城市验证。新的后期测试段可以增加时间外证据，但不证明跨城市泛化。

UCI CSV 没有直接给出可用的站点经纬度表。复用物理图需要另核对站点坐标及名称；如果不能及时核实，可先做掩码感知时间模型和训练段学习图，但不能把相关性图写成真实物理拓扑。这里是实质工作量，不作“下载即跑通”的承诺。

### Birmingham：场景新，但原始数据比看上去复杂

已下载的官方 CSV 有 **35717 行、30 个不同 ID**，每个 ID 记录数为 88—1312，覆盖约两个半月，记录时刻集中于 07—16 时。30 个 ID 还没有验证为 30 个相互独立停车场；不能直接照抄文献中经筛选后的 27/29 等数量。CSV 无空单元格，也不意味着重采样后的时间网格完整。文件中没有坐标列。[UCI 官方数据](https://archive.ics.uci.edu/dataset/482/parking+birmingham)

因此停车方向需要先明确营业/记录时段、ID含义、容量与空间关系，再定义传感器缺测。把夜间全补成缺失、直接套用 24h 连续预测，会制造一个与数据采集机制不符的问题。

## 6. 主推场景的具体边界

| 方面 | 第一阶段约定 |
|---|---|
| 应用对象 | 一个城市内已设置、历史上有记录的固定空气质量监测站 |
| 数据 | PM2.5 质量浓度；每站单目标；12—36 站的小型/中型网络 |
| 可用输入 | 截止预测起点的过去 24h 浓度与掩码、已知日历、经核验的站点位置或训练段学习关系 |
| 输出 | 一次输出 t+1…t+6h；重点报告 t+3、t+6h，t+1h作为参照 |
| 缺失条件 | 保留原始缺失，补充一种预先固定的站点观测中断压力条件；额外遮蔽仅施加在原本已观测输入 |
| 主要应用问题 | 本地历史不足时，其他站的近期变化是否能帮助预测高浓度过程，减少预测偏低 |
| 主评价 | 全部有效未来标签上的 MAE/RMSE，逐站宏平均、逐提前量报告 |
| 重点诊断 | 按历史观测率分组，再报告训练段阈值确定的高浓度子集误差与有符号偏差 |
| 第一阶段范围 | 固定站点的短期数值预测；跨未见站点、空间制图和长期预测另设研究协议 |

“高浓度”首先采用各站训练段分位数定义，表示统计上的高值，不称作法定污染等级；如论文需要采用环境标准，须另核对浓度平均时间和标准适用范围。以未来真实标签划分子集仅用于评价，不能把这个分组标记作为预测输入。自然缺失的未来标签没有真值，不评分，也不以插补值代替真值。

还要防止一种评价陷阱：按未来高真值筛选后，预测偏低并不自动证明模型失效或缺失造成偏差。应在同一起点、同一未来标签上比较原始输入与额外遮蔽输入，观察缺失带来的增量损害，同时报告正常时段误差、整体偏差及高值预测误报的代价。全部自然缺失评价只适用于未来仍有真实观测的样本，不能代表无法观测的未来状态。

选择 3—6h 的理由是：在保留短期应用意义的同时，能够检查持续性之外的变化预测；是否比 1h 更有研究空间必须看基线。环境文献观察到更长小时跨度的峰值低估，而非证明任何北京缺失条件都产生该问题。[Wood，2024](https://doi.org/10.1016/j.jenvman.2024.120561)

## 7. 差异化依据与边界

| 对比对象 | 已有工作已经做了什么 | 本次需要独立回答什么 |
|---|---|---|
| 你已有的 DRR-MSGF | 观测支持约束关系学习、物理/学习图融合、区域多尺度聚合；已用 AQI36 验证 | 小规模环境网络中，高浓度时段的变化信息是否被缺失和聚合削弱；怎样在全体误差可接受时改善该具体问题 |
| S17，JSAN 2026 | 稀疏网络下跨地点预测，并比较缺失处理 | 已有站点每小时滚动更新时，观测不足与高浓度子集的预测表现；采用严格时间切分与共同评价样本 |
| S16，CGLU-BNF 2025 | 空气质量、多类缺失、贝叶斯时空建模 | 侧重浓度过程的有符号误差及轻量趋势利用；不是再次泛称“缺失感知空气质量预测” |
| S18，Wood 2024 | 利用近期趋势做短时 PM2.5 预测，讨论峰值低估 | 在本地趋势无法完整观测时，跨站近期信息究竟有无帮助 |

[JSAN 工作](https://www.mdpi.com/2224-2708/15/4/52)和[CGLU-BNF](https://arxiv.org/abs/2511.02175)是必须面对的近邻研究。DeepSIP 的正文未清楚给出未来标签位移，本轮把它作为需求与处理流程背景，不用它证明特定预测跨度上的竞争水平。[DeepSIP](https://link.springer.com/article/10.1007/s44408-026-00145-y)

**以下三个判断目前均是待验证假设：**

1. 观测不足对高浓度时段的预测损害，比对普通时段更明显。
2. 区域多尺度聚合可能使局部变化被平滑，但也可能有益，方向不能预设。
3. 利用其他站点的近期变化，可以补充本地信息，而不是把不相关污染变化带过来。

完成这些验证，再加一个能解释其作用的改进，才可能组成新的工作。仅换数据、挑出一段好看的污染曲线，或者把旧门控改名，都不足以支撑新稿。

## 8. 最少需要尝试的模型与方法

**先做诊断，不先设计大型网络。** 第一轮用持续性、训练段同小时均值、带掩码/观测年龄特征的 LightGBM，以及旧模型，对照自然缺失和一个固定压力条件。树模型依据应用研究作为强对照，不能只比较多个复杂神经网络。

若诊断支持问题，优先尝试一个小改动：**在原有预测器上增加近期变化的辅助预测分支，融合本地和其他站点有效历史的变化特征，校正未来浓度预测。** 有效变化由两个真实已观测值及其时间间隔计算，附带间隔/有效性，不能用零填充值制造下降或上升。辅助分支是否需要空间传播，必须与纯本地版本比较。

这是一个待实验的组合方案：S18 支撑近期变化作为预测信息；旧模型提供缺失感知时空骨架。两者都不能证明新增分支一定有效，更不能证明该组合从未被研究。

复用还需要一个小规模适配检查：旧模型的 top-k=8 和最多8节点的区域，在12节点网络上覆盖比例很大。应在验证集比较较小邻域/区域与不做区域聚合的对照，避免把配置失配误写成新机制收益。这属于必要适配，不单独包装为创新。

另设两个便宜对照：旧模型加高值样本加权损失；旧模型仅做缺失增强。前者检查收益是否只来自损失重加权，后者检查是否只来自更匹配的训练缺失分布。S11 的盐度研究支持缺失增强值得比较，但不保证该结论迁移到 PM2.5。

第一轮只选择一个有证据的改进进入最终实验。尽量复用旧训练流程，并先修正时间切分、归一化和掩码流转。插值只能使用预测时刻已知的信息；全序列双向填补后再切窗要检查被填值是否真的进入模型或统计量。旧加载器存在填充操作并不自动证明泄漏，必须顺着有效掩码检查。

## 9. 一周内的决策与止损

| 时间 | 工作 | 继续条件 |
|---|---|---|
| 第1天 | 确认新数据、坐标/图、时间切分；复核旧结果；统计高值与缺观测交集 | 有足够分布于不同日期/站点的有效评价样本 |
| 第2天 | 跑简单强基线与旧模型；只用训练/验证集查 1/3/6h 误差、偏差 | 存在可重复的具体问题；不能只由一场污染过程支撑 |
| 第3天 | 一个趋势分支与损失/增强对照；不并行堆叠新主模块 | 收益超过简单对照，且普通时段没有不可接受退化 |
| 第4天 | 冻结场景、模型和评价口径；小范围调参结束 | 结果方向稳定，记录失败方案 |
| 第5天 | 固定至少3个训练种子；同一起点、同一掩码配对评估 | 不挑选种子或只展示有利缺失率 |
| 第6天 | 消融、逐站/逐提前量、过程图及计算成本 | 用按日期块的重采样或事件汇总处理重叠窗口；不把每个小时当独立样本做显著性检验 |
| 第7天 | 写作与近邻文献对比，整理可复现材料 | 结论限定到实际验证范围；按证据决定是否已达到投稿完整度 |

若第二天发现高浓度低估并不稳定、目标样本集中在极少日期、或新方法不及强简单基线，应停止包装该假设。可以保留“缺失下短期 PM2.5”作为应用任务，重新选择确有证据的瓶颈；不应靠增加多个模块硬凑论文。若坐标和新数据适配超过一天仍未解决，也应重新估计进度，而不是承诺一周完成全部实验。

本轮完成的是文献筛选、场景比较和数据可行性审计。尚未完成新场景模型实验，因此推荐强度是“最值得首先验证”，不是“已证实可以发表”。
