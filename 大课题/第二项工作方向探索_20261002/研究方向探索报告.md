## 一、本次研究从哪里开始，筛选依据是什么

### 1. 从全部已有文献出发

起点是上一轮调研的 68 篇记录、综述、逐篇笔记和核验说明，而不是此前临时挑选的六篇。对每一条记录重新判断其在本次探索中的作用：直接竞争工作、可借鉴的机制、实验基线、任务边界或暂缓研究的方向。逐篇理由见 [全库筛选与用途.csv](全库筛选与用途.csv)。

本轮同时阅读了项目的四轮实验总结，以及现有小论文的内部评阅与后续机制控制结果。它们用于评估已有基础和重复研究的风险，不当作已经独立复现的公开结论。

### 2. 使用五条判断标准，不做缺少依据的数值评分

1. **任务相关性**：是否真正预测未来；是否允许历史缺失；是否建模空间或跨变量依赖。
2. **问题独立性**：是否超出已有小论文的图关系融合与区域信息传播。
3. **已有覆盖程度**：最接近的论文已经做了什么，不能把已实现的功能重新包装为创新。
4. **证据强度**：本轮核对的原文段落、沿用的上一轮证据、仅摘要信息分别标注。
5. **实现与验证可行性**：是否可利用现有数据和代码，是否有强基线、明确实验与停止条件。

“已下载”不作为研究价值的筛选条件。没有公开全文的论文仍进入比较，但不能依据摘要断言其没有某项实验。

## 三、方向 A：缺失条件变化下的时空预测泛化

### A1. 需要解决什么问题

模型训练时看到的缺失情况可能与部署时不同。需要分开研究四种变化：

- 缺失率变化：散点 20% → 散点 60%；
- 缺失几何变化：相同缺失率的散点 → 连续时间块；
- 空间分布变化：独立节点掉线 → 相邻节点共同掉线；
- 训练可用信息变化：有完整历史教师 → 从一开始就只有不完整历史。

“泛化”在这里首先指**训练结束后冻结模型，在未用于调参的缺失条件下预测**。在线更新属于另一个信息条件，不能把获得测试标签后更新的模型与冻结模型直接排名。

有实际意义的研究问题是：**在没有完整历史监督、测试缺失形态又发生变化时，怎样利用不同缺失视图学习稳定的预测能力，同时保留观测丰富样本中特有的信息？**

这不是新颖性结论，而是当前值得验证的问题范围。

### A2. 文献已经解决到什么程度

| 工作 | 已有机制 | 对本方向的约束或支撑 |
|---|---|---|
| Merlin | 完整观测教师的知识蒸馏，多缺失率视图对比 | 提供强训练策略基线；原文明确教师使用完整观测，因此需单独登记其额外信息 |
| CRIB | 信息瓶颈和不完整视图的一致性约束；进一步随机遮蔽和加噪 | “不完整输入 + 一致性”已经存在，不能只取消教师就宣称新方法 |
| StableMiss | 掩码条件化参数、重加权去相关；MCAR/MAR 与完整数据联合分布不变假设 | 已有掩码迁移理论及交通实验；理论边界不能直接推广到数据动力学也变化或 MNAR |
| HD-TTS | 缺失条件下的时间/空间下采样与自适应尺度融合 | 单纯缺失感知的尺度选择已被覆盖 |
| ImputeFormer | 低秩偏置与缺失配置泛化 | 是“插补器 + 同一预测器”流程对照，不能直接比较插补 MAE |
| ChannelTokenFormer | 通道异步表示、训练 patch 遮蔽、测试块缺失 | 比只在散点上训练的弱基线更接近所需对照 |
| Under-Cali | 冻结源模型、在线轻量校准，标签到达后更新 | 若扩展到在线场景必须纳入；不能与无标签冻结评测混用 |

### A3. 可尝试的方法，不预设必须全部组合

**路线 A-a：在不完整训练数据上进行多视图学习。** 只从实际已观测位置继续遮蔽，形成点、块和局部区域视图。比较普通混合掩码训练、CRIB 式一致性、仅用可用数据的自蒸馏。研究点不是“增加更多掩码”，而是不同视图应该对齐哪些预测信息，哪些信息应允许不同。

一个必须注意的推理例子：设未来目标取决于最近一次突变。如果视图一保留了突变、视图二删除了突变，那么两个视图的最优条件预测一般不同。强迫它们完全一致，可能损害第一个视图。这说明“一致性越强越好”不能作为默认假设，但也不构成任何现有模型必然失败的证据。

可检验的设计包括：只对共同可支持的部分表征加约束；将共享表征与视图特有表征分开；根据训练期可验证的信息损失调整一致性强度。权重必须由推理时可用输入产生，不能借用测试未来误差。

**路线 A-b：按缺失条件分组的稳健训练。** 用块长、预测起点距最近观测的间隔、受影响节点比例等划分训练组，对最差组误差进行稳健优化；与相同骨干、相同预算下的混合掩码训练比较。分组稳健优化属于已有通用技术，直接套用不是充分创新；需要证明分组如何对应时空信息破坏，并在未见组合上有效。

**路线 A-c：小型条件适配器。** 借鉴 StableMiss 的掩码条件化思想，对时间处理或跨节点聚合进行低成本调整；与简单掩码拼接、固定门控和第一项工作的关系模块分离比较。完整掩码维度很大时，可尝试局部统计与空间结构摘要，但摘要可能丢信息，必须对照验证。

以上三条是替代或逐步推进的方案，不建议第一版同时实现。

### A4. 可以形成什么贡献

- 清楚刻画缺失“数量变化”和“结构变化”对预测的不同影响，排除纯粹少看了数据造成的误差增加。
- 在不依赖完整历史教师的条件下，提出信息对齐或条件适配方法，并验证它超出普通增强、一致性正则及现有迁移方法。
- 明确在哪些信息不足的条件下仍不能泛化。

仅有“点→块测试变好”不足以独立支撑贡献；需要机制对照以及至少一个未参与训练和选择的缺失族。

### A5. 最小验证实验与停止条件

1. METR-LA + 一个环境监测数据集；冻结同一时间切分和未来预测集合。
2. 训练协议分别为单一散点、多缺失率散点、混合点/块；测试采用相同有效缺失率但不同块长/位置/空间聚集度。
3. 区分自然缺失训练和合成完整训练；完整教师只作为额外信息对照。
4. 先比较简单增强、HD-TTS/或现有可运行骨干、CRIB 一致性、适配后的 StableMiss 思路；再选择候选方法。论文级对照补入 Merlin/ChannelTokenFormer 等相关路线。
5. 除绝对 MAE/RMSE，报告各模型的同条件训练参照与迁移差距。训练时见过目标缺失模式的模型是参照，并非严格数学上界。
6. 三个种子先筛查，正式结果再扩大；均值之外用按日期/连续时间块重采样的误差区间处理窗口相关性。

**停止或降级条件**：等预算的简单混合掩码训练已消除大部分差距；新方法在块缺失上的收益来自低缺失条件明显退化；或与 CRIB/StableMiss/ChannelTokenFormer 无法界定清楚区别。此时可以保留为实验分析，不强行写成独立算法论文。

### A6. 与大课题的相关性及可行性

第一项工作研究“缺失条件下如何构建空间关系”；本方向研究“训练得到的预测能力在缺失条件变化后是否仍有效”。可以先用相同骨干隔离训练策略贡献，再在另一骨干上验证。数据和评测设施复用度高，启动成本相对较低；新颖性难度较高，必须正面比较近邻方法。

## 四、方向 B：面向未来预测的历史信息恢复与概率建模

### B1. 需要解决什么问题

连续缺失区间往往对应多种合理的历史轨迹。只填入一个均值会压平峰值和变化相位，但“生成很多历史样本”也未必能改善预测：若生成模型错误，可能只是把错误传播得更复杂。

本方向关注：**如何保留对未来预测有用的历史信息及其不确定性；在什么条件下显式恢复历史值得做，何时直接学习未来分布更合适？**

这里可有两个相邻入口：预测目标导向的恢复、输入缺失不确定性向未来的传播。它们共同要求评价未来目标，不以历史重构排名代替预测证据。

### B2. 文献已经解决到什么程度

| 工作组 | 已有认识或方法 | 对本方向的意义 |
|---|---|---|
| 任务导向插补评估 | 历史点的重构误差不能充分代表下游价值 | 提供诊断工具；“重构好不等于预测好”不是新发现 |
| CoIFNet、GSTAE、CRIB | 联合学习、顺序预训练、直接预测等不同流程 | 必须把训练方式与骨干能力分开对照 |
| FCS 风电概率预测 | 联合描述输入与目标，通过缺失边缘化得到预测 | 多重插补和预测联合建模已有成熟出发点 |
| CSDI、PriSTI、SSSD | 条件分布生成与多样本恢复 | 可作历史恢复模块；原论文插补结果不能自动成为本任务预测证据 |
| TSDiff | 完整序列训练，推理时按缺失上下文进行自引导生成 | 既有缺失历史预测基线，但训练完整性与多步采样成本需控制 |
| TACTiS/TACTiS-2、ProFITi/MOSES | 联合分布、可变查询、流模型或 Copula | 与只输出独立边际区间的方法目标不同；也能作为直接概率预测路线 |
| CGLU-BNF | 空气质量多缺失模式预测与贝叶斯输出 | “图网络 + 概率输出层”已被覆盖 |
| 训练后自适应共形预测 | 针对不完整时序调整区间与条件覆盖 | 简单按缺失率校准区间不能单独当作新方向 |
| 水文扩散应用（2026 预印本） | 自然不完整水文序列上的插补与概率预测 | 提供现实环境数据情境；不把其插补长空洞结果误当未来预测结果 |

来源：[任务导向评估](https://proceedings.neurips.cc/paper_files/paper/2024/hash/f88264fcc54775ee1706116e90fe351a-Abstract-Conference.html)、[CoIFNet](https://arxiv.org/abs/2506.13064)、[风电 FCS](https://arxiv.org/abs/2203.08252)、[CSDI](https://arxiv.org/abs/2107.03502)、[TSDiff](https://arxiv.org/abs/2307.11494)、[TACTiS](https://proceedings.mlr.press/v162/drouin22a.html)、[CGLU-BNF](https://arxiv.org/abs/2511.02175)、[共形预测](https://openreview.net/pdf?id=KMBU4wx79B)、[水文扩散](https://arxiv.org/abs/2607.21200)。

### B3. 可尝试的模型与方法

设 O 为历史已观测信息，M 为缺失掩码，U 为缺失历史，Y 为未来目标。一个标准的概率分解是：

\[
p(Y\mid O,M)=\int p(Y\mid U,O,M)\,p(U\mid O,M)\,dU.
\]

这只是概率论分解，**不是拟提出的创新公式**。它提示三种值得对照的实现：

**路线 B-a：多样本历史恢复 → 同一预测器 → 预测分布汇总。** 以 CSDI/PriSTI 或更轻的条件潜变量模型产生若干历史样本；对每个样本预测，再汇总。需要比较“先平均历史再预测”和“分别预测再平均”，并固定同一预测骨干。若预测器还输出自身条件分布，应保留这部分未来噪声；仅凭多个确定性预测结果的离散程度，不一定覆盖所有预测不确定性。

**路线 B-b：以未来目标训练的联合潜变量模型。** 使用图或时空编码器读取可用历史，学习条件潜变量，并输出未来分布；对人为从已观测位置遮蔽的历史点施加辅助约束。可借鉴 CoIFNet 的共享表示和 FCS/TACTiS 的联合分布思想。研究恢复约束的权重是否应随预测跨度和缺失位置变化，而不是固定优化所有历史点。

需要防止辅助“重构”实际上变成任意编码：若恢复值已不再表示真实历史，就应称为潜在表征，而不能宣称插补准确。训练可以使用训练样本的未来标签，测试输入必须严格止于预测起点。

**路线 B-c：直接概率预测，并显式利用观测条件。** 保留一个直接分位数/分布预测器作为可能更简单的方案。探索空间相关的预测分布、区域汇总风险或缺失条件变化后的校准。若直接模型已经能解决问题，没有必要强制加入插补模块。

共形校准适合作为评测对照或后处理组件。时间相关、缺失条件变化和稀少极端事件会影响其前提，不能把经典独立同分布保证原样套到本任务上。

### B4. 有可能成立的贡献及不能成立的说法

可探索的差异点：

- 分析历史缺失的位置、事件阶段与未来跨度如何共同影响恢复信息的价值，并将这种关系转化为可验证的学习目标。
- 在给定计算预算下，将缺失历史的多种可能性有效传到多节点、多步未来预测。
- 在相同区间覆盖率下改善区间宽度/概率评分，或改善区域联合事件的估计，而不只是增加输出方差。

不应作为贡献：“首次联合插补与预测”“首次给缺失时序输出区间”“加入扩散就解决误差传播”。这些都已有直接相关工作。

### B5. 最小验证实验与停止条件

1. 从交通与空气质量的时间块缺失开始，尤其区分窗口中部空洞和预测起点前的连续空洞。
2. 使用同一预测骨干对比：简单填补、强确定性插补、概率插补后取均值、概率插补后多样本传播、直接概率预测、联合学习。
3. 采样数可先设 1/4/8，完整记录延迟与显存；精度改善要和额外计算同时报告。
4. 点预测评估 MAE/RMSE，分布评估 CRPS/分位数损失；按缺失模式、块长和未来跨度报告区间覆盖与宽度。
5. 若主张空间联合分布，增加区域总量或区域同时超阈值的诊断，并使用 Energy/Variogram 等相应评分；只评价各节点边际区间不够。
6. 峰值、突变等诊断可用测试真值定义评估分组，但阈值从训练集固定，且不得用测试标签选择方法或恢复策略。
7. 自然缺失处无真值，不能报告其“恢复准确率”；预测评价限于有标签的位置，并注明无法代表所有缺失目标。

**停止或降级条件**：直接概率预测 + 简单后处理已达到同样效果；多样本传播的收益仅来自更大计算；模型仅通过扩大区间提高覆盖，概率评分和宽度没有改善；所谓目标导向重构无法稳定超越固定损失权重。

### B6. 与大课题的相关性及可行性

第一项工作侧重空间关系；本方向转向“恢复哪些信息、如何表示预测的不确定性”，独立性较强。项目中已有插补与直接预测比较，可以作为起点，但早期简化实现和统一短训练的结果只能形成假设。

开发和评测成本中等至较高。建议首先用轻量分位数/潜变量模型与现有插补器做诊断；只有发现必要性后再引入扩散或复杂生成流。它也可为后续整节点缺失章节提供概率预测工具，但当前不同时承诺完成全部强缺失任务。

## 五、方向 C：稀疏与连续缺失下的时空信息表示和利用

### C1. 需要解决什么问题

稀疏观测通常有三种处理方式：补齐固定网格、将观测放入固定/自适应片段、直接表示实际观测事件。三者都可能在聚合时损失对预测重要的信息。

举例：两个历史窗口观测点数量相同，一个保留了临近预测起点的变化，另一个只保留较早的平稳片段；它们的信息量对未来预测并不等价。另一个节点的较早观测也可能因传播时延，比本节点更新但无关的观测更有用。

本方向可以研究：**在长期空洞和观测密度不均衡时，如何以可控计算成本，保留并利用与目标节点、预测时刻相关的时空信息？**

这里的“相关”是待学习、待验证的预测关联，不预先称为因果关系。规则采样下发生缺失也能使用观测事件表示；不必把课题转到临床不规则序列。

### C2. 文献已经解决到什么程度

| 工作 | 可借鉴内容 | 不能直接声称的新意 |
|---|---|---|
| GraFITi、HyperIMTS | 将时间、通道与实际观测表示成稀疏图/超图 | “只处理观测值”和“稀疏图表示”已有工作 |
| t-PatchGNN、Hi-Patch、ReIMTS | 片段内/片段间、递归多尺度的信息组织 | “层次片段 + 图”已相当成熟 |
| APN | 可学习软时间窗，通道独立聚合，预测时间查询 | “可变片段边界”“按查询预测”已存在 |
| TimeCHEAT | 局部跨变量、全局通道独立 | 固定组合两种策略不是充分差异 |
| ChannelTokenFormer | 通道特定片段与异步表示；块缺失处理 | “考虑异步与块缺失”不是空白 |
| S4M、GCN-M | 原型/记忆补充局部缺失 | 简单加入记忆库不是独立贡献 |
| KRNO | 连续时间平移算子、非规则观测、时空分辨率泛化 | 原生连续时间和跨分辨率预测已有算子路线 |
| TFMixer、LSCD | 非均匀时间下的频率信息 | 周期信息恢复必须与这些方法比较；LSCD 原任务为插补 |
| INTER、VIMTS | 缺失片段学习、预训练和表示恢复 | 片段选择或预训练自身不能保证新颖性 |

### C3. 可尝试的方法路线

**路线 C-a：按预测查询聚合实际观测。** 将观测表示为“节点、时间、变量、数值”，将未来目标表示为“目标节点、目标时刻”。使用时间差、节点结构与数值表征检索或聚合历史信息。可借鉴 GraFITi 的观测结构、APN 的软时间聚合和既有查询解码器。

潜在研究点不是增加一个查询头，而是：能否让历史压缩保留不同预测跨度需要的不同信息，并在相同 token/显存预算下改善长空洞预测。例如短期目标更需要最近可用的局部变化，长期目标可能需要周期上下文，但这种分工必须由实验检验，不能硬写成普遍规律。

**路线 C-b：为连续空洞建立时间演化与观测更新。** 借鉴 CRU 的连续演化和观测融合、S4M 的状态空间模型，在空洞内传播状态，在新观测到达时更新；空间观测作为补充条件。比较显式时间间隔、均匀离散步进和直接长跨度解码。若观测模式原本规则，可先使用离散模型与时间间隔，避免一开始承担 ODE 求解成本。

**路线 C-c：观测密度与预测价值共同决定计算分配。** 将 APN/Hi-Patch/INTER 等作为强参照，研究如何避免仅按缺失率丢弃片段时丢掉少量关键事件。可用分组稀疏注意力、局部邻域检索、预算约束的片段保留等已有技术实现。评分器不能从测试未来标签获知哪个片段最有价值。

上述路线只在发现具体的表示损失后才值得做；“稀疏”不自动更快，图构造和不规则批处理也可能更慢。

### C4. 有可能成立的贡献

- 在相同观测数/缺失率下，区分观测密度、观测距预测起点的间隔、跨节点时延对预测的影响。
- 提出保留目标相关时空信息的表示或聚合方法，并通过固定参数量、固定计算预算、去除查询条件等对照验证。
- 在真实传感器网络上提供准确率—延迟—显存的关系，而不只在低维临床数据上论证“高维时空”能力。

仅有“APN + 一个图层”或“替换 Transformer 为 SSM”不足以支撑上述贡献。

### C5. 最小验证实验与停止条件

1. 固定历史物理时长和观测点数，分别改变：空洞位置、节点间异步程度、连续块长度；另设固定观测密度但增加历史长度的测试。
2. 使用交通或多站点环境数据保持空间任务；可补一个具有已知传播延迟的合成过程用于机制诊断，不能用合成结果替代真实数据。
3. 比较网格骨干、HD-TTS、APN、TimeCHEAT/或 t-PatchGNN、一个稀疏观测模型；新方法的空间图与基线遵守相同信息预算。
4. 做“观测表示 → 相同解码器”和“相同表示 → 不同聚合器”的分离对照，避免把骨干变化误判为表示收益。
5. 查询目标必须始终在预测起点之后；原本历史内双向处理不等于允许读取未来。
6. 如果模型需要节点身份，还要测试节点顺序同步置换的结果是否合理；物理图、坐标和外生变量的使用单独登记。
7. 测延迟时计入观测打包、图构造、排序和邻域检索，不能只计核心网络算子。

**停止或降级条件**：APN/TimeCHEAT 等已有模型在相同空间信息下已解决大部分问题；收益只来自更长历史或更多 token；稀疏表示明显增加延迟且没有准确率收益；方法无法在交通和环境任务间保持合理效果。

### C6. 与大课题的相关性及可行性

它研究缺失历史的时间组织与跨节点信息利用，能与第一项工作的“关系构建”分开。但需要控制边界：若最终改动仍主要是重新学习邻接并融合区域尺度，就可能又回到第一项工作。

现有交通和 AQI 数据可支持规则网格转观测列表的研究；这只验证“规则采样后的缺失”，不能据此声称覆盖所有原生异步系统。该方向需要更多数据接口和批处理工作，方法竞争也密集，适合先进行表示层诊断。

## 六、三个方向如何比较，而不是立即选定

| 比较项 | A：缺失条件变化下泛化 | B：信息恢复与概率预测 | C：稀疏时空表示 |
|---|---|---|---|
| 主要研究对象 | 学习目标、训练缺失环境和迁移 | 历史恢复与未来分布的关系 | 观测组织、聚合和时间演化 |
| 与第一项工作区别 | 图结构可固定，研究训练策略 | 图模块可复用，改变预测目标与概率输出 | 关系可固定，研究时序表征与压缩 |
| 启动成本判断 | 较低至中等 | 中等至较高 | 中等 |
| 最大风险 | 普通增强已足够；已有迁移与一致性方法覆盖 | 复杂分布模型未优于简单概率头；计算代价高 | 自适应 patch/稀疏模型已覆盖；接口工作多 |
| 最有说服力的证据 | 未见缺失组合上改善，常规条件不明显退化 | 相同覆盖/计算预算下概率评分与预测改善 | 相同观测/计算预算下长空洞与异步预测改善 |
| 是否依赖完整训练数据 | 主问题设为不依赖；完整教师作对照 | 可以不依赖，但恢复监督只用已观测点 | 不必依赖；预训练变体另列预算 |
| 概率校准是否必做 | 非必需 | 若声称可信度则必做 | 非必需 |
| 可支撑的大论文章节 | 缺失条件变化下的预测方法 | 缺失历史下的概率预测方法 | 稀疏观测下的时空预测方法 |

这些成本等级是根据现有工程基础和方法复杂度作出的规划判断，不是实测工时或算力估算。当前没有充分证据给出某一方向“必定最优”的排序。

**可以先做 A 的诊断，因为评测设施复用较多；这只是验证顺序，不等于选题优先级。** B 和 C 应保留为同等级候选，尤其在 A 的失败现象不能稳定复现时，不应继续围绕它堆叠模块。

## 七、与毕业论文整体框架的连接

此前七章大纲是可调整的工作安排，其中将第五章直接称为“主创新”只是规划，不能当作已经证明的事实。

已有第一项工作提供空间关系建模的基础。第二项工作可以从三个候选中选择一条，形成独立的方法章节。第三项工作再依据第二项结果确定：

- 若选 A：第三项可考察整节点/区域长期故障与在线变化；
- 若选 B：第三项可考察区域或整节点缺失时的预测风险，避免再重复写一个普通概率头；
- 若选 C：第三项可考察未见节点或区域扩展，但须补足静态信息与归纳任务定义。

三个候选都应在交通/环境等空间网络上保留主实验。仅在 ETT、Exchange 或独立站点样本上有效，最多支撑一般多变量时序方法，仍不足以独立证明大课题要求的空间建模能力。

## 八、下一阶段的具体交付物与决策规则

当前已完成文献层面的候选形成，下一步不宜直接做三个完整模型。建议分为两轮：

### 第一轮：三个方向各做一个问题诊断

| 方向 | 先验证的现象 | 最少需要的对照 |
|---|---|---|
| A | 同缺失率、不同几何的迁移差距是否超出简单增强可解决的范围 | 固定骨干、单一/混合掩码训练、现成一致性约束、同条件训练参照 |
| B | 单点恢复、样本传播、直接概率预测是否呈现稳定的精度或校准差异 | 同预测器、同恢复器不同汇总方式、轻量概率头、计入采样成本 |
| C | 表示方式是否会在同观测数下丢失关键时间/空间信息 | 网格、片段、稀疏观测；固定历史时长/计算预算；已有自适应片段基线 |

先选一个交通数据集进行调试与筛查，再用一个环境数据集复核现象。探索阶段可以少量种子，不能据此声称论文级显著提升。基线复现不成功时，先排查实现与预算，不将基线失败作为新方法有效的证据。

### 第二轮：对有证据的两个候选做最小方法改进

每个候选只改变一个关键机制。必须能写清楚：

1. 观察到什么可重复的失败；
2. 提议机制为何可能修复它；
3. 哪个近邻方法或简单方案构成最强反例；
4. 哪个实验会推翻该机制；
5. 改善是否足以支持与第一项工作不同的章节贡献。

只有当“文献差异清楚 + 失败现象稳定 + 简单方案仍不足 + 可行性可接受”同时成立，才进入正式选题、模型命名和投稿规划。
