# papers 目录论文分类整理

> 分类依据：优先读取 PDF 标题和摘要；按论文主任务归类。若论文同时涉及插补和预测，则按最终主目标归入预测或插补，并在备注中说明。

## 分类口径

| 类别 | 判定标准 |
|---|---|
| 非时空缺失预测 | 主任务是 time series forecasting / MTSF / IMTS forecasting，处理缺失、不规则采样或变量缺失，但摘要中没有明确以物理空间拓扑、传感器空间图或 spatiotemporal system 作为核心对象。 |
| 时空缺失预测 | 主任务是 forecasting，且摘要明确涉及 spatial-temporal / spatiotemporal graph / sensor-point / spatial structure / STGNN 等空间或时空依赖。 |
| 缺失插补 | 主任务是 imputation、imputation evaluation 或 missing data recovery，即使模型可辅助 forecasting，也优先归入插补。 |
| 异常检测 | 主任务是 time series anomaly detection。 |
| 资料与综述 | 非 PDF 论文正文，如综述、下载清单和补充文献列表。 |

## 重复和边界项

| 项目 | 说明 | 建议 |
|---|---|---|
| `Graph-based Forecasting with Missing Data through Spatiotemporal Downsampling.pdf` 与 `2024plus-recommended/02_HD_TTS_ICML2024.pdf` | 标题和摘要相同，应为同一篇论文的重复文件。 | 若想精简目录，可保留 `2024plus-recommended/02_HD_TTS_ICML2024.pdf`，删除或归档根目录重复版。 |
| CoIFNet | 同时输出插补和预测，但摘要和标题主目标是 MTS forecasting with missing values。 | 归入非时空缺失预测，备注为联合插补-预测。 |
| GraFITi / T-PATCHGNN / HyperIMTS | 都使用图或超图，但摘要重点是不规则多变量时间序列预测，不是明确的物理空间传感器网络。 | 归入非时空缺失预测；若你的论文综述把“变量图”也算广义时空，可移动到时空缺失预测。 |
| ImputeFormer / CoFILL / P-GUTS | 都是时空数据插补。 | 主任务是 imputation，因此归入缺失插补，而不是时空缺失预测。 |
