# 缺失值场景下多变量时间序列预测论文综述

> 说明：本报告基于目录中的 7 篇本地 PDF 全文整理。目录 manifest 中列出的第 8 篇 `GinAR+` 未下载成功，原因是 IEEE Xplore 官方 PDF 访问被阻断；因此本报告只对它做资料状态说明，不把它纳入核心横向比较。

## 1. 一句话总览

这组论文共同讨论一个问题：现实中的多变量时间序列往往不完整，模型还能不能可靠地预测未来？

早期常见做法是“先插补缺失值，再做预测”。但这批新论文明显在反思这个范式：如果缺失位置没有真实标签，插补出来的值可能只是“看起来合理”，却会破坏真实的数据分布和变量关系。因此，新的方向主要分成三类：

1. **直接预测**：不再显式填补缺失值，而是让模型从部分观测中提取稳定信号。代表：CRIB、MissTSM。
2. **联合建模**：不把插补和预测拆成两个阶段，而是在一个模型里同时利用缺失掩码、时间信息、变量关系和预测目标。代表：S4M、CoIFNet、GinAR、IBN。
3. **鲁棒增强**：不完全替换预测模型，而是让已有模型对不同缺失率更稳。代表：Merlin。

最重要的综述结论是：**缺失值预测的重点正在从“把缺失值补得像真的”转向“让预测表示对缺失模式不敏感，同时保留真正有用的时序和变量关系”。**

## 2. 先厘清几种缺失设定

这些论文表面都叫 missing values，但处理的缺失类型并不完全一样。理解这一点很关键，否则很容易把不同赛道的结果混在一起比较。

| 缺失设定 | 含义 | 代表论文 | 难点 |
|---|---|---|---|
| 点缺失 | 随机时间点上的若干值缺失 | CRIB、CoIFNet | 缺失位置分散，模型需要避免局部噪声 |
| 块缺失 | 连续一段时间或一块区域缺失 | S4M、CoIFNet | 连续上下文断裂，简单注意力或插值容易失效 |
| 变量缺失 | 某些变量整段历史都不可用 | GinAR、IBN、S4M | 无法依靠该变量自身历史，只能借助其他变量 |
| 非固定缺失率 | 不同时间段缺失比例变化 | Merlin | 一个模型要适应多种缺失强度 |
| 不规则采样 IMTS | 不同变量在不同时间点观测不齐 | MissTSM | 常规 Transformer 的“按时间/按变量 token 化”不再适用 |
| 自然缺失 | 数据原本就缺，不是人工 mask | CRIB、MissTSM | 没有完整真值，评估和训练都更贴近真实应用 |

## 3. 逐篇论文梳理

### 3.1 CRIB：直接预测，不要迷信插补

**核心观点**：很多插补方法没有缺失值真值监督，插补结果可能破坏数据分布和变量相关性，最终反而伤害预测。

CRIB 的贡献首先不是模型，而是对“imputation-then-prediction”范式的系统质疑。论文用实验说明：两阶段插补预测和端到端插补预测都可能把错误插补传给预测器。CRIB 因此选择绕开插补，直接从部分观测序列中预测未来。

方法上，CRIB 使用信息瓶颈思想，让表示尽量压缩掉缺失引入的噪声，同时保留和预测目标有关的信息。它包含三个关键设计：

| 模块 | 作用 |
|---|---|
| patch embedding | 把稀疏点级输入转成更稳定的片段级表示 |
| unified-variate attention | 同时建模不同变量和时间片段之间的关系 |
| consistency regularization | 让不同缺失扰动下的表示保持一致 |

实验覆盖 11 个数据集，包括 PEMS-BAY、Metr-LA、ETT、Weather、Exchange、Electricity、AQI 等。论文报告 CRIB 相比强基线平均提升约 18%，并在自然缺失 AQI 上显示直接使用稀疏原始数据优于先全量插补。

**适合记住的结论**：如果缺失值没有可靠监督，不要默认“补全数据”一定有益；直接学习缺失鲁棒表示可能更稳。

### 3.2 MissTSM：模型无关、无需插补的 IMTS 适配层

**核心观点**：处理不规则多变量时间序列时，不一定要重写一个专门模型；可以设计一个 plug-and-play 层，把任意 MTS backbone 接到缺失数据上。

MissTSM 面向的是 IMTS，即不同变量在不同时间点可能缺失。常规 Transformer 把一个时间步的所有变量当成 token，iTransformer 把一个变量的整段时间当成 token；但只要某些值缺失，这两种 token 组织方式都会变得尴尬。

MissTSM 的做法是把每个“时间-变量”组合独立嵌入，即 Time-Feature Independent embedding。缺失位置不插补，而是在后续 Missing Feature-aware Attention 中通过 mask 排除或聚合可观测信息。这样它可以作为一层适配器，接到 MAE、PatchTST、iTransformer 等模型前面。

实验很全面，既有预测也有分类：

| 任务 | 数据集 |
|---|---|
| 预测 | ETTh2、ETTm2、Weather、Solar-Energy、Lake 数据 |
| 分类 | Epilepsy、EMG、Gesture、PhysioNet、P12、P19 |
| 缺失方式 | MCAR、周期缺失、真实缺失 |

论文的关键发现很实际：当缺失比例很高、数据周期性不明显时，MissTSM 比很多先插补再预测的方法更稳；但在低维、强周期数据上，简单的 Spline + backbone 有时也很有竞争力。

**局限**：每个时间-变量点都做 token，面对高维长序列时计算量会变大；MFAA 本身主要建模跨变量聚合，非线性时序动态仍依赖后续 backbone。

### 3.3 S4M：把缺失模式接入 S4 的高效长序列建模

**核心观点**：S4 本来适合长序列高效建模；如果把缺失表示和掩码一起放进 S4，可以兼顾效率和缺失鲁棒性。

S4M 关注点缺失和变量缺失，尤其强调块状缺失场景。它认为传统两阶段方法容易误差累积，而 RNN、ODE、图模型等方法要么慢，要么内存大。S4M 基于 Structured State Space Sequence Model，设计了两个组件：

| 模块 | 作用 |
|---|---|
| ATPM | Adaptive Temporal Prototype Mapper，用历史模式原型库为缺失场景提供更稳的潜在表示 |
| MDS-S4 | Missing-aware Dual Stream S4，把时间序列表示和缺失 mask 作为双流输入建模 |

实验在 Electricity、ETTh1、Weather、Traffic 上进行，设置不同 lookback 长度和不同缺失比例。结果显示 S4M 在多数设置下达到最好或次好表现，并且训练时间和内存相对可控。

**适合记住的结论**：缺失 mask 不只是辅助标记，它本身就是有信息的输入；在高效序列模型里显式建模 mask 可以带来稳定收益。

### 3.4 Merlin：让已有模型适应“缺失率会变”的现实

**核心观点**：现实中缺失率不是固定的。与其为每个缺失率训练一个模型，不如让模型学习不同缺失率下语义对齐。

Merlin 的定位比较特殊：它不是一个单独预测器，而是增强已有 MTSF 模型鲁棒性的训练框架。它处理的问题是 unfixed missing rates，即缺失率随时间段变化。

Merlin 有两个核心训练信号：

| 组件 | 思想 |
|---|---|
| offline knowledge distillation | 用完整数据训练 teacher，再让 student 在缺失数据上模仿 teacher 的表示和预测 |
| multi-view contrastive learning | 同一时间段不同缺失率的样本作为正样本，不同时间段作为负样本，使缺失率变化下的语义对齐 |

实验在 METR-LA、PEMS04、China AQI、Global Wind 上进行，缺失率为 25%、50%、75%、90%。论文显示 STID+Merlin 在多个缺失率和数据集上优于 raw STID、两阶段插补模型和其他组合，并且在非固定缺失率测试中只训练一次就能适应不同缺失强度。

**适合记住的结论**：Merlin 把缺失问题从“恢复值”转成“对齐语义”。这对生产场景很有启发，因为线上缺失率通常不会固定。

### 3.5 CoIFNet：插补和预测不是先后关系，而是协作关系

**核心观点**：完全抛弃插补不一定是唯一答案。关键是不要两阶段割裂，而要让插补和预测在同一目标中互相协作。

CoIFNet 站在 CRIB 的“反插补”对面，但不是回到传统两阶段插补。它提出 Collaborative Imputation-Forecasting Network，用一个统一框架同时做历史缺失重建和未来预测。

主要模块包括：

| 模块 | 作用 |
|---|---|
| RevON | 对观测值做可逆归一化，缓解缺失场景下分布漂移 |
| CTF | Cross-Timestep Fusion，融合跨时间信息 |
| CVF | Cross-Variate Fusion，融合跨变量信息 |
| joint loss | 同时包含 imputation loss 和 forecasting loss |

实验在 ETTh1、ETTh2、ETTm1、ETTm2、Weather、Exchange 上进行，考虑点缺失和块缺失，缺失率 0.3 和 0.6。论文报告 CoIFNet 在这些设置下稳定优于 BiTGraph 等方法，尤其在 0.6 缺失率下有明显提升，并且时间和内存效率也更好。

**如何理解它和 CRIB 的差异**：CRIB 反对的是没有可靠监督、容易污染分布的插补；CoIFNet 支持的是作为预测辅助任务、与预测目标共同优化的协作式重建。二者并不完全矛盾，它们在提醒同一件事：插补不能脱离预测目标单独优化。

### 3.6 GinAR：变量整段缺失时，重建变量关系比补点更重要

**核心观点**：当某些变量整段历史缺失时，普通插补很难靠该变量自身历史恢复信息，必须依靠正常变量之间的空间关系。

GinAR 研究的是 variable missing：某些变量长期不可用，但仍要预测所有变量未来值。交通传感器、空气质量站点故障都可能出现这种情况。

GinAR 基于简单递归单元 SRU，但把其中的全连接层替换成两个关键模块：

| 模块 | 作用 |
|---|---|
| Interpolation Attention | 根据正常变量和缺失变量之间的对应关系，为缺失变量生成可用表示 |
| Adaptive Graph Convolution | 在恢复表示后重新建模变量之间的空间相关性 |

实验在 METR-LA、PEMS-BAY、PEMS04、PEMS08、China AQI 上进行，变量缺失率为 25%、50%、75%、90%。结果显示 GinAR 优于 11 个基线，即使 90% 变量缺失仍能预测所有变量。消融实验表明 Interpolation Attention 是最关键组件，尤其在高缺失率下，自适应图也很重要。

**适合记住的结论**：变量缺失不是普通点缺失的放大版。它更像“图上的节点观测消失”，核心是恢复跨变量依赖。

### 3.7 IBN：在 GinAR 基础上加入不确定性和可解释图

**核心观点**：变量缺失场景下，模型不仅要预测准，还要知道自己重建的值靠不靠谱，并让图关系更可解释。

IBN 可以看作 GinAR 的改进版。它指出 GinAR 有三个不足：插补可靠性不可解释，图结构学习不够透明，简单单向 RU 不能充分捕获时序模式。

IBN 的三个改进是：

| 模块 | 相比 GinAR 的改进 |
|---|---|
| UAI | 用 MC Dropout 估计重建不确定性，不确定性越高，重建值权重越低 |
| GGCN | 用高斯核构建动态图，并结合预定义图，增强空间关系解释性和稳定性 |
| Bi-RU | 双向递归建模，捕获更充分的时间上下文 |

实验在 METR-LA、PEMS-BAY、PEMS04、PEMS08 上进行，变量缺失率为 25%、50%、75%。论文报告 IBN 相比 GinAR 在平均 MAE 上分别提升约 1.89%、2.63%、6.72%，缺失率越高优势越明显。

**适合记住的结论**：在高缺失率下，重建值的不确定性本身应进入模型决策，而不是只输出一个确定的“补充值”。

## 4. 横向比较

### 4.1 方法路线比较

| 论文 | 是否显式插补 | 是否端到端 | 是否模型无关 | 主要处理缺失类型 | 关键词 |
|---|---:|---:|---:|---|---|
| CRIB | 否 | 是 | 否 | 点/块/列缺失、自然缺失 | 信息瓶颈、直接预测、一致性 |
| MissTSM | 否 | 作为适配层 | 是 | IMTS、MCAR、周期缺失、真实缺失 | TFI embedding、MFAA |
| S4M | 弱显式/潜在表示 | 是 | 否 | 点缺失、变量缺失、块缺失 | S4、prototype bank、mask stream |
| Merlin | 否，不做值恢复 | 训练增强框架 | 较强 | 非固定缺失率 | 蒸馏、对比学习、语义对齐 |
| CoIFNet | 是，作为辅助任务 | 是 | 否 | 点缺失、块缺失 | 协同插补预测、CTF/CVF |
| GinAR | 是，恢复变量表示 | 是 | 否 | 变量缺失 | 插值注意力、自适应图 |
| IBN | 是，但带不确定性 | 是 | 否 | 变量缺失 | MC Dropout、高斯核图、双向 RU |

### 4.2 这些论文对“插补”的态度

这组论文最有价值的地方，是它们围绕“到底要不要插补”形成了一个清晰讨论链：

1. **CRIB、MissTSM**：强调不要依赖不可靠插补。缺失真值不可得时，插补可能引入伪模式。
2. **CoIFNet、S4M**：并不完全否定插补，而是让缺失处理进入预测模型内部，避免两阶段误差传递。
3. **GinAR、IBN**：在变量整段缺失时，完全不恢复变量表示很难预测所有变量，因此需要恢复，但恢复必须利用变量图关系，IBN 进一步加入不确定性。
4. **Merlin**：绕开“补不补值”的争论，直接让不同缺失率下的表示对齐。

可以把它们的共同判断概括为：**坏的插补会伤害预测，好的缺失建模必须和预测目标绑定。**

### 4.3 数据集和评估侧重点

| 论文 | 数据集覆盖 | 评估指标 | 侧重点 |
|---|---|---|---|
| CRIB | 11 个 MTSF 数据集，含自然缺失 AQI | MAE、MSE | 验证直接预测是否优于插补范式 |
| MissTSM | 预测、分类、湖泊真实缺失、医疗数据 | MSE、F1、AUROC、AUPRC | 验证模型无关适配器的通用性 |
| S4M | Electricity、ETTh1、Weather、Traffic | MAE、MSE | 兼顾缺失鲁棒性和 S4 效率 |
| Merlin | METR-LA、PEMS04、China AQI、Global Wind | MAE、RMSE、MAPE | 固定/非固定缺失率下的一次训练适应 |
| CoIFNet | ETT、Weather、Exchange | MAE、MSE | 点缺失和块缺失下统一插补预测 |
| GinAR | 交通和空气质量图数据 | MAE、RMSE、MAPE | 变量整段缺失，还要预测所有变量 |
| IBN | METR-LA、PEMS-BAY、PEMS04、PEMS08 | MAE、RMSE、MAPE | 变量缺失下的准确性和可解释性 |

## 5. 综合观察

### 5.1 研究趋势

第一，**两阶段插补预测正在失去默认地位**。多篇论文都显示，单独训练插补器再接预测器，容易目标错位。插补器追求重建像不像，预测器关心未来准不准，这两个目标不天然一致。

第二，**mask 正在从“缺失标记”变成“模型输入”**。S4M、CoIFNet 等方法都显式使用 mask。原因很简单：缺失模式本身包含信息，例如设备故障、采样规律、外部事件等。

第三，**变量关系越来越重要**。GinAR 和 IBN 表明，变量整段缺失时，时间维度上已经没有该变量自身历史，只能依赖空间/变量关系恢复信息。

第四，**鲁棒性比单点 SOTA 更贴近真实应用**。Merlin 关心的是缺失率变化时是否还能稳定工作；MissTSM 关心的是换 backbone、换任务、换数据后是否仍可用。这些问题比单个 benchmark 上的最佳数值更接近实际部署。

第五，**可解释性和不确定性开始进入缺失预测模型**。IBN 是这一方向的明显例子。对于缺失值重建，模型应当能表达“我对这个重建有多不确定”。

### 5.2 主要矛盾与未解决问题

1. **人工缺失与自然缺失仍有差距**  
   很多实验通过随机 mask 构造缺失，但真实缺失往往和设备、天气、业务流程有关，不一定满足随机缺失假设。

2. **不同缺失类型之间缺少统一 benchmark**  
   点缺失、块缺失、变量缺失、非固定缺失率经常被分别研究，导致方法之间很难公平横向比较。

3. **高缺失率下的泛化仍不稳**  
   虽然各论文在高缺失率下都有提升，但 75% 或 90% 缺失时，模型更依赖结构假设和训练策略，跨数据集泛化仍值得怀疑。

4. **计算成本和高维扩展仍是压力点**  
   MissTSM 的 time-feature token 化很灵活，但高维长序列成本高；图方法在变量数量很大时也会遇到邻接关系和计算复杂度问题。

5. **插补质量和预测质量的关系还没有完全讲清楚**  
   CRIB 证明坏插补会伤害预测，CoIFNet 证明协同插补能帮助预测。未来需要更系统地区分“什么时候插补有害，什么时候插补有益”。

## 6. 如果要做后续研究，可以从哪里切入

### 方向一：统一缺失设定的 benchmark

可以构建同一批数据上的多种缺失协议：点缺失、块缺失、变量缺失、非固定缺失率、自然缺失。这样才能真正比较 CRIB、CoIFNet、S4M、GinAR/IBN 等方法的适用边界。

### 方向二：直接预测与协同插补的混合模型

CRIB 的思想适合避免错误插补，CoIFNet 的思想适合利用辅助重建。一个自然问题是：能否让模型自动判断某些区域直接预测，某些区域协同重建？

### 方向三：缺失不确定性的显式建模

IBN 的 UAI 很有启发。未来可以把不确定性扩展到预测输出、图结构学习、缺失率变化检测中，让模型不仅给出点预测，还能告知风险。

### 方向四：面向真实部署的缺失率漂移适应

Merlin 处理非固定缺失率，但仍主要通过训练阶段构造多种缺失率。进一步可以研究在线场景：当传感器故障模式逐渐变化时，模型如何低成本自适应。

### 方向五：大规模变量系统的轻量图建模

GinAR、IBN 在交通和空气质量中很自然，但如果变量数达到上万，完整图学习会很贵。可以研究稀疏图、分层图、局部-全局混合图。

## 8. 总结

这批论文的主线非常清晰：多变量时间序列预测中的缺失值问题，已经不再只是一个预处理问题，而是预测模型本身必须面对的建模问题。

如果缺失只是少量随机点，现代预测模型加上合适 mask 或直接预测策略可能已经很强。如果缺失是连续块，模型需要更强的跨时间融合能力。如果缺失是整变量，关键变成跨变量图关系和空间依赖。如果缺失率会变化，重点则是表示对齐和鲁棒训练。

因此，一个实用判断是：

| 场景 | 优先考虑 |
|---|---|
| 高缺失率、缺失真值不可得 | CRIB、MissTSM 类直接预测 |
| 点/块缺失且希望统一建模 | CoIFNet、S4M |
| 变量整段缺失、图结构明显 | GinAR、IBN |
| 线上缺失率变化大 | Merlin 类鲁棒增强 |
| 需要可解释和风险提示 | IBN 式不确定性建模 |

总的来说，未来更有希望的路线不是简单追求“补全数据”，而是构建一种能理解缺失模式、利用变量关系、对缺失率变化稳健、并能表达不确定性的预测模型。
