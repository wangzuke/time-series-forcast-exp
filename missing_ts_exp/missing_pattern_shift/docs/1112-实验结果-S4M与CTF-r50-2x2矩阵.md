# S4M 与 ChannelTokenFormer：r=50% 2×2 缺失模式矩阵结果

> 本文保留为 S4M/CTF 的分模型执行与复核记录。请优先引用包含全部当前模型的 [统一框架主结果报告](1113-实验结果-统一框架-r50-2x2矩阵.md)。

## 结论摘要

在严格逐变量配平的 50% 缺失协议下，训练—测试缺失模式组合会显著改变预测误差，但影响的方向与幅度依赖于模型和数据集。

- **S4M** 的变化相对温和。在 B 测试下，使用 P 而非 B 训练的 MSE 增幅为 ETTh1 **4.25%**、Weather **4.29%**、Electricity **9.22%**；Electricity 最明显。
- **CTF** 的模式交互更强。在 B 测试下，P 训练相对 B 训练的 MSE 增幅为 ETTh1 **68.90%**、Weather **27.22%**、Electricity **40.78%**。Electricity 的 B→P 还出现明显失配：相对 P→P，MSE **+100.08%**。
- 两模型没有全局胜者：CTF 在 ETTh1 全部四格更优；S4M 在 Weather 全部四格更优；Electricity 中 S4M 在 P 训练两格和 B→P 更优，CTF 在 B→B 更优。

这组结果支持“仅在单一、同分布缺失模式上评估不足以刻画鲁棒性”的问题设定。不过仅有两个训练种子，结果应视为描述性证据；后续需要增加训练种子或采用 paired 的统计检验确认显著性。

| 项目 | 设置 |
| --- | --- |
| 数据集 | ETTh1、Weather、Electricity |
| 历史长度 / 预测长度 | 96 / 96 |

| P | 分散点缺失 |

## 模式漂移的直接量化

为避免把“B 测试本身可能更难”与“训练/测试模式不一致”混为一谈，主要比较在**测试模式固定**时改变训练模式的差异：

| 模型 | 数据集 | B 测试：P→B 相对 B→B 的 MSE / MAE 变化 | P 测试：B→P 相对 P→P 的 MSE / MAE 变化 |
| --- | --- | --- | --- |
| S4M | ETTh1 | +4.25% / +2.02% | −2.41% / −0.83% |
| S4M | Weather | +4.29% / −1.10% | +1.89% / +4.02% |
| S4M | Electricity | +9.22% / +2.48% | +4.35% / +3.76% |
| CTF | ETTh1 | +68.90% / +38.02% | −14.02% / −8.69% |
| CTF | Weather | +27.22% / +5.31% | −9.44% / −0.64% |
| CTF | Electricity | +40.78% / +17.80% | +100.08% / +34.73% |

解释：正数表示不匹配训练模式使误差升高。最稳定的现象是：**在 B 测试时，使用 B 训练优于使用 P 训练**，两种模型、三个数据集均成立。P 测试下则不具有一致方向：ETTh1/Weather 的 CTF 在 B→P 反而较好，而 Electricity 的 CTF 明显失效，表明“模式漂移”不是单一难度尺度，而是模型归纳偏置与数据动态的交互。

## S4M 与 CTF 的比较

按 MSE 比较：

- **ETTh1**：CTF 在四格均低于 S4M，幅度为 22.7%–59.3%；尤其 B→B 最好（9.173 对 22.547）。
- **Weather**：S4M 在四格均低于 CTF，幅度为 9.2%–26.2%。
- **Electricity**：S4M 在 P→P、P→B、B→P 低于 CTF（分别约 7.3%、8.9%、51.6%）；CTF 仅在 B→B 更低（6.295M 对 7.389M）。

因此，不能用单一平均分数宣称一个模型对模式漂移全面更鲁棒。更有信息量的结论是：S4M 的跨格波动相对温和但绝对性能取决于数据集；CTF 在 ETTh1 和 Electricity B→B 可很强，但在某些训练—测试失配（特别是 Electricity B→P）下脆弱。

## 注意事项与下一步

1. 每个单元仅两个训练种子，且同一训练模型在两个测试掩码上重复评估；需要增加训练种子来形成更可靠的方差估计。
2. 对 CTF 的“B 测试误差低于 P 测试”现象不能简单解读为块缺失更容易；它可能反映模型的 patch/token 机制与 24 步块结构的适配。建议在后续消融中改变块长（如 12/48）并保持每变量缺失率不变。
3. 建议将本表作为问题动机实验的主体：报告 2×2 全表，同时重点展示固定 B 测试条件下 P→B 相对 B→B 的失配增幅。
