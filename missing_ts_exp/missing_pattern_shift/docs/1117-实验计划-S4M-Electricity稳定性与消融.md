# 实验计划：Electricity 上 S4M 缺失模式稳定性与机制消融

**日期：2026-11-17**  
**范围：仅 Electricity 数据集；不包含 Traffic 或更高通道数数据集探索。**  
**状态：计划按已批准的 S4M 严格掩码参照实验与 Electricity 消融实验执行。**

## 1. 研究目标

已有 2×2 实验中，S4M 在 Electricity 上受到训练—测试缺失模式变化的影响较小。本实验只研究这一现象在严格统一掩码协议下能否复现，以及 S4M 的两项机制是否与这一表现有关：

1. MDS-S4 中直接输入的显式缺失掩码流；
2. ATPM 记忆库中的原型读取。

本实验不检验“通道数越高，S4M 越鲁棒”，也不据此对其他数据集或缺失场景作普遍结论。

## 2. 数据和缺失协议

| 项目 | 设置 |
|---|---|
| 数据集 | Electricity，321 个变量，按时间顺序划分 |
| 输入长度 / 预测长度 | 96 / 96 |
| 输入缺失率 | 每个窗口、每个变量精确 50% |
| P 模式 | 每个变量在 96 步中缺失 48 个分散点 |
| B 模式 | 每个变量有两个彼此分离的 24 步连续缺失块 |
| 训练种子 | 2024、2025 |
| 固定测试掩码种子 | 9101、9102 |
| 预测目标 | 保持完整，不施加人工缺失 |

所有训练模式均在 P、B 两种测试模式下评估。每种测试模式使用两个固定掩码种子。训练与验证按对应训练模式生成掩码；测试掩码仅用于最终评估。

按时间顺序使用训练、验证、测试切分；标准化统计量只从训练段计算。掩码审计须验证每个变量的缺失数量准确，并确认 B 掩码的两个 24 步缺失块之间至少有一个观测点，避免相邻块合并成 48 步长缺口。

## 3. 实验矩阵

| 变体 | 训练掩码 | 训练种子 | 训练模型数 |
|---|---|---|---:|
| 完整 S4M 参照 | P、B | 2024、2025 | P 的 2 个既有检查点复用；B 新训练 2 个 |
| 去掉显式掩码流 | P、B | 2024、2025 | 4 |
| 去掉 ATPM 原型读取 | P、B | 2024、2025 | 4 |
| **合计** |  |  | **10 个新训练 + 2 个复用** |

P 训练的完整 S4M 参照已存在于严格逐通道 r50 实验中：其数据、掩码平衡方式、层数、宽度、batch size 与优化器均与本计划一致，直接复用检查点。本轮重新生成两种测试模式、两个测试掩码种子的评估结果。旧 B 训练参照的审计发现最长缺失段为 48 步，因此 B 训练的两个完整参照仍需按严格分离 B24 掩码重训。

每个模型检查点都在 P、B 测试模式及两个掩码种子上评估，共 4 个测试条件。因此总计 48 个模型—测试条件结果，不代表 48 次独立训练。

### 消融定义

- **完整 S4M：**保留显式掩码流、查询编码器和 ATPM 原型读取。
- **去掉显式掩码流：**只取消首个 MDS-S4 层对显式掩码流的直接输入；保留掩码驱动的填补及其余网络结构。
- **去掉 ATPM 原型读取：**保留查询编码器和预测融合层，以查询表示替代读取到的原型表示，并停用记忆库读取与更新。结果解释为原型读取路径的贡献，不扩大为对 ATPM 所有组成的否定。

## 4. 模型训练配置

使用当前公开 S4M 模型实现及已核验的实验适配器。所有变体使用相同的数据切分、训练/验证掩码协议、优化器、训练种子和早停规则。

| 参数 | 设置 |
|---|---|
| S4 层数 | 4 |
| 隐藏宽度 | 512 |
| Batch size | 16 |
| 优化器 | SGD，学习率 0.01，动量 0.9，权重衰减 1e-5 |
| 训练上限 | 20 轮，patience=4 |

优化器取公开训练入口实际启用的 SGD；论文文字与公开代码在优化器描述上存在差异，报告中保留这一说明。每个任务记录代码版本、配置、设备、每轮耗时、最佳轮次和峰值显存。不得根据测试集结果调整参数。

## 5. 评估与分析

主要报告原始尺度 MSE、MAE，并补充按训练集标准差归一化的误差。按训练种子分别呈现结果，并报告两个测试掩码种子的变化范围；不把训练种子与测试掩码种子混为独立模型重复。

分别计算两种测试方向的错配代价：

- **B 测试错配代价：**同一训练种子下，P 训练模型在 B 测试上的误差，相对 B 训练模型在 B 测试上的误差变化；
- **P 测试错配代价：**B 训练模型在 P 测试上的误差，相对 P 训练模型在 P 测试上的误差变化。

消融分析同时比较：

1. 匹配测试下的预测误差，确认移除机制是否损害基本预测能力；
2. P/B 错配代价，判断机制变化是否影响跨模式稳定性；
3. 两个训练种子、两个测试掩码种子下的结果是否方向一致。

按相同测试窗口配对汇总误差。只有两个训练种子时，将结论限定为当前 Electricity 协议下的证据，不作强泛化推断。若预测误差低但匹配模式性能也差，应报告为低敏感性，不能称为有效鲁棒性。

- Electricity 参照和消融共 12 个模型条件，其中 P 参照复用已有检查点，实际新增训练 10 个；Traffic、CTF、PatchTST、DLinear、iTransformer 的 Traffic 扩展均不再排队。
- 在 GPU 7 上串行运行 S4M，避免重模型并发争抢显存。
- 结果、检查点和日志沿用隔离 suite：`exp/results/s4m_traffic_electricity_stability_1115`、`exp/checkpoints/s4m_traffic_electricity_stability_1115`、`exp/logs/s4m_traffic_electricity_stability_1115`。目录名保留原始 suite 标识以避免迁移或覆盖已有文件；本计划限定其中后续新增任务仅为 Electricity。
- 每个检查点完成后执行 P/B 两类测试及两个固定掩码种子，并保留掩码审计信息。
