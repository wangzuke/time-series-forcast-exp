# 缺失模式偏移下的多变量时间序列预测：阶段进展与后续研究计划

**阶段汇报日期：2026 年 11 月 16 日**
**研究范围：历史输入缺失模式发生变化时，多变量时间序列预测模型的性能与稳定性。**

## 摘要

本课题研究多变量时间序列预测中的缺失模式变化问题。许多缺失数据预测工作在训练与测试阶段采用相同或相近的缺失机制；但在实际采集过程中，设备故障、传感器部署或数据管理策略变化可能改变缺失的时间形态及不同变量之间的同步关系。例如，模型训练时的历史输入为散点缺失，部署时却出现连续时间块缺失。由此产生的核心问题是：训练与测试缺失模式不一致时，预测性能会受到多大影响，这种影响是否因模型结构而异？本研究将围绕这一问题开展受控实验，并进一步考察跨变量同步性和缺失块位置。相关研究包括 StableMiss [1] 和 VaryST [3]，但二者的任务与评估设置均与本课题不完全相同。本报告总结当前实验进展、结论边界及后续计划。

## 一、研究问题与实验边界

设 $X$ 表示完整历史序列，$Y$ 表示未来预测目标，$L$ 和 $H$ 分别表示历史输入长度与预测长度。历史观测掩码 $M$ 标记哪些历史值可见（1 为观测、0 为缺失）。缺失感知模型将可见历史值和掩码作为输入；对不直接处理缺失值的预测器，则先仅依据历史窗口内可见数据进行插补，再预测完整未来目标。当前研究假设完整数据与预测目标的联合分布保持稳定，变化的是历史输入的缺失掩码分布：

$$
\mathcal{D}_{train}(X,Y)=\mathcal{D}_{test}(X,Y),\qquad q_{train}(M)\ne q_{test}(M).
$$

其中，$q_{train}$ 和 $q_{test}$ 分别表示训练阶段与测试阶段历史缺失掩码的分布。

缺失只作用于历史输入；未来预测标签保持完整。课题目前聚焦三类可分别控制的缺失特征：

为便于展示实验矩阵，本文将历史窗口内分散位置缺失简称为“散点缺失”，并用 P（point missing）标记；将一段或多段连续时间缺失简称为“连续块缺失”，并用 B（block missing）标记。通道在此指一个变量维度。各变量分别生成、缺失位置彼此独立的块称为“变量独立块缺失”（B-ind）；所有变量在相同时间位置出现缺失块，称为“跨变量同步块缺失”（B-sync）。下文表格中的 P、B、B-ind 和 B-sync 均按此定义使用。

| 问题轴       | 训练—测试变化                                       | 需要回答的问题                                                                 |
| ------------ | ---------------------------------------------------- | ------------------------------------------------------------------------------ |
| 时间形态     | 散点缺失（P）↔ 连续块缺失（B）                      | 训练时见到散点，能否适应连续观测中断？反向迁移是否不同？                       |
| 跨变量同步性 | 变量独立块缺失（B-ind）↔ 跨变量同步块缺失（B-sync） | 其他变量能否弥补某一变量的缺口？所有变量同时缺失时，变量间的信息补偿是否减弱？ |
| 块位置       | 历史窗口起始端、中部、末端（紧邻预测起点）           | 缺失最近历史信息是否比缺失较早历史信息影响更大？                               |

每个实验只改变一个因素；在适用时，控制每个变量的缺失比例、缺失块长度和块数等其他因素，并固定预测窗口。研究不预设缺失模式变化必然损害预测：已有研究指出，在一定假设下，理论上的最优预测器可能不受缺失机制变化影响；本课题检验的是在实际数据、有限模型和具体缺失设置下，模式变化会不会增加预测误差 [1,2]。

因此，本课题并不声称此前无人研究缺失模式变化，而是在已有掩码分布偏移和交通时空鲁棒研究基础上，分别控制缺失的时间形态、跨变量同步关系和缺失位置，并在一般多变量预测数据集上比较模式变化带来的误差。当前检索尚未发现与“训练时各通道独立错位地缺失、测试时各通道在同一时间段缺失”完全相同、且严格控制每个通道缺失比例和块长的预测实验；这一判断仍需随文献检索更新，不作为绝对的研究空白结论。

## 三、已经开展的实验及其目的

### 3.1 早期实验设置核查与协议修正

早期尝试覆盖 30% 缺失率、多个块长和预测长度。核查发现，部分设置按全体数据元素的总数控制缺失率，没有保证每个变量的缺失比例一致；旧版 S4M 输入配置的一次先导检查中，两种缺失掩码下的预测几乎相同，因此我们进一步核对了数据掩码、模型输入和训练参数。这些早期结果仅作为设置核查，不作为本报告的主要科学证据。详细记录见[缺失率与掩码敏感性审计](1108-实验设置核查-缺失率与掩码敏感性.md)及[S4M 实现对齐记录](1109-S4M论文与实现对齐核查.md)。

### 3.2 主实验：缺失率 50%、历史与预测长度均为 96 的散点/连续块缺失 2×2 矩阵

| 项目                    | 设置                                                                                                  |
| ----------------------- | ----------------------------------------------------------------------------------------------------- |
| 数据集                  | ETTh1（7 个变量）、Weather（21 个变量）、Electricity（321 个变量）                                    |
| 历史输入长度 / 预测长度 | 历史窗口和预测区间各为 96 个时间点（$L=H=96$）                                                      |
| 目标缺失率              | 每个变量的历史输入精确缺失 48/96 = 50%                                                                |
| 散点缺失（P）           | 每个变量的 96 个历史时刻中有 48 个时刻缺失，缺失位置分散                                              |
| 连续块缺失（B）         | 每个变量生成两个名义长度为 24 个时间点的缺失块；旧生成器未保证两块之间一定有观测点                    |
| 训练—测试矩阵          | 将两种缺失模式分别用于训练和测试，组成 2×2 矩阵；包括训练与测试模式一致的两种组合，以及两种交叉组合  |
| 重复                    | 两个训练随机种子（2024、2025）；两个固定测试掩码生成随机种子（9101、9102）                            |
| 模型                    | S4M、ChannelTokenFormer（下文简称 CTF）、BiTGraph；以及线性插补后输入 PatchTST、DLinear、iTransformer |

该矩阵用于区分连续块缺失本身的难度，以及训练与测试缺失模式不一致带来的额外误差。测试输入为连续块缺失时，比较“散点缺失训练、连续块缺失测试”和“连续块缺失训练、连续块缺失测试”；测试输入为散点缺失时，则比较“连续块缺失训练、散点缺失测试”和“散点缺失训练、散点缺失测试”。若只比较散点缺失训练后的两种测试结果，就无法区分误差变化是来自测试缺失形态本身，还是来自训练—测试模式不一致。

PatchTST、DLinear 和 iTransformer 本身不是缺失感知模型，本轮采用“历史窗口内线性插补 + 常规预测器”的流水线；插补器只访问历史窗口，不访问预测目标或未来值。相关结果应解释为基线流水线表现，而非模型原生处理缺失的能力。

### 3.3 主矩阵的相对模式迁移代价

以下用均方误差（mean squared error，MSE）作为主指标。下表报告各训练—测试组合的平均 MSE 相对于同一测试缺失模式下、训练与测试模式一致时的相对变化，计算方式为“（跨模式组合的平均 MSE ÷ 匹配模式组合的平均 MSE − 1）× 100%”。每格第一项为连续块缺失测试时，散点缺失训练相对于连续块缺失训练的误差变化；第二项为散点缺失测试时，连续块缺失训练相对于散点缺失训练的误差变化。**表中值表示缺失模式变化预测性能的被影响程度，值越大说明缺失模式变化对其影响越大**。

| 模型                    | ETTh1（7通道）：连续块缺失测试 / 散点缺失测试 | Weather（21通道）：连续块缺失测试 / 散点缺失测试 | Electricity（321通道）：连续块缺失测试 / 散点缺失测试 |
| ----------------------- | --------------------------------------------: | -----------------------------------------------: | ----------------------------------------------------: |
| S4M                     |                                +4.3% / −2.4% |                                    +4.3% / +1.9% |                                         +9.2% / +4.4% |
| ChannelTokenFormer      |                              +68.9% / −14.0% |                                  +27.2% / −9.4% |                                      +40.8% / +100.1% |
| BiTGraph                |                               +18.1% / +24.6% |                                  +76.0% / +89.2% |                                                还在训 |
| PatchTST + 线性插补     |                               +22.5% / +55.1% |                                   +5.0% / −5.7% |                                     +296.7% / +338.8% |
| DLinear + 线性插补      |                               +22.3% / +57.3% |                                   +0.2% / −0.1% |                                     +304.6% / +988.3% |
| iTransformer + 线性插补 |                               +35.7% / +19.2% |                                    +1.3% / +0.4% |                                     +796.5% / +271.7% |

从上面结果中可以简单总结：在ETTh1这个低维数据集上，S4M展现出了领先的稳定性，同时在Electricity这个高维数据集上，其领先更加大了。再Weather数据集上，六个模型与方法中，除了BitGraph都表现不错的稳定性，可能是因为这个数据集的趋势性比较明显，预测难度比较小。

高维数据集上S4M的这个表现相比于其他几个方法与模型相当不错，那么我就思考了，S4M模型整体表现这么好的原因是什么呢，是因为其作为状态空间模型结构的特点吗，还是因为其模型方法设计的其他部分带来的，并且我也想更进一步分探索其在更大维度的数据集上会不会依然有领先的表现，于是我计划并正在实验，将862个通道的Traffic数据集纳入实验，这也是S4M其论文工作中实验了的数据集。


## 三、目前可以得到的结论

1. **模式不一致会影响部分模型，但影响取决于模型和数据集。** Electricity 上多种插补后预测模型的误差增幅很大；ETTh1 上也有多个模型在模式变化时退化。Weather 上 PatchTST、DLinear、iTransformer 的变化接近零或方向不一致，而 BiTGraph 变化明显。因此不能概括为所有模型、所有数据集都会因散点与连续块缺失的切换而退化。
2. **训练、测试缺失模式一致时的预测精度，与面对模式变化时的稳定性是不同评价维度。** Electricity 上 iTransformer 在训练和测试模式一致时误差较低，但在两种模式之间变化时误差明显增大；S4M 的相对误差变化较小，却并非绝对误差最低。需要同时报告模式一致时的精度、模式变化造成的额外误差和最差测试条件下的误差。
3. **目前 S4M 的结果只支持“本协议下对模式变化的误差变化较小”，不支持机制归因。** S4M 包含显式处理缺失掩码、读取时间原型和状态空间传播等设计，但当前整体实验不能判断其中哪项导致了较小的误差变化；平滑预测、欠拟合、数据冗余及训练细节也可能产生相同现象。要识别具体原因，仍需在相同实验条件下开展诊断与组件消融。
4. **Traffic-862 上的 DLinear 初步结果显示该现象可能不局限于三种已有数据集。** 但完整模型矩阵尚未结束，且这是单一模型的扩展证据。

## 五、现存问题与结论边界

### 5.1 块长度控制尚不严格

主实验（每个变量缺失率 50%）使用的旧块掩码生成器允许两个名义长度为 24 的缺失块相邻。对 ETTh1、Weather、Electricity 的掩码审计均观察到最长连续缺失达到 48 个时间点。每个变量的缺失总量配平是成立的，但实际连续缺口长度并非始终为 24。因此，现有主结果可说明散点缺失与连续块缺失的分布变化会影响部分预测器，却不足以把影响精确归因于单个 24 时间点缺失块。Traffic-862 新套件保证两个缺失块之间至少有一个观测点，但其掩码分布与旧矩阵并不完全相同。

### 5.2 统计重复有限，部分矩阵未完成

主矩阵每种训练缺失模式只有两个独立训练随机种子，并用两个固定测试掩码重复评估。两个测试掩码共用同一训练得到的模型权重，不能视为额外的独立训练重复；当前重复次数也不足以支持统计显著性结论。BiTGraph 在 Electricity 上的连续块缺失训练结果尚缺；当前仍运行的一个 BiTGraph 任务使用旧的 30% 全体数据元素缺失率配置，不能补齐每个变量缺失率均为 50% 的矩阵。

### 5.3 数据缺失机制仍属受控人工注入

现阶段在原本完整的公开数据中按预设规则人工施加随机缺失掩码，未来标签保持完整。结果暂不覆盖自然发生的缺失、设备长期掉线、由未观测值决定缺失概率的情形，或完整数据分布同时变化等情况。实验结论应限定在当前受控的掩码变化范围内。

### 5.4 模型结构与输入预处理需要分开解释

S4M、ChannelTokenFormer（CTF）和 BiTGraph 可以直接接收不完整历史输入或缺失标记；PatchTST、DLinear、iTransformer 则先对历史缺失值做线性插补，再进行预测。因此两类方法的误差差异同时受到模型结构和输入预处理影响。Electricity 上的 CTF 配置是我们为统一实验补充的设置，原论文没有发布该数据集的对应命令；S4M 论文文字与作者公开训练入口中的优化器设置也存在差异，已在实验记录中说明。最终报告应保留这些可比性边界。

## 六、后续工作计划

### 第一阶段：完成并整理正在运行的 Traffic-862 扩展

- 完成 S4M 在散点缺失和连续块缺失下的训练及两个训练随机种子的评估，并完成 ChannelTokenFormer、PatchTST、iTransformer 的预定矩阵；保留已经完成的 DLinear 结果。
- 继续核验每个变量的缺失比例、两个长度为 24 的缺失块之间是否确有观测值、峰值显存和训练时间；资源无法支持的设置如实标记，不缩小模型后仍称为原配置。
- 汇总 Traffic-862 完整矩阵，再判断 S4M 的相对稳定性和 DLinear 的初步模式变化代价是否能在其他模型上观察到。

### 第二阶段：建立严格的散点/连续块缺失对照并补全主矩阵

- 对旧主矩阵的块掩码重新审计；通过新生成器确保每个变量缺失 48/96 个历史值，且两个名义长度为 24 的缺失块中间至少保留一个观测时刻。
- 优先补齐 BiTGraph 在 Electricity 上、缺失比例为 50% 且按变量配平的连续块缺失训练格。另有一个旧任务按全数据元素总体配平 30% 缺失，各变量的实际缺失比例不固定；该任务单独归档，不用于填补当前主矩阵。
- 结合算力预算，在 ETTh1 和 Electricity 上对关键模型复跑严格隔开的 24 步块缺失条件，确认主要结论不依赖于两个缺失块相连形成的 48 步缺口；Weather 保留为效应较弱的边界数据集。

### 第三阶段：解释 S4M 在 Electricity 上较小的模式变化误差

- 复用相同窗口和模型权重，配对比较散点与连续块缺失输入下逐窗口、逐变量的预测差异、绝对误差和预测振幅，并比较其相对简单预测基线的误差改善。
- 按最长连续缺口、距预测起点最近观测距离和通道误差分层，检查均值是否掩盖了局部失效。
- 在统一、严格的掩码协议下开展 S4M 组件消融：分别检验其模型结构设计中的双流 S4 模块显式输入缺失掩码是否有帮助，以及自适应时间原型模块读取原型信息是否有帮助。若相关组件无法通过小幅、可审阅的改动单独关闭，则不强行作机制解释。

### 第四阶段：深入研究“缺失模式”变化这一个场景问题，块缺失的同步缺失与异步缺失的研究

- 对变量独立块缺失与跨变量同步块缺失采用 2×2 训练—测试矩阵；每个变量的缺失数、缺失块长度、块数和位置分布保持一致，只改变各变量的缺失块是否在时间上对齐。
- 位置实验固定缺失率、块长和同步度，比较窗口开头、中部及靠近预测起点的块；重点记录预测误差随预测步长的变化。
- 初期优先使用 ChannelTokenFormer 和 BiTGraph，并加入一个不显式接收缺失标记的“插补后预测”对照。任何关于跨变量同步性的结论都必须先排除各变量缺失比例和缺失块分布不一致造成的影响。

### 第五阶段：在诊断结果支持后评估提升跨模式稳定性的训练方法

先比较单一缺失模式训练、ChannelTokenFormer 原有的随机遮挡历史时间片段策略，以及均衡混合多种缺失结构的训练方式。具体做法是在训练过程中按预设比例抽取散点缺失、各通道独立错位的块缺失、所有通道同位置的块缺失及不同块位置，使模型在训练时见到多种可能的输入缺失形态。随后报告每种测试模式下的误差、各模式的平均误差、最差测试条件下的误差，以及相对于“在目标测试缺失模式下单独训练的模型”的误差差值。

在随机结构化遮挡基线上，再检验受 VaryST 启发的重要性导向扰动：在缺失比例、块长、变量间缺失位置是否对齐以及位置分布相同的条件下，比较随机选择缺失区间与优先遮挡模型较依赖的历史时间片段。可先用模型注意力或输入梯度估计重要性，再通过遮挡前后的预测误差变化进行抽查；若重要性导向方法不能稳定优于同等缺失数量下的随机块遮挡，则不保留这项复杂设计。只有同步块缺失实验显示跨变量信息确实变得不可靠后，才进一步考虑增加一种按各变量当前可观测信息调整变量间融合权重的门控结构。

## 七、阶段判断

目前课题已初步建立“问题定义—受控 2×2 诊断—模式变化误差比较”的证据链。Electricity 上的明显退化现象提供了研究动机；ETTh1 和 Weather 的结果差异则说明结论必须限定到具体数据集和模型。当前最需解决的是严格控制连续块长度并补齐 BiTGraph 的实验格；在此基础上，再完成 Traffic-862 扩展、S4M 机制诊断、跨变量同步性与块位置实验，以及多种缺失结构联合训练的比较。

我们建议将阶段性主张限定为：**在当前受控人工掩码实验中，训练与测试的缺失结构不一致会对部分多变量预测模型造成明显且依赖数据集的迁移代价；不同模型在训练、测试缺失模式一致时的预测精度，不能单独代表其面对部署缺失变化时的稳定性。**是否能通过多种结构化缺失模式联合训练或重要性导向遮挡稳定降低该代价，仍是待实验检验的问题。
