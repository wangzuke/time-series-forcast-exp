# OCPE 补充编码与关键机制验证：实验结果报告

**报告日期：2026-11-21**  
**实验：Weather、Electricity；四个版本；P/B_u双向2×2；32次训练、128项测试。**  
**状态：核心训练与测试全部完成，CPU产物审计通过。ETTh1与S4M确认实验尚未开展。**

## 阅读摘要

**本轮支持“观测条件编码在Weather上有预测价值”，但不支持“完整矩阵后验求解普遍优于简单逐维归一化”。**

- Weather：F1对角归一化在两向错配中分别降低标准化MSE约22.7%、23.5%；F3均值＋方差约降低23.8%、25.0%。匹配条件也明显改善，说明增益并不只出现在错配条件。
- Electricity：F1最接近保持基线水平，错配均值小幅改善，但B_u→P的种子方向不一致。F2/F3在P→B_u有收益，在B_u→P分别恶化约30.3%、22.3%，没有解决双向变化。
- 完整求解：F2相对F1，在两个数据集的八个平均结果格中均没有更好。本轮未得到保留完整矩阵求解的普遍性能依据。
- 方差：F3相对F2的八格标准化MSE均值均改善，Weather的两个训练种子也均改善；但F3对F1的优势小得多，Electricity的反方向退化仍然存在。不能把方差的增量等同于整个后验方案占优。

这些是两次独立训练种子下的经验结论，不作为统计显著性声明。方法取舍建议见第11节。

### 1.1 四个版本的作用

四版本都保留“历史窗口内插值＋有效掩码”的输入分支，再接同一个普通S4。F1/F2/F3增加一个条件编码分支，投影后与历史表示相加：

\[
h_t=E_{\mathrm{history}}([\widetilde X_t,M_t])+W_{\mathrm{enc}}u_t.
\]

| 版本 | 条件分支输入 | 要回答的问题 |
|---|---|---|
| F0：常规历史 | 无 | 同协议下的常规预测基线 |
| F1：对角归一化 | `[b_t / diag(J_t), 0]` | 简单逐维条件归一化已经能带来多少收益？ |
| F2：后验均值 | `[J_t^{-1}b_t, 0]` | 潜在方向之间的完整矩阵条件化是否比F1更有用？ |
| F3：均值＋方差 | `[J_t^{-1}b_t, log diag(J_t^{-1})]` | 在均值表示之外，方差是否提供额外信息？ |

J_t和b_t来自相同定义的线性高斯观测模型及当前有效观测前缀。一个窗口共享一个16维潜变量，没有新增动态状态转移；方差也不是未来预测区间。

三个增强版本的参数量、辅助观测似然、编码接口维数和主干一致。它们独立端到端训练，因此F2与F1比较的是**不同表示路径及其学习结果**，不是固定同一个已训练载荷后只切换求解操作。

新增投影无偏置、零初始化，各版本初始预测与配对F0相同；共同模块初始化与CUDA随机状态也已核对。F0不具有额外观测模型，整体增益仍可能涉及新增容量和学习机制，不能全部归因于后验语义。

### 2.2 Weather修正及与旧报告的关系

训练段81个`-9999`分布在三个变量中，标为自然无效。它们不进入统计量、观测似然或预测标签损失。历史输入采用“自然有效×人工可见”的掩码；不删除行或改变时间切分。验证和测试段没有该占位值。

例如，wv训练标准差修正为约1.667；旧版纳入占位值时约52.10。标准化指标对这些变量的加权已经改变，因此**不能把本轮Weather的0.2—0.3与旧版0.1—0.2直接比较来判断方法进退**。

本轮还改变了B的位置分布，并改为历史分支与条件分支融合。新旧结果不构成只改变一个组件的旁路消融，也不能直接接入1113旧主表排名。本报告的四版本之间共享相同数据、标准化与掩码，内部对比成立。

### 2.3 数量与统计单位

两数据集×四版本×两source×两个训练种子=32次训练。每个模型进行P/B_u×两个测试掩码的四项测试，共128项。

每个训练种子先平均两个测试掩码，再平均两个训练种子。主表的“±”是**两个训练种子均值之间的样本标准差**，不是四个测试值的标准差，更不是置信区间。相对变化由未舍入的格均值之比计算，逐种子变化另列。

## 5. 对方法的三个核心判断

### 5.1 Q1：补充编码能否改善预测？——Weather支持，Electricity有限

Weather中F1/F2/F3的四格均改善，标准化与原量纲MSE方向一致；两个训练种子中的错配收益均为正。收益覆盖全部21个变量的平均标准化误差，具有实用价值。

Electricity中，F1错配均值只降低约1%—2%，B_u→P一个种子改善、另一个恶化。F3的P→B_u降低约4.3%，但反方向增加约22.3%。因此不能把本轮结论概括为“保留历史旁路后，双向错配和精度取舍都已解决”。

融合通路允许网络保留常规历史信息，但训练完成后的表示和权重仍会共同改变，不自动保证性能不差于原基线。

### 5.2 Q2：完整矩阵求解是否优于对角归一化？——本轮不支持

| 数据集 | 关键对比 | P→P | P→B_u | B_u→P | B_u→B_u |
|---|---|---|---|---|---|
| Weather | F2 相对 F1 | +5.7% | +6.1% | +0.5% | +1.0% |
| Weather | F3 相对 F1 | +0.2% | -1.4% | -1.9% | -0.7% |
| Weather | F3 相对 F2 | -5.3% | -7.0% | -2.4% | -1.7% |
| Electricity | F2 相对 F1 | +1.3% | +0.3% | +31.8% | +6.0% |
| Electricity | F3 相对 F1 | +1.0% | -1.9% | +23.7% | +3.7% |
| Electricity | F3 相对 F2 | -0.4% | -2.2% | -6.1% | -2.2% |

F2对F1的八格平均标准化MSE变化全部为正；Electricity的B_u→P约增加31.8%，两个训练种子分别约增加26.5%、37.0%。这不是仅由一个幸运种子或一个测试掩码造成的平均现象。

它否定的是“当前学习与模型配置下，完整联合条件化比简单逐维归一化更好”的经验预期，不否定高斯后验公式的数学正确性。载荷估计误差、表示尺度和联合训练等都是可能解释，本轮尚未区分其原因。

因此，不能继续把“完整矩阵后验更精确，所以预测必然更好”作为本轮方法结论。

### 5.3 Q3：方差是否有增量？——有条件支持，Weather较清楚

F3对F2的八个平均标准化MSE均改善。Weather中，每个格的两个训练种子都改善；两种错配的平均增量约7.0%、2.4%。这支持方差输入在该设置下能提供有用特征。

但还有两点决定最终取舍：

- 相对F1，Weather两种错配的额外收益只有约1.4%、1.9%；其中B_u→P的原量纲MSE反而增加约3.5%。它不是所有尺度下都优于简单归一化。
- Electricity的B_u→P中，F3对F2的标准化均值改善约6.1%，但两个种子一个恶化约2.0%、另一个改善约13.5%，原量纲MSE均值恶化约2.4%。并且F3仍明显差于F0/F1。

**方差可以作为候选特征保留讨论，但不是完整后验方案已经成立的证据。** 本轮没有重新做校准实验，也没有输出未来预测分布；不以预测收益证明方差校准。

**Weather：更有把握的是普遍精度提升，而非专门消除了布局变化的影响。** F3的匹配和错配都改善约23%—25%。P训练模型从P切换到B_u时，F0平均变化约+2.2%，F3约+2.3%，没有表现为这一部署变化明显缩小。固定B_u目标的错配代价从约16.2%降到14.3%，幅度远小于绝对预测误差的下降。

Weather的固定P目标代价为负，表示该组B_u训练模型在P测试上比P训练模型更好，不代表缺失具有神奇的增益，也不能将每次布局变化预设为退化。

**Electricity：单一方向的代价下降不能代表双向更稳。** F3固定B_u目标的代价从约85.6%降到70.5%，但它的B_u匹配误差也变差。更重要的是固定P目标代价由约13.3%增加到39.1%，与B_u→P绝对误差退化一致。

本轮因此不支持“完整方案普遍降低P↔B_u错配敏感性”的主张。

## 9. 与上一轮结果的联系和区别

这一轮支持继续探索“用实际观测构造补充表示”，并显示简单归一化的重要性。它没有证明低秩前端完全替代历史表示的旧结构一定不如融合，也没有隔离旁路单独的因果效果。

Weather统计量、B位置分布、输入结构、配对随机流与训练实现均有相应调整。即便P的人工位置沿用，跨轮标准化MSE和整体收益也不能作为同一条件的单组件比较。

本轮尚未验证S4M增强、未验证新版本ETTh1、不与1113旧主表直接排名，也不宣称优于VaryST/NeuMISE等文献方法。这些边界不影响本轮四版本内部对比。

## 10. 本轮能支撑的结论

| 原问题/主张 | 结果判断 |
|---|---|
| 补充观测条件表示有实用价值 | Weather支持；Electricity增量有限且依赖方向 |
| 完整矩阵求解比逐维归一化更好 | 不支持，F2八格平均结果均未超过F1 |
| 方差具有额外预测特征价值 | Weather较支持；Electricity仅部分指标/条件支持 |
| 方差已经得到可靠校准 | 本轮未验证 |
| 保留历史分支可以保证匹配精度和错配都不受损 | 不支持，Electricity的B_u训练仍有代价 |
| 增益主要来自专门减轻缺失错配 | 证据不足，Weather更像普遍精度提升 |
| 方法可以帮助强主干S4M | 未验证 |

## 11. 方法取舍建议

1. **把F1保留为下一阶段的优先统一候选和机制参照。** 它在Weather取得大部分收益，在Electricity更接近基线；但Electricity收益小且反向种子不稳，不能称为已经成熟的通用方法。
2. **F3保留为Weather上的增量候选。** 它比F2更值得继续，两个错配主指标略优于F1，但新增收益、尺度依赖和适用范围必须如实报告。
3. **不继续把“完整矩阵求解必然更优”作为已获支持的核心主张。** 若坚持完整后验主线，应先解释F2弱于F1、F3在Electricity反向失效的问题；单纯加大实验规模不能替代这一判断。
4. 后续是否执行ETTh1和S4M，依据上述候选取舍推进。本报告不自动启动新训练，也不将这份建议写成已完成的确认结果。

这一轮得到的是明确的方法筛选信息：**有效部分在于观测条件补充表示；完整联合后验求解的必要性尚未成立。** 理论计算正确与真实预测有效需要分别判断。
