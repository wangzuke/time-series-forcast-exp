# OCPE 文献整理范围与核验规则

- 建立日期：2026-11-20（Asia/Shanghai）。
- 类型：围绕当前 OCPE 原型的定向范围调研与来源核验，不是穷尽式系统综述。
- 对象：静态窗口线性高斯潜变量；根据实际观测前缀计算后验均值与协方差；将均值与对数边际方差输入普通 S4；用于散点 P 与时间块 B 的训练—测试缺失错配预测。
- 问题：哪些计算属于标准统计工具？哪些先行方法结合概率推断、不确定性和预测？哪些论文确实研究缺失机制变化？现有证据能否支持组合的新颖性？

## 纳入与排除

纳入可定位的一手论文、正式会议页面、作者原文、预印本及官方实现；保留经典统计依据，不设起始年份，检索截至建立日期。方法相关文献与场景相关文献分开编码。预印本不视为已同行评审。

不因为论文处理缺失数据、使用掩码或测试不同缺失率，就自动认定它研究了 P↔B 训练测试错配。不将另一条“观测归一化残差校正”路线的文件、检索结果或设计结论搬入本目录。

## 证据与历史来源

- history_role 区分：原实验计划已列依据／此前讨论的相关工作／本轮补充核验。不能将本轮补充文献追溯成方法最初来源。
- read_depth 记录实际读取位置；摘要核验不写成全文精读。
- shift_evidence 区分：明确场景实验／一般缺失机制变化／未核实此场景。未核实不等于论文一定没有。
- novelty_status：本轮不出具“无人做过完整组合”的结论；逐篇相似性不构成全领域排重。
- 搜索命中数只统计工具实际返回内容；不伪造数据库总命中数、PRISMA 筛选数或独立双人筛选。

## 采集方式

优先尝试技能建议的 parallel-cli；环境未安装时使用 web.run 学术检索与一手页面读取。补充查询 arXiv、Crossref、DBLP 等来源，访问失败和限流也保留记录。数据库元数据核验与方法原文核验分别记载。
