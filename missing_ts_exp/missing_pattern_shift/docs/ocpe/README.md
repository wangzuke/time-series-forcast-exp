## 方法依据与目录范围

OCPE 原计划注明的方法基础见[原实验计划附录 B](1119-实验计划-观测条件后验推断与轻量S4验证.md)。本轮新建的[专属文献资料](literature_sources/1120_ocpe_method_foundations/README.md)区分原有依据、相关工作与补充核验，不将后续检索倒推为最初设计来源，也不声称已经完成穷尽查新。

跨领域文献调研、观测归一化残差校正候选方案及其调研附件不归入本目录，不将这些材料视为当前 OCPE 的设计或已确认后续计划。

## 历史材料与目录约定

- `archive/` 保存两数据集阶段结果、Weather 补充记录和早期运行记录，见[归档说明](archive/README.md)。
- 第一轮以三数据集报告为准；本轮补充编码以1121详细报告为准。数据处理与B协议发生变化，两轮不合并为直接模型排名。
- 本目录中的相对链接已按新位置修正。
- 实验代码与原始产物仍在 `../../exp/`，没有随文档迁移。

共同框架及其他基线资料见[上级文档导航](../README.md)。
