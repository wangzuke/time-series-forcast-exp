# 实验计划：OCPE 补充编码与关键机制验证

**日期：2026-11-20**  
**状态：E0/E1及E2核心队列已完成：32次训练、128项测试；E3分析与产物审计已完成，方法取舍建议见[详细结果报告](1121-实验结果-OCPE补充编码与关键机制验证.md)。E4/E5尚未启动。执行情况见[运行记录](1120-运行记录-OCPE补充编码与关键机制验证.md)。下文保留本轮实验设计。**  
**核心路线：保留常规历史输入分支，将观测条件编码作为补充；用四个关键版本决定完整矩阵求解、后验均值和方差是否值得保留。**

## 阅读摘要

上一轮已经支持 OCPE 在部分数据集的缺失错配预测中有价值，但 Electricity 有匹配精度代价，ETTh1 四格退化，Weather 还存在需要纠正的数据占位值。下一步应形成更有实用价值的方法版本，同时识别真正有效的组件。

本轮不要求完整鲁棒性定理、完善的方差校准或覆盖所有真实故障。理论用于解释“为什么根据实际观测重新求解有意义”，实验用于回答“这一计算是否改善预测，哪些组件值得保留”。

| 优先级 | 要做什么 | 动机与目的 | 正式训练量 |
|---|---|---|---:|
| 准备 | 修正 Weather 占位值；统一 P / B-uniform 协议 | 排除明显的数据失真，减少旧块位置偏好的影响 | 0 |
| 准备 | 新融合接口、后验运算及 GPU 短检查 | 确保新增分支实现正确，能够高效运行 | 短运行，不计入主表 |
| 核心必做 | Weather、Electricity 的四版本双向 2×2 | 检验补充编码、完整矩阵求解与方差的作用 | 32 |
| 核心必做 | 配对结果、训练状态与计算开销分析 | 决定保留哪一版，而非只报告一个最优数字 | 复用上述结果 |
| 后续确认 | ETTh1 的基线与冻结候选版 | 检查方法是否改善已知失败，不回避反例 | 8 |
| 后续确认 | S4M 与 S4M＋冻结候选模块 | 检查方法是否能为强主干提供增量 | 16 |

核心队列只有 **32 次正式训练**。后两项在核心结果分析、候选版本冻结后执行，不预先混入同一训练队列；若两项均推进，总量为 56 次训练。训练种子加密、更多数据集和额外故障家族不列入本轮默认任务。

## 1. 当前证据与本轮要回答的问题

### 1.1 继续研究的理由

- Electricity、Weather 已出现双向错配收益，说明观测条件表示值得继续验证。
- 当前后验前端完全替代常规历史表示，可能保留公共结构却损失局部信息；这是值得检验的解释，尚未被上一轮实验确证。
- 旧 STAT 对照同时改变了矩阵信息、特征尺度和均值/方差表示，不能决定最终方法应该保留哪些运算。
- Weather 训练段有 81 个 `-9999` 占位值，被当作普通有限数值处理。修正后重训是本轮数据准备的一部分。
- 原主 B 通过多项分布分配间隔，逐位置缺失概率高度集中。本轮以合法块位置组合等概率的 B-uniform 为主 B。

### 1.2 三个核心问题

| 问题 | 主要对比 | 能得到的结论 |
|---|---|---|
| Q1：保留历史通路后，观测条件编码能否提供实际增量？ | 增强版本 vs 常规历史基线 | 方法在新统一协议下是否有预测价值 |
| Q2：完整矩阵求解是否比简单逐维归一化更有用？ | 后验均值 vs 对角归一化 | 是否值得保留潜在方向之间的联合条件化 |
| Q3：方差是否提供可重复的额外收益？ | 均值＋方差 vs 仅均值 | 方差是否进入最终结构 |

Q1 是方法的实用性问题，Q2、Q3 用于方法取舍。无需让三个问题全部得到肯定答案：方差无效可以删除；简单归一化足够好也应接受并如实调整方法主张。

## 2. 新候选结构：保留历史分支，增加条件编码

### 2.1 信息流

```text
历史可见值 X_obs、有效观测掩码 M
                 │
          ┌──────┴─────────────┐
          │                    │
 历史窗口内插值＋掩码     可学习线性高斯观测模型
          │                    │
       历史投影          逐前缀条件编码 u_t
          │                    │
          │                编码投影
          └─────────相加────────┘
                      │
                 同一个普通 S4
                      │
                    预测头
                      │
                  未来 96 步
```

融合规则为：

\[
h_t=E_{\mathrm{history}}([\widetilde X_t,M_t])+W_{\mathrm{enc}}u_t.
\]

其中，历史分支与 LI-S4 一致；新增分支提供观测条件表示。相加后的宽度保持 64，不扩大 S4 主干。新增投影不设偏置，权重以零初始化，使各增强版本初始预测与相同种子的基线一致；随后端到端训练。

零初始化下，编码投影第一步可获得预测梯度，观测模型第一步仍可由辅助似然更新；不应错误地要求第一步预测梯度已经传至全部观测模型参数。短检查应确认投影更新后，预测梯度能够进入载荷和噪声参数。

这是拟实现的新结构，不能称为已经存在于上一轮 OCPE 中的功能。它不使用“真实历史减模型重建值”的残差作为输入，与其他目录中的观测残差校正路线分开。

### 2.2 共同的观测模型

沿用窗口共享潜变量与时间—通道载荷：

\[
z\sim\mathcal N(0,I),\quad x_{t,c}=\mu_c+a_{t,c}^{\mathsf T}z+\epsilon_{t,c},\quad
\epsilon_{t,c}\sim\mathcal N(0,v_c).
\]

对实际有效观测构成的前缀集合 O_t：

\[
J_t=I+\sum_{(s,c)\in O_t}a_{s,c}a_{s,c}^{\mathsf T}/v_c,\qquad
b_t=\sum_{(s,c)\in O_t}a_{s,c}(x_{s,c}-\mu_c)/v_c.
\]

\[
m_t=J_t^{-1}b_t,\qquad \Sigma_t=J_t^{-1}.
\]

这仍是静态窗口潜变量，不新增动态状态转移。理论动机采用带先验正则的加权最小二乘与高斯条件均值解释；不为融合后的整网预先声明风险保证。

### 2.3 只保留四个训练版本

| ID | 展示名 | 常规历史分支 | 编码分支输入 u_t | 主要用途 |
|---|---|---|---|---|
| F0 | LI-S4 | 保留 | 无，补充分支恒为 0 | 常规预测基线 |
| F1 | LI＋DIAG-S4 | 保留 | `[b_t / diag(J_t), 0]` | 简单逐维条件归一化 |
| F2 | LI＋MEAN-S4 | 保留 | `[m_t, 0]` | 完整矩阵条件求解 |
| F3 | LI＋MEANVAR-S4 | 保留 | `[m_t, log diag(Σ_t)]` | 检验方差的增量 |

F1/F2/F3 的输入接口均为 2r=32 维，使用相同投影形状；占位 0 为 r 维向量。三个增强版本具有相同的载荷、均值、噪声、辅助似然与 S4 配置，独立端到端训练。共同模块采用配对初始化，避免因创建前端而改变主干初始化随机流。

F1 的预测表示不做完整矩阵求解，但其共同辅助似然仍需末步后验运算。因此，F1 是表示与机制对照，不是已经优化到最快的无矩阵求解实现。

F0 没有观测模型，参数量小于增强版本。F2/F3 对 F0 的收益代表整体模块增量，不能单独排除新增容量或辅助训练的影响；F1/F2/F3 之间的比较承担更细的机制区分。F2 与 F3 接口宽度相同，但有效特征内容不同，不把它们称为完全等信息。

旧 STAT-S4 和旧“只输入后验表示”的 PU-S4 保留为已有结果，本轮不默认增加这两个训练版本。由于数据与块采样已经改变，不能用新旧数字直接证明“新增历史分支单独导致了提升”。

## 3. 实验 E0：数据修正与统一掩码准备

**动机：**正面结果需要建立在有效数值和清楚定义的布局变化上。  
**目的：**形成所有新模型共享的数据处理与掩码版本，不把旧占位值或旧块位置偏好混入方法排名。

### 3.1 Weather 占位值处理

1. 保留原始 CSV，派生有效值指示 Q：已知 `-9999` 占位值为无效，正常数值为有效；同时扫描 NaN/inf，记录位置和数量。
2. 均值、标准差只由训练时间段中各变量的有效值计算。验证、测试不参与统计量拟合。
3. 人工观测掩码记为 M_art，模型实际使用 `M = Q × M_art`。无效原值先通过选择操作置零，再参与张量运算，避免 `NaN × 0` 污染计算。
4. 历史插值仅使用当前历史窗口中实际有效且未被人工隐藏的值；内部缺口线性插值，边界延拓最近有效值，全通道无观测时回退为标准化 0。
5. 原始无效的未来目标不计入预测损失和指标，不将填补后的标签当真实监督。预测损失按有效目标数归一化，记录有效计数。
6. 观测辅助似然只使用有效可见历史，不使用自然无效值或被人工隐藏的历史真值。

因此，训练中“每变量人工隐藏 48/96”仍保持，而叠加少量自然无效值后，实际有效观测数可能小于 48。审计分别报告人工缺失数与实际观测数，不强行把两者都描述成精确 50%。当前复核中 Weather 验证和测试段未发现该占位值，实施时再次确认。

Electricity、ETTh1 使用同一有效值接口，先扫描而不擅自裁剪正常极值。共同预处理仍允许使用完整训练段的有效数值估计标准化统计，这是受控实验约定，不表述为完全缺失训练数据下的统计量学习。

**产物：**数据质量清单、原始文件哈希、有效值掩码哈希、训练统计量及其哈希、各切分有效目标数。

### 3.2 新主掩码协议

| 项目 | 冻结设置 |
|---|---|
| 历史 / 预测长度 | L=96，H=96 |
| P | 每变量等概率选择 48 个人工缺失位置 |
| 新主 B，记为 B_u | 每变量两个严格分离 B24；在全部合法位置组合中等概率采样 |
| 块间隔 | 至少一个观测位置 |
| 通道关系 | 各通道独立抽样，不增加同步故障 |
| 训练 | P 或 B_u 分别训练；掩码随 epoch 更新 |
| 验证 | 与 source 相同的掩码家族；固定掩码 |
| 测试 | P、B_u 两种目标家族；每种固定两个掩码种子 |

沿用已核验 B-uniform 的位置映射：从 0…48 中等概率选择两个不同整数 a<b，两个缺口起点分别为 a 和 b+24，共有 C(49,2)=1176 种合法组合。

这里“均匀”指合法块位置组合等概率，不意味着每个时间点的缺失概率完全相同。位置审计仍保留，但本轮不要求彻底分离连续性、近期可见性等所有因素。

### 3.3 掩码与此前实验如何对应

**P 沿用此前的人工掩码；旧主 B 改为 B-uniform；已有 B-uniform 测试掩码继续复用。** 不因新增模型而为每个版本重新独立抽一套掩码。

| 数据阶段 / 家族 | 与此前的关系 | 执行规则 |
|---|---|---|
| P 训练 | 保持同一个 epoch、窗口、训练种子对应的人工掩码一致 | 保留旧 P 的算法及完整种子派生规则；依然每个 epoch 更新，不固定为一张掩码 |
| P 验证、测试 | 保持此前固定掩码 | 验证种子为训练种子+10000；测试9101/9102；保留原切分与窗口索引 |
| B_u 训练 | 需要新生成，此前未按 B-uniform 训练 | 固定新规则，种子派生包含协议版本、dataset、split、训练种子、epoch、窗口索引与家族 |
| B_u 验证 | 本轮生成固定验证掩码 | 使用训练种子+10000，同一个验证窗口跨epoch及跨版本一致 |
| B_u 测试 | 复用上一轮 B-uniform 压力测试掩码 | 保留旧 `stable_seed(dataset, split, seed, index, "B-uniform-v1")` 及采样顺序，使用9101/9102 |

P 的旧派生规则为 `stable_seed(dataset, split, seed, epoch_component, index, "P", 24, "per_channel")`；验证和测试的 `epoch_component=0`。新协议版本写入任务元数据，不额外加入需要兼容的 P 或 B_u 测试随机种子。**相同整数种子并不足以保证相同掩码，算法、派生键、窗口索引和抽样顺序也必须一致。**

旧 B-uniform 测试分支未包含 epoch，不能不加修改地用于动态训练；新增训练分支与兼容测试分支分别处理。所有新版本、以及后续普通S4和S4M，在同数据集、切分、种子、epoch和窗口索引上使用同一人工掩码；不同模型早停轮数可以不同。

Weather 清洗保留原行数、变量顺序和时间切分，不删除行或重排窗口，以便人工掩码兼容。清洗后实际有效观测掩码为 `Q × M_art`，受原占位值影响的位置可能与旧实际输入不同；“沿用”指人工掩码，不隐去这一数据修正。

旧主 B 不进入本轮主表；文件中保存明确的 `B_uniform_sep24_v2` 类似版本标签，展示用 B_u，避免和旧 B 混淆。

**产物：**掩码版本、固定样例指纹、与旧 P / 旧 B-uniform 测试掩码的兼容核对、缺失段审计、逐时间缺失概率、最后有效观测位置和通道平均共同缺失比例。样例指纹配合确定性生成器与源码哈希使用，不称为完整训练掩码的逐项存档。

## 4. 实验 E1：融合接口与 GPU 短检查

**动机：**融合结构增加了投影与梯度路径，且新掩码需要动态训练支持。  
**目的：**在正式训练前确认数学结果、数据边界与 GPU 效率，尽早发现实现问题。

仅进行针对新增改动的必要检查：

- 对角归一化、完整求解、对数方差与小维度 CPU float64 参考结果一致；复用上一轮已有的后验数值核对，不重新扩展合成实验矩阵。
- 未观测值改变不影响两条分支输出；自然无效值不进入标准化统计、似然与目标损失。
- F1/F2/F3 零初始化投影时与同种子 F0 初始预测一致；短训练后预测梯度可以进入编码分支。
- 同模型保存恢复后结果一致；输出形状为 `[batch,96,C]`。
- 相同 epoch 和索引跨版本掩码相同；训练 epoch 改变后掩码更新，验证/测试不随 epoch 改变。
- 普通 S4 实际使用官方 DPLR CUDA kernel，后验在 GPU 批量计算；记录数据加载、前向、反向耗时与峰值显存。

使用训练段和同模式验证段做短运行，不用正式测试分数调整结构。没有代码或数值问题时，不因短运行分数不理想而增加变体或超参数搜索。

**产物：**检查摘要、吞吐表、每任务显存上限估计以及可执行的并行配置。

## 5. 实验 E2：四版本双向 2×2 核心实验

**动机：**需要同时看到实用收益、矩阵求解的必要性与方差的增量，避免仅凭一个完整版本的最好结果决定方法。  
**目的：**在统一数据与掩码下，用最少的关键版本筛选候选结构。

### 5.1 数据范围与规模

| 数据集 | 选择原因 | 本阶段训练数 |
|---|---|---:|
| Weather，21 变量 | 清洗重训后检验原有正面结果是否保留 | 4版本 × 2来源 × 2种子 = 16 |
| Electricity，321 变量 | 检验补充编码是否获得错配收益且控制匹配代价 | 4版本 × 2来源 × 2种子 = 16 |

每个训练检查点分别测试 P 与 B_u，每种测试家族使用 9101、9102 两个掩码种子。因此核心阶段共有 **32 次训练、128 项主测试**。测试掩码种子不计为独立训练重复。

完整四格为：

| 训练来源 | 测试 P | 测试 B_u |
|---|---|---|
| P | P→P，匹配 | P→B_u，错配 |
| B_u | B_u→P，错配 | B_u→B_u，匹配 |

### 5.2 普通 S4 的固定训练设置

| 项目 | 设置 |
|---|---|
| 数据切分 | Weather、Electricity 按时间 70%/10%/20%；边界上下文沿用现有框架 |
| 训练种子 | 2024、2025 |
| 验证掩码种子 | 对应训练种子 + 10000 |
| 潜变量秩 | r=16；载荷 `[96,C,16]`，每变量均值与残差方差 |
| S4 | 普通 DPLR，2层；宽度64、状态32、前馈128、dropout=0.1 |
| 预测头 | 沿用当前轻量 S4 的时间映射与通道映射 |
| 预测损失 | 有效未来目标上的标准化 MSE |
| F1/F2/F3 辅助损失 | 有效可见历史的样本归一化观测 NLL，权重0.1 |
| F0 损失 | 仅预测损失 |
| 优化 | AdamW，基础学习率1e-3、基础权重衰减1e-4；S4特殊参数组沿用已有配置并保存 |
| 训练上限 | 30轮，patience=5；不新增学习率搜索 |
| 检查点选择 | 最低 source 同模式验证预测 MSE，不使用辅助损失或目标模式验证选择 |
| 梯度裁剪 | 全局范数1.0 |
| microbatch / 有效batch | 默认64 / 64；显存不足用32 / 64累积，不改变有效batch |
| 数值精度 | 后验求解FP32，S4所需complex64；本轮不引入AMP |
| 加载起点 | 每任务workers=10、计算线程=2，按并行总吞吐调整并记录 |

模型初始化、训练窗口次序和人工掩码按种子配对。配对意味着共同模块初值与数据次序一致，不意味着独立训练后的权重相同。

### 5.3 执行顺序

先完成一个训练种子的全部四版本、两个数据集和两种 source，再补第二个种子；也可按 GPU 可用性交错排队。首批结果只用于发现运行错误，不据此修改后续种子的配置。

核心矩阵完成后统一分析，不因一个数据集或方向失败而只补有利条件。

## 6. 实验 E3：关键比较、方法取舍与开销分析

**动机：**下一步需要形成可保留的方法，而非积累更多不容易解释的版本。  
**目的：**使用 E2 已有结果回答三项核心问题，原则上不增加训练。

### 6.1 三项主要比较

| 实验项 | 对比 | 动机与结果解释 |
|---|---|---|
| E3-A：模块是否有用 | F1/F2/F3 分别对 F0 | 看错配绝对误差是否下降、匹配损失是否可接受；不能只看错配比值变小 |
| E3-B：联合条件化是否值得 | F2 对 F1 | 二者使用同样的观测模型、辅助损失和输入维度；检验完整矩阵求解相对逐维处理的增量 |
| E3-C：方差是否值得保留 | F3 对 F2 | 若没有稳定额外收益，最终默认选择更简单的均值版本 |

同时列出两类布局变化指标：

1. **部署变化：**固定已训练模型，比较 `E(P→B_u)` 与 `E(P→P)`，以及反方向。
2. **固定目标下的错配代价：**`E(P→B_u)/E(B_u→B_u)−1`，以及 `E(B_u→P)/E(P→P)−1`。

二者与四格绝对误差共同解释。分母误差上升也可能令错配代价变小，因此单独降低比值不作为成功。

### 6.2 统一报告口径

- 主指标：标准化 MSE；辅指标：标准化 MAE、原量纲 MSE/MAE。按数据集分别展示，不平均不同量纲的绝对误差。
- 每个训练种子先平均两个测试掩码，再报告训练种子的均值、离散程度及逐种子配对变化。
- 保留逐变量、逐预测步与逐窗口误差摘要，优先检查收益是否由少量变量主导，以及前24步与后72步是否一致。
- 记录最佳epoch、验证曲线、训练耗时、推理吞吐、峰值显存、总参数量及新增分支参数量；方差若只带来很小收益，应结合代价判断。
- 两个训练种子用于原型筛选，不声明强总体显著性。配对时间块bootstrap可作为已有误差的补充分析，不作为启动下一阶段的硬性前置条件。

### 6.3 预先约定的取舍原则

下面是工程判断参考，不是统计显著性门槛，也不是所有数据集必须同时满足的发表条件。

| 观察结果 | 后续决定 |
|---|---|
| F2 在错配条件下稳定优于 F1，且匹配精度有竞争力 | 保留完整求解作为方法核心 |
| F3 相对 F2 的错配平均增量达到约1%以上、两个种子方向一致，且未明显恶化匹配精度 | 可以保留方差；分别报告数据集和方向，避免总平均掩盖退化 |
| F3 与 F2 接近或方向不稳 | 默认选择 F2，方差作为消融结果 |
| F1 已取得主要收益，F2没有稳定增量 | 接受简单条件归一化路线，不强行把完整后验作为核心创新 |
| 增强版本错配平均改善约3%以上，两匹配格各自恶化不超过约2%，且错配方向跨种子一致 | 视为该数据集值得进入确认阶段的候选表现 |
| 仅某一方向或某一数据集改善 | 保留有效范围与失败结果，不宣称统一鲁棒；判断是否仍值得做确认 |
| 四版本均没有有用的增量 | 停止扩大主干和数据集，先分析表示/训练失败，不自动启动更多模型搜索 |

最终选择**一套共同候选结构**，不在各个测试格分别挑选最佳版本。若两个数据集给出不同取舍，完整记录冲突，优先较简单且收益较稳的方案。

这一选择使用开发阶段经验，不能把已经查看过的测试结果重新描述成完全独立的最终确认。候选冻结后再做 E4/E5，不根据其中单个测试结果随意更换版本。

## 7. 实验 E4：ETTh1 已知失败条件复核

**动机：**原完整 OCPE 在 ETTh1 四格都较差，需要检验保留历史分支后是否仍有明显损失。  
**目的：**评价选定方法的适用边界，而不是只增加正面数据集。

- 只运行 F0 与 E3 冻结的一个候选版本，不重跑全部四版本。
- 沿用 ETTh1 的12/4/4月时间切分，新 P/B_u、L/H=96、r=16、两个训练种子和两个测试掩码种子。
- 其余轻量 S4 设置与 E2 相同。不得为了 ETTh1 单独改变秩、增加局部网络或搜索辅助权重。
- 规模：2版本 × 2来源 × 2训练种子 = **8 次训练、32 项测试**。
- 判断：比较新统一协议下四格绝对误差及新增模块的相对影响。若四格仍退化，记录为明确反例；若接近基线，支持损失得到缓解，但不因协议已变就把新旧数值差异全部归因于历史旁路。

ETTh1 的失败不自动否定其他数据集的有效性，也不强制要求它一定转为正收益。

## 8. 实验 E5：强主干 S4M 的增量确认

**动机：**只在轻量 S4 上有效，还不能判断模块能否帮助较强的缺失预测模型。  
**目的：**检验选定条件编码是否能作为补充模块，为 S4M 提供实际增量。

### 8.1 两个版本与接入位置

| 版本 | 结构 |
|---|---|
| S4M-base | 保留既有 S4M 的输入处理、显式掩码流、记忆库/原型读取和预测路径 |
| S4M＋selected | 仅增加冻结定义的条件编码与投影，在记忆模块输出 `c_s` 后、首个掩码 S4 层之前相加 |

接入形式为 `c_s_new = c_s + W_enc u`，投影输出维数等于 `en_conv_hidden_size`，不改变历史长度和原型库读取流程。u 由原始有效可见历史与掩码计算，不把 S4M 生成的填充值当作新观测。

这里迁移的是结构与计算规则，不迁移 E2 训练好的参数；两版本在各自数据集上重新训练。新增投影同样无偏置、零初始化。保持已有合法的记忆库训练/评估状态管理，验证与测试不更新记忆库，初始化及更新不读取被人工隐藏的历史真值。

### 8.2 配置与规模

- 数据：清洗后的 Weather 与 Electricity；使用与 E2 相同的数据、切分、P/B_u 及评估规则。旧套件数字不替代新基线。
- 主干配置：Electricity 优先复用已有稳定的4层、宽512配置；Weather 使用已核验的8层、宽256基准配置。两版本在同一数据集上完全配对，不进行深度搜索。
- 主干优化器：沿用已核验的官方SGD，momentum=0.9、weight_decay=1e-5；Electricity学习率0.01、Weather学习率0.001。训练上限20轮、patience=4，按 source 验证预测误差选择。
- 新增 OCPE 与投影参数沿用 AdamW、学习率1e-3及权重衰减1e-4；辅助似然权重0.1。同一总损失反向传播后更新两组优化器，不改变基线主干的优化规则；新增分支规则写入清单。
- batch 起点为既有 S4M 的16，不直接套用轻量 S4 的64。记忆库随batch更新，吞吐优化优先通过任务并发进行，不能把梯度累积当作完全等价的记忆库更新。
- 两个版本采用同一数据次序、掩码及主干初始化规则，保存并恢复原型库及优化器状态。
- 规模：2版本 × 2数据集 × 2来源 × 2训练种子 = **16 次训练、64 项测试**。

### 8.3 如何解释结果

S4M＋selected 在同协议下改善错配误差且匹配精度可接受，才支持“能为强主干增加价值”。只改善轻量 S4 或只增加参数量，不足以作这一结论。

若 S4M 上收益很小或没有收益，首先将结论限定为已验证主干，不立即增加多个融合点、多个强模型或大规模调参。GP-PoM等后验矩方法与VaryST等场景相关工作的进一步算法比较，可在候选方法成立后单独规划，本阶段不承诺已优于文献方法。

## 9. GPU 运行安排

使用此前授权的 GPU0、GPU5，启动前读取实际资源占用。所有正式任务使用固定持久会话与唯一job ID，支持断点续跑及失败定位。

1. 先每卡一个任务测量训练与数据加载吞吐；根据整卡总吞吐逐步试两任务、三任务，不预先认定并发越多越快。
2. 轻量 S4 默认microbatch64、有效batch64。若显存不足，改32并累积到64，记录变更；三个增强版本与基线保持一致有效batch。
3. S4M单独测量，保留batch16及记忆库批次语义，不沿用轻量阶段的任务并发上限。
4. 保留显存余量，避免OOM；并发时同步检查GPU利用率、CPU加载和内存。workers=10是单任务起点，不把每卡所有任务都盲目固定为10。
5. 记录官方CUDA扩展路径、实际调用情况、后验计算设备及每任务峰值显存，不静默退回明显更慢的路径。
6. 启动后汇报任务矩阵、进程、GPU安排与预计完成顺序；数值非有限、数据审计不符、重复失败或吞吐异常时及时汇报。

E0/E1完成并冻结设置后再运行正式队列；不凭尚未测量的吞吐预先承诺完成时间。

## 10. 结果文件与交付要求

新增代码和结果使用独立名称，例如 `ocpe_fusion_uniform_r50_l96_h96_1120`；S4M确认阶段使用独立后缀。它们表示本计划中的新结构和新协议，不覆盖旧 OCPE/PU-S4。

每项任务至少保存：

- 数据、有效值规则、标准化统计量、掩码生成器及源码指纹；共同训练配置和随机种子。
- 每轮训练/验证记录、最佳检查点、优化器及随机状态；S4M额外保存记忆库状态。
- P/B_u各两种测试掩码的标准化与原量纲指标、有效目标计数、逐窗口/变量/预测步误差摘要。
- 参数量、训练与推理耗时、峰值显存、实际并发与batch设置；失败任务原因也保留。

最终报告按以下顺序呈现：

1. 数据修正与协议变化，以及为什么旧数字不进入新排名。
2. Weather、Electricity四版本2×2主表及逐种子结果。
3. 完整求解、方差的关键对比，以及最终结构取舍。
4. 匹配/错配误差、两类变化指标和计算开销。
5. 实际执行的ETTh1与S4M确认结果；未执行阶段清楚标注。
6. 当前方法可以支撑的主张、失败条件与仍需后续研究的部分。

## 11. 本轮暂缓事项与理论写作范围

本轮暂缓：同步/组故障、连续时间轴真实停机、更多缺失率和块长、P+B混合训练、新增多个强主干、完整不确定性校准、完整参数贝叶斯化及逐前缀vs末步的独立模型矩阵。

对应地，本轮不主张已经解决这些范围。若后续论文把方差校准、未见故障家族或逐前缀优越性作为主要贡献，再增加相应证据。

理论正文仅需清楚交代：

- 高斯后验均值等价于按当前可见集合求解带先验正则的加权最小二乘。
- 在线性高斯观测与相应线性目标关系成立时，末步条件均值具有最优点预测解释。
- 学习参数、真实模型失配与非线性预测器不自动继承上述理想保证；平均风险仍可随缺失布局变化。

这是本轮可行的理论支撑，不把标准公式或均值方差拼接本身声称为新定理。方法价值重点由E2/E3及实际执行的E4/E5提供。
