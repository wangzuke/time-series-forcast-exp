# 研究路线：缺失模式偏移下的结构化鲁棒训练与重要性扰动

**日期：2026-11-14**  
**状态：方法路线讨论稿；供后续实验设计与审核，不代表方法已实现或有效性已验证。**

## 1. 研究问题与边界

本课题研究多变量时间序列预测中的缺失模式偏移。给定历史窗口 $X_{t-L+1:t}$、完整预测目标 $Y_{t+1:t+H}$ 和历史观测掩码 $M$，模型接收 $(X\odot M,M)$ 并预测未来。第一阶段假设完整序列与预测目标的生成规律不变，只改变历史输入的掩码分布：

$$P_{train}(X,Y)=P_{test}(X,Y),\qquad q_{train}(M)\ne q_{test}(M).$$

预测目标不施加缺失；人工掩码只作用于历史输入。当前 r50 主实验使用 $L=H=96$、逐变量缺失率 50%、P/B24 及 P→P、P→B、B→P、B→B 矩阵。已完成结果和设置以[统一框架 r50 结果报告](1113-实验结果-统一框架-r50-2x2矩阵.md)为准。

路线把缺失几何拆成三个单独控制的因素：

1. **时间形态**：散点缺失 P 与连续块缺失 B；
2. **跨通道同步度**：各通道独立错位的 B-ind 与通道共享位置的 B-sync；
3. **块位置**：历史窗口开头、中部和靠近预测起点的位置。

每项实验只改变目标因素，并控制每变量缺失率、块长、块数、输入长度和预测目标。该边界避免把“缺失更多”“连续间隔更长”或“跨通道同时不可见”混为同一种影响。

## 2. 方法层的两条路线

### 2.1 结构化掩码族鲁棒训练

常规单一模式训练只要求模型在一个训练掩码分布 $q_{train}(M)$ 下表现好。若部署时的掩码分布改变，模型不一定能保持原有误差。结构化掩码族训练是在训练时从一组预先定义、具有实际含义的掩码机制中采样，让模型在多种可见性结构下都接受未来预测监督。

对每个训练窗口，先保留完整未来目标 $Y$，然后从掩码族 $\mathcal G$ 选一种掩码 $g$，遮挡历史输入并训练预测器。一个均衡风险目标为：

$$\min_\theta \sum_{g\in\mathcal G} w_g R_g(\theta),\qquad R_g(\theta)=\mathbb E[\ell(f_\theta(X\odot M_g,M_g),Y)].$$

其中 $w_g$ 控制各类结构的训练权重。简单起点是各类均衡采样或等权计算损失，防止样本数量较多的模式支配训练。另一种更强调最差场景的目标是 $\min_\theta\max_{g\in\mathcal G}R_g(\theta)$；它可能改善最坏组，但也可能牺牲平均精度或引入训练不稳定，因此应作为对照，而不是预先认定更好。

在当前 $L=96$、50% 缺失率的设置中，掩码例子可以是：P 每变量缺失 48 个散点；B-ind 每变量缺失两个长度为 24 的块、各变量独立选位置；B-sync 所有变量共享同样的块位置。位置实验再分别限制块出现在开头、中部或末端。

**必须区分两种实验含义：**

- 单一模式训练、另一模式测试，是纯粹诊断模式偏移的实验，例如 P→B。
- 掩码族混合训练时模型已经见过多种训练掩码，测试的是“已知可能模式下的鲁棒训练”，不应称为对完全未见模式的零样本泛化。

因此，前者用于证明问题和量化偏移代价；后者用于检验训练策略能否降低多种部署模式下的最坏误差。若要检验对未见块长的泛化，应单独留出训练未见的块长。

### 2.2 重要性导向的结构化掩码扰动

掩码族训练回答“训练时覆盖哪些缺失结构”；重要性导向扰动进一步回答“在给定结构与缺失预算下，遮掉哪些历史信息”。普通块增广随机选缺失区间；重要性导向方法优先选择模型当前最依赖的历史 patch 或时间段，再让模型在这些信息不可用时预测同一个未来目标。

假设模型把历史表示为 patch，并为通道 $c$ 的 patch $p$ 估计重要性 $I_{c,p}$。要构造长度为 $k$ 个 patch 的连续块，可以给候选区间打分：

$$S_{c,j}=\sum_{p=j}^{j+k-1} I_{c,p}.$$

对 B-ind，各通道独立选择高分区间；对 B-sync，对每个共同区间汇总各通道分数后选一个共享位置；对位置偏移实验，只在相应的开头、中部或末端候选范围内选取。掩码预算、块长和位置分布应与随机块对照严格一致，唯一变化是区间的选择依据。

一次训练迭代可按以下流程进行：

1. 从预先设定的掩码族选中 P、B-ind、B-sync 或位置受限的块掩码；
2. 用当前模型估计 patch 重要性，并在指定几何约束下选择要遮挡的 patch 或连续区间；
3. 用新掩码重新生成模型输入和掩码表示，遮挡后重新执行插补/特征处理，防止原始值泄漏；
4. 对预测结果与原始完整未来目标计算常规预测损失并更新模型；
5. 测试时只输入实际观测掩码，不执行额外扰动。

重要性可以由注意力分数、预测损失对 patch 表示的梯度、或“遮掉候选 patch 后误差增加量”估计。三者代价与可信度不同：注意力便宜但只是代理量；梯度能反映局部敏感度但可能有噪声；逐候选遮挡测试更直接但需要额外前向计算。起步可用注意力或梯度筛选，再在一部分候选上用遮挡敏感度检查重要性分数是否真的对应预测依赖。

重要性遮挡并不自动证明模型学会了替代依赖。它的假设机制是：当惯常依赖的信息被有针对性地移除，预测监督会推动模型使用其他时间片段或其他变量；该机制需要通过跨通道/时间依赖消融和等预算随机遮挡对照验证。

### 2.3 与网络结构改动的区别

结构化掩码族与重要性导向扰动首先是**训练方法**，不是新的网络结构。若后续实验确认 B-sync 会让跨通道补偿失效，再考虑加入显式的可靠性门控：输入每通道的可观测比例、距最近观测的时间等信息，调节跨通道融合时各变量表示的权重。这个门控才是明确的结构改动，应单独消融，不能与掩码训练增益混在一起报告。

## 3. Idea 来源与已有工作的关系

| 来源 | 对路线的支撑 | 与本课题的区别 |
|---|---|---|
| [StableMiss，IJCAI 2023](https://www.ijcai.org/proceedings/2023/525) | 正式研究完整特征—标签关系稳定、掩码分布变化的预测问题，支持把掩码分布作为偏移对象 | 表格预测；其双参数化预测器与去相关不是我们提出的掩码族增广方法 |
| [ChannelTokenFormer，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/f924dab7a06d0463fe238904678acaee-Abstract-Conference.html) | 训练时随机遮挡通道 patch 作为测试块缺失的代理，说明 patch 级缺失训练可用于时序预测 | 未系统覆盖 P/B 2×2、B-ind/B-sync 和块位置错配；随机 patch 遮挡也不等同于我们的模式族风险目标 |
| [VaryST，arXiv:2610.19813](https://arxiv.org/abs/2610.19813) | 提出重要性导向观测扰动：用编码器 patch 注意力估计重要性、遮掉高分 patch、重新处理观测，再用原未来目标训练；是“重要性导向”路线的直接启发 | 图时空预测预印本；其 patch 选择机制和空间支持结构不能直接等同于无图多变量预测，注意力分数也只是重要性代理 |

因此，方法构想是对已有“缺失分布偏移”“patch 缺失训练”和“重要性引导遮挡”思路的组合与场景化扩展。仅使用掩码增强或仅把 VaryST 的遮挡方式搬到 CTF，都不足以自动构成创新；创新主张需要由受控协议、目标明确的鲁棒目标和消融结果共同支持。

## 4. 建议的实验路线

### 阶段 A：冻结并复核诊断基线

以现有 r50 P/B 2×2 结果为起点；补齐或明确标注 BiTGraph Electricity 未完成格子。重新核对每变量缺失率、B24 块数和掩码响应。P→B 与 B→B 在固定测试掩码下的差异用于估计模式偏移代价；Weather 上的弱效应或反例也保留，不能只展示偏移显著的数据集。

### 阶段 B：检验掩码族训练

优先在 CTF 上做主方法验证，因为它本身处理 patch 缺失和跨通道交互；用 BiTGraph 或轻量插补预测流水线做跨架构检查。建议的对照为：

1. **CTF 单一模式训练**：P-only 或 B-ind-only，作为未覆盖目标掩码的诊断基线；
2. **CTF 原生 patch-mask 对照**：按原文配置使用随机 patch 遮挡，并明确其训练时已见块级删除；
3. **CTF 掩码族训练**：均衡覆盖 P 与 B-ind，随后按阶段加入 B-sync 和位置变化；
4. **最坏组目标（可选）**：在相同掩码族下比较均衡平均风险与最坏组风险。

开始时只需 ETTh1 与 Electricity 验证主效应，Weather 作为边界/弱效应数据集；最终方法再补齐三数据集。固定训练预算、训练种子和测试掩码种子，所有方法使用同一测试窗口。

### 阶段 C：检验重要性扰动

只在阶段 B 找到明显且可重复的偏移场景后开展。优先选择一个因素，例如 B-ind→B-sync 或 B-end。比较随机结构化块与重要性导向块，确保总缺失预算、块长、同步度、位置分布一致。若重要性版本没有稳定优于等预算随机块，就不保留复杂机制。

第一版采用“均衡随机结构 + 少量重要性困难扰动”的混合训练，避免一直遮挡同一高分历史段导致训练退化或掩码过度集中。重要性分数定期更新或缓存，以控制额外计算。

### 阶段 D：必要时增加模型结构

只有当诊断显示 B-sync 明显削弱模型跨通道补偿、且掩码族/重要性训练仍不足时，再加入可靠性门控。报告完整方法及“去门控”“去同步缺失训练”“均匀权重融合”等消融，确认增益来自预期机制。

## 5. 评价方式与统计要求

除了 MAE/MSE，还应报告目标掩码下的偏移代价。对训练模式 $A$、测试模式 $C$，定义：

$$SR(A\to C)=R(f_A,C)-R(f_C,C),$$

其中 $f_C$ 是在目标测试模式 $C$ 下匹配训练的诊断模型。鲁棒方法则报告所有测试几何上的平均风险、最坏组风险及相对匹配模型的 regret。指标需按数据集分别呈现，不能直接平均不同量纲的 raw MSE。

每格至少保留训练种子与固定测试掩码种子的配对结果；同一 checkpoint 重复测试不同掩码不等同于独立训练重复。计算资源允许时，方法比较增加独立训练种子，统计以配对差值和区间估计为主。训练与验证不得读取最终测试掩码或未来值；若鲁棒方法用多模式验证，应事先定义并固定验证模式族。

## 6. 创新主张的证据门槛

1. **问题与协议层**：现有 r50 结果已提供初步证据，显示模式匹配误差与模式迁移能力不同，但效应依赖模型和数据集。应继续通过 B-sync 和位置实验明确几何来源。
2. **掩码族训练层**：只有在同等预算下，它稳定降低未覆盖测试几何或总体最坏风险，且不以严重牺牲匹配性能为代价，才支持其鲁棒训练贡献。
3. **重要性扰动层**：必须优于缺失率、块长、位置、同步度一致的随机结构化遮挡，并通过重要性分数验证；否则应视为复杂的数据增强，而非已证明的新机制。
4. **结构改动层**：可靠性门控只有在针对同步性错配的消融中产生预期效果，才能支持模型结构创新。

当前不应声称“点转块必然导致性能崩溃”“注意力等于因果重要性”或“该方案已具有首创性”。这些都是待由完整实验和进一步文献查新决定的结论。

## 7. 推荐执行顺序

1. 以 r50 报告为基准，确认剩余基线格子和掩码统计；
2. 先做 CTF 的 P/B-ind 均衡掩码族烟测，检查速度、显存和是否损害匹配模式性能；
3. 通过后加入 B-sync 与位置族，按三个几何轴分别做消融；
4. 选一个偏移稳定、机制清楚的场景，比较随机块与重要性导向块；
5. 结果支持跨通道可靠性问题后，再实现并评估门控结构；
6. 最后在 BiTGraph 或另一轻量骨干上验证方法能否迁移。
