# S4M 论文、公开实现与缺失模式漂移协议：对齐核查

核查日期：2026-11-09。目标是解释 r=50%、L=H=96 先导实验中 8 层 S4M 的预测退化，并明确哪些差异属于本课题有意设计，哪些需要在后续实验中控制或报告。

## 结论摘要

1. **没有发现 P/B 掩码在数据集、DataLoader、CUDA 迁移或 S4M 调用接口中被丢弃。**逐层 hook 表明 P/B 差异进入了记忆模块、mask embedding 和第一个 MDS-S4 块。
2. 8 层 checkpoint 的差异在后续普通 S4 块中逐层衰减至预测端约 `1e-6`；交换完整历史且保持掩码时也近乎不改变预测。这是当前训练配置的表征/预测塌缩，而不是稳定 SSM 的正常性质。
3. 论文的最接近场景与本课题的 `P(独立点)→B24(每变量两段块)` 有本质不同；S4M 没有报告训练–测试缺失模式漂移实验。因此，当前协议是**有意的分布外泛化评估**，而不是原文复现。
4. 公开仓库脚本与论文存在可复现性矛盾（优化器、Weather 学习率、memory bank 生命周期）。此前的 8 层结果不能称为严格官方复现，也不能用于模式漂移结论。
5. 按论文允许的候选层数训练的 2 层先导模型恢复了输入敏感性；但目前只有一个种子且绝对误差仍落后于 CTF/BiTGraph，尚不应启动 S4M 全量矩阵。

## 原论文实际做了什么

论文：*S4 for Multivariate Time Series Forecasting with Missing Values*，附录 D.2–D.3、表 1–3、19–24。

- 数据集：Electricity、ETTh1、Weather、Traffic；按时间切分 `70% / 10% / 20%`。
- 所有主实验预测长度固定为 `H=96`，观察长度取 `L∈{96,192,384,768}`。
- 使用两种**块状**缺失：
  - *time point missing*：先随机选比例 `r` 的时间点；每个被选时间点及其之后连续 5 个时间步的**全部变量**均设为缺失。
  - *variable missing*：同一“连续 5 步”的过程对每个变量独立进行。
- `r∈{0.03,0.06,0.12,0.24}` 不是最终单元格缺失率。论文表 8 报告：ETTh1 在 `r=0.12` 时实际缺失率约 `0.399`，在 `r=0.24` 时约 `0.616`。
- 训练/测试均由同一类合成块状缺失数据产生；论文未报告 P 训练、B 测试，或任何训练–测试掩码家族变化的结果。
- 论文 D.3：Adam；ETTh1 学习率 `0.005`，Weather `0.001`，Electricity/Traffic `0.01`；隐藏维度为 ETTh1/Weather `256`、Electricity/Traffic `512`；batch size `16`；层数从 `{2,4,8}` 根据验证集选择；早停。其余超参按验证集调节。
- 表 3 进行 mask stream 和 ATPM 消融，说明在作者自身的同分布块缺失设置下掩码输入通常有益；这不等同于跨模式泛化证据。

## 当前协议与论文的差异

| 项目 | 原论文 | 当前 r=50% 补充协议 | 影响 |
|---|---|---|---|
| 研究目标 | 同家族缺失训练与测试 | P 训练 / B24 测试及完整 2×2 | 有意的研究扩展，不是复现 |
| P 定义 | 全变量同步的连续 5 步 time-point block | 每变量恰好 48/96 个独立散点 | 统计结构不同 |
| B 定义 | 连续 5 步；变量缺失则每变量独立 | 每变量两段 24 步块 | 块长度和连续性明显更强 |
| 缺失率 | 选择率 r 与实际率不同；ETTh1 覆盖约 12.2%–61.6% | 每个变量精确 50% | 总强度处于原文范围附近，但几何形状不同 |
| 掩码生成 | 先生成一个完整缺失数据集，再按时间切分；重叠窗口共享同一掩码轨迹 | 每个窗口、每个 epoch 用可复现独立掩码 | 训练样本的相关结构不同 |
| target 缺失 | 训练/验证损失仅计算被观测的未来 target；测试用完整真值 | target 始终完整，只有历史输入缺失 | 我们更符合“历史观测缺失、未来需预测”的受控问题，但不等同原实现 |
| ETTh1 切分 | 论文/`Dataset_Custom4` 为 70/10/20 | 当前共享协议使用 ETT 常用 12/4/4 月，即 60/20/20 | 与论文的 ETTh1 复现不对齐；与三个基线公平对照保持一致 |
| 标准化 | 公开 loader 在含 NaN 的训练数据上拟合 scaler，之后将 NaN 填 0 | 先用完整训练源数据标准化，再在标准化空间掩码填 0 | 受控比较更一致，但改变了 S4M 原始预处理 |

因此，当前 S4M 的差表现不能简单归因于“模型无效”：它可能受到严重缺失、训练–测试模式漂移、mask 统计结构、切分及预处理变化的共同影响。反过来，这些变化正是本课题所希望评估的稳健性压力。

## 公开代码与论文/当前封装的差异

| 项目 | 论文 | 公开代码/README | 当前封装 | 判断 |
|---|---|---|---|---|
| 优化器 | Adam | `experiments/exp_pretrain1.py` 实际启用 SGD(momentum=0.9, weight decay=1e-5)，Adam 被注释 | Adam | 当前遵循论文，不是逐行复现公开训练脚本 |
| Weather 学习率 | 0.001 | 唯一发布命令使用 0.005 | 0.001 | 当前遵循论文；仓库与论文不一致 |
| 层数 | 验证集从 2/4/8 选 | 唯一 Weather 命令为 8 | 最初固定 8；现可试 2/4/8 | 固定 8 没有当前协议验证依据 |
| 训练轮数/早停 | 只说明 early stopping | README 为 15 epochs、patience 默认 3；脚本为 10 epochs | 最多 20、patience 4、无 LR decay | 存在中等差异；未按论文给出唯一值 |
| 学习率调度 | 未明确 | 训练代码每 epoch 将 LR 减半 | 未启用调度 | 公开代码分支和论文训练细节不可完全确认 |
| memory bank | 算法描述为持续更新 | 默认每 epoch `init_bank()`，却只在第一个 epoch 的第一个 batch warmup；未见发布命令传 `--no_renew`，按字面多 epoch 可能失去 `repre` | 跨 epoch 保留已 warm 的 bank | 当前做法更接近论文“持续更新”，但与公开默认路径不同 |
| memory 存储 | 未规定设备 | CPU queue 与硬编码 `.cuda()` 混用 | 保持 serial update 规则，但将 queue/centroid 留在 CUDA | 为可运行性/性能作的实现修改，需作为偏离记录 |

此外，公开 `model/S4M.py` 中 `min_idx` 标准化表达式使用了 `max_idx` 作为分子：

```python
min_idx = (max_idx - torch.mean(min_idx, dim=1, keepdims=True)) / torch.std(min_idx, dim=1, keepdims=True)
```

这很可能是源码笔误；当前封装为保持作者前向语义也复现了该表达式。它不是 8 层预测塌缩的直接证据（2 层在同一表达式下已有输入敏感性），但严格复现时必须披露。

## 针对 8 层塌缩的证据

相同的 ETTh1、r=50%、L=H=96、每变量精确 50% 缺失、训练种子 2024 的测试 batch：

- P 与 B 的 5,300 个 mask 单元格位置不同；两个 batch 的零填充输入 L1 差为约 3,781。
- 8 层模型：memory features 的 P/B 相对 L1 差约 0.64，第 1 个 MDS-S4 block 约 0.17；第 2、3、4 个 S4 block 后依次约 `1.2e-2`、`7.2e-4`、`8.1e-5`；预测端约 `1.4e-6`。
- 交换整个 batch 中每个样本的历史值、保持原 mask，不是微弱扰动；8 层预测相对变化仍仅约 `1.4e-6`。
- 相同设置的 2 层候选模型：P/B 预测相对差约 `0.376`；历史置换对照约 `0.654`。说明数据接口、mask 入模路径和官方前向签名可以传递有效信息。

## 对结果的处理决定

1. 旧的 S4M 8 层主实验结果保留为运行记录，但从所有模式漂移结论和模型排名中排除。
2. 不把 2 层、单种子先导指标作为正式结果；它只通过了“预测依赖输入”的必要有效性检查。
3. S4M 在当前协议下应先完成小型验证选择：`e_layers∈{2,4,8}`，每项至少检查验证误差、输入置换敏感性和 P/B 敏感性；淘汰预测相对敏感性近零的候选。
4. 若需主张“原论文方法在其设置下有效”，另行执行一条原文对齐复现：70/10/20 切分、L=H=96、原文连续 5 步缺失、同家族训练/测试，并明确选择论文版 Adam 还是仓库版 SGD。该复现应与本课题的模式漂移实验完全隔离。
