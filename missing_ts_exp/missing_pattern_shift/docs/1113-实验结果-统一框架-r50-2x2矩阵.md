# 统一框架结果总报告：r=50% P/B 2×2 缺失模式矩阵

> 本文是当前实验的**主结果报告**。它统一汇总 S4M、ChannelTokenFormer（CTF）、BiTGraph、PatchTST、DLinear 与 iTransformer；此前两份分模型报告保留为可追溯的执行记录，不再单独作为总报告引用。

## 结论摘要

在同一 r=50%、L=H=96、逐变量配平的 P/B 缺失模式 2×2 协议下，模型的同分布精度和跨模式鲁棒性是两件不同的事。

- **ETTh1**：插补+iTransformer/PatchTST 在四格中总体精度最好；但是所有三种插补常规模型及 BiTGraph 的两种失配方向均恶化。S4M 跨格变化最小但绝对误差较高；CTF 在 B→B 很强、但 P→B 明显变差。
- **Weather**：结果强烈依赖模型。PatchTST、DLinear、iTransformer 几乎不受 P/B 变化影响；BiTGraph 却有明显失配惩罚；CTF 与 S4M 居中。因此不能宣称某一缺失模式对所有模型都更难。
- **Electricity**：匹配格中 iTransformer 最优（P→P 5.122M、B→B 4.918M），但模式失配时 S4M 最稳且最好（P→B 8.070M、B→P 7.538M）。三种插补常规模型在失配下大幅退化，最高达 DLinear B→P 的 76.606M。

这支持本课题的核心动机：**匹配场景下的高预测精度不等价于缺失模式变化时的可靠性。** 同时，线性插补+常规模型是必须保留的强基线，不能预设“原生缺失感知模型必然更准确”。

## 统一协议与指标口径

| 项目 | 设置 |
| --- | --- |
| 数据集 | ETTh1、Weather、Electricity |
| 历史长度 / 预测长度 | 96 / 96 |
| 缺失率 | 每变量历史窗口精确缺失 48/96 = 50% |
| P | 分散点缺失 |
| B | 每变量两个不重叠的连续 24 步缺失块 |
| 训练—测试矩阵 | P→P、P→B、B→P、B→B |
| 训练种子 | 2024、2025 |
| 测试掩码种子 | 9101、9102 |
| 每个完整格 | 2 checkpoint × 2 个固定测试掩码 = 4 个值 |

所有模型都以训练集统计量标准化输入和预测目标，并在标准化空间训练。下表报告的是预测反标准化后计算的 **raw-scale MSE / MAE**，格式为 `MSE ± SD / MAE ± SD`；误差越低越好。因同一 checkpoint 在两个测试掩码上重复测试，四个值不是四次独立训练，SD 不能解释为独立重复实验的置信区间。不同数据集的 raw MSE 不可横向比较。

模型类别如下：

- **直接缺失建模**：S4M（掩码双流 S4 与原型记忆）、CTF（缺失 patch/token 处理）、BiTGraph（PartialTCN 与图卷积）。
- **线性插补常规模型**：PatchTST、DLinear、iTransformer。每个变量只使用历史窗口内的观测做线性插补；模型本体不接收 mask。

## 模式漂移效应

为了隔离“训练—测试模式不一致”的影响，应固定测试模式，只改变训练模式：

- 固定 **B 测试**，比较 P→B 相对 B→B；
- 固定 **P 测试**，比较 B→P 相对 P→P。

主要现象如下。

1. **ETTh1**：插补模型在两方向均稳定退化：PatchTST 为 +22.5% / +55.1%，DLinear 为 +22.3% / +57.3%，iTransformer 为 +35.7% / +19.2%。BiTGraph 同样为 +18.1% / +24.6%。S4M 变化仅 +4.3% / -2.4%；CTF 的 B 测试退化很强（+68.9%），但 B 训练在 P 测试时反而较好（-14.0%）。
2. **Weather**：插补模型的变化近零或方向不一致，不能作为普适漂移证据；但 BiTGraph 的两方向增幅约 +76% / +89%，CTF 的 B 测试也增加 +27%。说明缺失模式敏感性是模型—数据交互，而不是缺失率的单调函数。
3. **Electricity**：模式漂移最清晰。S4M 仅 +9.2% / +4.4%，CTF 为 +40.8% / +100.1%；插补模型分别为 PatchTST +296.7% / +338.8%、DLinear +304.6% / +988.3%、iTransformer +796.5% / +271.7%。

## 结构解释与研究含义

这些差异与模型的归纳偏置一致，但目前仍是结构性解释而非因果证明：

- **S4M** 直接利用掩码、衰减表示和原型记忆，因此能维持较窄的跨模式误差范围；其代价可能是较强平滑/汇聚偏置，使匹配格的绝对误差不总最小。
- **CTF** 的有效 patch 数、位置与 channel token 汇聚方式会随块缺失而改变；B24 与 patch 网格的对齐关系可导致强且非对称的模式交互。
- **BiTGraph** 的局部 PartialTCN 更容易在分散点缺失下保留邻域信息；连续 B24 会破坏局部上下文，随后图传播也更难弥补。
- **插补模型** 看不到掩码。匹配时可从稠密、平滑的插补输入取得很高精度；失配时，插补产生的局部形状、频谱和跨变量伪相关改变，模型无从辨识插补值，因而可能大幅失效。

因此，后续方法不应只追求平均 MSE，而应同时报告匹配精度和最坏失配格；目标是保留强常规模型的匹配精度，同时降低跨缺失模式的性能下界风险。
