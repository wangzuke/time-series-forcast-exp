# 线性插补常规预测基线：r=50% 2×2 缺失模式矩阵结果

> 本文保留为三种线性插补基线的分模型执行与复核记录。请优先引用包含全部当前模型的 [统一框架主结果报告](1113-实验结果-统一框架-r50-2x2矩阵.md)。

## 结论摘要

PatchTST、DLinear、iTransformer 的正式实验已全部完成并通过完整性校验。它们都不是原生缺失感知模型：每个历史窗口逐变量线性插补后才进入模型，掩码不输入模型。

- **ETTh1：三种模型均显示明确的模式失配。** 固定 B 测试时，P 训练替代 B 训练使 MSE 上升 **22.3%--35.7%**；固定 P 测试时，B 训练替代 P 训练使 MSE 上升 **19.2%--57.3%**。iTransformer 四个格子的 MSE 均最低（8.667--12.313）。
- **Electricity：失配效应最强且方向一致。** 两个失配方向在全部三种模型上均显著恶化，MSE 上升 **271.7%--988.3%**；其中 B→P 对 DLinear 最脆弱（+988.3%），P→B 对 iTransformer 最脆弱（+796.5%）。
- **Weather：没有稳定的模式漂移惩罚。** 相应 MSE 变化介于 **-5.7% 到 +5.0%**（PatchTST）、**-0.1% 到 +0.2%**（DLinear）、**+0.4% 到 +1.3%**（iTransformer）。该数据集/设置下，插补后的输入对 P/B 形状近乎不敏感。

因此，问题动机得到了跨模型、跨数据集但**非普适**的证据支持：在 ETTh1 和尤其 Electricity 上，训练--测试缺失模式一致性至关重要；Weather 的反例表明，不能将“块缺失一定更难”或“所有数据必有模式漂移惩罚”作为结论。

## 固定测试模式下的失配效应

正数代表把训练模式切换为与测试不一致后误差升高。此比较控制了测试掩码形状，因此不把“不同测试模式的内在难度”混入模式漂移效应。

| 模型 | 数据集 | B 测试：P→B 相对 B→B | P 测试：B→P 相对 P→P |
| --- | --- | --- | --- |
| PatchTST | ETTh1 | +22.48% MSE / +9.98% MAE | +55.11% / +24.73% |
|  | Weather | +5.02% / +5.77% | -5.70% / -7.78% |
|  | Electricity | +296.72% / +101.37% | +338.80% / +117.44% |
| DLinear | ETTh1 | +22.29% / +10.63% | +57.29% / +25.45% |
|  | Weather | +0.20% / -0.32% | -0.07% / +0.51% |
|  | Electricity | +304.62% / +95.72% | +988.35% / +220.88% |
| iTransformer | ETTh1 | +35.73% / +16.97% | +19.23% / +7.57% |
|  | Weather | +1.33% / +1.84% | +0.36% / -1.02% |
|  | Electricity | +796.45% / +188.11% | +271.68% / +91.51% |

ETTh1 的四个失配比较全部为正，Electricity 的六个失配比较也全部为正，并且远大于其组内 SD；这是当前最有力的“缺失模式变化会损害预测”的证据。Weather 的效应量接近零，且 PatchTST 的 P 测试方向相反，提示应研究数据周期性、变量维度、局部平滑度以及插补误差如何调节该效应。

## 与已完成缺失感知模型的定位

与 [S4M/CTF 报告](1112-实验结果-S4M与CTF-r50-2x2矩阵.md) 使用相同的 r=50%、L=H=96、P/B 和数据切分协议，可以作描述性并列：

- ETTh1 上，iTransformer 的四格 MSE（8.667--12.313）低于 S4M（22.547--23.506）和 CTF（9.173--18.162）；但它仍在两种失配方向上退化。
- Weather 上，插补+iTransformer 为 2810--2864，低于 S4M 的 4313--4511 与 CTF 的 4760--6056，且模式效应几乎为零。这说明在该协议中，一个稳定的插补基线不能省略。
- Electricity 上，插补模型的性能和鲁棒性有明显分离：iTransformer 在匹配格很强（B→B 4.918M），却在 P→B 达到 44.090M；S4M 的跨格范围更窄（7.224M--8.070M）。因此只报告最佳匹配格会掩盖模式漂移风险。

这些比较不意味着插补本身“优于”缺失感知建模：模型容量、训练配置和归纳偏置不同。它们的价值在于确立一个强且透明的常规基线，并说明高的同分布性能不等价于高的模式漂移鲁棒性。

## 可用于论文的问题动机与下一步

建议主文展示完整 2×2 表，并用 Electricity 与 ETTh1 的固定测试模式对比作为核心图/表：常规预测器在插补后仍对缺失形状的训练--测试不一致敏感，且部分场景的惩罚可达数量级。Weather 应作为边界条件而非删除：它说明所提问题是“数据动态与模型相关”的鲁棒性问题，而非由缺失率自动决定。

下一轮最小的有解释力实验是保持 50% 缺失率，改变块长（12、24、48）并加入混合模式训练；同时增加独立训练种子，并对固定 checkpoint 的 P/B 测试作配对差异统计。这样才能区分“模型仅适配 B24”与“模型真正学会缺失模式鲁棒性”。
