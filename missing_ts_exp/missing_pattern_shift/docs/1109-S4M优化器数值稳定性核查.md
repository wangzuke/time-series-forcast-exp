# S4M 优化器数值稳定性核查

## 问题与定位

在 r=50%、L=H=96、逐变量精确掩码、Electricity、P 训练、`e_layers=2` 的固定重放中，原选择套件采用的 Adam（学习率 0.01）在第 249 个优化步首次出现非有限预测和损失。此时输入掩码与模型参数仍为有限值，因此这不是数据读取、GPU 转移或显存不足造成的异常。

## 作者材料的冲突

论文附录 D.3 记为 Adam；但作者发布仓库的实际训练入口 `s4m/experiments/exp_pretrain1.py` 的非注释代码是：

```python
optim.SGD(model.parameters(), lr=args.learning_rate, momentum=0.9, weight_decay=1e-5)
```

Adam 行在该文件中被注释。两种来源不能被默认为等价。

## 可复核对照

除优化器外保持完全相同的随机种子、数据、掩码、模型和学习率：

| 优化器 | 学习率 | 重放结果 |
| --- | ---: | --- |
| Adam（论文文字） | 0.01 | 第 249 步首次 NaN |
| SGD + momentum 0.9 + wd 1e-5（作者入口） | 0.01 | 完成 319 个更新步，预测、损失、梯度/参数检查均有限 |

诊断文件分别为：

- `exp/diagnostics/s4m_electricity_e2_nonfinite_lr001_full_epoch.json`
- `exp/diagnostics/s4m_electricity_e2_nonfinite_sgd_lr001_320steps.json`

## 处理决定

后续深度选择采用作者实际训练入口的 SGD，并将结果隔离到 `s4m_depth_selection_r50_l96_h96_official_sgd`。旧的 Adam 选择套件保留为实现—论文不一致的审计证据，不与新套件合并或用于模型选择。每份新结果的 protocol JSON 显式记录优化器及其来源。
