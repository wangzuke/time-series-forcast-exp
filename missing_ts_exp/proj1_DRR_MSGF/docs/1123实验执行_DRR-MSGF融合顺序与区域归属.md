# 1123 实验执行：DRR-MSGF 融合顺序与区域归属

## 本轮任务

- **P2 验证在哪一层融合。** 两组共享节点层细图、细粒度表示、固定物理分区、区域传播参数和读出。FTR 用融合细图构造粗图，CTF 分别将两图聚合并归一化，再用同一逐边门按区域对取均值来混合。两组先烟测，再用 seed 2024 完整训练。
- **P3 验证如何划分区域。** 保持论文当前的 FTR 顺序，比较物理静态分区、由训练历史构造的功能静态分区、物理锚定的窗口软分区、固定软分区和无新增区域传播。固定软分区取同一冻结模型在训练窗口上的平均软归属，用于检验随窗口调整本身的价值。随机大小匹配分区作为已准备的诊断资源。
- **P3 先检查归属稳定性。** 使用 P2 的 FTR checkpoint。在验证窗口上检查软归属行和、区域质量、相邻窗口变化、与固定软分区的差异，以及按观测量和最长缺失段分组的熵。通过后运行全部五组。若软分区诊断失败，队列继续物理静态、功能静态和无区域这三组。

核心协议沿用 METR-LA、Block-T 50%、24 步历史预测 12 步。正式比较采用相同 seed 内的同一掩码和验证 MAE checkpoint 规则，测试在原始有效未来标签上计算 MAE 和 RMSE。

P2 可以直接开始。P3 在 P2 训练后取得用于诊断的冻结 checkpoint，其训练顺序固定为 FTR。先跑完单 seed 试运行，P2/P3 的三 seed 确认入口已实现，可使用 2025、2026、2027 重新执行成对比较。
