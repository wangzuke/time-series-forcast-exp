# 1122 实验报告：DRR-MSGF 双图融合 P1 试运行

## 1. 实验动机与问题

物理图提供稳定的道路空间关系，历史窗口如何缺失都不会改变这些连接。观测图从当前窗口构建，能够反映当下的数据关系，但连续缺失会减少构图可用的观测证据。需要用对照回答两个问题：在相同预测模型中，结合两种关系是否比任一单图更有效？如果两图值得结合，固定比例或全局学习一个比例是否已经足够？

本轮在 METR-LA 的 Block-T 50% 条件下改变细粒度传播图，其余训练设置保持一致。所有变体使用 `mr_variant=fine`，沿用 HD-TTS 主干及其物理图空间层级，保留同一种观测特征读出，关闭新增的区域传播与注入支路。这样可以把对照集中在新增细图分支如何组织两种关系。

## 2. 已执行的实验

| 编号 | 细图设置 | 实现 | 目的 |
|---|---|---|---|
| F-P | Physical | 只用物理邻接 | 测量稳定道路拓扑在新增细图分支中的效果，给融合组提供单图参照 |
| F-O | Observation | 使用窗口观测邻接，整窗无观测节点回退物理邻接 | 测量当前历史构出的动态关系能否单独承担细图传播 |
| F-H | Fixed-half | 两图各占 0.5，再行归一化 | 检查简单等权混合能否取得相似效果 |
| F-G | Global-scalar | 训练一个全模型共享的混合比例，再行归一化 | 检查每条边共享一个可学习比例是否足够 |
| F-E | Edgewise | 根据两端节点观测率、成对共同观测率及两图边权，为各窗口的各候选边计算混合比例 | 检查不同边使用不同混合比例能否改善预测 |

上述名称限定的是新增细图分支的传播邻接。公共 HD-TTS 主干仍使用物理图，读出也仍接收同一组观测统计。除 Physical 直接使用物理行外，其余设置遇到整窗零观测源节点时都回退到物理图。五组均登记 407,448 个模型参数。各变体实际参与前向和训练的融合参数不同，例如只有 Global-scalar 使用全局标量，只有 Edgewise 使用逐边 MLP。

- **烟测完成 5 组。** 每组 1 轮、2 个训练 batch，验证和测试各限 1 个 batch。五组均写出结果，用于检查训练、评估与落盘链路。
- **完整预算试运行完成 5 组。** 每组均用 seed 2024，于 2026 年 11 月 20 日结束。五份结果及对应最佳 checkpoint 都已落盘，原先中断的 Physical 尝试未计入结果。
- **后续阶段待执行。** 本轮产物覆盖 P1 烟测与试运行。P1 多种子确认、P2 先融合或先区域化、P3 静态或动态区域，以及 P4 范围检查尚未开展。

## 3. 共用协议与指标口径

| 项目 | 实际执行设置 |
|---|---|
| 数据与任务 | METR-LA，207 个传感器。历史 24 步，预测 12 步，窗口步长 1 |
| 切分与标准化 | TSL 时间顺序切分，参数 `val_len=0.1, test_len=0.2`。标准化沿用 runner 的训练段统计与遮蔽设置 |
| 输入缺失 | 使用已有的 seed 2024 Block-T 掩码，与数据原始有效掩码取交集。人工缺失率 49.9972%，掩码资源记录的连续缺失长度范围为 12–48 步 |
| 输入构造 | 缺失位置按 runner 前向填充、反向补齐并将剩余空值置零，同时向模型提供独立的历史观测掩码 |
| 物理图 | runner 实际使用 TSL `MetrLA` 提供的道路距离，取距离核相似度并按 `threshold=0.1` 稀疏化 |
| 观测图 | 对掩码感知历史表示计算候选边分数，在 `top-k=8` 前使用当前窗口的成对共同观测率修正分数 |
| 随机种子 | 五组训练 seed 与人工掩码 seed 均为 2024 |
| 训练与选择 | AdamW，学习率 0.001，权重衰减 0.01。最多 100 轮，每轮 300 个训练 batch，batch size 32。按 `val_mae` 选 checkpoint，early stopping patience 20 |

结果文件记录两次测试。两次均使用同一个最佳 checkpoint，历史输入均保留人工缺失。训练和验证，以及第一次测试 `masked_test`，使用人工掩码与原始掩码交集；第二次测试 `unmasked_test` 恢复原始目标及其有效掩码，测试输入继续使用带人工缺失的历史。**本报告主表采用实验计划指定的 `unmasked_test`。** 上次会话汇报的是 `masked_test`，其结果在本报告中列为补充口径。两种口径的 RMSE 均取相应 MSE 的平方根。现有结果 JSON 汇总全部 12 个预测步。

五份 JSON 的模型与 runner 文件指纹、数据 SHA-256、掩码 SHA-256、固定区域资源 SHA-256 和关键训练配置一致。掩码 SHA-256 为 `291f2e864e081457b8fd7f1f34c42b09bd50a9e01eb1dc6931311aebf3c4a9f7`。受控代码指纹为 `ce9479e39c2d047d56eb7cb068b561ab1b60a2c523e3e8d686e5da7b59886de0`。Global-scalar 的工作区状态快照与其他组有差异，五组 Git HEAD 和受控文件指纹仍相同。

## 5. 分析与阶段判断

1. **逐边融合在这次试运行中取得最低测试 MAE。** 相比 Observation，主口径 MAE 低 0.0225、RMSE 低 0.0585。相比更强的 Physical，MAE 只低 0.0079（约 0.24%），RMSE 反而高 0.0362（约 0.53%）。因此，当前观察到的双图收益主要体现在平均绝对误差，尚不足以确认融合能稳定改善整体预测误差。
2. **混合方式比“是否用了两张图”更值得区分。** Fixed-half 和 Global-scalar 的主口径测试 MAE 均高于 Physical。Edgewise 在 MAE 和 RMSE 上均优于这两种混合，说明逐边调节在当前设置下有进一步验证的价值。Fixed-half 的最佳验证 MAE 最低，测试排序不同。验证 MAE 用于各自选 checkpoint，比较效果以共同的测试协议为准。
3. **主辅口径给出同样的首位排序。** Edgewise 在两种标签口径下均取得最低测试 MAE，Physical 均取得最低 RMSE。对照只有一个训练与掩码 seed，目前无法估计跨 seed 方差或显著性，也无法定位逐边融合究竟在哪些节点、缺失窗口或预测步上起作用。现存 JSON 没有逐预测步结果与分组门值诊断。
4. **P1 的整体误差还无法回答两张图在哪些场景互补。** 五组测试 MAE 的最大差距是 0.0225（约 0.7%）。接近的均值既可能来自样本上的表现普遍接近，也可能来自不同场景中的优势彼此抵消。此外，五组都保留了 HD-TTS 主干中的物理图，Observation 细图在整窗无观测的节点上也回退到物理邻接。因此结果针对新增细图分支的图来源，不能外推为整个模型对物理信息的依赖程度。
5. **后续阶段已经完成各自的单 seed 试运行。** P2 在固定区域成员下比较了融合层级，P3 比较了区域成员策略。两者都提供了独立的对照，P1 的多 seed 确认也不再作为它们的前置条件。若要继续验证双图互补，优先复用 P1 checkpoint，在相同节点与窗口上按观测率、最长缺失段和物理邻居可用性比较误差，了解两种单图设置是否在不同条件下占优，以及融合能否保留这些优势。

**阶段结论。** 在 METR-LA Block-T 50% 的单 seed 试运行中，逐边融合取得最低测试 MAE，物理细图取得最低测试 RMSE。当前最稳妥的结论是不同细图方案的整体误差接近，互补性及其适用场景仍待分组对照验证。
