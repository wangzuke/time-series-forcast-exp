# DRR-MSGF 项目迁移说明

迁移日期：2026-11-09。

原先散落在 `missing_ts_exp/` 下、服务于 DRR-MSGF 的模型代码、训练入口、
R0902--R0917 脚本、固定掩码与区域资源、实验报告、结果和日志已集中到本目录。
后续新实验应只使用本目录中的 `src/`、`scripts/`、`resources/`、`results/`
与 `logs/`。

数据集继续共享仓库顶层的 `dataset/`，官方 HD-TTS 和 BiTGraph 代码继续共享
`external_repro/official/`，没有复制或改动。通用的
`missing_ts_exp/src/data/missing.py` 仍留在原位置，因为其他实验项目也依赖它。

`results/` 和 `logs/` 是已完成实验的原始归档。为保持审计信息，JSON manifest 和
日志内记录的旧绝对路径没有回写；它们描述的是当时实际运行的环境，不应被当作新
实验的可执行配置。新实验的脚本和命令清单已改为本项目路径。
