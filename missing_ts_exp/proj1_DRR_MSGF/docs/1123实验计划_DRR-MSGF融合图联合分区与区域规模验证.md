# 1123 实验计划：DRR-MSGF 融合图联合分区与区域规模验证

## 1. 要回答的问题

本轮让**物理图和观测图先融合，再由融合细图决定区域成员和区域数量**。每个窗口内，每个传感器恰好属于一个区域。区域大小可以不同，例如在上限为 32 的设置下，可以一组 5 个、另一组 23 个。动态组会按当前窗口重新分区，节点可以换组，区域也可以合并或拆开。

1. **区域多大合适？** 将每区最大成员数作为超参数，检验放宽 8 个节点的上限是否改善预测，以及实际分区有没有用到更大的区域。
2. **固定分区是否足够？** 两组都用融合图和同一分区规则，比较由训练历史确定的固定成员和由当前窗口重新确定的成员。
3. **两张图共同决定分区是否有价值？** 在单区上限、合并规则与更新策略固定后，对比依据物理图、观测图及融合图得到的分区。下游传播一律使用融合图，区域成员和数量都是分区结果。

P2 固定谁和谁一组，只比较区域间怎么连。P3 中功能静态组表现最好，但分组只依据训练历史相关性。原动态软分区只能围绕固定物理归属调权。本轮检验的是**两类信息共同决定唯一归属，节点可随窗口换组**。 [P2 报告](1123_p2_p3_regions_p2_pilot_实验报告.md) · [P3 报告](1123_p2_p3_regions_p3_pilot_实验报告.md)

## 2. 数据与对照条件

| 项目 | 首轮设置 |
|---|---|
| 数据 | METR-LA 的 207 个传感器、已有物理图和项目的时间顺序切分 |
| 缺失与预测 | Block-T 50%，历史 24 步预测未来 12 步，复用 seed 2024 的预生成掩码 |
| 划分预算 | 比较每区上限 8、16、32。两组均由分区算法得到实际区域数 |
| 预测模型 | 同一 HD-TTS 主干和逐边融合方式，区域支路统一采用先融合再区域化 |
| 训练预算 | 1 个配对 seed。复用 batch size 32、最多 100 轮、每轮 300 个训练 batch、patience 20 |
| 评估 | 验证集选 checkpoint 和区域上限。锁定选择后，在原始有效未来标签上报告测试 MAE、RMSE |

旧实验的 31 组是一次物理静态划分得出的结果。新实验里的区域数 $K_t$ 由当前图与合并规则决定。静态组只划一次，得到的区域数固定使用。动态组逐窗口划分，区域数可以随窗口变化。对 207 个节点，单区上限为 8、16、32 时，理论上分别至少有 26、13、7 组。实际会形成多少组取决于融合图的连边与权重。

## 3. 分区如何计算

### 3.1 先融合，再决定区域成员

每个窗口 $t$ 使用当前历史观测与掩码构造 $A_t^{\mathrm{obs}}$，与固定物理图 $A^{\mathrm{phy}}$ 做现有的逐边融合，得到 $A_t^{\mathrm{fine}}$。整窗无观测的源节点沿用物理行回退。

- **联合静态**：只在训练窗口上平均 $A_t^{\mathrm{fine}}$，得到参考图 $A^{\mathrm{ref}}$。在参考图上分组一次，所有窗口沿用同一组成员。
- **联合动态**：每个窗口使用自己的 $A_t^{\mathrm{fine}}$ 跑同一个分组算法，分别得到成员和区域数。它只依赖当前历史窗口。

得到硬归属 $S_t\in\{0,1\}^{207\times K_t}$ 后，两组都用**当前窗口**的融合细图构造区域邻接。静态组固定成员与区域数，区域边仍随窗口变化。动态组同时更新成员和区域数。

$$
A_t^{\mathrm{coarse}}=\operatorname{RowNorm}\!\left(S_t^\top A_t^{\mathrm{fine}}S_t\right).
$$

例如，有两个路段在某个窗口里交通变化同步、融合边较强，可以合成一个 14 节点区域。另一个窗口下两者之间的支持变弱，算法可以划成两个区域。两个窗口的区域数和成员因此都可能不同。

### 3.2 唯一归属与不等大小

首轮采用**基于融合边权的逐步合并**。静态、动态和图来源对照共用以下规则：

1. **从单节点区域开始。** 对用于分区的图去掉自环，将双向边权取均值，得到对称关系图 $W$。所有节点先自成一区，孤立节点也可以最终保留为单节点区域。
2. **优先合并联系最强的两个区域。** 区域 $U,V$ 的合并分数为跨区节点对的平均边权 $s(U,V)=\sum_{i\in U,j\in V}W_{ij}/(|U||V|)$。每步在满足 $|U|+|V|\leq C$ 的候选里选分数最高的一对。并列时按节点索引确定顺序。
3. **按边权停止。** 只有分数为正且达到阈值才合并。阈值先取训练参考融合图正边权的第 25 百分位，所有容量与实验组共用，避免无连接或连接很弱的节点只为填满区域而被强行合并。没有可合并的区域时停止，当前非空区域即为输出。

区域大小允许从 1 到 $C$，可以跨原物理组。合并过程没有固定代表和预设区域数。报告实际组数、组大小、空间连通率、融合边的区内权重比例，以及停止时有多少候选因容量或边权未合并。**提高上限只是让更大的区域成为可能，实际分区由图决定。**

### 3.3 保证划分与传播使用同一张融合图

拟复用 P1 的 Edgewise checkpoint。所有对照从同一初始化出发，冻结编码器、观测图投影、共观测分数系数和逐边融合门，继续训练时序传播、细图与区域消息传播及读出。这样能先验证**给定同一融合机制时，区域划分策略本身的价值**。

预计算分区与训练内构图使用同一套冻结权重、掩码和历史输入，并逐窗抽样核对边权。分区路径显式遮蔽无效历史值，检查现有填补通路是否可能引入窗外信息。如果掩码处理的修正需要重训图生成器，所有变体共用一次重训结果。按数据切分和绝对窗口起点缓存整数成员编号及哈希，避免保存每个窗口的密集邻接。

## 4. 实验矩阵与执行顺序

### A. 区域大小上限 × 静态或动态

| 上限 $C$ | 联合静态 | 联合动态 | 对照目的 |
|---:|:---:|:---:|---|
| 8 | ✓ | ✓ | 保留原容量上限作为参照，用同一合并规则重新划分 |
| 16 | ✓ | ✓ | 将单区容量翻倍，观察成员和区域数如何变化 |
| 32 | ✓ | ✓ | 将单区容量放宽到原来的四倍，检验更大的区域是否有益 |

首轮跑 **6 组、共用一个 seed**。先看同一上限下静态与动态的配对结果，再看提高上限后分区和误差如何变化。按两种策略的验证 MAE 均值选择共同上限，完全并列时取较小上限。保留完整验证矩阵，锁定容量后再评估该容量下的两组测试 checkpoint。对照衡量的是**允许动态改变整个分区的综合效果**，包含区域成员与区域数量变化。

### B. 两种图是否共同改善分组

采用 A 选定的容量上限和验证集上表现更好的更新策略。复用已跑的融合图组，补一组物理图分区和一组观测图分区。共用合并规则、阈值和下游融合图，**只改变分区所使用的邻接**，各组的实际区域数可以不同。

- 静态观测分区使用训练窗口平均的观测图。物理分区使用固定道路图。
- 动态观测分区使用当前窗口观测图。整窗无观测的源节点统一回退物理行，并单独查看这类节点。物理图随窗口固定，因此用物理图分配得到的是固定成员。
- 对齐同一批节点和窗口，按节点观测比例、最长连续缺失和物理邻居可用性分组比较误差。由此观察单图分组是否各有擅长的场景，以及融合分组能否保住这些优势。

A 完成后再投入 B 的 **2 个新增对照**。若要声称联合分区优于旧功能静态分区，或证明区域支路本身有收益，应在新协议中重跑功能静态或无区域对照。先用单 seed 探索，后续只复验直接回答研究问题的比较。

## 5. 输出与判断

| 输出 | 要报告的内容 | 能回答什么 |
|---|---|---|
| 规模对照表 | 各上限的验证 MAE、RMSE，选定上限的测试结果。实际区域数的分布、组大小分布及大于 8 的组比例 | 放宽上限是否有益，是否实际用到更大的区域 |
| 静态与动态对照 | 同一上限的配对误差。逐窗区域数、相对静态和相邻窗口的同组成员变化率。成员变化与未变化样本的误差差值 | 动态分区是否实际变化，收益是否集中于特定窗口 |
| 图来源对照 | 三种成员划分的整体与分组 MAE、RMSE。归属一致率、区内边权和空间连通率 | 哪种图在什么缺失场景提供有用的分组依据 |

- 较高上限实际产生了大于 8 的组，而且误差改善，才支持继续考察放宽上限。若各区实际仍在 8 以内，本轮没有充分检验较大的区域。
- 区域编号只用于当前窗口。判断某节点的归属是否变化，直接比较它的同组成员集合，也可报告集合重合度，避免仅因区域重新编号而误判。结合实际区域数和预测误差，区分区域合并、拆分和成员调整。滑窗高度重叠，确认阶段使用配对 seed 做统计。
- 融合组与单图组若整体接近，先检查归属是否实际不同、各自在哪类样本占优。结果限定于 METR-LA Block-T 50%、候选规模和本轮分区算法。
