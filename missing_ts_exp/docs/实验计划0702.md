# 实验计划 0702：面向优化方向的第三轮实验

> 承接《0702实验与论文分析报告》，本文档设计第三轮实验方案。  
> 核心目标：基于代码级根因分析和文献调研，验证最有前景的优化方向。  
> 设计原则：**先修复再优化**——先修正已发现的代码Bug，再探索架构改进。

---

## 一、实验目标

### 1.1 核心问题

两轮实验揭示了一个核心矛盾：**缺失感知方法在理论上应优于两阶段方法，但实验中仅在窄条件下成立**。第三轮实验的目标是：

1. **修复**：纠正 CRIB 的 IB 通路 bug，评估真正的信息瓶颈效果
2. **改进**：针对已诊断的架构瓶颈（高维压缩、单一 query、skip 策略），设计针对性改进并验证
3. **融合**：探索"轻量级缺失感知"路线——在两阶段框架中引入 mask 信息，兼得两者优势
4. **边界**：给出定量的"缺失率×维度"方法选择矩阵

### 1.2 预期产出

- 每个优化方向的量化效果（MSE 改善百分比）
- 更新后的方法排名（是否改变"两阶段全局最优"的结论）
- "缺失率×维度"条件矩阵（指导实际应用中的方法选择）

## 二、实验组设计

### 组 A：CoIFNet 移植偏差修复（优先级 P0）

**背景**：与原始仓库（github.com/KaiTang-eng/CoIFNet）代码对比发现三处移植偏差：(1) hidden 维度 128 vs 原始 256；(2) 用独立 Linear embedding 层替代了原始的 TSBlock 渐进压缩；(3) 输入拼接用 `cat([x*mask, mask])` 而非原始的 `cat([x, mask])`。其中 hidden 维度差异导致 Traffic 上的压缩比从原始的 6.8:1 恶化到 13.6:1。

**代码改动**：

| 改动项 | 具体内容 | 文件 |
|---|---|---|
| 修复 1 | hidden 从 128 改为 256 | `coifnet.py` |
| 修复 2 | 去掉独立 embedding 层，还原 SharedModule 第一层负责维度变换的原始架构 | `coifnet.py` |
| 修复 3 | 输入拼接从 `cat([x*mask, mask])` 改为 `cat([x, mask])` | `coifnet.py:299-301` |

**实验矩阵**：

| 变体 | 描述 |
|---|---|
| A0: CoIFNet-full（当前） | 基线，直接复用 R2 数据 |
| A1: CoIFNet-h256 | 仅改 hidden=256，其余不变 |
| A2: CoIFNet-faithful | 修复 1+2+3，全面对齐原始代码 |

**实验参数**：
- 数据集：ETTh1, Weather, Electricity, ExchangeRate（4 个）
- 缺失类型：random_point, continuous_segment
- 缺失率：0.1, 0.3
- 预测长度：96, 336
- 种子：2024, 2025

**实验量**：
- A1: 4 数据集 × 2 缺失类型 × 2 缺失率 × 2 预测长度 × 2 种子 = **64 条**
- A2: 同上 = **64 条**
- 合计：**128 条**

**判定标准**：
- A1 vs A0 在 Electricity 上：MSE 若显著下降，说明 hidden 维度是核心差异
- A2 vs A1：验证完整还原是否进一步改善
- A2 vs Interp+iTrans（MSE 0.2834）：修复后的 CoIFNet 是否有可能接近两阶段最优
- **关键意义**：如果修复后 CoIFNet 在高维数据集（Electricity）上显著改善，则 R2 报告中"缺失感知方法在高维上失败"的结论需要修正——失败原因部分来自移植偏差而非方法本身

### 组 B：CRIB 移植修复 + 设计探索（优先级 P1）

**背景**：CRIB 存在一处移植偏差（位置编码退化使用）和两个原始设计问题（z 未参与预测路径、MultivariateNormal 效率低）。移植偏差优先修复；设计改进属于探索性实验。

**代码改动**：

| 改动项 | 性质 | 具体内容 | 文件/行号 |
|---|---|---|---|
| 修复 1 | 移植偏差 | 位置编码改为原始的完整 2D 切片用法 | `crib.py:370-375` |
| 修复 2 | 效率优化 | `MultivariateNormal` → `Normal`，解析 KL | `crib.py:226, 384` |
| 改进 1 | 设计探索 | 预测头输入从 `enc_out_1` 改为 `z = qz_1.rsample()` | `crib.py:410` |

**实验矩阵**：

| 变体 | 描述 |
|---|---|
| B0: CRIB-full（当前） | 基线，复用 R2 数据 |
| B1: CRIB-pe-fixed | 仅修复 1（位置编码） |
| B2: CRIB-efficient | 修复 1 + 修复 2（位置编码 + Normal 替换） |
| B3: CRIB-z-path | 修复 1 + 修复 2 + 改进 1（完整修复 + z 路径探索） |
| B4: CRIB-z-beta | B3 + KL 权重搜索（beta=0.001, 0.01, 0.1, 1.0） |

**实验参数**：
- 数据集：ETTh1, Weather, Electricity, ExchangeRate（4 个）
- 缺失类型：random_point, continuous_segment
- 缺失率：0.1, 0.3
- 预测长度：96, 336
- 种子：2024, 2025

**实验量**：
- B1: 4 数据集 × 2 缺失类型 × 2 缺失率 × 2 预测长度 × 2 种子 = **64 条**
- B2: 同上 = **64 条**
- B3: 同上 = **64 条**
- B4: 64 × 4 beta = **256 条**（条件触发：B3 有显著改善时）
- 合计：**192 条**（不含 B4），**448 条**（含 B4）

**判定标准**：
- B1 vs B0：位置编码修复是否改善序列建模（预期改善 2~5%）
- B2 vs B1：训练速度提升 >30% 且性能不降，说明 Normal 替换有效
- B3 vs B2：z 路径是否有效。若 Electricity h336 MSE 显著降低，说明 IB 通路改进有价值；若反而恶化，则验证了原始作者弃用该路径的合理性
- B4：最优 beta 下是否能接近 SAITS+iTrans（MSE 0.2851）

### 组 C：MissTSM 架构改进（优先级 P1）

**背景**：MissTSM-full 已在 Electricity 上反超两阶段（R2 发现 M1），但在 Traffic 上仍大幅落后。核心瓶颈是 64 维单一 query 的信息通道不足（原始设计本身的局限，非移植偏差）。

**代码改动**：

| 改动项 | 具体内容 |
|---|---|
| C1: 条件化 query | `q = var_query + time_proj(sinusoidal_pe[t])`，time_proj 为 Linear(d_pe, q_dim) |
| C2: 多 query | var_query 从 `(1,1,64)` 扩展为 `(1,K,64)`，K=8，attention 输出做 mean pooling |
| C3: 加权 skip | `feat = mask*(alpha*x + (1-alpha)*feat) + (1-mask)*feat`，alpha = sigmoid(Linear(feat)) |

**实验矩阵**：

| 变体 | 描述 |
|---|---|
| C0: MissTSM-full（当前） | 基线，复用 R2 数据 |
| C1: MissTSM-cond-q | 时间步条件化 query |
| C2: MissTSM-multi-q | 多 query（K=8） |
| C3: MissTSM-soft-skip | 加权融合 skip |
| C4: MissTSM-best | C1~C3 中最优组合 |

**实验参数**：
- 数据集：ETTh1, Weather, Electricity, ExchangeRate（4 个）
- 缺失类型：random_point, continuous_segment
- 缺失率：0.1, 0.3（Weather/Electricity 额外 0.5 验证高缺失率）
- 预测长度：96
- 种子：2024, 2025

**实验量**：
- C1: 4 数据集 × 2 缺失类型 × 2 缺失率 × 1 预测长度 × 2 种子 = **32 条**（Weather/Electricity 额外 +8 条 50% 缺失率 = 40 条）
- C2: 同上 = **40 条**
- C3: 同上 = **40 条**
- C4: 基于 C1~C3 结果选择最优组合，补充 h336 实验 = **约 16 条**
- 合计：**~136 条**

**判定标准**：
- C1/C2 vs C0 在 Electricity 上：MSE 降幅说明 query 瓶颈是否是关键因素
- C3 vs C0 在 Weather 上：验证加权 skip 是否优于硬 skip
- C4：在 Electricity 上是否能进一步拉大对两阶段的优势

### 组 D：Mask-Aware iTransformer（优先级 P1）

**背景**：当前两阶段最优方法（Interp+iTrans）的 iTransformer 完全不知道哪些位置是插值的。引入 mask 信息可能让 iTransformer 对不可信位置降权，进一步提升性能。

**设计思路**：在保持两阶段流水线的前提下，修改 iTransformer 的输入：

| 变体 | mask 引入方式 | 改动量 |
|---|---|---|
| D0: Interp+iTrans（当前） | 无 mask | 基线 |
| D1: mask 拼接 | `input = cat([x_imputed, mask], dim=-1)`，Linear(2L, d_model) | ~5 行 |
| D2: mask embedding 加和 | `emb = value_emb(x) + mask_emb(mask)`，mask_emb 为 Linear(L, d_model) | ~5 行 |
| D3: mask-weighted attention | attention score 乘以 mask 置信度 `score = score * confidence(mask)` | ~10 行 |

**实验参数**：
- 数据集：ETTh1, ETTh2, ETTm1, ETTm2, Weather, Electricity, ExchangeRate（7 个）
- 缺失类型：random_point, continuous_segment
- 缺失率：0.1, 0.3, 0.5
- 预测长度：96, 336
- 种子：2024, 2025

**简化策略**：先在 ETTh1 + Weather 上跑 D1/D2，快速筛选：
- Phase 1: 2 × 2 × 3 × 2 × 2 × 2 变体 = **96 条**
- Phase 2: 基于 Phase 1 结果选择最优变体，补充 Electricity + ExchangeRate 和 h336 = **约 64 条**
- 合计：**~160 条**

**判定标准**：
- D1/D2/D3 vs D0：任何变体在 3 个数据集上平均 MSE 改善 >2%，说明 mask 信息对强预测器有价值
- 如果在高缺失率（50%）下改善更明显，支持"不确定性传播"假说
- 如果 Electricity 上改善最大，说明高维数据的 mask 信息更有价值

---

### 组 E：条件矩阵补全（优先级 P2）

**背景**：为构建"缺失率×维度"的方法选择矩阵，需要在更多条件下收集数据点。R2 的高缺失率实验仅覆盖了 Weather 和 Traffic。

**实验参数**：
- 新增 ETTh1 和 ExchangeRate 的 50%/70% 缺失率实验
- 方法：Interp+iTrans, MissTSM-full, CoIFNet-faithful（+ 组 A~D 中最优变体）
- 缺失类型：random_point, continuous_segment
- 预测长度：96
- 种子：2024, 2025

**实验量**：
- 3 方法 × 4 数据集 × 2 缺失类型 × 2 缺失率 × 1 预测长度 × 2 种子 = **96 条**
- 加上最优变体的补充实验 ≈ **+16 条**
- 合计：**~112 条**

## 四、执行计划

### 4.1 分阶段执行

```
Phase 0: 代码改动（1~2天）
  ├── A: 修复 CoIFNet 移植偏差（最高优先，还原原始架构）
  ├── B: 修复 CRIB 位置编码 + Normal 替换 + z 路径探索
  ├── C: 实现 MissTSM 改进变体
  └── D: 实现 mask-aware iTransformer 变体
      烟测：每个改动跑 ETTh1 × 1 epoch 验证不报错

Phase 1: 核心验证（2~3天，7卡并行）
  ├── 优先跑 A（P0，移植修复，~96 条）
  ├── 然后跑 B + C + D（P1，~280 条）
  └── 最后跑 E（P2，~36 条）

Phase 2: 深化验证（1~2天，条件触发）
  ├── B4: CRIB beta 搜索（若 B3 z 路径有效）
  ├── C4: MissTSM 最优组合 + h336（若 C1~C3 有效）
  └── D Phase 2: 最优变体补充 Traffic（若 D Phase 1 有效）
```

### 4.2 决策节点

| 节点 | 条件 | 动作 |
|---|---|---|
| A 完成后 | CoIFNet-faithful 在 Electricity 上 MSE 降幅 > 10% | 确认移植偏差是高维失败的主因；更新 R2 结论 |
| Phase 1 完成后 | B 组：CRIB-z-path 在 Electricity h336 MSE < 0.30 | 触发 B4 beta 搜索 |
| Phase 1 完成后 | C 组：任何变体在 Electricity 上 MSE 降幅 > 5% | 触发 C4 组合实验 |
| Phase 1 完成后 | D 组：最优变体平均 MSE 改善 > 2% | 触发 D Phase 2 |
| Phase 1 完成后 | 所有方向均无显著改善 | 转向引入新架构（S4M）或基础模型插补器（NuwaTS） |

## 五、风险与缓解

| 风险 | 可能性 | 影响 | 缓解措施 |
|---|---|---|---|
| CoIFNet 修复后仍不如两阶段（联合优化梯度冲突未解决） | 中 | 组 A 无法改变全局结论 | 记录为"移植偏差加剧了问题但非根因"的结论 |
| CRIB z 路径被原始作者弃用是有道理的（IB 压缩过度） | 中-高 | 组 B 改进 1 无效 | B4 的 beta 搜索覆盖弱约束（beta=0.001） |
| Mask-aware iTrans 改善微弱（<1%） | 高 | 组 D 无效 | Phase 1 先用小规模验证，不投入全量实验 |
| 所有方向均无显著改善 | 低-中 | 需调整研究方向 | 转向引入新架构（S4M）或基础模型插补器（NuwaTS） |

## 六、成功标准

### 最低标准（验证性）
- 修复 CoIFNet 移植偏差后，Electricity 上 MSE 有显著改善（确认移植偏差的影响范围）
- 至少一个优化方向在至少一个数据集上改善 >3%

### 理想标准（突破性）
- CoIFNet-faithful 在 Electricity 上接近两阶段方法
- Mask-aware iTransformer 全局平均 MSE < 0.28（超越当前两阶段最优 0.2834）
- 构建出完整的"缺失率×维度×缺失类型"方法选择矩阵

### 论文标准
- 移植偏差的量化影响被清晰记录（对 reproducibility 研究有参考价值）
- 至少两个优化方向被证明有效
- 条件矩阵覆盖 3 个维度尺度 × 5 个缺失率 × 2 个缺失类型
