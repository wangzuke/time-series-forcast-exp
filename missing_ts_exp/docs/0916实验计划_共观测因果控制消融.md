# 0916 实验计划：METR-LA 共观测证据因果控制消融

## 1. 背景、目标与范围

本计划响应 `0916审稿意见-实验补充.md`。当前论文已完成 METR-LA Block-T/Point 主表、常规机制消融、AQI36 泛化和预测跨度分析；这些结果不得重跑或混入本计划。本轮只新增两个预先声明的因果控制变体，回答一个更窄但更关键的问题：MR-MSGF 的收益是否来自**正确节点对上的共同观测证据**，而非仅向网络输入更多缺失统计量、额外参数或任意数值正则化。

正式实验固定为 METR-LA、Block-T 50%、24 步历史、12 步预测、5 个配对 mask seed（2024--2028）。选择该条件是因为已有主表中它是 MR-MSGF 相对 HD-TTS-AMP MAE 增益最大的 Block-T 条件，且和论文的“连续历史缺失但空间邻居仍有部分观测”动机一致。

本轮**不**新增数据集、复杂基线、Block-ST、超参数敏感性或大规模重训；AQI36 的自然缺失负结果继续保留为适用边界。论文主文中以本计划的机制控制表替换当前缺少方差检验且与核心机制联系较弱的 horizon decomposition 表；原跨度结果保留在附录/补充材料。

## 2. 预注册假设与判据

### H1：可靠性统计量本身不足以解释完整模型收益

若 Full MR-MSGF 在 MAE（主要指标）和 RMSE（辅助指标）上优于 Feature-only，则结果支持“仅把节点可靠性统计送入 HD-TTS-AMP 读出端不能恢复完整增益”。这不单独证明区域图机制，但排除“只是增加缺失特征”的解释。

### H2：正确的节点对对应关系是必要信息

若 Full MR-MSGF 优于 Permuted-Q，则结果支持模型使用了正确节点对的共同观测语义，而非任意具有相同数值分布的矩阵正则化。

两项比较是本表仅有的主要检验。若任一条件不满足，不追跑、不过滤结果；按第 10 节的失败解释修改论文主张。

## 3. 正式比较与控制变量

| 变体 | 是否新训练 | 结构与允许信息 | 主要回答的问题 |
|---|---:|---|---|
| HD-TTS-AMP | 否，复用 | 官方 HD-TTS-AMP 主干 | 基础对照 |
| HD-TTS-AMP + Reliability features（Feature-only） | 是 | 官方静态时空主干加可靠性读出偏置；不含动态图或区域分支 | 是否只因多输入缺失统计量获益？ |
| MR-MSGF + Permuted-Q | 是 | Full 的所有参数和路径不变，仅以逐窗口 `Q_perm=PQP^T` 替代所有 `q` 相关使用 | 是否必须保留正确节点对？ |
| Full MR-MSGF | 否，复用 | 已验证的完整模型 | 完整对照 |

每个新变体训练 5 次，共 **10 个正式训练作业**。所有行使用完全相同的 Block-T 50% 输入 mask、顺序 train/validation/test 划分、输入窗口、输出目标、归一化、AdamW、学习率调度、`100 epochs`、每 epoch `300` 个 batch、batch size `32`、patience `20`、最佳 validation MAE checkpoint 选择规则以及未遮蔽有效未来目标 MAE/RMSE。随机初始化 seed 与 mask seed 同为 2024--2028。

不允许借本计划改变 Full 的参数量、训练预算或缺失生成器。所有 JSON 记录 data SHA256、mask SHA256、完整命令/配置、代码提交、模型参数量、最佳 checkpoint、masked 与 unmasked 测试指标。

## 4. 变体 A：Feature-only 的严格实现

### 4.1 输入统计量

从历史 `input_mask` 直接计算每个节点的

`R_i = [r_i, qbar_i, rho_i, b_i]`：

- `r_i`：节点历史观测率；
- `qbar_i`：节点与**固定物理邻居**的平均共同观测率；
- `rho_i`：固定物理区域内的平均观测率/区域覆盖率；
- `b_i`：最长连续缺失块占 24 步历史的比例。

物理邻接和区域分配沿用 Full 的静态资源，但仅用于计算上述掩码统计量，不能用于新的消息传播。

### 4.2 架构约束

Feature-only 必须从官方 HD-TTS-AMP 的静态时空层级和原 readout 出发。在 readout 的 scale score 上仅加入轻量可靠性偏置，例如 `Linear(4, L)`，其中 `L` 为原 AttentionReadout 的 scale 数；其布局需与 Full 的 Eq. (17) 读出偏置一致。

该变体**禁止**：

- 构造 `A_obs`、top-k 观测图、`obs_query/obs_key` 或任何 Eq. (4) 动态关系；
- 物理图与观测图融合、`edge_gate`、细图传播；
- coarse/region 消息传播、节点自适应区域门控 `alpha`；
- 使用 Full 的未使用图分支参数来虚增“同一模型”名义。

实现应作为单独的 `official_base_feature_only` 模型路径，而不是让 `feature_only` 先构造动态观测图再跳过传播。日志须打印总参数量；Feature-only 较小是允许且预期的，因为该对照检验的是统计量输入本身，而非参数匹配。若审稿阶段仍质疑容量，再另行预注册一个无图、容量匹配 MLP 对照，不能事后替换本轮主控制。

## 5. 变体 B：Permuted-Q 的严格实现

### 5.1 定义与随机性

对每个样本历史窗口的共同观测矩阵 `Q`，生成节点置换 `P` 并使用

`Q_perm = P Q P^T`。

置换由 `(mask_seed, split_id, absolute_window_index)` 的确定性哈希种子生成。同一绝对窗口在 train/validation/test 的任何 forward、任意 epoch、任意 batch 排序下得到相同 `P`；不同窗口使用不同置换。实现须把 absolute window index 作为 dataloader 协变量/样本元数据传入模型，不能依赖 batch 内位置或每次 forward 临时 `randperm`。

### 5.2 替换范围与不变量

`Q_perm` 必须替换 Full 内的所有 `q` 相关位置：

- 观测图打分的 `log(q_ij + epsilon)`；
- 细图 `edge_gate` 的 `q_ij` 特征；
- 物理邻居共同观测率 `qbar_i`；
- coarse gate、区域覆盖/可靠性特征以及 readout reliability features 中由 `q` 导出的量；
- 诊断输出中的“实际送入模型的 q”。

必须保持 Full 其他部分逐字一致：编码器、物理图、动态图算法、细图/粗图传播、门控网络、参数初始化、训练预算和 readout 均不改。`Q_perm` 的元素多重集合、形状、范围、对称性和窗口级稀疏度必须与 `Q` 相同；它仅破坏节点对语义。对原始历史完全无观测的节点，保留已有的安全规则：其 `A_obs` 行为零并回退物理图，不能因 top-k 并列产生任意观测边。

当前代码的扁平 `randperm(n_nodes*n_nodes)` 不满足此定义，不能直接用于正式实验。

## 6. 实现与安全验收（正式训练前）

### P0：代码实现与单元检查

1. 为 datamodule 的每个滑窗暴露稳定的绝对 window index，并写入 batch；确认不改变原有 `x/u/input_mask/target` 的值或切分。
2. 增加 `official_base_feature_only`，从 mask 直接计算 `R_i`；通过模块审计确认其 forward 不调用 `_observed_graph`、`_fine_graph` 或 `_coarse_propagate`。
3. 增加 `q_mode=permuted_pairwise`；使用稳定哈希构造每窗口节点置换并实现 `PQP^T`。
4. 对随机小 mask 写单元测试：同窗口重复调用完全相同、不同 window index 通常不同、`sort(Q.flatten()) == sort(Q_perm.flatten())`、`Q_perm` 对称、数值范围不变。
5. 对全缺失节点写回归测试：`A_obs[i,:]=0`，输出有限，且融合退化至物理图。
6. 对 Feature-only/Permuted-Q/Full 分别做 CPU 单 batch forward、backward 和 checkpoint reload 烟测；输出无 NaN/Inf。

### P1：协议烟测

仅用 Block-T 50%、seed 2024 的一小段训练（1 epoch、极少 batch）验证：两新变体均可保存 JSON/checkpoint；Feature-only 不含动态图模块；Permuted-Q manifest 含 window permutation spec；三者 data/mask SHA 与既有 Full 完全一致。该烟测不得写入正式汇总表。

### P3：验证、统计与报告

验证脚本须要求 20 行完整记录：10 行新训练，加 5 行既有 HD-TTS-AMP 和 5 行既有 Full MR-MSGF。检查每行 checkpoint、有限指标、配对 data/mask SHA、模型变体标识和置换元数据；Feature-only 还检查无动态图标识。

统计以未遮蔽 future MAE 为主要终点，RMSE 为辅助终点。对 Feature-only 和 Permuted-Q 分别计算五个配对差：

`d_s = metric_variant,s - metric_full,s`。

## 10. 结果解释预案

- **Full 同时优于两种控制**：可写为“受控测试显示，仅向 backbone 提供可靠性统计不能恢复增益；破坏正确节点对对应关系会削弱性能”。
- **Feature-only 接近/优于 Full**：结论调整为可靠性统计增强有效，区域图分支的必要性尚未被该实验支持；不再强称区域化带来主要收益。
- **Permuted-Q 接近 Full**：结论调整为 observation-aware regularization 有效，但当前证据不支持正确节点对语义是关键机制。
- **统计不显著或 RMSE 大幅反向**：如实报告 effect size 与 CI，避免因普通消融的方向性结果作因果表述；不通过增加数据集、挑 seed 或改超参数来追求显著性。
