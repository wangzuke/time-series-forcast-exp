## 二、现阶段结论与待验证问题

### 2.1 已较稳定的结论

1. **中低缺失率下，两阶段强预测器仍是强基线**  
   在缺失率 `0.1/0.3` 下，`Linear Interpolation + PatchTST/iTransformer` 长期保持最优或接近最优。

2. **补值误差与预测误差不等价**  
   SAITS 的补值 MSE 常优于线性插值，但预测 MSE 未必更低；CoIFNet 和 MissTSM 的补值 MSE 可以较高，但预测仍有竞争力。

3. **mask 信息有价值，但融合方式决定收益**  
   直接拼接 mask 不稳定；`Mask-Aware iTransformer(add)` 在 R3 中以较小参数增量获得了较稳定改善。

4. **高缺失率会放大缺失感知方法优势**  
   R2/R3 均显示缺失率 `0.5/0.7` 时，CoIFNet 或 MissTSM 更容易反超两阶段方法。

5. **变量维度改变最优缺失感知方法**  
   低维高缺失下 CoIFNet 更有优势，高维高缺失下 MissTSM 更稳；Traffic 仍是高维缺失感知模型的难点。

### 2.2 仍需验证的问题

| 编号 | 问题 | 为什么重要 |
|---|---|---|
| Q1 | ExchangeRate 缺少完整两阶段基线，R3 低维结论不闭合 | 当前无法判断 CoIFNet/CRIB 在 ExchangeRate 上是否真正优于两阶段 |
| Q2 | `Mask-Aware iTransformer(add)` 只在 ETTh1/Weather 上初步验证 | 需要确认其在 Electricity、ExchangeRate、高缺失率下是否仍有效 |
| Q3 | 缺失率阈值是否稳定落在 `0.3~0.5` | 需要跨低维/中维/高维数据集补齐曲线 |
| Q4 | 变量通道缺失仍是现有主线方法短板 | 需要引入 GinAR/IBN 或至少设计专项评测 |
| Q5 | CoIFNet 的 R2 变体为何在 Weather 更好 | 需要把独立 embedding、`x*mask`、hidden 维度拆开做小规模消融 |
| Q6 | MissTSM 高维优势是否能通过 grouped query 进一步增强 | R3 multi_q/soft_skip 没有全局收益，需要更保守的高维结构改造 |

## 三、实验总路线

本轮不再以“全面替换模型实现”为目标，而按优先级分为四条路线：

1. **P0：补齐关键空白**  
   补 ExchangeRate 两阶段基线，扩展 `Mask-Aware iTransformer(add)`。

2. **P1：构建条件边界矩阵**  
   以缺失率、变量维度、缺失类型为轴，明确何时两阶段胜出，何时缺失感知方法胜出。

3. **P2：针对最有价值的模型做小规模结构消融**  
   包括 CoIFNet R2 变体拆解、MissTSM grouped query、D2 add + PatchTST。

4. **P3：引入新论文基线**  
   S4M 用于高缺失率/block missing；GinAR/IBN 用于 variable missing；Merlin 暂作为表示学习方向储备。

## 四、P0 实验：补齐关键空白

### 4.1 P0-A：ExchangeRate 两阶段基线补跑

**目的**：R3 中 ExchangeRate 只跑了 CoIFNet 与 CRIB，缺少两阶段基线，导致低维高缺失结论不完整。

**方法**：

| 方法 | 说明 |
|---|---|
| `Linear + DLinear` | 低维线性强基线，ExchangeRate 上必须保留 |
| `Linear + PatchTST` | Transformer patch 基线 |
| `Linear + iTransformer` | R1/R2 全局强基线 |
| `SAITS + iTransformer` | 检查强补值器是否有效，若不稳定可只记录有效种子 |

**实验矩阵**：

| 维度 | 取值 |
|---|---|
| 数据集 | ExchangeRate |
| 缺失类型 | random_point, continuous_segment |
| 缺失率 | 0.1, 0.3, 0.5, 0.7 |
| 预测长度 | 96, 336 |
| 种子 | 2024, 2025 |

**实验量**：  
4 方法 × 1 数据集 × 2 缺失类型 × 4 缺失率 × 2 预测长度 × 2 种子 = **128 条**  
若先跳过 SAITS，则为 **96 条**。

**判定标准**：

- 若 `Linear + DLinear/iTransformer` 仍优于 CoIFNet，则 R3 中 CoIFNet 的 ExchangeRate 优势需要收窄解释。
- 若 CoIFNet 在 `0.5/0.7` 明显优于两阶段，则“低维高缺失适合 CoIFNet”的结论增强。

### 4.2 P0-B：扩展 Mask-Aware iTransformer(add)

**目的**：验证 D2 add 是否是稳定的低成本增强，而非只在 ETTh1/Weather 有效。

**方法**：

| 方法 | 说明 |
|---|---|
| `Linear + iTransformer` | 原两阶段基线 |
| `Linear + Mask-Aware iTransformer(add)` | 插值后加入 mask embedding |
| `Linear + PatchTST` | PatchTST 对照 |
| `Linear + Mask-Aware PatchTST(add)` | 若代码改动可控，作为扩展 |

**Phase 1 实验矩阵**：

| 维度 | 取值 |
|---|---|
| 数据集 | Weather, Electricity, ExchangeRate |
| 缺失类型 | random_point, continuous_segment |
| 缺失率 | 0.1, 0.3, 0.5, 0.7 |
| 预测长度 | 96 |
| 种子 | 2024, 2025 |

**实验量**：  
2 方法 × 3 数据集 × 2 缺失类型 × 4 缺失率 × 1 预测长度 × 2 种子 = **96 条**  
若加入 PatchTST add，则增加 **96 条**。

**Phase 2 补充**：

对 Phase 1 中改善超过 2% 的数据集/缺失率组合补跑 `pred_len=336`。

**判定标准**：

- 平均 MSE 改善超过 2%，且没有明显 seed 不稳定，即可作为下一阶段主力改进。
- 如果改善只出现在低缺失率，说明 mask embedding 主要用于识别插值噪声。
- 如果改善只出现在高缺失率，说明 mask embedding 在插值失真严重时更有效。

## 五、P1 实验：缺失率 × 变量维度 × 缺失类型条件矩阵

### 5.1 核心目标

建立一个明确的方法选择矩阵，回答：

```text
给定变量维度、缺失率和缺失类型，应该优先选择两阶段方法、mask-aware 两阶段方法，还是缺失感知方法？
```

### 5.2 数据集分层

| 层级 | 数据集 | 变量数 | 作用 |
|---|---|---:|---|
| 低维 | ETTh1 | 7 | 低维周期型数据 |
| 低维 | ExchangeRate | 8 | 低维非平稳金融数据 |
| 中维 | Weather | 21 | 中维物理变量 |
| 高维 | Electricity | 321 | 高维群组结构 |
| 超高维 | Traffic | 862 | 高维传感器网络，计算压力最大 |

### 5.3 方法集合

| 方法 | 角色 |
|---|---|
| `Linear + iTransformer` | R1/R2 强基线 |
| `Linear + PatchTST` | 当前全局平均最强两阶段之一 |
| `Linear + Mask-Aware iTransformer(add)` | 低成本 mask-aware 两阶段增强 |
| `MissTSM(含 skip connection)` | 高维高缺失候选 |
| `CoIFNet(R2独立embedding+x*mask)` | 低维/中维候选，R2/R3 中表现较稳 |
| `CoIFNet(含 TSBlock/AttentionBlock/RevON)` | 原仓库对齐版本，用于判断 R2 变体收益是否稳定 |

CRIB 暂不纳入高维条件矩阵主实验，只在低维/中维保留对照，原因是 `CRIB(原仓库对齐)` 在 Electricity 上显存溢出，且 R3 位置编码对齐后性能不稳定。

### 5.4 实验矩阵

| 维度 | 取值 |
|---|---|
| 数据集 | ETTh1, ExchangeRate, Weather, Electricity, Traffic |
| 缺失类型 | random_point, continuous_segment |
| 缺失率 | 0.1, 0.3, 0.5, 0.7 |
| 预测长度 | 96 |
| 种子 | 2024, 2025 |

**全量实验量**：  
6 方法 × 5 数据集 × 2 缺失类型 × 4 缺失率 × 1 预测长度 × 2 种子 = **480 条**。

**减负策略**：

- 已有 R1/R2/R3 结果不重复跑，只补缺失组合。
- Traffic 只跑 `Linear+iTransformer`、`Linear+Mask-Aware iTransformer(add)`、`MissTSM(含 skip connection)`、`CoIFNet(R2独立embedding+x*mask)` 四种方法。
- `pred_len=336` 只在边界反转附近补跑，例如缺失率 `0.3/0.5`。

### 5.5 输出形式

1. 方法胜出热力图：`dataset × missing_rate × missing_type`
2. 两阶段与缺失感知差值曲线：`MSE_missing_aware - MSE_two_stage`
3. 阈值估计：每个数据集上方法反转的缺失率范围
4. 结论表：

| 条件 | 推荐方法 | 证据 |
|---|---|---|
| 低维 + 低缺失 | 待实验确认 | ExchangeRate 基线补齐后判断 |
| 低维 + 高缺失 | CoIFNet 候选 | R3 ExchangeRate 初步支持，但缺两阶段基线 |
| 中维 + 高缺失 | CoIFNet / MissTSM 混合 | Weather 已有条件性反转 |
| 高维 + 高缺失 | MissTSM 候选 | Electricity 高缺失支持 |
| 超高维 + 中低缺失 | 两阶段 | Traffic R1/R2 强支持 |

## 六、P2 实验：结构消融与小规模改进

### 6.1 P2-A：CoIFNet R2 变体拆解

**背景**：`CoIFNet(R2独立embedding+x*mask)` 在 Weather 上优于 `CoIFNet(含 TSBlock/AttentionBlock/RevON)`，说明独立 embedding 和 `x*mask` 可能是有效正则化。

**实验变体**：

| 变体 | hidden | embedding | 输入形式 |
|---|---:|---|---|
| A0 | 128 | 独立 Linear | `cat([x*mask, mask])` |
| A1 | 256 | 独立 Linear | `cat([x*mask, mask])` |
| A2 | 128 | 独立 Linear | `cat([x, mask])` |
| A3 | 256 | SharedModule 首层 | `cat([x, mask])` |
| A4 | 256 | 独立 Linear | `cat([x, mask])` |

**数据集**：Weather, Electricity  
**缺失率**：0.3, 0.5  
**预测长度**：96  
**实验量**：5 变体 × 2 数据集 × 2 缺失类型 × 2 缺失率 × 2 种子 = **80 条**。

**判定标准**：

- Weather 上 A0/A1 若持续优于 A3，说明独立 embedding 是低维有效正则。
- Electricity 上 A1/A3 若优于 A0，说明 hidden=256 对高维压缩有必要。

### 6.2 P2-B：MissTSM grouped query

**背景**：R3 的 multi_q 在低维有收益，但 soft_skip 在高维恶化。高维场景需要减少单 query 面对数百变量的瓶颈，同时避免过多参数。

**设计**：

| 变体 | 说明 |
|---|---|
| `MissTSM(含 skip connection)` | 基线 |
| `MissTSM(grouped-query, G=4)` | 将变量按顺序或相关性分为 4 组，每组一个 query |
| `MissTSM(grouped-query, G=8)` | 更细粒度分组 |
| `MissTSM(grouped-query + shared output)` | 分组聚合后共享投影，控制参数量 |

**数据集**：Weather, Electricity, Traffic  
**缺失率**：0.3, 0.5, 0.7  
**预测长度**：96  
**实验量**：4 方法 × 3 数据集 × 2 缺失类型 × 3 缺失率 × 2 种子 = **144 条**。

**判定标准**：

- Electricity/Traffic 高缺失率下 MSE 改善超过 3%，说明 grouped query 有价值。
- Weather 不明显恶化，说明改动没有破坏低维表现。

### 6.3 P2-C：D2 add + PatchTST

**背景**：R3 中 `Mask-Aware iTransformer(add)` 有低成本收益，但 PatchTST 在全局平均上很强，值得验证 mask embedding 是否同样适用。

**实验**：

| 方法 | 数据集 | 缺失率 | 预测长度 |
|---|---|---|---|
| `Linear + PatchTST` | ETTh1, Weather, Electricity, ExchangeRate | 0.1, 0.3, 0.5 | 96, 336 |
| `Linear + Mask-Aware PatchTST(add)` | 同上 | 同上 | 同上 |

**实验量**：2 方法 × 4 数据集 × 2 缺失类型 × 3 缺失率 × 2 预测长度 × 2 种子 = **192 条**。

## 七、P3 实验：新论文基线引入

### 7.1 S4M：高缺失率 / block missing 基线

**适用问题**：S4M 使用 Adaptive Temporal Prototype Mapper 与 Missing-Aware Dual Stream S4，将序列和 mask 作为双流输入。它适合验证：

```text
端到端缺失感知方法的问题，是当前 Transformer 架构的问题，还是端到端范式本身的问题？
```

**优先实验**：

| 数据集 | 缺失类型 | 缺失率 | 预测长度 |
|---|---|---|---|
| Weather, Electricity | continuous_segment | 0.3, 0.5, 0.7 | 96 |
| ETTh1, ExchangeRate | continuous_segment | 0.5, 0.7 | 96 |

**实验量**：1 方法 × 4 数据集 × 1 缺失类型 × 2~3 缺失率 × 2 种子 ≈ **40 条**。

### 7.2 GinAR / IBN：variable missing 专项

**适用问题**：GinAR 和 IBN 面向变量级缺失，即整个变量历史不可见。R1/R2 已显示 variable_channel 是现有主线方法的短板，因此应单独设为专项。

**优先顺序**：

1. GinAR：先引入，验证图插值注意力 + 自适应图卷积在 variable missing 下的收益。
2. IBN：若 GinAR 可运行，再引入不确定性感知插值和 Gaussian kernel graph convolution。

**数据集**：Electricity, Traffic, ETTm1  
**缺失类型**：variable_channel, mixed  
**缺失率**：0.1, 0.3, 0.5  
**预测长度**：96  
**基线**：`Linear+iTransformer`, `Mask-Aware iTransformer(add)`, `MissTSM(含 skip connection)`, `CoIFNet(R2独立embedding+x*mask)`。

### 7.3 Merlin：表示对齐方向储备

Merlin 的核心是 teacher-student + multi-view contrastive，让不同缺失率下的表示对齐。它更像方法创新方向，不建议马上大规模跑。可以先设计一个轻量版本：

- teacher：无缺失或低缺失率训练的 iTransformer/PatchTST。
- student：高缺失率输入。
- 对齐对象：encoder hidden states 或 forecast head 前的 representation。
- 损失：forecast loss + representation distillation loss。

该方向适合在条件矩阵明确后再推进。

## 十、预期结论形式

本轮最终希望形成三类结论：

### 10.1 方法选择矩阵

| 条件 | 推荐方法 | 证据状态 |
|---|---|---|
| 低维 + 低缺失 | 待 ExchangeRate 基线补齐 | P0-A |
| 低维 + 高缺失 | CoIFNet 候选 | R3 初步支持，需两阶段补齐 |
| 中维 + 高缺失 | CoIFNet / MissTSM 混合 | R2/R3 支持 |
| 高维 + 高缺失 | MissTSM 候选 | R3 Electricity 支持 |
| 超高维 + 中低缺失 | 两阶段 iTransformer/PatchTST | R1/R2 Traffic 支持 |
| variable missing | 待 GinAR/IBN 专项 | 当前主线方法不足 |

### 10.2 低成本改进结论

重点判断：

```text
Linear + Mask-Aware iTransformer(add)
```

是否能成为默认两阶段增强。如果是，它将比大改端到端模型更适合作为工程型贡献。

## 十一、风险与注意事项

1. **不要混淆模型名与实验变体**  
   报告中必须写清 `CoIFNet(R2独立embedding+x*mask)`、`CoIFNet(含 TSBlock/AttentionBlock/RevON)` 等具体名称。

2. **优先复用已有结果，避免重复跑**  
   P1 条件矩阵应以补缺口为主，不要重跑所有 R1/R2/R3 已完成组合。

3. **异常 seed 单独标注**  
   如 R3 中 CoIFNet Weather 片段缺失 0.5 的异常种子，应在汇总表中单独标记，不直接吞进平均值解释。

4. **CRIB 不进入高维主力矩阵**  
   `CRIB(原仓库对齐)` 在 Electricity OOM，且对齐后性能不稳定，应避免在高维主线实验中消耗资源。

5. **SAITS 结果需标记稳定性**  
   SAITS 在 R1 扩展实验中多次数值溢出，若继续使用，应记录有效种子数，并避免只看均值。

6. **新增模型先小规模验证**  
   S4M/GinAR/IBN 先跑 smoke + 小矩阵，通过后再扩展。

---

## 十二、建议的最小执行清单

若只做一轮最小但高价值的实验，建议执行：

1. ExchangeRate 两阶段基线：`Linear + DLinear/PatchTST/iTransformer`，缺失率 `0.1/0.3/0.5/0.7`。
2. `Mask-Aware iTransformer(add)` 扩展到 Weather/Electricity/ExchangeRate，缺失率 `0.1/0.3/0.5/0.7`。
3. 条件矩阵补缺口：只补 `pred_len=96`，只跑已有结果缺失的组合。
4. S4M 在 Weather/Electricity 的 continuous_segment `0.5/0.7` 小规模测试。

这四项完成后，基本可以判断下一阶段是继续做 mask-aware 两阶段增强，还是转向 S4M / variable missing 专项。
