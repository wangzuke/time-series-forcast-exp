# MR-MSGF / HD-TTS 实验总结

**记录日期：** 2026-09-07  
**结果目录：** `missing_ts_exp/results/r0906_mrmsgf/`  
**状态：** 已完成；82 个正式任务和 2 个烟测任务均已结束。

## 1. 结论摘要

本轮以官方 HD-TTS 为主干，在其上实现并评估 MR-MSGF（Missing-Robust Multi-Scale Graph Fusion）。主实验使用 METR-LA 的 Block-T 缺失，目标场景是目标节点在时间轴上连续缺失、但邻近空间节点仍可提供观测的预测问题。

在三种 Block-T 缺失率和三个随机种子下，MR-MSGF 的平均 MAE 均低于官方 HD-TTS backbone：30%、50%、70% 缺失率的相对 MAE 降幅分别为 1.88%、3.07%、3.28%。完整模型在 50% 和 70% 的内部消融中也均为最优变体。这与研究假设一致：物理图提供稳定先验，观测图补充当前关系，区域粗图及可靠性门控在较高缺失时带来额外收益。

这些结果是当前工程内的可复现实验结果，不应直接表述为统计显著结论：每个主条件只有 3 个随机种子，尚未进行配对显著性检验，也尚未覆盖 HD-TTS 原论文的全部数据集与设置。

## 2. 实现与可复现性

### 2.1 主干和方法

- 对照方法：官方开源 HD-TTS 的 `HDTTSModel`，结果元数据记录的官方源码版本为 `external_repro/official/hdtts`，commit `6faea3e34412b7a080fc09f5a9b5c5da58765f58`。
- MR-MSGF：保留官方 HD-TTS 的时间编码器、DRNN、静态物理空间层级和读出模块；新增的显式分支为：观测图 `A_obs`、物理图与观测图的可靠性融合 `A_fine`、基于固定连通区域 assignment 的 `A_coarse = S^T A_fine S`、细到粗残差与可靠性门控。
- 训练入口是本地统一数据/训练循环，**不是** HD-TTS 原仓库的原始数据加载管线；因此本实验应称为“采用官方 HD-TTS 模型主干的本地复现实验”。
- 核心代码：`src/models/hdtts_official_reliable.py`、`src/training/run_official_hdtts_local.py`。

### 2.2 固定设置

| 项目 | 设置 |
|---|---|
| 历史窗口 / 预测窗口 | 24 / 12 |
| 隐层维度 | 64 |
| DRNN 层数 / pooling 层数 / dilation | 3 / 3 / 4 |
| 图消息传递 | `anisoconv,anisoconv` |
| 训练上限 / early stopping patience | 100 epochs / 20 |
| batch size / 优化器学习率 / weight decay | 64 / 0.001 / 0.01 |
| 训练损失 | 归一化空间 MAE |
| 主评估指标 | 反归一化后的 MAE、RMSE |
| 区域 assignment | 物理连通区域，最大区域大小 8 |

METR-LA 使用 207 个节点，训练/验证/测试划分样本数为 23965 / 3423 / 6849。METR-LA assignment 有 31 个连通区域；AQI36 assignment 有 5 个连通区域。主实验模型使用同一份经验证的区域 assignment，而非按 batch 或按测试样本重新聚类。

### 2.3 完整性检查

| 检查 | 结果 |
|---|---|
| GPU 烟测 | 官方 base 和 MR-MSGF 各 1 项，均完成 |
| 正式结果文件 | 82 份：阶段 1 为 4，主实验为 18，辅助实验为 30，消融为 30 |
| 数值检查 | 每份 JSON 的 `loss`、`mae`、`rmse`、`mape` 均为有限值，且 `n_values > 0` |
| 区域图检查 | `A_fine` 行和最大误差 `2.38e-7`，`A_coarse` 为 `5.96e-8` |
| batch 独立性 | 同一样本单独推理和置入 batch 的最大预测差为 `1.34e-7` |

结果中的 MAPE 在 METR-LA 上会被接近零的交通流量值明显放大，数值可达很大数量级；因此本总结不据 MAPE 作性能结论，论文主表应报告 MAE 和 RMSE。

## 4. 主实验：METR-LA Block-T

下表为 `stage2_blockt_all` 中三个种子的均值 ± 标准差。数值越低越好；相对降幅按 `(base - MR-MSGF) / base` 计算。

| 缺失率 | HD-TTS MAE | MR-MSGF MAE | MAE 降幅 | HD-TTS RMSE | MR-MSGF RMSE |
|---:|---:|---:|---:|---:|---:|
| 30% | 5.1246 ± 0.0201 | **5.0281 ± 0.0805** | 1.88% | 12.7007 ± 0.0925 | **12.5830 ± 0.1738** |
| 50% | 5.4626 ± 0.0288 | **5.2947 ± 0.0228** | 3.07% | 13.1375 ± 0.1005 | **12.8352 ± 0.0624** |
| 70% | 5.6461 ± 0.1022 | **5.4609 ± 0.0290** | 3.28% | 13.4772 ± 0.1645 | **13.1496 ± 0.0471** |

### 解读

1. 三个缺失率下 MAE 与 RMSE 的方向一致，未出现以 RMSE 恶化换取 MAE 下降的现象。
2. 提升在 50% 和 70% Block-T 下更明显，符合粗尺度区域信息用于缓解连续观测断裂的设计动机。
3. 30% 条件下 MAE 标准差较大，且绝对提升较小；该条件不宜作过强结论。
4. 这张表是当前论文最适合的主结果表。阶段 1 与该条件有重叠，只作为预验证记录，未被重复合并进这里的三种子统计。

## 5. 辅助结果

### 5.1 METR-LA 点缺失

| 缺失率 | HD-TTS MAE | MR-MSGF MAE | HD-TTS RMSE | MR-MSGF RMSE |
|---:|---:|---:|---:|---:|
| 30% | 4.7520 ± 0.0277 | **4.7320 ± 0.0411** | 12.1418 ± 0.0468 | **12.0574 ± 0.1331** |
| 50% | 4.9017 ± 0.0576 | **4.7772 ± 0.0317** | 12.4144 ± 0.0966 | **12.1167 ± 0.0712** |
| 70% | 5.1761 ± 0.0688 | **5.0244 ± 0.0124** | 12.8396 ± 0.1291 | **12.5639 ± 0.0603** |

MR-MSGF 在点缺失下也保持正向结果，但 30% 的 MAE 差距很小。它支持方法并非只对一个特定 Block-T 掩码有效，却不应取代 Block-T 作为论文的主场景。

### 5.2 AQI36 辅助验证

| 条件 | HD-TTS MAE | MR-MSGF MAE | HD-TTS RMSE | MR-MSGF RMSE |
|---|---:|---:|---:|---:|
| 原始观测（0%） | **30.6053 ± 0.6346** | 30.6552 ± 0.1783 | **49.9801 ± 1.4913** | 50.1275 ± 0.7444 |
| point 25% | 31.6025 ± 0.3276 | **30.9788 ± 0.2074** | 50.7355 ± 0.6254 | **50.4371 ± 0.6847** |

AQI36 在完整观测时没有收益，说明图融合并非无条件提升；在 point 25% 时 MAE 下降约 1.97%，与“缺失时才需要额外关系补偿”的预期一致。由于 AQI36 只覆盖一种点缺失率，本轮它是辅助证据而非主结论。

## 6. 消融：模块贡献

消融均在 METR-LA Block-T 50% 和 70%、三个种子下运行。`phy_only` 只保留物理图，`obs_only` 只保留观测图，`fine` 使用融合细图但无粗图，`coarse_no_gate` 使用粗图残差但取消可靠性门控，`full` 为完整 MR-MSGF。

| 变体 | 50% MAE | 70% MAE | 跨条件平均 MAE |
|---|---:|---:|---:|
| phy_only | 5.3521 ± 0.0524 | 5.5750 ± 0.0490 | 5.4635 |
| obs_only | 5.3778 ± 0.1543 | 5.5814 ± 0.0570 | 5.4796 |
| fine | 5.3208 ± 0.1553 | 5.5703 ± 0.0652 | 5.4455 |
| coarse_no_gate | 5.3541 ± 0.0338 | 5.5751 ± 0.0873 | 5.4646 |
| **full** | **5.3040 ± 0.0469** | **5.4847 ± 0.0443** | **5.3944** |

### 解读

1. `full` 在两个缺失率下都最低。70% 时相对 `fine` 的 MAE 降幅约 1.56%，说明粗图分支在高 Block-T 缺失下有可见贡献。
2. `coarse_no_gate` 明显差于 `full`，尤其在 70% 下，支持“粗尺度信息应按观测可靠性选择性注入”而非恒定相加。
3. 两个单图变体均弱于融合细图和完整模型，支持物理图稳定先验与观测图当前关系的互补性。
4. `fine` 在 50% 下已接近 full，说明粗图收益更应被描述为高缺失下的稳健补充，而不是每个条件都带来大幅增益。

## 7. 运行记录与异常处置

正式训练在沙箱外的 8 张 GPU 上运行。第一阶段通过后，续跑器自动启动第二阶段；第二阶段结束时，调度脚本刚被更新，触发了一次瞬时 Bash 解析失败。已先独立核验第二阶段 18 份结果完整、有限，再从第三阶段恢复，未重复覆盖主结果。恢复器随后自动完成第三阶段和消融阶段。

为避免慢任务使 GPU 空闲，`scripts/run_experiments.sh` 已改为动态 worker-pool：任一任务完成后，下一任务会分配到同一张空闲 GPU；脚本也会向上传播子任务失败状态。该调度改动经成功与失败任务的本地测试，并在第三阶段和消融阶段实际使用。

## 8. 结论边界与下一步

本轮已充分支持如下有限表述：在本地 METR-LA 的 Block-T 设置下，采用官方 HD-TTS 主干的 MR-MSGF 能稳定降低 MAE/RMSE；融合物理图、观测图、区域粗图和可靠性门控共同构成了当前最优变体。

3. 增加独立外部数据集上的 Block-T 主实验，而不只将 AQI36 作为辅助 point 缺失验证。
