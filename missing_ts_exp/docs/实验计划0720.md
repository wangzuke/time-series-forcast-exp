# 实验计划0720：BiTGraph 与 HD-TTS-AMP 的严格公平数据 / 缺失位置对照实验

## 一、实验目标

0718 实验统一了观测长度和预测长度，但没有做到两个模型使用完全相同的数据矩阵和完全相同的缺失位置。本轮 0720 实验只解决这个核心问题：

> BiTGraph 与 HD-TTS-AMP 必须读取同一份 canonical HDF5 数据，并使用同一份 `mask.npy` 缺失位置。

本轮不引入 Block-HMBGNet，不做融合模型，不做 readout 改造，只比较两个 baseline 在严格公平输入条件下的表现。

## 二、公平性定义

本轮“完全真正公平”定义为以下条件同时成立：

| 项目       | 要求                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| 数据源     | 两个模型读取同一份 HDF5：`dataset/metr_la/metr_la.h5` 或 `dataset/pems_bay/pems_bay.h5`              |
| 数据预处理 | HD-TTS-AMP 不再使用`MetrLA(impute_zeros=True)` / `PemsBay()` 作为目标数据源；直接读取 canonical HDF5 |
| 缺失位置   | 两个模型读取同一个 observed-mask`.npy` 文件，`1=observed, 0=missing`                                 |
| 缺失模式   | point 与 temporal block 均由同一个 0720 mask 脚本生成                                                    |
| 缺失率     | 30%、50%、70%                                                                                            |
| 观测长度   | 24                                                                                                       |
| 预测长度   | 24                                                                                                       |
| 样本切分   | 先按`window=24,horizon=24,stride=1` 滑窗，再按窗口样本顺序做 70%/10%/20% train/val/test 切分           |
| batch size | 512                                                                                                      |
| seed       | mask 统一使用 seed=2024；HD-TTS-AMP 训练 seed 固定为 2024                                                |

注意：HD-TTS-AMP 仍使用 TSL 的距离图作为邻接矩阵来源，但目标序列不再来自 TSL dataset 的预处理结果。也就是说，本轮强制统一的是“时序数据矩阵”和“缺失位置”；图结构保持各模型原实现所需的默认来源。

## 三、实验矩阵

| 数据集   | 缺失类型 | 缺失率        | 模型                 |
| -------- | -------- | ------------- | -------------------- |
| METR-LA  | point    | 30%, 50%, 70% | BiTGraph, HD-TTS-AMP |
| METR-LA  | block    | 30%, 50%, 70% | BiTGraph, HD-TTS-AMP |
| PEMS-BAY | point    | 30%, 50%, 70% | BiTGraph, HD-TTS-AMP |
| PEMS-BAY | block    | 30%, 50%, 70% | BiTGraph, HD-TTS-AMP |

总计：

```text
2 datasets × 2 missing types × 3 rates × 2 models = 24 runs
```

### 4.2 BiTGraph 改造

修改文件：

```text
external_repro/BiTGraph/data/GenerateDataset.py
external_repro/BiTGraph/main.py
external_repro/BiTGraph/test_forecasting.py
```

新增参数：

```text

```

当 `--mask_path` 存在时，BiTGraph 不再调用内部 `random_point` / `temporal_block` 随机生成逻辑，而是直接读取统一 mask。

### 4.3 HD-TTS-AMP 公平入口

新增文件：

```text
external_repro/hdtts/run_fair_h5_patched.py
```

该入口直接读取：

```text
--data_path <canonical h5>
--mask_path <common observed mask npy>
```

并构造 HD-TTS-AMP 所需的 `SpatioTemporalDataset`。这样 HD-TTS-AMP 的目标数据矩阵和 BiTGraph 完全一致。

另外，该入口不再使用 TSL 默认 `TemporalSplitter(val_len=0.1,test_len=0.2)`，而是使用 BiTGraph 等价的固定窗口样本索引切分：

```text
train = 前 70% window samples
val   = 中间 10% window samples
test  = 最后 20% window samples
```

每次 HD-TTS-AMP 运行会在 `fair_config.json` 中记录 `split_policy` 与 `split_lengths`，用于后续核查。

0720 的验收指标只使用第一次 masked test 输出的 `test_mae/test_mre/test_mse`。原 HD-TTS 仓库里额外的 unmasked diagnostic test 不属于本轮公平实验验收项，因此公平入口默认跳过该步骤，避免附加诊断失败影响主实验进程退出码。如需单独调试该诊断分支，可显式添加：

```bash
--run_unmasked_test
```

  --data_path /data/wangzuke/time-series-forecast-exp/dataset/metr_la/metr_la.h5 \
  --mask_path /data/wangzuke/time-series-forecast-exp/missing_ts_exp/results/0720_fair_b512/fair_data/mask_observed_Metr_point_r30_seed2024.npy \

## 七、验收标准

正式分析前必须逐条确认：

1. `fair_data/manifest.csv` 有 12 行 mask 记录。
2. 每条 BiTGraph log 中出现 `[external_mask]`，且实际缺失率与 manifest 对应。
3. 每条 HD-TTS log 中出现 `[fair_h5]`，其中 `data_path` 和 `mask_path` 与 manifest 对应。
4. 所有正式 log 文件名包含 `h24_b512`。
5. `csv/fair_metrics_summary.csv` 中应有 24 条正式结果。
6. BiTGraph 与 HD-TTS-AMP 的同一 `(dataset, missing_type, rate)` 必须具有相同的 `mask_sha256`。
7. HD-TTS-AMP 的 `fair_config.json` 中 `split_policy` 应为 `BiTGraph-equivalent sequential window split`。
8. HD-TTS-AMP 的 `fair_config.json` 中 `run_unmasked_test` 默认为 `false`；这不影响 0720 验收指标。

如果任一条件不满足，本轮结果不得写成“严格公平实验结论”。

## 八、与 0718 的区别

| 项目              | 0718                                            | 0720                               |
| ----------------- | ----------------------------------------------- | ---------------------------------- |
| 数据源            | BiTGraph 读 workspace h5；HD-TTS 读 TSL dataset | 两者都读 workspace canonical h5    |
| METR-LA zero 处理 | BiTGraph 保留 0；HD-TTS`impute_zeros=True`    | 两者都使用 canonical h5 原值       |
| PEMS-BAY 长度     | BiTGraph 52116；HD-TTS 52128                    | 两者都使用 canonical h5 的 52116   |
| 缺失位置          | 两套独立算法/seed                               | 同一份`mask.npy`                 |
| 样本切分          | 两边口径不完全一致                              | 两边均使用滑窗后 70/10/20 顺序切分 |
| 缺失率            | 30/50/60/70/80，部分未校准                      | 30/50/70，manifest 记录实际缺失率  |
| batch size        | BiTGraph 256，HD-TTS 128                        | 两者均 512                         |

## 九、预期分析方式

本轮报告只回答一个问题：

> 当数据矩阵、缺失位置、window/horizon、样本切分、batch size 都一致时，BiTGraph 与 HD-TTS-AMP 在 point/block 缺失下的相对表现是否仍与 0718 一致？

不要把本轮与 0718 的绝对 MAE 直接混合比较，因为 0720 的 HD-TTS 输入数据和 mask 协议已经发生了根本变化。
