# BiTGraph × HD-TTS 结合方案报告

本报告回应 `实验计划0715.md` §十一"预期结论形式"第 3 条（"若二者各有优势，结合"）以及 `0715复现实验报告.md` §6.5 的初步设想，目标是把那个一句话方向（"HD-TTS 主干 + BiTGraph 叠加"）落到**可实现的具体架构**上，并给出验证路径。写作前重新通读了两篇论文全文（ICLR 2024 BiTGraph、ICML 2024 HD-TTS）以及两边的核心代码（`external_repro/BiTGraph/models/BiaTCGNet/BiaTCGNet.py`、`BiaTCGNet_layer.py`；`external_repro/hdtts/lib/nn/models/hdtts_model.py`、`lib/nn/layers/{encoder,pooling,anisotropic,diff_conv}.py`），确保方案建立在实现细节上而不是论文摘要的转述。

## 1. 两篇论文的核心机制（精确到公式与代码）

### 1.1 BiTGraph：瞬时跨变量补偿

BiTGraph 的信息流是"先时间、后空间、逐层交替"（Biased TCGBlock 堆叠 L 层）：

- **Multi-Scale Instance PartialTCN**：对每个变量独立做 partial 卷积（Eq 3-4），`x' = K/sum(m) · (x⊙m)W + b`，只用观测点计算特征并按有效观测点数重新缩放；卷积核 1×3/1×5/1×7 三尺度后对 mask 做 max-pool 聚合（Eq 6）。这一步是**变量内**的，不涉及跨变量信息。
- **Biased GCN**（图 1b，Eq 7-11）：核心是 `A = ReLU(tanh(E1E2ᵀ)) + βB`，其中 `B = softmax(M_{t-H:t} M_{t-H:t}ᵀ + b1ᵀ - 1bᵀ)`——**同一时间窗口内，用两个节点 mask 向量的内积**去修正邻接强度，并用可学习标量偏置 `b_i` 制造"观测更全的节点更能输出信息"的方向性。之后用修正后的 A 做图卷积扩散（Eq 11）。
- 代码层面（`BiaTCGNet_layer.py` 的 `nconv`/`mixprop`）：`nconv.forward` 里 `mask_weight = sigmoid(mask_projection · mask_projectionᵀ / √10)`，再与静态邻接 `A` 相加，取 `top-k` 近邻做图扩散：`x = einsum('ncwl,nbvw->ncvl', x, A)`——这个 einsum 对时间维 `l`（下采样/膨胀卷积后的时间索引）**逐时刻独立**地在 N 个节点间做矩阵乘法。也就是说，**每一个时间索引上，图卷积能传播多少有效信息，完全取决于该时间索引上 mask 的观测密度**——如果该时刻全部变量都被置零（block missing 恰好制造这种情况），无论 mask-bias 怎么修正邻接权重，参与扩散的 `x` 本身就是全零，图卷积无信息可传。这与我们在 Phase 3 观察到的"块缺失下退化远大于点缺失"完全对应：机制假设（同一时刻至少部分变量可观测）被 `block_len=12` 的连续块缺失直接破坏。

**一句话概括 BiTGraph 的比较优势**：当同一时刻有部分变量观测到时，用这些变量去补偿同一时刻其他缺失变量，补偿是"瞬时的、同分辨率的"。

### 1.2 HD-TTS：跨尺度桥接

HD-TTS 走的是 **time-then-space（TTS）** 范式，核心是"先把每个节点的时间序列压缩成多个时间尺度的表征，再对每个时间尺度做空间层级传播，最后用注意力自适应组合所有（时间尺度 × 空间尺度）表征"（论文 Fig.2、Eq 11-18）：

- **输入编码**（Eq 11，对应代码 `Encoder.forward`）：`h_t^{i,(0)} = MLP(x_t^i, u_t^i, m_t^i, θ^i)`——观测值、外生变量、**mask 本身**、节点嵌入一起进 MLP。缺失值先用最近观测值填充（`whiten_missing`/last-observed-value），mask 作为一路独立通道编码进隐向量，而不是像 BiTGraph 那样在每一层显式维护并更新一个 0/1 mask 张量。
- **时间处理**（Eq 12，代码 `DRNN`）：`h_{t-W_l:t}^{(l)} = T_l(TMP^l(h_{t-W_{l-1}:t}^{(l-1)}))`，用 GRU + 逐层 1-every-d 膨胀降采样，产生 L 个不同时间分辨率的表征 `z_(l)`。**关键点**：这一步在拿到跨节点信息之前，先把每个节点自己的历史窗口压缩、扩展感受野——这意味着即使某个时间步在所有变量上都缺失（block missing），只要膨胀 RNN 的感受野跨过这段空洞，之前/之后时刻的信息仍能通过时间维的记忆传递过来，不需要依赖"当前时刻有其他变量可看"。这正是它在 block missing 下退化远小于 BiTGraph 的机制原因。
- **空间处理**（Eq 14-15，代码 `HierPoolFactory`/`HierarchicalPooling`）：对每个时间尺度 `z_(l)` 的表征，用 k-MIS 图池化 + SMP（`DiffConv`/`GraphAnisoConv`/`PropConv`）做 K 层空间层级传播，再递归 lift 回原始节点分辨率。空间消息传递操作的是**已经过时间压缩的表征**，而不是原始逐时刻观测——所以空间层的作用主要是"节点之间互相借用彼此的时间摘要"，而非"同一时刻的瞬时变量互补"。
- **解码**（Eq 16-18，代码 `AttentionReadout`）：`α_(l)^{i,(k)} = softmax(Θ_α · z_(l)^{i,(k)})`，对每个预测步 h、每个节点 i，学习一组 attention 权重去组合 `(L layers) × (K+1 spatial scales)` 个表征，`z̃_t^i = Σ α z`。论文 Fig.4/8 的可解释性分析证实：**当前观测缺失越多，注意力越倾向于更粗的时间/空间尺度**——即模型已经隐式学会"绕过局部缺失、找更远/更粗的可靠信息"，但这个决策目前只能通过 `z` 里隐式编码的 mask 信息间接驱动，没有一个显式的"当前尺度的有效观测密度"信号直接喂给 attention。

**一句话概括 HD-TTS 的比较优势**：先在时间维压缩多尺度表征、再传播空间，让"时间上离得较远但仍然可靠"的信息绕过局部（甚至整段）缺失，天然对块缺失鲁棒；但它没有 BiTGraph 那种"利用同一时刻其他变量做瞬时补偿"的显式机制。

### 1.3 两者互补的本质

两个模型解决的是**同一个问题的两个正交子问题**：

| | 同一时刻跨变量信息 | 跨时间尺度信息 |
|---|---|---|
| BiTGraph | ✅ 显式建模（Biased GCN） | ❌ 无（图卷积在每个时刻独立操作，只靠 TCN 卷积核宽度获取有限时间上下文） |
| HD-TTS | ⚠️ 隐式（mask 编码进 h，随 RNN/池化传播，但空间层作用于已压缩的时间表征，非瞬时值） | ✅ 显式建模（多尺度时间下采样 + 层级空间池化 + 注意力选择尺度） |

这与本轮实验现象完全吻合：点缺失（保留"同一时刻有其他变量可观测"这一前提）下两者退化幅度相近（3 ~ 9%）；块缺失（整段时间所有变量同时致盲）下 BiTGraph 退化远大于 HD-TTS（32 ~ 41% vs 5~ 8%）。

## 2. 本轮实验证据（复述关键数字，供设计决策参照）

- 点缺失 50→80%：BiTGraph +4 ~ 5%（仅 50/70% 两点，60/80% 未测）；HD-TTS +5.7 ~ 9.1%（4 点全覆盖）。**点缺失下没有看到 BiTGraph 明显优于 HD-TTS**——即"利用瞬时跨变量补偿"这一机制优势，在本轮实验条件下没有转化成可观测的 MAE 优势（可能被更长 horizon=24 抵消、也可能样本量太小无法下结论）。
- 块缺失 50→80%：BiTGraph +32.3%(METR-LA)/+40.8%(PEMS-BAY)；HD-TTS +4.9%/+7.7%。差距扎实、跨数据集一致。
- **NaN bug caveat**：BiTGraph 的 `get_temporal_block_mask` 会让约 5.6%（50% 缺失率时）的训练窗口 `target_mask` 全零，我们的修复是跳过这些 batch（不参与梯度）——这意味着 BiTGraph 块缺失的测试指标可能是**乐观偏置**的（最难的样本组合被系统性地少学了，而不是多学了）。换言之，**如果重新实现一个不跳过难样本的版本，BiTGraph 块缺失下的真实退化可能比表格显示的更严重**。这是本方案设计的一个重要输入：不能假设 BiTGraph 现有数字是其真实能力的下限。
- 训练效率：HD-TTS 参数量是 BiTGraph 的 2.2 ~ 3.3×，但有早停（61-158 epoch vs 固定 200 epoch），METR-LA 上单 epoch 训练时间约为 BiTGraph 的一半。
- **不能忽视的局限**：predict horizon 不同（BiTGraph 24 步、HD-TTS 12 步），MAE/RMSE 实现细节不完全一致，单种子结果，BiTGraph 点缺失只有 2 个采样点。以下方案的优先级排序和验证计划都把这些局限当作"需要先补的证据缺口"，而不是忽略它们直接开始复杂的架构改造。

## 3. 结合方案：从低侵入到深度融合，三个递进选项

设计原则：**先用最小改动验证"跨变量瞬时补偿分支是否真的在点缺失下带来增量收益"这一核心假设，验证成立后再投入更大的架构改造**——避免在证据不充分（当前点缺失样本量太小）的情况下直接做高工程量的深度融合。

### 方案 A（推荐起点）：把 BiTGraph 的 Biased-GCN 作为一个"零号尺度"挂到 HD-TTS 的注意力读出上

**做法**：HD-TTS 的 `AttentionReadout`（对应论文 Eq 16-18）本身就是"从一组候选表征里，用 softmax 注意力自适应选择相关尺度"的机制，代码里 `out_space` 的 shape 是 `[batch, (pooling_layers+1)*rnn_layers, nodes, hidden]`——是一个**可以扩展的表征列表**。方案 A 只需要：

1. 把 BiTGraph 的 Biased-GCN 单元（`nconv` + `mixprop` 的组合，不依赖 BiaTCGNet 整个 TCN 主干，可独立抽取）包装成一个独立分支，直接作用在**原始分辨率**的输入 `x_{t-W:t}` 和 mask `m_{t-W:t}` 上，产出一个与 HD-TTS 隐藏维度对齐的表征 `z_bias^{i}`（沿用 HD-TTS "取最后一个时间步的编码" 的约定，类似论文正文 "z_t^{i,(l)} = h_{t-1,(l)}^i" 的做法）。
2. 把 `z_bias^i` 作为额外的一个候选尺度，拼接进 `out_space` 的表征列表，让 attention readout 的 softmax 多一个可选项（`dim_size` 从 `(pooling_layers+1)*rnn_layers` 变成 `+1`）。
3. **不改** HD-TTS 原有的 DRNN、HierPoolFactory 内部结构，全部改动集中在模型 forward 的"拼接一个额外分支"和 `AttentionReadout` 的 `dim_size` 参数。

**为什么这是对的起点**：HD-TTS 的注意力机制已经被论文证明（Fig.4/8）能够根据缺失模式自适应地在多尺度间分配权重——把 BiTGraph 的瞬时补偿表征作为"另一个尺度"塞进这个已经验证有效的选择机制里，等价于让模型自己学习"什么时候该信瞬时跨变量补偿、什么时候该信跨时间尺度桥接"，不需要人工设计融合规则。如果点缺失场景下瞬时补偿确实有增量价值，attention 权重会自动升高；块缺失场景下这个分支产出接近零信息（同上文机制分析），attention 应自动学会压低其权重，预期不会拖累块缺失性能。

**工程量**：小。BiTGraph 的 Biased-GCN 单元参数量级在原论文里是全模型 11.82K 参数的一部分（远小于 HD-TTS 自身 378K 参数量级），新增分支对整体参数量/显存的影响可忽略。

**验证方式**：消融矩阵 `HD-TTS baseline` vs `HD-TTS + Biased-GCN分支`，在点缺失 50-80% 和块缺失 50-80% 两组协议下都跑，同时记录 attention 权重分布（HD-TTS 已有可解释性工具，直接复用 Fig.4 的分析方法）看这个新增分支的权重是否如预期地"点缺失时高、块缺失时低"。

### 方案 B：把 Biased-GCN 的 mask-bias 邻接修正机制注入 HD-TTS 每个空间池化层

**做法**：HD-TTS 的 `HierarchicalPooling`/`HierPoolFactory` 在每个空间尺度调用 SMP（`DiffConv`/`GraphAnisoConv`）时，边权重 `edge_weight` 目前是静态的（来自距离核或 DCRNN 官方图，不随缺失模式变化）。方案 B 是在每次 SMP 调用前，参照 BiTGraph Eq 8-9 的做法，用当前尺度的"有效观测密度"计算一个 mask-bias 项叠加到 `edge_weight` 上：

```
edge_weight'_{ij} = edge_weight_{ij} + β · bias(density_i, density_k^{(l,k)}, density_j^{(l,k)})
```

这需要额外维护一个"每个时间/空间尺度上的有效观测密度"张量——类似 BiTGraph Eq 5-6/10 中渐进更新的 mask `M^{(ℓ)}`，但 HD-TTS 目前没有这个显式状态（mask 信息只在输入编码阶段进入 `h`，之后隐式地随网络流动）。需要新增：(1) 时间尺度上的密度，可以复用 HD-TTS 已有的降采样矩阵 `T_l` 对原始 mask 做同样的降采样/池化得到；(2) 空间尺度上的密度，可以复用 k-MIS 池化的 `SEL` 矩阵 `S_k` 对节点密度做加权平均。

**预期收益**：比方案 A 更深——不仅是"多一个候选尺度给 attention 选"，而是让 HD-TTS 自己每一层的空间传播都知道"该往哪个方向倾斜信息流"（复刻 BiTGraph Eq 9 `b_i - b_j` 的方向性直觉：更全的节点应该更多地"输出"信息给更缺的节点）。

**风险与工程量**：中高。需要改造 `HierarchicalPooling.forward` 的内部调用链，让密度张量和 `x` 一起流过递归池化/lift 过程；需要新增可学习偏置参数 `β`、`b_i`；需要验证不会破坏 HD-TTS 现有的 `cached=True` 邻接缓存优化（当前 SMP 结果依赖静态图结构缓存计算图，一旦边权重变成逐 batch 动态量，缓存假设会被打破，可能带来显著的计算开销上升，需要重新评估方案 3.2 节提到的"regularization/scalability"设计初衷是否还成立）。

**建议**：作为方案 A 验证出"瞬时补偿确有增量价值"之后的第二阶段，不建议跳过 A 直接做 B。

### 方案 C（更激进，探索性）：显式维护跨尺度的观测密度状态，同时驱动方案 A/B 与 attention 读出

**做法**：把 BiTGraph "mask 随卷积/图卷积渐进更新"（Eq 5-6/10）这一设计思路，系统性迁移进 HD-TTS 的多尺度框架——为每个 `(l,k)` 尺度显式维护一个观测密度标量/向量（而不只是让 mask 隐式编码进 `h`），并把这个密度信号**同时**用作：(a) 方案 B 的边权重修正输入；(b) 直接拼接进 attention readout 的打分输入（Eq 16 的 `Θ_α · z` 改成 `Θ_α · [z; density]`），让"这个尺度当前有多少有效观测"成为注意力选择的显式特征而非隐式特征。

**定位**：这是一个更完整、理论上收益上限更高，但工程量和验证成本也最高的方案，需要方案 A、B 都跑出正向信号后再考虑投入。本报告不建议现在启动，仅记录设计思路供后续参考。

## 4. 推荐路径

1. **先做方案 A**，理由：工程量小（预计 1-2 天可实现+跑通 smoke test）、不破坏 HD-TTS 现有稳定性、直接检验"瞬时跨变量补偿是否有增量价值"这个本轮实验尚未验证清楚的核心问题（本轮点缺失样本太少，无法单独下结论）。
2. **在启动方案 A 之前，先补齐两个证据缺口**（`0715复现实验报告.md` §6.3 已指出）：
   - BiTGraph 点缺失 60%/80% 两个未测的采样点（当前只有 50/70%），否则无法确认点缺失下 BiTGraph 是否真的有独立于 HD-TTS 的优势可供借鉴；
   - 修复 NaN bug 后重新评估块缺失结果是否需要用不跳过难样本的方式重新验证一遍（哪怕只在一个数据集/一个缺失率上做交叉检查），确认当前块缺失数字的乐观偏置量级有多大。
3. 方案 A 验证后，若 attention 权重确实呈现"点缺失高、块缺失低"的预期模式，且点缺失下的 MAE/RMSE 相对纯 HD-TTS baseline 有稳定的正向 delta（哪怕幅度不大），再投入方案 B。
4. 全程保持消融可关闭（新增分支/机制用开关控制），确保任何时候都能退化回纯 HD-TTS baseline 做对照。

## 5. 验证实验设计（消融矩阵草案）

| 消融配置 | 目的 |
|---|---|
| HD-TTS baseline（现状） | 对照组 |
| HD-TTS + Biased-GCN 分支（方案 A），attention 可见 | 检验瞬时补偿的增量价值 |
| 同上，但强制 Biased-GCN 分支权重恒为 0（等价 baseline，验证实现无 bug） | sanity check |
| 同上，强制 Biased-GCN 分支权重恒为非零常数（去掉自适应性） | 检验"自适应选择"本身是否是收益来源，而非分支本身 |

覆盖协议：沿用 Phase 3 的统一高缺失率协议（point/block_t × 50/60/70/80%，PEMS-BAY/METR-LA），额外**必须**补上 BiTGraph 点缺失 60/80% 两点。所有新增实验建议至少 2-3 个随机种子（本轮所有已有结果均为单种子，方法改进阶段不应重复这个局限）。

**预测的结果模式（用于判断假设是否成立，而非预先认定）**：点缺失下方案 A 相对 baseline 有小幅稳定提升（因为跨变量瞬时信息本身在点缺失下没有被破坏，理论上有用）；块缺失下方案 A 应接近中性（attention 学会压低该分支权重），如果块缺失下反而变差，说明新增分支引入了无关噪声或参数量增加导致轻微过拟合，需要缩小分支容量或加正则。

## 6. 限制与风险提示

1. 本报告的"互补性"论证建立在**代码机制的静态分析**上（读源码得出的结构性推理），不是运行时的因果验证——最终是否真的互补，只有第 5 节的消融实验能确认。
2. 本轮实验的证据基础本身有限（单种子、BiTGraph 点缺失仅 2 点、horizon 不一致、NaN bug 可能使块缺失数字乐观偏置），方案设计已经尽量避免依赖这些不稳的数字做强结论，但读者仍应把第 2 节的数字当作"方向性证据"而非"精确基准"。
3. 方案 B/C 涉及修改 HD-TTS 内部的图缓存机制（`cached=True`），如果后续要做，需要重新做一次显存/训练时间基准测试，因为动态边权重可能显著抵消 HD-TTS 相对 BiTGraph 的训练效率优势（第 4 节已提及）。
