# ICASSP 审稿意见：最小且最有力的实验补充

## 结论与范围

在 ICASSP 4+1 页篇幅限制下，不建议继续扩展数据集、临时复现多套复杂基线或进行大规模超参数搜索。最值得投入的是一个**因果控制消融实验**：只在 METR-LA、Block-T 50% 下新增两种模型训练，以验证 MR-MSGF 的增益是否真正来自正确的节点对共观测证据，而非额外缺失特征、参数量或正则化数值本身。

选择 Block-T 50% 的理由：它是当前主表中 MAE 提升最大的条件（3.3546 → 3.3079），RMSE 也改善，且连续缺失最贴近“关系证据不足”的论文动机。

## 核心待证主张

论文需要建立如下证据链：

> 共观测率 `q_ij` 提供超出节点自身可观测率的信息；模型使用的是正确节点对上的该信息；性能提升并非仅来自向模型输入更多缺失统计量。

现有 `No q_ij penalty` 消融不够强：它同时删除了信息及其分布，无法区分“成对语义有效”与“任何正则化都有效”。现有 `No rel. gate` 也不能区分区域架构贡献与额外可靠性特征贡献。

## 仅新增两种训练变体

主结果中的 HD-TTS-AMP 和 Full MR-MSGF 已存在。因此只需增加以下两个变体，最终形成四行比较：

| Variant | 新增训练 | 回答的问题 |
|---|---:|---|
| HD-TTS-AMP | 否 | 主基线 |
| HD-TTS-AMP + reliability features | 是 | 是否只是多输入了缺失统计量？ |
| MR-MSGF + permuted pairwise evidence | 是 | 是否真正需要正确节点对上的 `q_ij`？ |
| Full MR-MSGF | 否 | 完整方法 |

所有变体沿用现有 Block-T 50% 的五个匹配 mask seed、相同数据划分、训练步数、优化器和模型选择规则。除被控制的因素外，保持参数量、输入窗口、目标和评估代码不变。

### 变体 A：HD-TTS-AMP + reliability features（Feature-only）

在 HD-TTS-AMP 的预测读出端输入与 MR-MSGF 相同的可靠性统计量：

`R_i = [r_i, qbar_i, rho_i, b_i]`。

建议采用与 MR-MSGF Eq. (17) 同形的轻量线性偏置，或用一个很小的 MLP 映射 `R_i` 后加入 readout score。该变体**不能**包含：

- `A_obs` 或 Eq. (4) 的新图构建；
- 物理图—观测图融合；
- 新的区域传播分支；
- 节点自适应区域门控 `alpha`。

若担心参数量质疑，可给 Feature-only 加一个参数量相近的 readout MLP；但不能引入图传播或区域表示。

该实验的判据是：Full MR-MSGF 应在 MAE、最好也在 RMSE 上优于 Feature-only，并给出配对差值的置信区间。否则论文应将贡献重新定位为“可靠性特征增强”，不能宣称区域图机制本身有效。

### 变体 B：MR-MSGF + permuted pairwise evidence（Permuted-Q）

保留 Full MR-MSGF 的全部结构和参数量，但对每个历史窗口的共观测矩阵 `Q` 施加随机节点置换：

`Q_perm = P Q P^T`，

其中 `P` 是该窗口独立采样的节点置换矩阵。用 `Q_perm` 替代模型内所有按节点对使用 `q_ij` 的位置，包括：

- Eq. (4) 的 `log(q_ij + epsilon)`；
- Eq. (5) 的边门控输入；
- 由 `q_ij` 计算的 `qbar_i`；
- 区域门控和多尺度读出中所有 `q` 相关特征。

该操作严格保留每个窗口中 `Q` 的取值分布、稀疏度、模型结构和总缺失强度，却破坏“该 `q_ij` 属于该对节点”的语义对应关系。为保证可复现，应把置换随机种子由 `(mask_seed, window_index)` 确定，且对同一窗口在每个 forward 中保持固定；不要每次 forward 重新抽样而引入额外训练噪声。

若 Full 显著优于 Permuted-Q，才能有力支持：模型利用的是正确的节点对共观测证据，而不只是把一个数值矩阵当作正则化噪声。

统计规则：

1. 对 Full vs Feature-only、Full vs Permuted-Q 分别计算五个匹配 seed 的差值 `d_s = metric_variant,s - metric_full,s`。
2. 报告 `mean(d_s)`、双侧配对 t-test 的 95% CI 与 p 值；正的 Delta MAE 表示 Full 更优。

## 成功与失败的解释

### 理想结果

- Full 显著优于 Feature-only：性能并非仅来自额外缺失统计量；
- Full 显著优于 Permuted-Q：正确的节点对共观测语义至关重要；
- 两项比较在 RMSE 上至少不出现方向相反的大幅退化。

此时可将论文核心表述改为：

> Controlled tests show that the gain cannot be recovered by supplying reliability statistics to the backbone alone, and is reduced when pairwise co-observation is detached from its true node pairs.

### 若 Feature-only 接近或优于 Full

诚实结论应是可靠性统计量有价值，但区域图分支的额外复杂度尚无充分必要性。投稿版本应弱化“regional graph”机制主张，而非掩盖结果。

### 若 Permuted-Q 与 Full 接近

说明当前实验证据不支持“节点对对应关系”是关键。可保留 `q_ij` 作为轻量缺失正则化设计，但应把表述改为 observation-aware regularization，避免宣称 relation reliability。

## 不建议在当前阶段新增的实验

- 为增加数量临时下载并重训 PEMS-BAY、PEMS04 等新数据集；
- 临时复现 GRIN、GinAR 等多套复杂官方基线；
- 继续添加 `k`、`m`、`beta` 的大规模敏感性表；
- 仅增加 alpha 与输入特征的 Pearson 相关性图或表。

这些工作耗时且占版面，但都不如上述两项控制实验直接回应“可靠性机制是否真实成立”的审稿质疑。

## 额外的实现安全检查（不计入新增实验）

若某节点在整个历史窗口都未观测到，`u_i=0` 且所有 `q_ij=0`。此时 top-k 的并列分数可能产生任意观测图边。建议在实现中显式处理：当 `r_i=0` 时令 `A_obs[i,:]=0`，并使该节点的融合退化为物理图；这应作为算法鲁棒性修复，而非占用论文版面的又一套实验。
