# 论文复现实验计划：CRIB / CoIFNet / MissTSM 及两阶段方法对比

> 目标：在本框架中复现三篇论文的核心实验结果，然后在**同等实验条件**下用两阶段方法（简单填补 + 预测器）进行对比，验证"端到端一阶段方法 vs 两阶段方法"的性能差异。

---

## 一、三篇论文实验设置总结

### 1.1 CoIFNet（arXiv:2506.13064, 2025）

| 项目 | 设置 |
|---|---|
| 数据集 | ETTh1, ETTh2, ETTm1, ETTm2, Weather, Exchange Rate（6个） |
| seq_len / pred_len | 96 / 96 |
| 缺失类型 | Point Missing（随机点）、Block Missing（块缺失，l_t=10, l_c=5） |
| 缺失率 | 0.3, 0.6 |
| 超参 | hidden=256, dropout=0.1, lr=0.001, λ=0.2, batch_size=512, epochs=100, patience=10 |
| 损失函数 | L = (1-λ)·L_I + λ·L_F，L_I 和 L_F 均为 MAE |
| 重复次数 | 3次不同随机种子，取平均 |
| 评价指标 | MAE, MSE |
| 对比方法 | STID, DLinear, AGCRN, MTGNN, iTransformer, GPT4TS, PatchTST, BRITS, SAITS, BiTGraph |

### 1.2 CRIB（arXiv:2509.23494, 2026）

| 项目 | 设置 |
|---|---|
| 数据集 | PEMS-BAY, Metr-LA, ETTh1, ETTh2, ETTm1, ETTm2, Weather, Exchange, Electricity, BeijingAir, AQI（11个） |

| 缺失类型 | point（随机点）、block（块）、column（整列变量缺失） |

| 重复次数 | 论文报告 mean±std，seed=0 从 bash 脚本看 |
| 评价指标 | MAE, MSE |
| 对比方法 | BiTGraph, BRITS, GRIN, SAITS, SPIN, SegRNN, WPMixer, iTransformer, PatchTST, DLinear, TimeXer, PAttn, ImputeFormer, TimesNet, NeuralCDE, CSDI |

## 三、复现实验设计

### 3.1 设计原则

1. **聚焦可复现的数据集**：只使用本框架已有数据集（ETTh1/h2/m1/m2, Weather, Exchange, Electricity）
2. **对齐论文超参**：seq_len、pred_len、lr、batch_size、epochs 等严格按论文设置
3. **缺失类型对齐**：实现论文所用的缺失注入方式，保证语义等价
4. **两阶段对比一致**：在完全相同的数据/缺失/评价条件下对比两阶段方法

### 3.2 实验组 R1：CoIFNet 论文复现

#### 3.2.1 实验条件

```
数据集:     ETTh1, ETTh2, ETTm1, ETTm2, Weather, ExchangeRate (6个)
seq_len:   96
pred_len:  96
缺失类型:   point_missing, block_missing (l_t=10, l_c=5)
缺失率:     0.3, 0.6
种子:       2024, 2025, 2026 (3次取平均，对标论文3次独立运行)
```

#### 3.2.2 CoIFNet 模型超参

```python
# 对齐论文 Table 3 + conf.yaml
hidden = 256
dropout = 0.1
lr = 0.001
batch_size = 512          # 论文值；若显存不足降至 256
epochs = 100
patience = 10
lambda_balance = 0.2      # 论文值，L = (1-λ)L_I + λL_F
                          # 对应框架中 impute_weight = (1-λ)/λ = 4.0
intra_type = "TSBlock"
inter_type = "TSBlock"
use_time_feat = True      # 时间戳特征（day-of-week + hour-of-day，各 embed_size=8）
```

#### 3.2.3 两阶段对比方法

在完全相同的 (数据集, seq_len, pred_len, 缺失类型, 缺失率, 种子) 条件下：

| 方法 | 描述 | 预测器超参 |
|---|---|---|
| Linear+iTransformer | 线性插值 → iTransformer | d_model=128, n_heads=8, e_layers=2 |
| Linear+DLinear | 线性插值 → DLinear | 默认 |
| Linear+PatchTST | 线性插值 → PatchTST | d_model=128, n_heads=8, e_layers=2 |
| Zero+iTransformer | 零值填充 → iTransformer | 同上 |
| SAITS+iTransformer | SAITS 补值 → iTransformer | 同上 |

> 两阶段方法的训练超参（lr, batch_size, epochs, patience）保持与 CoIFNet 一致，确保公平对比。

#### 3.2.4 实验量估算

- CoIFNet: 6 数据集 × 2 缺失类型 × 2 缺失率 × 3 种子 = **72 条**
- 两阶段对比: 6 × 2 × 2 × 3 × 5 方法 = **360 条**
- **合计: 432 条**

#### 3.2.5 预期验证目标

- 论文 Table 4 (Point Missing): CoIFNet AVG MAE 0.295±0.00 (r=0.3), 0.295±0.00 (r=0.6)
- 论文 Table 5 (Block Missing): CoIFNet AVG MAE 0.305±0.00 (r=0.3), 0.317±0.00 (r=0.6)
- 验证标准：复现结果在论文报告值的 ±5% 范围内视为成功

### 4.2 缺失类型扩展（P0）

在 `src/data/missing.py` 中新增两种缺失注入方式：

#### Block Missing（CoIFNet 论文使用）
```python
def _block_missing_mask(L, C, rate, rng, block_len=10, block_width=5):
    """块状缺失：每次随机选一个 (t0, c0)，将 [t0:t0+l_t, c0:c0+l_c] 区域置缺失。
    l_t ≤ block_len, l_c ≤ block_width。重复直到达到目标缺失率。"""
```

#### Periodic Masking（MissTSM 论文使用）
```python
def _periodic_mask(L, C, rate, rng, period=None):
    """周期性缺失：在每个周期内，随机选择固定比例的变量为缺失。
    模拟传感器按固定周期故障的场景。"""
```

### 4.3 损失权重修正（P1）

CoIFNet 论文的损失公式为 L = (1-λ)·L_I + λ·L_F，λ=0.2，即 imputation loss 权重 80%，forecasting loss 权重 20%。

当前框架中 `CoifnetPipeline` 的实现为 `total_loss = fc_loss + impute_weight * rec_loss`。

映射关系：`impute_weight = (1-λ)/λ = 0.8/0.2 = 4.0`

需在复现实验中将 `aware_impute_weight` 设为 **4.0**（当前默认 0.5）。

### 4.4 PatchTST+MissTSM 骨干组合（P1）

MissTSM 论文核心结果使用 PatchTST 作为骨干。需确认 `MissTSMModel` 支持 `backbone="PatchTST"` 且参数传递正确（特别是 patch_len, stride, n_heads 等）。

### 4.5 Spline 插值（P2）

MissTSM 论文用 2nd-order spline 插值作为两阶段基线之一。如时间不足，可用 linear 插值替代并在报告中说明。

## 六、两阶段方法设计要点

### 6.1 对比公平性保障

两阶段方法在每个实验组中必须遵循的原则：

1. **同数据同缺失**：使用完全相同的训练/验证/测试集和缺失mask
2. **同训练预算**：相同的 lr, batch_size, epochs, patience
3. **同模型规模**：预测器的参数量（d_model, e_layers）与一阶段方法可比
4. **同评价方式**：对相同的测试集 ground truth 计算 MAE/MSE

### 6.2 填补策略

| 填补方式 | 适用场景 |
|---|---|
| zero（零填充） | 最简单基线 |
| linear（线性插值） | 标准两阶段基线，通常最有效的简单方法 |
| SAITS | 学习型填补，代表强填补方法 |
| mean（均值填充） | 简单基线 |

### 6.3 预测器选择

- **iTransformer**：我们此前实验中两阶段最优预测器
- **PatchTST**：MissTSM 论文主要骨干
- **DLinear**：轻量级基线

## 七、成功标准与预期产出

### 7.1 复现成功标准

- CoIFNet 复现 MAE/MSE 在论文报告值 ±5% 内
- CRIB 复现 MAE/MSE 在论文报告值 ±10% 内（d_model=32 较小，方差可能较大）
- MissTSM 复现 MSE 在论文报告值 ±5% 内

### 7.2 两阶段对比预期

基于已有实验经验和论文结果分析：

- **CoIFNet 条件下**（seq=96, pred=96）：CoIFNet 论文报告其在所有设置下优于 iTransformer，两阶段方法可能接近但不超过 CoIFNet
- **CRIB 条件下**（seq=24, pred=24）：CRIB 论文报告其大幅优于 iTransformer/PatchTST 等，但 d_model=32 极小，两阶段方法在此设置下可能也受限
- **MissTSM 条件下**（seq=336, pred=96~720）：MissTSM 论文已与两阶段(Spline/SAITS + backbone)直接对比，复现可验证其结论

### 7.3 预期产出物

1. **复现结果表**：每篇论文的核心表格的复现版本
2. **两阶段对比表**：在同等条件下的两阶段方法结果
3. **交叉分析**：
   - 不同 seq_len 下两类方法的相对优势
   - 不同缺失率下的性能交叉点
   - 不同数据集维度下的方法选择建议
4. **结论**：回答"一阶段方法在哪些条件下确实优于两阶段方法"
